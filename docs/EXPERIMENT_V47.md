# 실험 v47 사전 계획: 청산 문턱의 가산 제거 진단

2026-10-04. v46은 활동 관문 변경 뒤 개발·확인·최근 구간의 순손익이 양수였지만 표본 수가 부족했고, 장기 합산과 독립 연도의 결과도 달랐다. 청산은 상반기 F2 기준으로 선택한 문턱에 실행 단계에서 다시 1.5배가 적용된다. 첫 관리 주문과 구별해 청산 가산의 효과만 원본 상태에서 진단한다. v46의 남은 연도·원장 검증은 그대로 완료한다.

## 단일 변경과 고정 조건

- v46의 고정된 v35 관리 모델·절편·특징·상반기 청산 문턱을 사용한다. 청산 실행 배율만 1.5에서 1.0으로 바꾼 요청 마스크를 비교한다. 다른 배율이나 문턱을 검색하지 않는다.
- v35의 2021년 상반기 보정 행과 하반기 진단 행·정답·포지션 분리를 그대로 사용한다. 상반기의 F2 문턱과 선택 기록을 재계산해 저장값의 일치를 요구한다. 최소 예측 양성은 20개다.
- 첫 추가·축소는 v38의 문턱을 그대로, 반복 추가·축소는 원래 문턱의 1.5배를 사용한다. 해당 요청 마스크는 변경 전후 정확히 같아야 한다. 정답 누락·손실 제외·새 모형 학습·수량·진입·위험 변경은 없다.

## 고정 판정

하반기 청산 재현율과 F2가 모두 기존 배율보다 엄격히 높아야 한다(수치 허용 오차 1e-12). 추가·축소 요청 마스크의 정확한 보존, 두 구간의 청산 양성·음성 각각 20개 이상, 원래 시간·포지션 배제와 모델·문턱 파일 지문 일치도 요구한다. 미달하면 매매 적용을 금지하고 실패를 보존한다.

통과는 원본 상태에서의 요청 개선을 뜻한다. 봇의 자체 상태·우선순위·지연·비용·청산 후 재진입을 반영한 순수익 증거가 아니므로 별도 사전 계획 없이 매매 후보에 적용하지 않는다. 이미 관찰한 하반기 자료를 사용한다는 한계를 유지한다. 모든 원본·파생 자료와 개별 결과는 로컬에만 보존하며 실거래 연결은 없다.
