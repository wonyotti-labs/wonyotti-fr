# 실험 v70 사전 계획: 다일 시장 상태를 반영한 청산 비용 학습

2026-10-04. v69는 비용 가중 분류 지표를 개선했으나 실제 선택 효과와 최초 효과가 악화됐다. 비용으로 가중한 양수 효과 비중은 앞 반년과 다음 분기에 약 44.7%·44.4%였지만 마지막 10월·11월에는 약 31.4%·26.3%였다. 마지막 평균 예측 점수는 이에 맞춰 낮아지지 않았다. 현재 56개 입력의 가격 수익률은 최대 하루다. 더 긴 시장 상태가 빠진 영향을 단일 입력 확장으로 검증한다. 관찰한 차이가 새 입력의 유효성을 보장하지는 않는다.

## 기존 자료와 새 여덟 입력

v69와 이전 전체 모델·행·가중치·정답·원장·점수·판정을 재현한다. 원래 v59 정답 생성에 사용한 5분 특징 시세의 경로·지문을 확인하고 같은 BTCUSDT 자료만 사용한다. 새로운 시세 구간이나 종목을 선택하지 않는다.

v45에서 구현한 고정 다일 계산법의 다음 여덟 입력을 원래 56개 뒤에 추가한다.

- 확정 종가의 4일·16일·64일 수익률.
- 1일/4일·4일/16일·16일/64일 지수이동평균 비율에서 1을 뺀 추세.
- 16일 5분 로그 수익률의 표본 표준편차에 관측 수 제곱근을 곱한 변동성.
- 현재 확정 5분 거래량을 최근 16일 거래량 평균으로 나눈 비율.

기존 `context_features`의 기간·지수평균 초기화·연속 구간·64일 준비 조건을 바꾸지 않는다. 시세가 끊기면 연속 구간을 다시 시작하며 준비가 부족하거나 새 값이 비유한 원래 행이 하나라도 있으면 실패한다. 원래 행을 삭제하거나 미래 값으로 채우지 않는다. 방향별 변형·기울기·펀딩·추가 창 탐색은 더하지 않는다.

각 판단 시각에 정확히 종료된 5분 봉의 값만 연결한다. 현재보다 늦게 종료된 봉을 쓰지 않는다. 같은 시세로 기존 시장 입력 14개를 다시 계산해 원래 저장 값과 일치하는지 확인한다. 방향·포지션·현재 관리 의도를 비롯한 원래 56개 값과 순서를 보존한다. v45의 보유 방향 모형 실패를 취소하는 실험이 아니라 자체 봇 경로의 청산 효과를 다루는 별도 진단이다.

## 학습과 비교

v69와 같은 2021-01-01 이상 진입·판단부터 정답 종료가 2021-09-30 미만인 앞 학습, 2021-10-02 이상 진입·판단부터 정답 종료가 2021-12-31 미만인 마지막 진단을 사용한다. 모든 기간은 이미 관찰한 자료다. 포지션 교차·미확정 정답·뒤 구간에 따른 설정 변경을 금지한다.

후보는 64개 입력의 비용 가중 분류기 하나다. v69의 깊이 2·64회·학습률 0.05·말단·규제·구간·seed·조기 종료 미사용 설정과 `w × |y|` 비용 정의를 그대로 둔다. 정확한 0 효과의 학습 기여만 0이며 원장·평가는 보존한다. 비용 정규화·학습 상수·원래 평가 가중치는 v69와 정확히 같아야 한다. 숫자 모델 형식만 새 입력 차원을 구분한다.

점수는 비용 가중 선택 점수이며 일반 수익 확률이나 bp 단위 예상 손익이 아니다. 같은 고정 `q > 0.5`에서 추가 청산을 선택하고 원래 청산 요청은 제외한다. 앞 구간에서 모델·문턱을 더 고르지 않는다. 기존 v69와 그 모든 대조의 예측·행 지표·최초 효과를 함께 남긴다.

## 열아홉 가지 조건과 검증

v69의 열네 조건을 새 후보에도 그대로 요구한다. 여기에 다음 다섯 조건을 추가한다.

1. 비용 가중 로그 손실이 v69보다 1% 이상 개선.
2. 비용 가중 Brier가 v69보다 악화되지 않음.
3. 원래 가중 평균 기회손실이 v69보다 작음.
4. 전체 최초 평균 효과가 v69보다 큼.
5. 후보와 v69의 최초 효과 차이의 짝지은 주간 95% 구간 하한 양수.

Brier 허용치는 1e-12이며 나머지 부등식은 엄격하게 적용한다. 기존 v64 대비 주간 비교도 유지한다. 두 비교 모두 같은 13개 달력 블록·1,000회·seed 63·2.5 및 97.5 백분위와 동일 추출을 사용한다. 선택 없음·음수 최초 효과·전체 포지션을 보존하고 전체·방향·월별 행 지표와 최초 선택·진입 월별 결과를 기록한다.

미래 시세 변경이 과거 여덟 입력을 바꾸지 않는지, 끊김·준비 부족·미확정 봉·시세 변조를 거부하는지 검사한다. 원래 56개 입력·행·비용 원장·학습 상수와 기존 모델·점수 보존을 확인한다. 다일 입력을 다른 계산 방식으로 검산하고 독립 분류기 재학습의 모든 트리·초기 값·점수, 모든 최초 선택·주간 비교·열아홉 판정 및 원본 지문을 대조한다.

통과해도 별도 계획에 따라 자체 상태에서의 연속 실행·재진입·비용·다년 다시장 검증이 필요하다. 최종 v10 수익성·표본·비용·낙폭 기준은 그대로다. 실제 거래 연결과 원본·파생 자료의 Git 공개는 없다.
