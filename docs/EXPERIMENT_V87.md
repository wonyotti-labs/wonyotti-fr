# 실험 v87 사전 계획: 고정 관리 확률의 첫 판단 입력

2026-10-10. 같은 확장 자료에서 선형·깊이 2 트리의 최초 현금 효과가 모두 음수였다. 원래 정책은 현재 50개 관리 특징을 이미 학습된 행동 모델과 빈도 보정에 통과시켜 판단하지만, 추가 청산 모델은 그 행동 확률을 직접 입력받지 않았다. 원래 관리 모델의 비선형 표현을 전달하는 가설을 한 후보로 검증한다. 그 확률이 수익을 예측한다고 미리 단정하지 않는다.

## 고정 자료와 원래 관리 모델

v86의 검산 지문과 전체 입력·통합 첫 원장·보정·코드 봉인을 먼저 확인한다. 기존 v85 및 v84 생성 계획의 봉인된 메타데이터 연결에서 자료를 생성한 v54 부모와 지문을 식별한다. 다른 부모를 선택하거나 새 관리 모델을 학습하지 않는다. 실제 부모는 이전과 같은 v54이며 방향·관리·수량·문턱·위험·비용은 변경하지 않는다.

학습은 같은 첫 기회 1,277개, 보정은 같은 첫 기회 93개와 전체 96포지션을 사용한다. 기존 74개 특징·현금 정답·첫 순자산·동일 포지션 비중·비용·0 효과·손실·기회 없음·미확정·후속 원장을 정확히 보존한다. 추가 기간·거래·월·방향·특징 선택은 없다. 기존 정답과 후속 입력으로 새 특징을 만들지 않는다.

각 첫 기회의 저장된 현재 50개 관리 특징에 고정 부모의 관리 모델을 적용한다. 기존 빈도 보정까지 포함한 `exit`, `reduce`, `increase` 확률 세 개를 이 순서로 붙여 77개 입력을 만든다. 세 확률은 독립 행동의 점수이며 합이 1이어야 한다고 가정하지 않는다. 원래 사용하던 모델·보정 값은 숫자 JSON으로 보존하고 현재 입력에서의 출력과 별도 트리 순회·로짓 보정 계산을 대조한다. 이 과정에서 관리 모델·보정·문턱은 재적합하지 않는다.

앞 학습과 보정의 첫 입력에만 세 확률을 추가한다. 마지막 진단에 새 입력이나 후보 예측을 생성하지 않는다. 새 특징은 원래 정책이 현재 입력으로 계산할 수 있는 값이며 미래 체결·현금·원본 실제 잔량을 포함하지 않는다. 부모 자체가 2021년까지 학습했다는 기존 제한은 그대로다.

## 같은 선형 학습과 단일 판단

새 후보는 v85와 같은 표준화·L2 로지스틱 설정을 쓴다. 모든 첫 포지션을 표준화에 포함하고, 비영 비용 포지션만 절대 bp의 양의 평균으로 정규화해 적합한다. C=0.1, l1_ratio=0, lbfgs, fit_intercept=True, class_weight=None, seed 0, warm_start=False, max_iter=2000, tol=1e-9이다. 확률 입력 추가에 따라 표준화·계수가 바뀌지만 모델·비용·문턱 탐색은 없다. 수렴 실패는 보존한다.

적격 500포지션·각 방향 20·각 비용 부호 64·180일 지원을 유지한다. 한 번 적합하며 첫 적격 기회에서 점수가 엄격히 0.5보다 클 때만 추가 청산한다. 첫 거절 뒤에는 예측·선택을 반복하지 않는다. 학습 비용 상수와 원장은 v85·v86과 정확히 같아야 하며 새 상수 후보를 만들지 않는다.

## 열다섯 정책·열두 조건

v86의 기존 열네 정책·점수·선택·그룹·현금·실패를 보존하고 새 관리 확률 선형 정책 하나를 추가한다. 기존 저장된 점수에서 정책 산식을 다시 대조하며 기존 모델을 재적합하지 않는다.

새 후보는 선택 30포지션 이상, 전체 최초 평균 양수, 그리고 확장 트리·확장 선형·원래 고정 선형·주간 선형·원래 첫 트리·직접 회귀·이후 정책 분류·자연 종료 분류·항상 첫 청산·확장 상수 각각보다 엄격한 개선, 총 열두 조건을 모두 충족해야 한다. 동점은 실패다. 실패 시 마지막 평가를 차단하며, 성공 시 별도 고정 계획의 마지막 진단과 연속 계좌 검증으로 이어간다.

## 검증과 제한

부모·중간 생성 메타데이터·검산·전체 소비 파일·코드 사본의 지문과 실제 모델 연결을 확인한다. 세 추가 확률의 범위·행 대응·현재 50개 입력 동일성, 별도 관리 트리와 빈도 보정 산식, 77개 표준화·계수·절편·모든 점수를 검산한다. 미래 보정·후속 행·현금 변경이 과거 관리 확률과 앞 모델을 바꾸지 않아야 한다. 원래 모든 행·0·손실·미확정을 보존하고 열다섯 정책·열두 조건·후속 점수 부재·변조 차단을 확인한다. 실제 적합 전에 독립 검산 도구·검사·계획을 고정한다.

고정 부모의 과거 경로와 이미 관찰한 내부 보정을 이용한 반복 연구다. 이를 당시 가용한 전체 봇의 성과·원래 트레이더의 실제 전략·계좌 수익으로 해석하지 않는다. 최종 v10의 다년·다시장·비용·펀딩·지연·낙폭·표본·집중 기준을 유지한다. 원본·가공·시장·모델·개별 결과는 로컬에 유지하고 실제 거래 연결은 없다. 수익성 문제는 계속 미해결이다.
