# 실험 v24 사전 계획: 전량 청산 실행과 실제 보유 종료 정답의 일치

2026-10-04. v23은 확인 조건을 통과했지만 후속 장기 기본 조건에서 손실을 보였다. 이미 시작한 전체 대조와 실패는 끝까지 보존한다. 별도 원본 감사에서 기존 청산 정답의 의미와 시장가 전량 청산의 차이를 확인했다. 기존 정답은 독립 주문의 첫 체결 당시 요청 총수량으로 청산·반전을 분류한다. 일부만 체결된 주문도 전량 종료로 표시하거나 나중의 실제 종료 시각을 놓칠 수 있다. 요청 의도와 실제 보유 종료는 같은 사건이 아니다.

이번 후보는 v21 기준으로 청산 정답만 실제 포지션 종료 사건에 맞춘다. 원본에 없는 주문 제출·취소·판단 시각을 복원했다고 주장하지 않는다. 마지막 부분 체결은 관측된 실행 결과이며 새로 관측한 트레이더 결정이 아니다. 이 의미 차이가 전체 손실의 유일한 원인이라고 단정하지 않는다.

## 고정 정답 변경

- 감사된 실제 수량 원장의 `close`와 `reverse` 행을 사용한다. 해당 행 직전 보유가 0이 아니며 방향이 사라지거나 뒤집혔는지 수량으로 대조한다.
- 각 실제 종료 시각을 다음 1분 정답 창 `[경계, 경계+1분)`에 연결한다. 원래 분 경계 직전의 보유 에피소드와 종료 대상 에피소드가 같고 원래 입력이 지원되는 경우만 연결한다.
- 새 진입 이후 같은 분 안에서 끝난 다른 포지션, 범위 밖·미지원 상태는 원장에 사유와 함께 보존한다. 같은 경계에서 지원하는 종료 사건 유무를 새 `y_exit`로 정한다.
- 기존의 요청 수량 기반 정답과 실제 종료 정답을 모두 남기고 연도별 일치·과잉 표시·누락을 비교한다. 원본 행과 손실·부분 체결은 삭제하지 않는다.
- `reduce`·`increase` 정답, 44개 확정 특징, 지원 행·에피소드·학습 경계는 변경하지 않는다. 원래 축소 크기 모델도 유지한다. 부분 매매의 모든 의도를 새로 복원한 것으로 표현하지 않는다.

## 고정 학습·실행

원래 v21의 2020년~2021년 상반기 관리 학습, 2021년 하반기 빈도 보정, 표준화 로지스틱 C=0.1을 그대로 사용한다. 새 청산 정답으로 관리 모델을 재구성하고 청산 문턱·누적 빈도 배율을 같은 방식으로 계산한다. 동일 입력의 축소·추가 모델 숫자와 문턱·빈도 배율은 기존 v21과 정확히 같아야 한다. 차이가 나면 원인을 해결하기 전 성과 비교를 진행하지 않는다.

기존 진입 모델·16bp 대기·5분 만료, 예측 축소 크기, 수량·위험·비용·펀딩·지연과 평탄 청산 실행을 유지한다. v22 추가 필터나 v23 신규 진입 갱신을 함께 적용하지 않는다. 후보는 하나이며 수익으로 모델·학습 기간·문턱을 재선택하지 않는다.

2021년 새 정책과 원래 v21은 적합 대조다. 모델을 고정하고 2022년 양수·30거래·영구 중지 없음 조건을 확인한다. 실패하면 BTC 후속 두 기간·세 독립 연도만 진단한다. 통과하면 세 시장·두 기간·열한 조건·아홉 독립 연도를 평가한다. 조건은 새 정책, 원래 v7, 현금, 추가 제거, 30분 제한, 비용 2배·3배, 추가 1분 지연, 원래 v14, 원래 v20, 원래 v21이다. 전체 수익성 기준은 v10과 같고 모든 기간이 이미 관찰되었다는 한계를 유지한다.

## 검증

부분 체결의 첫 감소와 나중 전량 종료, 처음부터 반전한 체결, 같은 분 재진입·종료, 분 경계와 불완전한 마지막 구간을 합성 사례로 검사한다. 독립 원본 수량 대조·연결 합계와 전후 정답 차이를 보존한다. 미래 종료 정보는 목표에만 들어가고 당시 특징·상태에는 들어가지 않아야 한다. 지원 행·시간순 학습·보정·비청산 모델·원래 기준 정책의 전체 출력 일치, 회계·실제 종료 복원과 월간 재개를 검사한다.

원본·파생 자료·모델·개별 결과는 로컬에 보존하고 실제 거래를 연결하지 않는다. 청산 목표의 정정이 수익성을 보장하거나 원전략 전체를 복제한다는 뜻은 아니다.
