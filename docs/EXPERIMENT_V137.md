# 실험 v137 사전 계획: 추가 한도 전후의 조건부 관리 학습

2026-10-12. v136은 28/40개 조건을 충족했지만 한도 전 재시작 추가의 하반기 양성 35분을 모두 놓쳤고 오신호는 1분에서 2분으로 늘었다. 가격 기준·횟수 상한 제거·상대 가격 추가의 실패를 유지한다. 이번에는 새 입력을 추가하지 않고 원본의 추가 한도 전후 상태를 함께 학습하는 문제를 비교한다. 이전 턴은 v136의 실제 학습·독립 검산·결과 공개·푸시를 완료한 진행이다.

원본 상태의 혼합이 미검출 또는 계좌 손실의 원인이라고 확정하지 않는다. 기존 v128의 최초/재시작별 256회 학습도 실패했다. 이번 분리는 최초/재시작이 아니라 현재 알려진 누적 추가 횟수이며, 트리 총량도 늘리지 않는다. 이미 관찰한 기간의 후속 가설이다.

## 출처·지원·분리

v136 완료 증거에서 v127·v134·원본 교사의 출처를 확인한다. 기존 50개 입력과 원본 1,018,460행·정답·24시간 경계·포지션 분리를 유지한다. v133·v135·v136의 미채택 입력을 승격하지 않는다. 원본 사건에서 누적 추가 횟수를 독립 복원하고 v134 연결 원장과 일치하는지 확인한다.

각 행동의 quiet 안에서 판단 이전 누적 추가 횟수 `adds < 5`는 below, `adds >= 5`는 capped로 고정한다. 두 집단이 quiet를 누락·중복 없이 분할해야 한다. `adds_capped == min(adds, 5)`를 확인하며 선택은 기존 입력 `adds_capped < 5`와 정확히 같아야 한다. 미래 정답·손익·후속 주문은 분리에 쓰지 않는다. capped 행도 별도로 전부 학습·평가하며 삭제하지 않는다. 봇의 최대 추가 5회 제한은 유지한다.

## 고정 모델·보정·대조

- 축소/추가 × below/capped의 부스팅 네 개를 2020년 해당 quiet 행에서 학습한다. 기존 50개 입력, 깊이 2·말단 4·학습률 0.05·최소 말단 64·L2 1·255구간·seed 0·무가중·조기 종료 없음을 유지한다. 각 128회로 총 512개 트리를 고정한다. 기존은 행동별 256회 두 개이므로 총량은 같지만, 한 행에 적용되는 트리 수와 함수 구조는 다르다. 동일한 표현력이라고 주장하지 않는다.
- 각 집단에서 표준화한 선형 네 개(C=0.1·최대 2,000회·seed 0)를 함께 학습한다. 선형은 기존 두 개보다 많으므로 동일 파라미터 수 대조라고 주장하지 않는다. 기존 v127 두 선형 대조도 보존한다. 정답 또는 성적에 따른 집단·모형 크기·가중치 검색은 없다.
- 먼저 각 quiet 행의 현재 횟수에 맞는 모델의 원시 점수를 연결한다. 그 뒤 기존 v127처럼 상반기 전체 quiet에서 행동별 절편·문턱·빈도 상수를 정하고, 최초/재시작별 절편·문턱을 적용한다. 횟수 집단별 추가 보정이나 문턱은 만들지 않는다. 이렇게 학습 분리와 새로운 문턱 선택 규칙을 동시에 바꾸지 않는다.
- 청산 전체·recent 축소/추가·native/capacity의 점수와 요청은 기존과 정확히 같다. v127 원래 모델과 모든 예측·지표도 복원한다. 성적이 좋은 집단이나 행동만 골라 후보를 조합하지 않는다.

## 직접 지표·판정·검산

기존 전체/quiet/recent/first/restart, 모든 월, 0/1/2/3/4/5/>5 구간 및 한도 전 재시작 추가의 직접 지표를 유지한다. 두 횟수 집단의 지원·양성·양성 포지션 수·원시/보정/선형/빈도 대조 지표도 기간과 월별로 직접 계산한다. 빈 집단·양성 0개·손실 기록을 제외하지 않는다. 집단 간 포지션이 중복될 수 있으므로 포지션 수를 더하지 않는다.

후속 자체 계좌 연구 조건은 v135·v136과 같은 40개다. 기존 인과 관리 35개 조건, 두 행동의 v127 대비 quiet 로그 손실 1% 초과 개선 두 개, 한도 전 재시작 추가의 재현율·F 엄격 개선과 정밀도 보존 세 개다. 허용 오차 1e-12를 유지한다. 한 조건이라도 미달하면 이 후보를 자체 계좌 연구로 승격하지 않는다.

별도 사건 순회와 기존 연결 원장으로 횟수·분할을 검산한다. 기존 모형·예측 및 새 512개 트리·선형 네 개를 독립 재적합하며 모든 노드·계수·학습 전용 척도를 대조한다. 별도 행 선택·트리 분할 순회·선형 합으로 전체 연결 점수와 요청을 검산하고, 기존 절편·문턱·동일 요청 대조와 모든 상태·월·횟수·40개 조건을 독립 계산한다.

4→5 경계, 5와 그 초과, 방향·횟수·상한 손상, 모델과 분기 교환, 빈 집단·지원 부족, 미래 정답 변경 시 학습 불변, 청산/recent 보존을 검사한다. 실행 전후 입력·코드·계획 지문과 저장 후 재읽기를 확인한다. 원본·시세·모형·개별 출력은 로컬 전용이며 코드·방법·공개 집계만 작업별 커밋 직후 푸시한다.

원본 횟수 분리는 봇 자체 포지션의 상태나 모든 실행 조건 통과를 의미하지 않는다. 조건 통과 후 별도 계획에서 자체 체결로 누적한 횟수를 사용해 다년·다시장·비용·펀딩·지연·낙폭·표본·집중 기준을 검증한다. v10 최종 수익성 요구와 실패 이력을 유지하며 실제 거래 연결은 없다.
