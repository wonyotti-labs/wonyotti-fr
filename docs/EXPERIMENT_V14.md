# 실험 v14 사전 계획: 사건 점수의 누적 관리 빈도

2026-10-03. v13의 반전 해석만으로 손실이 해결되지 않았다. v12의 별도 문턱 조정 구간에서 세 행동의 점수 합은 실제 사건 분 수와 비슷하지만, 청산 문턱 초과 분 수는 사건 수보다 훨씬 많고 추가 문턱 초과는 적었다. 봇의 보유 시간 중앙값도 2분이다. 드문 다음 1분 사건의 점수를 즉시 명령 문턱으로 해석한 결정 규칙을 검증한다. 원본 상태의 점수 합이 실제 봇 상태에서도 맞는다고 가정하지 않는다.

## 고정 후보

- 이미 선택한 v12 모델·가격 경로 특징·신규 진입·위험·수량을 그대로 사용한다. v13의 반전 해석은 적용하지 않는다. 단일 후보이며 모델·후보·손절·보유 기간을 다시 선택하지 않는다.
- v12의 2020년 하반기 문턱 조정 자료만 사용해 행동별 실제 사건 분 수 / 점수 합을 고정 배율로 구한다. 점수 합·실제 양성·예측 유한성·시간 격리를 검사한다. 2021년 이후 빈도로 배율을 조정하지 않는다.
- 매 분 확정 상태에서 행동별 점수 × 배율을 [0, 1]로 제한해 세 누적량에 각각 더한다. 각 누적량의 상한은 1이다. 하나가 1에 도달하면 기존 청산·축소·추가 우선순위로 명령하고 해당 누적량을 0으로 초기화한다. 다른 행동 누적량은 유지한다. 무작위 추첨이나 성과에 따른 대기 시간 조정은 없다.
- 실제 최초 진입·반전·평탄 전환 시 누적량을 초기화한다. 보유 중 관리 대기·미체결 의도 동안에도 알려진 매 분 점수를 누적하되 기존 3분 관리 대기와 미체결 중복 차단을 지킨다. 명령이 위험 한도에 거절돼도 해당 명령의 누적량 초기화를 되돌리지 않는다. 시도와 체결·거절 수를 분리한다.
- 누적량·포지션 식별 시각은 영속 정책 상태에 저장한다. 오래된 시각·부분 필드·범위 밖 숫자를 거부한다. 가격 경로·포지션별 추가 횟수·회계·위험 청산은 기존과 같다.

## 검증과 판단

상수 점수의 수작업 누적·행동 충돌 우선순위·부분 매매·대기 중 누적·새 포지션 초기화·누락 상태·과거 불변·실제 중단 복원을 먼저 검사한다. 2021년 개발·2022년 확인을 기록하고 이미 고정한 v12와 대조한다. 양수 한 구간이나 거래 수 감소만으로 채택하지 않는다.

2022년 양수·30거래·중지 없음의 선행 조건을 실패하면 v12와 동일하게 BTC의 두 후속 기간·세 독립 연도 진단을 수행한다. 통과하면 전체 세 시장·여덟 조건·아홉 연도를 검증한다. 최종 수익성 기준은 v10을 유지하며 관찰 기간 재사용과 선택 편향을 명시한다. 실패·파생 자료는 로컬에 보존하고 전체 goal을 미해결 상태로 유지한다.
