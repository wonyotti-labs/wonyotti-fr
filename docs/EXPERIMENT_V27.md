# 실험 v27 사전 계획: 실제 신규 포지션 방향의 직접 학습

2026-10-04. v25는 활동 정답을 신규 포지션 시작으로 분리했지만 기존 확대 방향 모형을 유지했다. v26은 방향 빈도 차이만 보정했고 학습 구간 개선과 달리 2022년 확인에서 손실·위험 중지를 보였다. 빈도 보정으로 조건부 방향 모형을 대체할 수 있다고 결론내리지 않는다. 이전 후보의 전체 대조·실패·복원은 완료·보존한다.

새 모델·성과 계산 전 지원 표본을 진단했다. 최근 두 해의 실제 신규 방향 사건만으로 기존 분류기의 1,000행 기준을 충족하지 못하지만, 원본 전체 기간의 같은 사건은 그 기준을 충족한다. 이번 후보는 기준을 낮추지 않고 실제 신규 방향에 맞춘 계수를 직접 학습한다. 목표 의미와 학습 기간을 함께 바꾸므로 정답 변경 하나만의 인과 효과로 해석하지 않는다.

## 고정 학습·실행

기준은 v26이며 활동 모델·관리·축소·진입 대기·위험·비용·펀딩·지연은 그대로다. 방향 모형만 교체하고 v26의 절편 이동은 새 모형에 추가하지 않는다.

- 학습 범위는 2018-01-01~2022-01-01 미만이다. 실제 자료가 존재하는 시간만 사용한다. 양쪽 24시간과 현재·목표 에피소드의 경계 제거를 기존 방식대로 적용한다.
- v25와 같은 실제 수량 전이 `open`·`reverse`와 다음 5분 첫 사건 정답을 사용한다. 활동 1인 지원 행에서 신규 보유의 부호를 방향 정답으로 삼는다. 같은 시각의 안정된 순서·복수 사건·미지원·불완전 구간을 보존한다.
- 입력은 당시 확정된 원래 시장 특징 14개, 모형은 표준화 로지스틱 C=0.1·max_iter=2000이다. 기존 최소 1,000행·각 방향 20개 기준을 유지한다. 수익 기반 선택·클래스 균형 가중치·연도 가중치는 적용하지 않는다.
- 기존 활동 모델과 학습 점수 분위 .975, 방향 문턱 .65, v21 관리와 수량·위험 설정은 유지한다. 후보는 하나다. 신호는 새 방향 모델의 직접 점수를 사용한다.
- 과거 활동이 많은 해에 정답이 집중되는 점과 원본의 보유 중 반전을 봇의 무포지션 진입에 적용하는 한계를 유지한다. 기존 학습 기간의 모사 성능을 미래 성과로 부르지 않는다.

## 고정 대조와 검증

2021년 새 모델·기존 v26의 적합 대조와 기존 v26 전체 출력·상태 일치를 확인한다. 이후 고정한 2022년 양수·30거래·영구 중지 없음이면 전체 평가를 진행한다. 실패하면 BTC 후속 두 기간·세 독립 연도만 진단한다.
