# 실험 v37 사전 계획: 첫 관리 주문 문턱의 분리 진단

2026-10-04. v36은 원본 행동 예측의 개선을 실제 체결 정책에 연결했지만 2021년 추가·축소가 없었고 2022년 확인 조건에 미달했다. 고정 문턱을 원본 상태에 대조한 결과, 첫 추가·첫 축소 상태에서는 보정·진단 구간 모두 최대 점수가 실행 문턱보다 낮았다. 반복 주문이 다수인 전체 구간의 공통 문턱이 첫 주문을 막는 문제를 분리한다. 이 결과만으로 모든 손실 원인을 설명하지 않는다.

## 변경 범위

- v35의 관리 모형·절편·50개 입력과 v36의 배율 1.5를 그대로 유지한다. 새 모형 학습·새 시세 입력·손익 검색은 없다.
- 청산 문턱과 과거 동일 행동의 체결 이력이 있는 추가·축소 문턱은 v36과 정확히 같다.
- 동일 포지션에서 해당 행동 이력이 없는 첫 추가·첫 축소에만 별도 문턱을 계산한다. 구분에는 엄격히 과거인 존재 여부 특징만 사용한다.
- v35의 2021년 상반기 보정 행에서 해당 이력이 없는 행만 사용한다. 축소 F1·추가 F0.5, 예측 양성 최소 20개, 동률 시 높은 문턱이라는 기존 선택법을 그대로 적용한다. 별도 절편 보정은 없다.
- 상반기와 하반기의 각 첫 행동 집단 모두 정답 양성·음성 20개 이상을 요구한다. 마지막 진단 구간은 새 문턱 계산에 사용하지 않는다.

## 판정과 한계

원래 공통 문턱과 새 분리 문턱을 동일한 2021년 하반기 행에서 배율 1.5를 적용해 비교한다. 첫·반복·전체 집단의 정밀도·재현율·F점수·예측 건수·정답 건수를 기록한다.

후속 매매 연구를 허용하려면 추가·축소 각각에서 첫 행동 재현율과 F점수가 기존보다 엄격히 높아야 하고, 전체 집단 F점수가 기존보다 낮아지지 않아야 한다(수치 허용 오차 1e-12). 청산과 반복 행동의 요청 마스크는 정확히 같아야 한다. 두 행동을 모두 통과해야 하며 일부만 선택하거나 실패 후 기준을 완화하지 않는다.

원본 상태를 고정한 이 진단은 주문 요청 이후 달라지는 봇 상태나 수익성을 입증하지 않는다. 통과해도 별도 사전 매매 계획을 확정한 후에 적용한다. v36의 확인 실패·후속 BTC 두 기간·세 독립 연도·실제 복원·회계 검증은 계속 보존한다. 모든 기간은 이미 관찰했으며 원본과 개별 결과는 Git에 포함하지 않는다.
