# 실험 v12 사전 계획: 보유 중 가격 경로의 복원

2026-10-03. v11의 최근 구간 학습도 2022년 확인에서 손실이며 원본 청산 재현율이 낮다. 학습 시기만으로 문제가 해결됐다는 가설을 기각하고, 현재 입력이 보유 중 거쳐 온 가격을 구분하지 못하는 문제를 검증한다. 같은 수익률도 상승 후 반납한 상황과 하락 후 회복한 상황이 다르다. 이 차이가 원본 판단의 원인이었다고 단정하지 않는다.

## 고정 변경

- v11의 32개 특징에 과거 확정 1분 종가의 최선 변화, 최악 변화, 최선 대비 반납 폭 세 개만 추가한다. 현재 평균 진입가를 분모로 하고 보유 방향을 반영한다. 추가 진입으로 평균가가 바뀌면 당시까지 관찰한 종가 극값을 새 평균가로 다시 계산한다.
- 원본은 분 경계 직전의 동일 포지션에 연결된 종가만 누적한다. 새 진입·반전은 새 경로다. 분 안의 진입 전 고가·저가, 미래 종가·최종 수량·최종 손익을 사용하지 않는다. 첫 관측의 최선과 최악은 해당 종가이며 반납 폭은 0이다.
- 봇도 실제 진입 이후 확정 종가만 누적한다. 추가·축소·관리 대기·주문 지연 중에도 매 분 경로를 갱신한다. 평균가·최초 진입 시각을 엔진의 읽기 전용 상태로 제공하고, 경로는 영속 정책 상태에 저장한다. 평탄·반전 시 초기화하며 재시작 전후 입력이 같아야 한다.
- v11의 학습·문턱 조정 날짜, 두 모형과 네 후보, 행동 우선순위, 진입 및 위험 설정을 유지한다. 경로 특징 추가와 함께 손절·보유 기간·문턱·수량을 조정하지 않는다.

## 검증 순서

특징의 수작업 계산·롱/숏·평균가 변경·경계·미래 수정 시 과거 불변·온라인/일괄 일치·중단 복원을 먼저 검증한다. 기존 v10/v11 형식과 결과의 의미를 변경하지 않고 별도 형식으로 저장한다. 선택은 2021년 20거래 이상에서 수익 - 0.5 × 낙폭 절댓값 최대, 고정 후 2022년 확인과 2021년 행동별 모사를 기록한다.

2022년 확인이 v10의 수익성 선행 기준(양수·중지 없음·30거래 이상)에 미달하면 후속 전 시장 비용 조건을 무조건 반복하지 않고, 고정 BTC 2023~2025년·2026년과 세 연도 초기화의 진단 비교까지만 수행한다. 선행 기준을 통과하면 v10의 전체 세 시장·여덟 조건·아홉 연도 평가를 수행한다. 이 자원 배분 규칙을 결과 확인 전에 고정하며, 중단한 조건을 검증 완료로 계산하지 않는다.

이미 관찰한 시기의 반복 연구이며 선택 편향이 누적된다. 실패 결과와 이전 후보를 보존한다. 수익성 문제 해결 전에는 전체 goal을 완료하지 않는다. 원본·파생 자료는 로컬에만 보존하고 실거래 연결을 추가하지 않는다.
