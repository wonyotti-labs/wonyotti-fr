# 실험 v119 사전 계획: 첫 추가·축소의 분리 학습

2026-10-12. v118에서 최근 BTC는 보유 시간 98.7%·종료 8거래이며 관리 체결이 없었다. v114의 원본 상태 진단에서도 첫 추가·축소의 표본과 점수 분포가 반복 행동과 달랐다. v37~38은 첫 행동 문턱을 분리했지만 모델은 공통이었다. 이번에는 첫 상태의 조건부 예측을 분리한다. 반복 행동과의 혼합이 원인이라는 결론은 아직 없으며, 사후 관찰에서 출발한 새 가설이다.

## 입력·모형 고정

- v35의 전체 2020년 학습·2021년 상반기 보정·하반기 진단 행과 원본 50개 입력·정답을 보존한다. 기존 24시간 경계 제거·에피소드 분리와 모든 입력 지문을 확인한다. 원래 기간은 모두 관찰한 자료다.
- 첫 축소는 `past_reduce_exists == 0`, 첫 추가는 `past_increase_exists == 0`으로 정의한다. 해당 시각의 엄격한 과거 체결 여부만 사용한다. 성패·미래 행동·손익으로 행을 선택하지 않는다. 다른 행동의 과거 존재 여부는 제한하지 않는다.
- 각 행동의 첫 상태 학습 행에 동일한 부스팅 하나와 선형 대조 하나를 적합한다. 부스팅은 기존 64회·학습률 0.05·깊이 2·말단 4개·최소 64행·L2 1·255구간·seed 0·가중치 없음·조기 종료 없음이다. 선형은 학습 행 표준화와 로지스틱 C=0.1·최대 2,000회·seed 0이다. 설정 검색은 없다.
- 첫 상태 상반기 행으로 각 모델의 절편만 보정한다. 기존 기울기 1·기계 정밀도 경계·[-64, 64]·이분법 100회·평균 오차 1e-12를 유지한다. 상반기에서 축소 F1·추가 F0.5, 예측 양성 최소 20개로 문턱을 고른다. 진단 정답은 적합·보정·문턱에 사용하지 않는다.
- 각 기간·행동의 첫/반복 상태 모두 양성·음성 20개 이상을 요구한다. 첫 상태 학습 1,000행·보정/진단 100행 이상도 요구한다. 부족하면 그대로 미달 처리한다.
- 대조는 v115가 유지한 v48 관리 모델·절편·첫 문턱이며 반복 배율은 v115의 1.0이다. 첫 상태에만 새 점수와 문턱을 사용하고 청산·반복 점수 및 요청 마스크는 정확히 보존한다. 두 행동의 요청 충돌 시 최종 실행 선택까지 같다는 뜻은 아니다.

## 고정 판정과 검산

하반기 첫 상태에서 추가·축소 각각이 아래 9개 조건을 모두 만족해야 한다.

1. 보정 부스팅 로그 손실이 공통 모델과 첫 상태 선형 각각보다 1% 초과 개선(1e-12 경계 제외).
2. 평균 정밀도가 위 두 대조 이상(허용 오차 1e-12).
3. 보정 후 로그 손실이 보정 전보다 악화하지 않고, 상반기 첫 상태 행동 빈도 상수보다 개선.
4. 기존 첫 문턱 요청보다 첫 상태 재현율과 F점수가 각각 엄격히 개선하고, 전체 상태 F점수는 보존.

위 18개와 청산·반복 축소·반복 추가 요청의 보존 3개를 함께 판정한다. 일부 행동만 채택하거나 미달 뒤 기준을 낮추지 않는다. 전체 및 모든 월의 첫/반복 지표, 적중·오탐·누락, 행·양성 수를 모두 공개 집계한다. 월별 양성 0개도 삭제하지 않는다.

입력 행과 분할·첫 상태 선택, 독립 재적합한 128개 트리와 두 선형 계수, 저장 숫자 모델의 모든 확률, 별도 계산한 절편·문턱·지표·판정을 검산한다. 같은 입력의 미래 진단 정답을 바꿔도 적합·보정·문턱이 불변인 회귀 사례와 손상 모델·시간·지원 경계 검사를 포함한다. 기존 모델·절편과 저장 진단 예측도 대조한다. 실제 실행의 코드·입력·계획 지문을 전후 확인하고 실패 실행은 보존한다.

통과는 원본 상태의 후속 연구 허용이며 수익성 입증이 아니다. 새 계좌는 별도 고정 계획 뒤 전체 경로로 평가한다. 원래 손실과 표본 부족을 보존하며 최종 v10의 다년·다시장·비용·펀딩·지연·낙폭·표본 기준을 유지한다. 원본·모델·개별 예측은 로컬에만 저장하며 실거래 연결은 없다.
