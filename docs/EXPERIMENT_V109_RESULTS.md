# 실험 v109 결과: 청산 요청과 실제 종료의 시간 대응

2026-10-11. [사전 계획](EXPERIMENT_V109.md)의 전체 대조를 완료했다. 요청과 체결 종료의 시점 차이는 존재하지만 v108의 낮은 예측력을 설명하지 못했다. 하반기 B 모형의 청산 신호 651개 중 요청 정답 적중은 5개, 실제 종료 정답 적중은 6개다. 오탐은 여전히 645개다. 모형·문턱·정책 변경이나 새 매매 실행은 없으며 수익성 문제는 미해결이다.

## 독립 주문과 종료 사건

정상 XBTUSD 주문 18,397개와 실제 종료 사건 2,589개, 전체 403,776개 창을 독립 순회 계산과 대조했다. 요청량은 첫 체결에서 관측한 orderqty다. 제출 시각·취소·최종 의도를 복원한 값이 아니다. 같은 시각에서는 선언된 원본 순서를 유지했다.

청산·반전 크기 요청 2,786개 중 2,566개(92.10%)는 같은 주문이 시작 에피소드를 종료했고 220개는 다른 주문이 종료했다. 시작 에피소드가 같은 5분 창에서 끝난 요청은 2,616개(93.90%), 그중 같은 주문이 종료한 것은 2,534개다. 요청 여러 개가 하나의 종료에 연결될 수 있으므로 요청 수와 종료 수를 혼합하지 않는다.

실제 종료 사건 기준으로는 같은 에피소드의 청산·반전 요청에서 출발한 것이 2,566개, 최초 요청이 다른 행동이었던 것이 4개, 특수 주문이 19개였다. 정상 주문 종료 2,570개의 최초 관측부터 종료까지 지연 중앙값은 0초, 90% 분위수는 5.289초, 99% 분위수는 90.929초였다. 일부 긴 지연과 다른 주문의 종료도 모두 보존했다.

청산 요청 중 첫 체결 행동은 close 606개·reverse 1,378개·reduce 802개였다. 802개 차이는 모두 첫 부분 체결의 축소다. 관측 총 체결량이 최초 요청량보다 작은 청산 요청은 369개였고, 청산 요청의 관측 orderqty 변경은 없었다. 전체 정상 주문에서는 변경 1개였다.

마지막 관측행의 상태는 청산 요청 중 Filled 1,923개·PartiallyFilled 863개였다. 이는 최종 주문 상태나 취소 판정이 아니다. 전체 정상 체결 940,988행 중 원본 선언 순서의 주문별 체결량 누적과 cumqty가 다른 행도 350,480개 있었다. 누적 메타데이터를 정답이나 회계로 대체하지 않았으며 동일 시각의 순서·누락·상태 갱신 중 원인을 이번 진단만으로 단정하지 않는다. 실제 수량은 기존 원장과 원본 lastqty 합을 대조했다.

## 검산과 재현

신규 21개와 이전 관련 101개, 총 122개 검사 및 Ruff 통과. 부분 체결·주문 변경·다른 주문 청산·미종료·특수 주문·동시각 순서·5분 경계·나노초/마이크로초 입력·수량/정답 변조를 검사했다. 전체 프로젝트의 최신 검사나 원격 CI 통과를 주장하는 범위는 아니다.

실제 18,397개 주문·2,589개 종료·403,776개 창, 모든 기간·연도·월별 집계와 저장 예측의 혼동표를 독립 계산으로 대조했다. 정수·행동·연결은 정확히 같고 분위수 부동소수점 비교에는 절대/상대 1e-12 허용치를 사용했다. 파케이 저장 후 다시 읽은 원장도 일치했다. 원본 5개·당시 공개 소스 302개 및 선행 결과를 포함한 417개 고정 입력의 불변을 확인했다.

공개 실행 진입점은 `python -m wonyotti_fr.request_execution_research --help`다. 원본 참조와 v107·v108 검증 파일에 각각 SHA-256을 명시하고 프로토콜·출력 폴더를 전달한다. 고유 출력 폴더와 소스 스냅샷을 생성하며 실패 시 실패 내용도 보존한다. 원본과 개별 산출물은 공개 저장소에 포함하지 않는다.

## 남은 문제

청산 요청을 실제 종료로 해석하는 시점 차이는 확인했지만, 이를 v108의 낮은 예측력이나 전체 반복 손실의 주원인으로 채택할 근거는 부족하다. 같은 입력·같은 모형의 요청 정답 교체만으로 문제 해결을 주장하지 않는다. 최근 신규 진입 표본 부족, 당시 관측 가능한 정보로 독립 주문을 예측하는 문제, 자체 계좌의 상태 차이와 다년 수익성 기준은 그대로 남아 있다. 실제 주문 연결 없이 미해결 goal을 유지한다.
