# 실험 v91 사전 계획: 첫 청산 기준의 연속 계좌 대조

2026-10-10. v90의 정규화 선택은 보정 최초 효과를 개선했지만 항상 첫 적격 청산보다 낮았다. 앞 학습 안의 네 강도도 같은 기준을 넘지 못했다. 조건부 청산 효과와 실제 매매 순손익 사이의 차이를 먼저 확인한다. 실패한 v90 모델을 적용하거나 채택 조건을 낮추지 않으며, 기존 단순 대조 정책 자체의 실행 진단이다.

## 고정 대조와 두 기간

부모는 기존 v54 고정 정책이다. 원본에서 추정한 진입 방향·문턱·가격 대기·관리 모델·수량·보유 한도·손절·일별 손실·낙폭 중지·수수료·슬리피지·펀딩을 유지한다. 신규 학습·문턱 선택·수량 변경은 없다.

BTC 2021-01-01~2022-01-01 미만과 2022-01-01~2023-01-01 미만을 각각 초기 계좌로 재생한다. 같은 기간마다 기존 부모와 첫 청산 대조를 실행하는 총 네 번이다. 손실·중지 여부와 무관하게 두 기간을 모두 완료한다. 2021년은 부모의 적합 구간이고 2022년 역시 이미 관찰한 구간이다.

대조는 실제 부모가 보유 관리의 50개 현재 특징을 계산하고 모두 유한하며, 원래 의도가 청산이 아닌 첫 판단에서 청산 의도를 요청한다. 원래 청산은 그대로 둔다. 관리 대기·특징 미지원·무포지션·위험 중지에는 별도 판단을 만들지 않는다. 같은 판단의 부모 상태는 보존하며 부분 축소 수량을 전량 청산에 전달하지 않는다. 다음 거래 가능한 봉의 실행·추가 지연·위험 우선순위는 기존 엔진에 맡긴다. 첫 요청 뒤 무거래로 대기하면 원래 엔진의 대기 의도를 보존한다.

이는 고정 원장에서 첫 청산만 바꾼 반사실과 달리, 조기 청산 후 부모의 규칙으로 재진입해 새 포지션과 계좌 상태를 만든다. 기존 포지션별 효과를 단순 합산해 연속 수익으로 대신하지 않는다. 원래 관리 의도가 청산인 경우도 전체 계좌에 포함한다.

## 기록과 검증

기존 부모·자료 출처·계획·코드와 v90 독립 검산의 호출자 지정 SHA-256을 고정한다. v90의 실패와 마지막 예측 부재를 확인하며 그 모델은 실행에 사용하지 않는다. 과거 부모의 두 기간 전체 체결·거래·분별 계좌·최종 상태를 다시 재현해 일치 여부를 확인한다. 원본 자료는 변경하지 않는다.

대조의 모든 정책 호출에 대해 시각·보유 방향·특징 호출 수와 지원·원래 의도·최종 의도·변경 여부·사유를 기록한다. 같은 의사결정의 미래 가격을 사용하지 않는다. 합성 사례에서 롱·숏·대기·추가·축소·원래 청산·누락 특징·비유한 특징·무거래·지연·손절 우선순위·재시작과 미래 시세 변경 전 판단의 불변성을 검증한다. 대조 비활성화는 원래 부모의 전체 출력·상태와 정확히 같아야 한다.

실제 네 실행의 계좌 회계·체결 비용·펀딩·순손익·거래 수·낙폭·중지·방향별 및 월별 결과를 대조한다. 별도 순차 재생에서 부모 판단의 원래 특징 호출과 대조 의도를 다시 계산하고 저장한 의도·체결·상태를 확인한다. 저장된 수익률만 비교하는 것으로 검증을 대체하지 않는다.

## 해석과 후속 분기

각 기간에서 부모 대비 수익 차이, 순수 가격 손익과 거래 비용, 재진입·거래 수 변화와 중지 여부를 모두 보고한다. 조기 종료가 조건부 손실을 줄여도 잦은 왕복 비용이나 새로운 진입 때문에 계좌가 악화될 수 있으며 이는 검증할 가설이다.

이번 대조만으로 수익성 채택을 하지 않는다. 두 기간 양수·각 30거래 이상·중지 없음이면 별도 계획으로 다년·다시장·비용·지연·집중도 검증을 진행한다. 미달이면 원래 진입과 비용의 기여를 확인해 다음 구조 변경을 정한다. v90의 내부 실패와 최종 v10 기준은 그대로이며 실제 거래 연결은 없다.
