# 실험 v67 사전 계획: 확정된 청산 결과의 주간 누적 재학습

2026-10-04. v66에서는 복잡도를 늘린 세 후보 모두 내부 선택 오차가 악화됐고 기존 깊이 2·64회 설정이 선택됐다. 마지막 구간의 음수 선택 효과도 그대로였다. 복잡도를 더 늘리지 않고, 뒤 구간 진행 중 이미 확정된 결과를 학습에 반영하지 않는 고정 모델의 한계를 점검한다.

## 고정 모델·학습 갱신

v66 전체 결과와 이전 원장·대조·내부 선택·최초 선택·주간 지표를 다시 생성해 일치를 확인한다. v64의 현재 입력 56개·원래 계좌 기준 정답·깊이 2·64회 설정·포지션별 비중·0bp 문턱을 유지한다. 모델 종류·문턱·학습 창 길이를 손익으로 검색하지 않는다.

진단 시간은 기존 2021-10-02 이상 2021-12-31 미만이다. 시작 시각부터 7일마다 모델을 갱신하며 마지막 주는 남은 6일이다. 각 갱신 시각 t에서 진입과 판단이 2021-01-01 이상이며 원래 포지션의 정답 종료가 `t - 2일`보다 엄격히 이전인 확정 행만 사용한다. 최근 자료만 남기는 이동 창은 쓰지 않고 과거 모든 적격 행을 누적한다. 같은 현재 포지션의 미확정 결과와 이후 확정된 결과를 당겨 쓰지 않는다.

첫 갱신의 학습 행·가중치·모델·예측은 기존 v64와 정확히 같아야 한다. 이후에는 각 주가 시작되기 전에 확정된 새 결과만 추가한다. 각 갱신에서 원래 포지션별 총 비중을 같게 하고 평균 가중치 1을 적용한다. 최소 1,000행·100포지션·방향별 20포지션·판단 범위 180일이라는 기존 지원 조건을 유지한다. 하나라도 부족하면 실행을 실패로 남기며 임의 예측이나 표본 제거로 대체하지 않는다.

모델별 학습 행 인덱스·시각·포지션·정답 종료·가중치와 모델·지원·학습 기준 시각을 저장한다. 해당 주의 판단에만 그 시점 모델을 적용하고 모델 선택을 위한 마지막 구간 전체 지표는 사용하지 않는다. 평가 행·정답·원래 진단 포지션 가중치는 이전과 같다. 시각이 같은 종료는 엄격한 이전 조건을 만족하지 않으므로 포함하지 않는다.

## 판정과 해석

대조는 v66 선택 모델, v65 노출 변환, v64 의도 입력, v62 경제적 입력, v60 부스팅·Ridge·학습 상수 일곱 개다. 다음 열여덟 조건을 모두 요구한다.

1. 가중 제곱 오차가 일곱 대조 각각보다 1% 초과 개선: 일곱 조건.
2. 무가중 제곱 오차가 여섯 학습 대조 각각보다 악화하지 않음: 여섯 조건.
3. 추가 청산 100행 이상·30포지션 이상: 두 조건.
4. 선택한 실제 효과의 가중·무가중 평균 양수: 두 조건.
5. 최초 선택과 선택 없음의 0을 포함한 전체 공통 기준 포지션 평균 효과 양수: 한 조건.

전체·방향·월별 행 지표와 후보·v64 최초 선택 지표, 같은 13주 블록·1,000회·seed 63의 공통 효과 및 짝지은 차이 구간을 기록한다. 각 주의 모델은 원래 고정 봇 경로에서 이미 확정된 청산 반사실을 학습한다. 새 정책을 연속 실행한 결과나 실제 봇의 온라인 적응을 구현한 것으로 주장하지 않는다. 이후 주에서 과거 진단 주의 확정 행을 학습할 수 있으므로 고정 모델의 단일 미사용 평가와도 구분한다. 전체 연구에서 이미 본 기간이라는 한계는 유지한다.
