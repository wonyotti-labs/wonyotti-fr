실제 실행의 수치·입력 해시·코드 스냅샷·그림·실패 내역과 검증 파일은 로컬 `artifacts/INDEX.md`에서 확인한다. 공개 저장소의 테스트는 합성 자료만 사용한다. 데이터 보유자가 직접 재현할 명령은 README에 정리했다.

v1~v9 중 채택한 전략은 없다. 최신 v9은 설명 대조 후 고정한 네 관리 후보의 개발·확인과 48개 조건·9개 연간 초기화, 총 62개 실행을 대조했다. 실제 종료 복원·한 달 재개와 기존 v7의 최근 세 시장 전체 경로가 일치했다. 원본 체결 4개·지갑 1개 지문도 최초 감사와 같다. 합성 테스트 190개·정적 검사·원격 CI를 통과했으며 의존성 검사에서 알려진 취약점은 발견하지 못했다. 원본 수익 구조의 불일치 수정과 수익성 확보는 별도다.

v9 학습 감사의 첫 실행은 저장 시 제외된 pandas 인덱스를 값과 함께 비교해 실패했다. 실패 파일을 보존하고 양쪽 인덱스만 초기화한 새 감사에서 값·표준화 일치를 확인했다. 학습 자료·모델·후보는 바꾸지 않았다. 이전 v8의 50개 회계·진입·필터·복원 검사도 독립 결과로 보존한다.

이전 v6 전체 시점 비교와 v7의 대기·보유 중 실제 종료 복원, 원래 2022~2025년 및 2026년 1~9월 비교를 완료했다. v7의 36개 비교·12개 연간 초기화, 먼저 완료한 2022~2024년 추가 18개 비교·9개 연간 초기화는 각각 별도 결과로 보존한다.

BTC 전체 평가에는 성과 실행 전에 문서화한 미수정 봉의 추가 대조를 사용했다. 봉 값은 네 경로에서 정확히 일치하지만 개별 체결 10건은 두 집계 형식과 여전히 연결되지 않는다. 엄격 검사 실패와 미연결 행을 보존하며 이 한계를 해결한 것으로 표시하지 않는다. 이 문장의 과거 완료 표시는 v7까지의 유한한 연구 범위다. 현재 수익성 문제 해결 goal은 진행 중이다. 수익성 확보는 입증하지 못했으며 실거래 준비 완료를 뜻하지 않는다.


## v10~v13 진행 중 검증

v10과 v11 각각 개발 4개·확인 1개·후속 조건 48개·독립 연도 9개, 총 62개 실행의 회계와 진입 연결을 다시 대조했다. 최근 세 시장의 기존 v7 기준은 전체 출력·최종 상태가 이전 결과와 같다. 최초 원본 5개 파일 지문도 재확인했다. 두 후보는 수익성 기준에 미달했다.

v10 초기 평가의 지연 진입에서 새 진입 대기가 보유 상태에 남는 오류를 발견했다. 실패 폴더를 보존하고 유효한 신규 대기만 보유 시작 시 취소하도록 수정한 뒤 새 폴더에서 전체 평가를 재실행했다. 트리 단일 예측의 경계 정밀도도 수정했으며 선택·확인에서 실제 판단 698,418개의 점수와 명령이 바뀌지 않았음을 따로 검사했다.
