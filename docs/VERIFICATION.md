실제 실행의 수치·입력 해시·코드 스냅샷·그림·실패 내역과 검증 파일은 로컬 `artifacts/INDEX.md`에서 확인한다. 공개 저장소의 테스트는 합성 자료만 사용한다. 데이터 보유자가 직접 재현할 명령은 README에 정리했다.

v1~v8 중 채택한 전략은 없다. 최신 v8은 개발 4개·확인 1개와 후속 36개 비교·9개 연간 초기화, 총 50개 실행의 회계·진입·활성 분봉 체결과 필터 결정을 검증했다. 기존 v7의 최근 세 시장 전체 결과와 필터 제거 실행도 정확히 같다. 실제 종료 복원·한 달 재개와 소스 스냅샷을 대조했다. 합성 테스트 177개·정적 검사·원격 CI를 통과했으며 의존성 검사에서 알려진 취약점은 발견하지 못했다. 원본 체결 4개와 지갑 1개의 해시도 최초 감사와 일치했다.

이전 v6 전체 시점 비교와 v7의 대기·보유 중 실제 종료 복원, 원래 2022~2025년 및 2026년 1~9월 비교를 완료했다. v7의 36개 비교·12개 연간 초기화, 먼저 완료한 2022~2024년 추가 18개 비교·9개 연간 초기화는 각각 별도 결과로 보존한다.

BTC 전체 평가에는 성과 실행 전에 문서화한 미수정 봉의 추가 대조를 사용했다. 봉 값은 네 경로에서 정확히 일치하지만 개별 체결 10건은 두 집계 형식과 여전히 연결되지 않는다. 엄격 검사 실패와 미연결 행을 보존하며 이 한계를 해결한 것으로 표시하지 않는다. 이번 goal의 진단·후속 후보·사전 선택·전체 평가·오프라인 통합과 연구 기록 범위는 완료했다. 수익성 확보는 입증하지 못했으며 실거래 준비 완료를 뜻하지 않는다.
