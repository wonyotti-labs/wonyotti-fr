## 검증과 보존

새 후보 다섯 계좌의 총 4,600,800분을 별도 문턱 정책으로 다시 순차 재생했다. 모든 판단 결과·분별 계좌·체결·거래·최종 상태가 같았고 현금·수수료·펀딩을 직접 대조했다. 기존 모델 재학습이나 기존 부모 계좌의 새 전체 재생은 수행하지 않았다.

신규 17개와 관련 63개, 합계 80개 테스트 및 Ruff 검사를 통과했다. 실행 시작에 고정한 319개 공개 모듈과 입력·계획 지문을 전후 대조했다. 종료 후 별도 집계에서 다섯 계좌의 손익 분해·거래 수·보유·종료 사유·최대 이익 제거·연율 블록 재표집을 다시 계산해 일치했다. 원본 다섯 파일을 포함한 앞선 검산 출처도 확인했다. 전체 테스트 모음이나 원격 CI의 최신 통과를 주장하지 않는다. 원본·개별 결과·모델은 로컬에만 보존하며 실거래 연결은 없다.
