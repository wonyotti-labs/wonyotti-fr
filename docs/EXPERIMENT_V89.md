# 실험 v89 사전 계획: 직전 확정 분봉의 체결 방향

2026-10-10. v87·v88은 기존 관리 확률을 추가하거나 그 확률만 사용하는 방식으로도 첫 판단의 기준을 넘지 못했다. 현재 입력에는 확정 1분 수익률·범위·거래량이 있지만 체결 방향은 최근 확정 5분 묶음의 값이다. 분별 판단에서 0~4분 전의 묶음만 보는 제한을 확인했다. 같은 원장에 직전 확정 1분의 체결 방향 두 값만 추가하는 가설을 검증한다. 유효한 수익 신호라고 미리 단정하지 않는다.

## 같은 출처·현재 분봉

v88 독립 검산의 호출자 지정 지문과 전체 원장·부모·77개 저장 입력·보정·생성 코드 봉인을 확인한다. 봉인된 v84 생성 메타데이터에서 같은 BTCUSDT 1분 시세와 당시 manifest 지문을 찾는다. manifest와 정규화 시세 파일의 지문을 확인하고 기존 시세만 읽는다. 새로운 종목·기간·자료 제공자·가격 정정은 없다.

각 첫 판단 `decision_time`에 정확히 끝난 1분 봉만 연결한다. 봉의 시작은 판단 시각 1분 전이며, 종료 뒤 다음 분봉 시가에 청산을 실행하는 기존 순서를 유지한다. 동일 시각 종료 봉은 사용할 수 있지만 다음 분봉의 어떤 값도 입력에 쓰지 않는다. 분 경계·UTC·중복·OHLC·거래량·체결 수와 연결 누락을 검사하고 미래 값으로 채우거나 원래 행을 제외하지 않는다.

추가 값은 `minute_taker_imbalance_1m = 2 × taker_buy_volume / volume − 1`과 여기에 현재 포지션 방향을 곱한 값, 두 개다. 기존 v71의 기본자산 거래량 정의를 1분 봉 하나에 적용한다. 거래량은 유한하고 `0 ≤ taker_buy_volume ≤ volume`이어야 한다. 총거래량이 정확히 0인 봉은 불균형 0으로 기록한다. 실제 주문 장부·호가 잔량·트레이더 개인 주문으로 해석하지 않는다. 추가 창·거래량 문턱·월·방향·구간 탐색은 없다.

학습 첫 기회 1,277개·보정 첫 기회 93개·전체 96포지션을 그대로 유지한다. 기존 77개 값·현재 부모 확률·현금·첫 순자산·비용·비중·0·손실·미확정·기회 없음·후속 원장을 보존한다. 기존 74개와 부모 확률 세 개에 새 두 값을 붙여 79개 입력을 만든다. 선택한 분봉 원래 열과 입력 행 대응·시각·출처 지문을 로컬 원장으로 저장하며 마지막 진단에는 새 입력을 생성하지 않는다.

## 같은 후보 설정·판단

v87과 같은 StandardScaler와 L2 로지스틱 설정을 그대로 쓴다. C=0.1, l1_ratio=0, lbfgs, fit_intercept=True, class_weight=None, seed 0, warm_start=False, max_iter=2000, tol=1e-9이다. 모든 첫 포지션을 같은 비중으로 표준화하고 비영 비용만 기존 절대 bp 평균으로 정규화해 적합한다. 모델 하나를 한 번 적합하며 기존 비용 원장·학습 상수·지원 조건을 유지한다.

첫 적격 기회에서만 점수가 엄격히 0.5보다 클 때 추가 청산한다. 첫 거절 뒤 재예측·선택은 없다. 원래 진입·관리 모델·수량·위험·비용·문턱·학습 구간을 변경하지 않는다. 79개 특징·표준화·계수·절편과 학습·보정 점수를 숫자 JSON으로 보존한다.
