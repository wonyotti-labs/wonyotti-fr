# 실험 v139 사전 계획: 관리 요청과 이후 원본 행동의 일대일 시간 대응

2026-10-12. v138에서 한도 전 재시작 추가의 후보 새 적중 1분은 상반기 공통 FP 예산 아래 사라졌다. 정확히 같은 1분에 대응하지 않은 요청이 원본 행동보다 조금 앞섰는지, 대응할 행동 자체가 없었는지를 구분한다. 이 근거 없이 정답의 시간 범위를 넓혀 학습하거나 문턱을 완화하지 않는다. 직전 턴은 v138의 실제 완료 출력 해석·독립 검산·결과 공개·푸시를 마친 진행이다.

## 고정 자료와 범위

v138 완료 증거의 지문과 봉인에서 원본 교사·횟수 원장·v127/v137 고정 예측으로 이어지는 출처를 확인한다. 원래 1,018,460행·정답·입력·기간·포지션을 유지한다. 저장된 예측 문맥과 점수·요청, 공통 예산 문턱 및 요청 원장을 다시 대조한다. 이미 검산된 모델을 재학습하거나 중복 계좌를 실행하지 않는다.

v138의 축소/추가 × quiet/first/restart × all/below/capped 18집단을 그대로 사용한다. 각 집단에 v127/v137 × 기존 요청/공통 예산 요청 네 조건을 모두 보고한다. 미지원 문턱은 없음으로 보존한다. 각 요청과 목표 양성 분은 같은 집단·포지션에 있어야 한다. 집단은 각 시점의 과거 상태로 정의하지만 미래 목표를 연결하는 작업 자체는 사후 진단이다. 겹치는 집단을 합산하지 않는다.

## 시간 대응과 중복 방지

시간 범위는 1분과 15분 둘뿐이다. 1분은 기존 혼동표 재현, 15분은 기존 주문 이력 창과 같은 길이의 원인 진단이다. 길이를 검색하거나 성적에 따라 선택하지 않는다. 요청 경계 t와 원래 양성 경계 e는 `t <= e < t + 범위`일 때만 연결할 수 있다. 뒤늦은 요청을 이미 지난 행동에 연결하지 않는다. 목표는 보존된 양성 **분**이며 독립 주문 수나 종료 거래 수가 아니다.

같은 포지션에서 사건 경계 순으로 가장 이른 사용 가능한 요청을 연결한다. 한 요청·한 양성 분을 각각 한 번만 사용한다. 이 고정 길이 구간의 일대일 최대 대응 수를 별도 이분 그래프 최대 매칭으로 대조한다. 여러 최대 해가 가능하므로 그래프 알고리즘의 임의 쌍 자체가 아닌 최대 대응 수와 생산 원장의 시간·포지션·유일성을 검산한다. 원래 정확히 맞은 요청 수는 별도로 유지하며, 넓은 범위에서 배정된 쌍의 동일 분 수와 혼동하지 않는다.

요청 수·목표 수·일대일 대응 수·미연결 요청·미포착 목표·요청 대비 대응 비율·목표 포착 비율·0~14분 선행 분포를 기록한다. 비교용으로 중복을 허용한 목표 포착 수와 목표가 하나라도 있는 요청 수도 계산해 한 사건을 여러 번 맞힌 것으로 부풀리는 효과를 드러낸다. 이 비율을 수익 확률이나 실행 정확도로 부르지 않는다.

전체 기간에서 먼저 대응한 뒤 요청 시작 월과 목표 발생 월을 각각 집계한다. 월 경계를 넘은 대응을 잘라 재계산하지 않는다. 24개월의 무행·무요청·무양성도 보존한다. 모든 집단·조건에서 1분 대응 수는 기존 TP와 같고, 미연결 요청은 FP, 미포착 목표는 FN과 같아야 한다. 15분 최대 대응 수는 1분보다 작아질 수 없다.

## 관측 범위와 검산

목표는 기존 연구에 남은 양성 분으로 한정한다. 교사 표에 없는 경계의 실제 주문 유무를 추정하지 않는다. 요청마다 이후 15개 분 경계가 같은 기간의 보존 표에 모두 있는지와 기간의 마지막 관측 경계를 넘는지 따로 기록한다. 부재 구간·포지션 종료·분할 경계가 섞일 수 있으므로 미연결 요청을 새 15분 정답의 확정 FP로 바꾸지 않는다. 관측 부족 요청을 삭제하지 않는다.

합성 검사는 정확한 0/14/15분 경계, 뒤늦은 요청, 다른 포지션, 동일 시각·순서·비정수 식별자 손상, 한 사건 앞 여러 요청, 한 요청 뒤 여러 사건, 최대 대응을 위해 재배정이 필요한 그래프, 월 경계, 빈 요청·양성, 미지원 문턱, 원장 변조를 포함한다. 작은 사례는 모든 대응을 열거해 최대 수를 대조한다. 입력·정답의 미래 변경이 원래 예측·요청을 바꾸지 않음을 확인하며, 사후 대응 원장이 바뀌는 것은 정상이다.

실제 계산의 원장·전체/월별 집계를 독립 계산하고 저장 후 재읽기·실행 전후 지문 불변을 확인한다. 전체 특징과 모델을 출력에 중복 복사하지 않고 희소 대응 원장만 로컬에 저장한다. 원본·가공·시장·모델·개별 원장은 Git 제외다. 집계·코드·방법만 명사형 커밋 직후 푸시한다.

## 해석과 후속

v51은 청산 15분 목표를 직접 학습했다가 예측 조건에 미달했다. v109는 청산 요청과 종료의 대응이었다. 이번에는 quiet 축소·추가와 고정 두 모델·공통 예산 요청의 일대일 대응을 조사한다. 더 넓은 시간 범위의 정의상 포착 증가만으로 학습 개선을 주장하지 않는다. 두 모델의 요청량·중복·미연결·관측 부족과 함께 해석하고, 매칭의 미래 정보를 운용 신호로 사용하지 않는다.

기존 v137의 24/40 미달·v138 결과·실제 계좌 손실과 표본 부족을 보존한다. 시간 범위 학습이 필요한지에 대한 다음 가설의 근거이며 모델·정책 채택은 없다. 자체 계좌의 다년·다시장·비용·펀딩·지연·낙폭·표본·집중 요구와 v10 최종 기준은 그대로다. 실제 주문 연결은 없다.

독립 검산의 최대 매칭 정의는 [SciPy 공식 문서](https://docs.scipy.org/doc/scipy/reference/generated/scipy.sparse.csgraph.maximum_bipartite_matching.html)를 따른다. 최대 해의 개별 연결은 유일하지 않을 수 있다.
