# 실험 v134 결과: 누적 추가 횟수와 관리 오류의 분해

2026-10-12. [사전 계획](EXPERIMENT_V134.md)에 따라 원본 1,018,460행의 누적 추가 횟수를 다시 복원했다. 하반기 재시작 추가의 미검출 123분 중 88분은 5회 이상, 35분은 5회 미만이었다. 두 고정 모델 모두 35분을 전부 놓쳤으므로 추가 상한만으로 예측 실패를 설명할 수 없다. 새 모델·계좌 실행은 없으며 수익성 문제는 미해결이다.

## 해석

기존 입력은 실제 횟수를 5에서 자르므로 정확히 5회인 상태와 최대 104회까지 진행된 상태가 같은 값에 들어간다. 상한에 묶인 원본 행은 학습 59.411%·보정 70.486%·진단 71.856%다. 이는 입력 표현의 혼합과 원본·봇 상태의 차이를 확인한 결과다. 이 혼합이 손실을 일으켰거나 입력을 바꾸면 수익이 개선된다는 인과 근거는 아직 없다.

하반기 재시작 추가는 실제 1/2/3/4회에서 양성 7/13/9/6분, 정확히 5회에서 5분, 5회 초과에서 83분이었다. v127과 v133 모두 적중은 0개다. 따라서 제한 전 상태의 예측 실패와 제한 이후 원본 행동을 그대로 따라갈 수 없는 문제를 함께 다뤄야 한다. 0~4회도 횟수 제한 하나를 소진하지 않았다는 뜻이며 청산 우선순위·대기·위험 제한까지 통과한 실행 가능 상태가 아니다. 원본 횟수를 봇의 자체 포지션 횟수로 치환하지 않는다.

가격 입력 v133은 재시작 축소의 5회 초과 구간에서 적중을 0→3개로 늘렸지만 오신호도 2→28개로 늘렸다. 5회 미만에서는 적중 1개가 그대로이고 오신호는 3→7개다. 가격 입력의 일부 개선이 안전한 실행 상태의 개선이나 수익성으로 바로 이어진다는 주장은 하지 않는다.

과거 독립 주문 이력의 first와 누적 횟수 0은 완전히 같은 정의가 아니다. 보정의 첫 추가 824행·양성 2분, 진단의 첫 추가 52행·양성 1분은 누적 횟수 1이다. 전자는 주문 키의 최초 관측 이력, 후자는 진입·반전별로 초기화한 관측 횟수다. 이 정의 차이를 보존했으며 정답이나 행을 사후 변경하지 않았다.

원본 행동 원장의 주문 키 집합으로 복원한 횟수를 체결 방향·수량의 별도 누적 계산과 대조했다. 진입·반전 초기화, 초기 주문 후속 체결, 같은 주문의 부분 체결, 축소로 본 주문의 후속 증가, 청산·펀딩, 동시각 마지막 상태와 엄격히 이전인 시각 연결을 포함한다. 모든 원래 행·정답·입력·24시간 분리·포지션 경계를 유지했다.

기존 v127·v133의 저장된 상태 보정 트리 점수와 요청을 그대로 사용했다. 일곱 구간의 행·양성·요청·TP/FP/FN 합과 행 수로 가중한 로그 손실·Brier를 전체 지표와 대조했다. 평균 정밀도·F는 구간 평균으로 대체하지 않았다. 기존 전체 상태·월 지표도 재현했다.

[전체 기간·월·상태·구간 표](EXPERIMENT_V134_TABLES.md)에 기간 240개와 월 1,920개 조합의 지원과 두 모델 지표를 남겼다. 빈 집단과 양성 0개의 평균 정밀도 없음도 보존했다. 학습 2020년, 보정 2021년 상반기, 진단 하반기는 모두 이미 관찰한 연구 기간이다.
