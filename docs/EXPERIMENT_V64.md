# 실험 v64 사전 계획: 기존 관리 의도에 따른 청산 가치 예측

2026-10-04. v63에서는 같은 포지션의 최초 추가 청산 선택만 보아도 두 고정 모델의 조건부 평균 효과가 음수였다. 반복 신호 평균만이 실패 원인은 아니다. 기존 정책을 유지하는 비교 경로는 판단 시점에 이미 정해진 다음 관리 요청에서 출발한다. 이번에는 그 유지·추가·축소·청산 의도를 명시적으로 입력해 무엇을 취소하고 청산하는지 구분한다.

## 원장과 현재 의도

v63 전체 결과를 v62·v60·v59 검증부터 다시 생성하고 원장·모델·예측·최초 선택·지표·주간 블록 결과를 정확히 재현한다. 기존 v62의 학습 52개 입력·정답·시간 및 포지션 분리·지원 조건·포지션별 가중치를 그대로 유지한다. 기간은 v60과 같은 2021년 앞 학습과 마지막 분기 진단이다. 전체 미확정·경계 밖·제외 행을 보존한다.

추가 입력은 현재 원래 봇의 관리 의도 네 개를 나타내는 one-hot 값뿐이다. 순서는 `hold`, `exit`, `reduce`, `increase`이며 정확히 한 값만 1이다. v59에 기록된 판단 직후 `state.pending`과 `original_intent`가 일치하는 원자를 사용한다. 이는 다음 분의 실행 전에 원래 봇이 이미 결정한 요청이며 실제 미래 체결 여부나 트레이더의 미래 주문 정답이 아니다. 원래 정책의 상태와 기존 입력에서 계산된 의도를 명시하는 구조 보완이며 새로운 외부 정보가 추가된 것으로 주장하지 않는다.

## 단일 후보와 대조

후보는 기존 52개와 의도 4개를 사용한 히스토그램 회귀 하나다. 학습 행·가중치와 v62의 고정 설정 64회·0.05·깊이 2·최대 말단 4·최소 말단 64·L2 1·구간 255·전체 특징·범주형 없음·조기 중지 없음·seed 0을 유지한다. 방향·행동마다 따로 학습하거나 문턱을 검색하지 않는다.

대조는 그대로 재현한 v62의 52개 입력 부스팅, v60의 50개 입력 부스팅·Ridge·학습 평균 상수다. 모든 행의 오차에 원래 청산도 포함한다. 추가 청산은 예측 순효과가 0bp보다 크고 원래 의도가 청산이 아닌 경우다. 다음 열두 조건을 모두 요구한다.

1. 가중 평균 제곱 오차가 네 대조 각각보다 1% 초과 개선: 네 조건.
2. 무가중 평균 제곱 오차가 세 학습 대조 각각보다 악화하지 않음: 세 조건.
3. 추가 청산 100행 이상·원래 포지션 30개 이상: 두 조건.
4. 선택한 실제 순효과의 가중·무가중 평균 모두 양수: 두 조건.
5. v63과 같은 포지션당 최초 선택, 선택 없는 포지션의 0 효과, 첫 이용 가능 판단의 공통 순자산 기준을 적용한 전체 포지션 평균 효과가 양수: 한 조건.

모든 모형의 전체·방향·월별 행 단위 지표를 기록한다. 새 후보와 v62의 최초 선택 원장·포지션 지표도 남기며 동일한 13개 주간 블록·1,000회·seed 63으로 공통 기준 효과와 짝지은 차이의 2.5·97.5 백분위를 제시한다. 이 구간은 불확실성 설명이며 조건을 바꾸는 용도가 아니다. 반복 선택이나 최초 효과를 연속 계좌 수익으로 합산하지 않는다.

## 검증과 후속 경계

모든 원자의 현재 의도와 실제 원래 정책 요청을 대조하고 순서·파일·부모 지문을 확인한다. 알 수 없는 의도·누락·잘못된 one-hot을 거부한다. 현재 의도는 그대로 두고 미래 체결·종료·순손익을 바꾸어도 추가 입력이 같아야 한다. 기존 행·52개 입력·정답·가중치·대조 모델 보존, 숫자 내보내기와 독립 재학습, 모든 지표·열두 조건·최초 선택·주간 비교를 검산한다.

기존 실패 기록과 이미 관찰한 기간의 한계를 유지한다. 실패하면 매매 적용을 차단한다. 통과해도 전체 재학습·연속 정책 검증은 별도 계획을 요구하며 다년·다시장·비용·표본·낙폭의 전체 수익성 기준은 v10 그대로다. 원본·파생 자료·개별 출력은 Git에서 제외하고 실제 거래 연결은 추가하지 않는다.
