# 실험 v136 사전 계획: BTC·ETH 상대 가격 문맥 비교

2026-10-12. v135에서 실제 누적 추가 횟수 한 열을 구별해도 제한 전 재시작 추가의 양성 35분을 모두 놓쳤다. 이번에는 기존 단일 종목 입력에 없는 ETH/BTC 상대 가격 움직임을 조사한다. 다른 계약을 함께 보유한 원본 계좌의 맥락이 BTC 전용 상태와 같다는 가정은 하지 않는다. 상대 가격이 원인의 설명이나 유효한 신호라는 근거도 아직 없으며 검산 후 같은 조건의 예측 비교로 판단한다. 직전 턴은 실제 학습·실패 기록·공개·푸시를 완료한 진행이다.

## 출처와 연결

기존 v127의 50개 입력과 원본 학습 510,102행·보정 256,234행·진단 252,124행, 정답·24시간·포지션 경계를 유지한다. 미채택 v133 가격 입력과 v135 실제 횟수 입력을 새 기준으로 승격하지 않는다. v135 증거에서 v134·v127·원본으로 이어지는 출처를 확인한다.

시세는 로컬의 Binance USD-M 선물 BTCUSDT·ETHUSDT 5분봉이다. 같은 거래소·USDT 기준의 상대 가격을 사용하며 원본 BitMEX 입력 50개는 변경하지 않는다. 시세 manifest와 정규화 파일 및 기존 보정 증거의 지문을 검증한다. 기존 자료 보정의 범위를 실제 기록 이상으로 주장하지 않는다.

- BTC: `data/market-5m-btc-candle-verified`, manifest SHA-256 `687a6b1214f3d94114192d3775970b7078233b6323d883ecd1a4403b4a2521c3`.
- ETH: `data/market-5m-eth-sol-verified`, manifest SHA-256 `af755cd2eed681f45cf0f9f7cf777ce151f07a95027db6764ce3b17b6dc6b089`.

두 자료의 첫 봉 종료는 2020-01-01 00:05 UTC이고, 원본 학습의 최초 판단은 2020-01-02 03:56 UTC다. 계획 전 확인은 파일 지문과 시간·범위에 한정했으며 상대 가격 입력이나 정답별 성적은 계산하지 않았다. 2021년 이후의 추가 시세는 모델 입력 계산에서 사용하지 않도록 마지막 원본 판단까지 잘라서 처리한다.

## 고정한 입력 10개

시간 창은 기존 시장 특징에 쓰는 5분·15분·1시간·4시간·1일이다. 최신 확정 5분봉의 종료를 t, 창 길이를 h라 할 때 `log(ETH_t) − log(ETH_t−h) − log(BTC_t) + log(BTC_t−h)` 다섯 개와 각각 현재 보유 방향을 곱한 다섯 개를 사용한다. ETH가 BTC보다 상대적으로 상승하면 양수다. 다른 창·변환·수익 기반 가중치는 탐색하지 않는다.

두 시장의 시각은 정확히 같아야 하고, UTC·5분 경계·정렬·중복 없음·연속성·양수 유한 종가를 검증한다. 판단 시각 이하의 마지막 확정 봉만 연결하며 봉 종료부터 판단까지는 0 이상 300초 미만이어야 한다. 창 양 끝과 사이의 연속성을 모두 보장한다. 누락·오래된 봉·준비 부족은 오류로 남기며 원본 행 제외나 미래 채움·0 대체를 하지 않는다.

첫 단계는 입력 검산이다. 원래 모든 열과 행을 정확히 보존하고 원본 판단·시세 종료·선택 행·각 창 시작 행·경과 시간을 연결 원장에 기록한다. 별도 시간 검색과 가격 비율의 로그 계산으로 모든 입력을 대조한다. 모든 기간·월의 행동별 all/quiet/recent/first/restart 지원과 입력 분포를 보존한다. 서로 다른 시세 지연·누락, 동시각 포함과 미래 제외, 방향 반전, 가격 단위 변경 불변, 미래 가격 변경의 과거 불변을 검사한다. 이는 예측력·계좌 수익성 검증이 아니다.

## 동일 조건의 관리 모델 비교

첫 단계가 원본 전체 행에서 통과한 경우에만 두 번째 단계를 진행한다. 50개 기존 입력과 위 입력 10개의 총 60개로 2020년 quiet의 행동별 깊이 2·256회 부스팅 두 개와 선형 두 개(C=0.1, 최대 반복 2,000, random_state=0)를 학습한다. 선형 표준화는 학습 행만 사용한다. 상반기 전체 quiet 절편·문턱·빈도 상수 후 최초/재시작별 절편·문턱을 적용하는 기존 v127 절차와 용량을 유지한다.

기존 청산·recent·native/capacity 점수와 요청은 정확히 보존한다. 새 원시·보정·선형·빈도·문턱만 변경한 대조, 모든 상태·월과 v134의 0/1/2/3/4/5/>5 횟수 구간을 기록한다. 제한 전 재시작 추가는 원본 `adds < 5` 행에서 지표를 직접 계산하며 구간 평균으로 대체하지 않는다. 이 상태가 봇 자체 상태 또는 모든 실행 조건을 통과한 상태라는 뜻은 아니다.

후속 자체 계좌 연구의 조건은 v135와 같은 40개다. 기존 v130의 35개 예측·요청·보존 조건, 두 행동의 v127 대비 quiet 로그 손실 1% 초과 개선 두 조건, 제한 전 재시작 추가의 재현율·F 엄격 개선과 정밀도 보존 세 조건을 유지한다. 허용 오차는 1e-12다. 새 입력을 보고 문턱·모델·조건을 고르지 않는다. 기존 모델과 새 512개 트리·두 선형의 별도 재적합, 전체 확률·요청·보정·판정·구간을 독립 검산한다.

## 해석과 후속 실행

모든 연구 기간은 이미 관찰했다. 원본 행동 예측의 개선과 비용을 차감한 실행 수익을 구분하고 미달과 기존 실패를 보존한다. 40개 조건을 통과하면 별도 자체 계좌 계획에서 같은 시각의 공개 BTC·ETH 문맥을 연결한다. 원본의 미래 포지션이나 실제 거래자의 후속 주문은 실행 입력에 사용하지 않는다. 봇 추가 한도 5회와 기존 위험 제한을 유지하며 최종 수익성은 v10의 다년·다시장·비용·펀딩·지연·낙폭·표본·집중 기준을 따른다. 원본·파생 입력·모델·개별 결과는 로컬에만 두며 실제 거래 연결은 없다.
