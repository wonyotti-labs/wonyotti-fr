# 실험 v138 사전 계획: 같은 상반기 오신호 한도의 적중 비교

2026-10-12. v137은 한도 전 재시작 추가에서 하반기 TP/FP/FN을 0/1/35에서 1/18/34로 바꿨지만 24/40개 조건만 통과했다. 상반기에는 같은 집단의 FP가 기존 15분에서 후보 141분으로 늘었다. 적중 증가가 점수의 구분 능력인지 요청량 확대의 결과인지 분리하기 위해 고정 모형의 문턱만 진단한다. 새 모델·자체 계좌를 학습 또는 실행하지 않으며 기존 실패를 변경하지 않는다. 직전 턴은 실제 조건부 학습·독립 검산·공개·푸시를 완료한 진행이다.

## 출처와 범위

v137 완료 증거에서 원본 교사·v127 기준·v134 횟수 원장·v137 모델 및 예측의 봉인을 확인한다. 원본 1,018,460행·기존 50개 입력·정답·시간·포지션 경계를 보존하고 원본 사건에서 횟수와 한도 전후 분기를 다시 확인한다. 기존 숫자 모형·절편·문턱에서 v127과 v137 전체 확률·요청을 재구성하며 별도 트리 순회·선형 계산·상태 보정으로 대조한다. 원래 모든 지표와 실패 판정을 보존한다.

행동 축소/추가 × 상태 quiet/first/restart × 횟수 all/below/capped의 18개 집단을 고정한다. below는 판단 이전 추가 5회 미만, capped는 5회 이상이다. all도 각 상태 안에서 정의한다. 상태와 all/부분 집단은 겹치므로 서로의 행·포지션 수를 더하지 않는다. 원본 recent 및 청산은 수정하지 않는다.

이전 v129는 전체 최초/재시작에서 고정 상위 비율과 포지션 집중을 조사했다. 이번에는 v137 후보·한도 전후를 포함하고, 상반기 v127의 실제 저장 요청이 만든 FP 수 하나를 각 집단의 공통 한도로 사용한다. 여러 예산 중 좋은 결과를 고르지 않는다.

## 상반기에서만 고정하는 문턱

각 집단의 상반기 정답이 0이고 원래 v127 요청이 True인 행 수를 정수 예산 B로 정한다. 같은 집단의 v127·v137 상태 보정 트리 점수 각각에 아래 규칙을 적용한다. 기존 저장 요청도 별도 대조로 남긴다.

- 상반기 음성 수가 B 이하이면 문턱은 0이다.
- 그렇지 않으면 음성 점수를 내림차순으로 정렬한 B+1번째 값 q를 구하고 문턱을 nextafter(q, +∞)로 고정한다. 요청은 점수 >= 문턱이다. 같은 점수의 음성을 일부만 선택하지 않으며, 동점 때문에 실제 FP가 B보다 적을 수 있다.
- q가 1이면 문턱은 1 바로 다음의 유한 부동소수점 값이다. 이는 점수가 [0,1]인 모든 행에서 요청이 없는 명시적 경우다. 1로 잘라 동점 행을 다시 포함하지 않는다.
- 이 규칙은 해당 상반기 음성 한도를 넘지 않는 가장 낮은 표현 가능한 문턱이다. 양성 적중 수·하반기 정답·월별 성적·손익으로 문턱을 선택하지 않는다.
- 상반기에 집단 행이 없으면 문턱 없음 상태로 남긴다. 이후 해당 집단의 행이 생겨도 다른 집단의 문턱을 빌리지 않는다. 그 행 수와 미지원 상태를 보고하며 가상의 0점 요청 성적으로 대체하지 않는다. 월별로는 이미 고정한 집단 문턱을 그대로 사용한다.

한도 전 재시작 추가의 B는 기존 상반기 FP 15분이다. 이는 실제 주문 수·거래비용 예산이 아니다. 같은 상반기 FP 한도라도 하반기의 요청·FP·FPR이 같아진다는 보장은 없으며 그 차이를 결과에 명시한다. 두 모델 모두 같은 규칙으로 문턱을 다시 구하므로 v127의 기존 문턱·요청과도 달라질 수 있다.

## 진단 출력과 독립 검산

각 집단·모델의 B, 상반기 행·양성·음성·포지션·양성 포지션, q·동점 수·고정 문턱·실제 FP·남은 예산을 기록한다. 모든 학습/보정/진단 기간과 24개월에 기존 요청/공통 한도 요청의 TP/FP/FN·요청 수·정밀도·재현율·F·FPR 및 직접 점수 지표를 남긴다. F는 축소 β=1·추가 β=0.5다. 확률 자체는 바꾸지 않으므로 같은 집단의 로그 손실·평균 정밀도·Brier는 원래 점수와 같아야 한다.

기존 요청과 새 문턱 요청의 교집합·추가·제거를 TP/FP로 나눠 직접 계산한다. 한도 전 재시작 추가는 47,962행·양성 35분의 전체와 6개월을 빠짐없이 보존한다. 새로 검출된 한 분이 유지되는지도 로컬 행 대조로 확인하되 개인 시각·포지션·개별 원장은 공개하지 않는다. 평균 정밀도·F는 구간 평균으로 대체하지 않고 빈 집단·양성 0개·0 요청도 보존한다.

본 계산의 정렬 순서통계량과 별도 음성 점수별 빈도표·누적 수 계산을 대조한다. 선택 문턱에서 FP가 B 이하이고 바로 이전 표현 가능 값에서는 한도를 초과하는지 확인한다(0 문턱은 별도 경계). 양성 점수나 정답을 이용해 후보를 고르지 않았는지와 모든 집단·월의 요청·혼동·교집합·지원·점수 불변을 독립 검산한다. 상반기 음성 분류를 바꾸면 문턱이 달라질 수 있으므로 보정 정답 사용 사실을 숨기지 않는다.

합성 검사는 예산 0·전체 음성 수, 동점, 점수 0/1 및 바로 인접한 부동소수점, 빈 보정 집단과 미래 신규 집단, 양성·음성 0개, 손상 시각·문맥·확률·요청·문턱을 포함한다. 하반기 정답 변경 시 모든 문턱과 요청이 불변이고, 상반기 양성 행의 점수만 바꿔도 문턱이 불변인지 검사한다. 정렬이 원본 행 순서를 변경하지 않아야 한다.

입력·코드·계획 지문의 실행 전후 불변과 저장 후 재읽기를 확인한다. 공개 집계를 원래 JSON과 별도로 대조한다. 원본·모형·파생·개별 결과는 로컬 전용이며 코드·방법·집계만 작업별 명사형 커밋 직후 푸시한다.
