# 실험 v118 사전 계획: 기존 계좌의 진입 대기와 보유 시간 분해

2026-10-12. v117의 체결 방향 확장은 예측 기준에 미달했다. v115의 다섯 계좌를 읽은 설명 집계에서 최근 BTC는 333회 대기를 시작해 8회 진입했고, 393,120분 중 387,886분의 종료 시점에 보유 상태였다. 진입 신호 부족·가격 대기·장기 보유를 구별하기 위해 기존 경로를 상세 검산한다. 이 숫자는 이미 관찰한 사후 집계이며 새 정책 성과가 아니다.

## 고정 출처와 범위

v115 완료 검산 JSON의 신뢰한 SHA-256부터 원래 참조·선택·시세 지문과 다섯 계좌의 파일 봉인을 확인한다. BTC 2021년·2022년·2023~2025년·2026년 1~9월과 ETH 2023~2025년을 모두 포함한다. 새 모델·문턱·보유 한도·수량·시세·계좌 실행은 추가하지 않는다. 기존 v48 기반 반복 관리 변경의 결과와 v115 실패 판정을 유지한다.

기존 분별 잔고·정책 사건 및 상태·진입 체결·종료 거래를 읽는다. 저장한 동일 1분 시세와 연결해 `armed → waiting → triggered / expired / cleared`의 대기 원장을 재구성한다. 관리 상태 초기화의 `cleared`는 진입 대기 취소와 구분한다. 신호 시각·방향·참조 가격·5분 만료·16bp 조건과 다음 거래 가능 시가의 진입 연결을 검산한다. 실제 체결이 없는 트리거와 모든 만료·취소를 보존하며, 실행 거부 원인을 입증할 상태가 부족하면 추정하지 않는다.

## 보유와 대기의 독립 대조

1. 전체·무포지션·보유 분말 수, 일별 및 영구 중지, 무포지션 정책 사건 수를 구한다. 일별 중지와 보유의 집계는 중복 가능한 설명 지표이며 더해서 전체라고 표시하지 않는다.
2. 모든 거래의 진입·종료 시각과 종료 이유로 보유 구간을 별도로 만든다. 시가 청산과 분말 손절·최종 종료의 순서를 구분해 원래 분말 보유 방향 전부와 일치해야 한다. 거래별 보유 분과 날짜 차이를 대조하며 부분 축소를 새로운 독립 거래로 세지 않는다.
3. 대기 시작·종료 대응, 방향·가격·만료·16bp, 실제 진입의 양방향 연결을 별도 시간 검색과 수식으로 검산한다. 저장 원장은 모든 시작을 한 번씩 포함해야 한다. 취소·미체결을 제거하지 않는다.
4. 모든 UTC 월에 분말 보유·무포지션·정책 사건과 대기 결과를 기록한다. 분봉 시작 월로 집계하며 대기는 시작 판단이 발생한 분봉의 시작 월에 배정한다. 다른 달로 이어진 보유·대기는 원래 시각을 보존한다.

별도 순차 집계로 전체·월별 수와 정책 사건을 대조하고, 원본 파일·기존 코드 및 사전 계획의 실행 전후 지문을 확인한다. 합성 사례는 같은 분의 진입·손절, 시가 청산, 부분 수량, 월 경계, 정상 대기·만료·취소·관리 초기화·거래 없는 분 및 잘못된 연결을 포함한다.

## 해석 제한과 후속

고정 경로에서 대기 시간이 적다는 사실만으로 즉시 진입의 성과를 계산하지 않는다. 진입가가 바뀌면 손절·관리·재진입·수익 경로도 달라진다. 긴 보유를 자르거나 거래 수를 늘리면 개선된다고 가정하지 않으며, 수익성 기준을 맞추려고 보유 한도나 진입 문턱을 조정하지 않는다.

검산 결과로 실제 신호 부족·대기 미충족·보유 중 신규 진입 차단의 역할을 구분한 뒤 다음 후보를 별도 계획으로 정한다. v10의 다년·다시장·비용·펀딩·지연·낙폭·표본·집중 기준과 수익성 미해결 상태를 유지한다. 원본·시세·개별 원장·모델은 로컬에만 보존하고 실제 거래 연결은 없다.
