# 실험 v99 사전 계획: 노출 변경량의 회계 원인 분해

2026-10-11. v98의 변경량에는 주문 없이도 생기는 가격·펀딩·비용 효과가 섞여 있다. 이를 그대로 다음 주문 목표에 더하면 실제 매매 행동과 다른 정답을 학습할 수 있다. 이번에는 새 모형이나 수익률을 먼저 비교하지 않고, 원본의 노출 변화 중 어느 부분이 체결과 관련되는지 전체 행에서 분해한다. 분해 결과를 확인하기 전에 새 학습·문턱·후보를 선택하지 않는다.

## 고정 입력과 시간 경계

v96의 검산된 전체 체결·지갑·16개 계약 승수·가격, v97의 전체 현재·다음 정답, v98의 현재와 다음이 모두 지원되는 행을 연결한다. 2020년 학습 행과 2021년 진단 행을 유지하고 새로운 수익성 표본으로 부르지 않는다. 현재 경계 이전 체결만 현재 상태에 포함하며, 변경 사건은 `[현재 경계, 다음 경계)`로 구분한다. 입출금 날짜 확장 1일과 ±1% 가격 민감도의 기존 지원 규칙을 유지한다.

각 경계에 보유한 전체 계약 수량과 체결 원가를 정수 사토시로 복원한다. 가격·노출 비율은 Decimal로 계산한다. 현재 보유 계약을 다음 가격으로 평가하는 데 필요한 가격이 없거나 실제 거래가 없는 봉이면 미지원 사유를 추가한다. 해당 행과 기존 숫자는 보존하고 임의 가격 이월이나 0으로 채우지 않는다. 원자료나 이전 정답을 수정하지 않는다.

## 고정 분해 순서

노출 비율 `b = BTC 부분 민감도 / BTC 평가액`을 다음 순서로 평가한다. 각 기여분은 직전 단계와의 비율 차이다.

1. 현재 계좌·현재 확정 가격의 원래 비율.
2. 수량과 현금 성분을 그대로 두고 다음 확정 가격으로 평가한 비율: 가격 변화.
3. 해당 구간에 확정된 외부 입출금만 반영한 비율: 외부 자금.
4. 펀딩 기장액만 반영한 비율: 펀딩.
5. Trade·Settlement 수수료만 반영한 비율: 거래 비용.
6. Trade·Settlement의 원가·수량 변화를 반영한 비율: 체결·정산.

최종 비율은 기존 다음 정답과 일치해야 하며 기여분 합은 기존 변경량과 일치해야 한다. 중간 단계 평가액이 0 이하이면 해당 단계의 비율을 만들지 않고 이유를 남긴다. 비율의 분모가 변하므로 이 분해는 순서에 의존한다. 고정 순서의 회계 설명이며 유일한 인과 효과나 순수 주문 의도라고 부르지 않는다. 체결·정산 항에는 체결 가격과 말기 가격 차이 및 다른 자산의 거래도 반영된다.

## 기록할 결과와 독립 검산

전체·월별 지원 수, 거래·정산·펀딩·외부 자금 사건 수, 사건 없는 창의 비율, 기존 변경량과 다섯 기여분의 평균·MAE·RMS·분위수·공분산을 남긴다. 공분산 때문에 제곱 기여분을 합이 100%인 설명 비중으로 표시하지 않는다. 체결·정산이 없는 창의 해당 기여분이 0인지 검사한다. 어느 방향의 손실·이익도 사후 제거하지 않는다.

별도 계산에서는 현금과 계약별 수량·원가를 이용해 동일한 중간 계좌를 평가한다. 전체 지원 행의 초기·최종 정답과 각 단계·합계 잔차를 대조한다. 경계 시각에 정확히 일어난 사건, 만기 정산, 반전, 비용·펀딩 부호, 외부 자금 불확실성, 무거래 가격, 중간 평가액 비양수, 미래 사건 변경 불변을 합성 자료로 검사한다. 기존 원본·이전 결과·진행 중 공유 소스의 해시를 확인한다.

이번 범위에서는 매매 후보 채택·새 모형 학습·새 수익률 검증을 하지 않는다. 분해 결과를 근거로 다음 정답·학습의 변경 여부를 별도 사전 계획으로 고정한다. v10 수익성 기준, v98의 여섯 실패·대조 경로, 기존 모든 관찰 이력을 보존하며 전체 문제 해결 goal을 유지한다. 실제 거래 연결은 없다.
