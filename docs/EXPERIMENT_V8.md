# 실험 v8 사전 계획: 실행 순손익에 맞춘 진입 필터

2026-10-03. v1~v7과 2026년 9월까지의 결과를 이미 관찰했다. 새 미사용 평가 자료는 없다. 원본·고정 후보·실패 결과는 보존하며 실제 주문·인증·출금은 연결하지 않는다.

## 진단과 가설

v5는 원거래소에서 관측된 노출 확대 창의 종가 간 로그 가격 변화를 학습했다. 봇의 다음 시가 진입·슬리피지·가격 경로에 따른 손절·공식 펀딩과 다른 목표다. v7은 진입 가격이 유리해졌지만 순손실을 피하지 못했다. 이번 가설은 원본에서 학습한 신호가 제시한 진입 기회 중, 실제 실행 방식으로 계산한 기대 순손익이 부족한 기회를 과거 정보로 거르는 것이다. 원자료의 손실 거래를 삭제하거나 실제 원전략이라고 주장하지 않는다.

## 고정 기반과 학습 자료

- 기존 v7 후보 2의 활동·방향 모형, 16bp 대기, 5분 만료, 30분 최대 보유를 고정한다. 원본 모형은 2018~2019년 학습, 기반 후보 선택은 이미 관찰한 2020년이었다. 재학습하지 않는다.
- 실행 시장은 기존에 대조한 Binance BTCUSDT 1분 시세·펀딩과 확정 5분 특징이다. 비용 필터 학습은 2020년, 네 후보 선택은 2021년, 고정 후 확인은 2022년 BTC다. 기존 v7 선택 구간과 필터 학습 구간이 겹치므로 독립적인 기초 전략 발견으로 해석하지 않는다.
- 포트폴리오가 비어 있다고 가정한 각 5분 신호의 대기를 독립적으로 관찰한다. 신호 이후 5분 내 처음 확정된 유리한 종가만 기회로 삼는다. 대기 만료와 특징 부재·경계 부족의 건수를 기록한다. 실제 연속 봇의 보유·재진입 대기로 실행하지 못할 기회도 포함하므로 표본과 실제 거래 수를 구분한다.
- 각 기회에 대해 다음 1분 시가에서 독립 자본 10,000 USDT·첫 노출 25%로 진입하는 같은 `TradingEngine`을 실행한다. 편도 수수료 5bp·슬리피지 3bp, 4% 손절, 최대 30분, 일별 3%·누적 25% 중지와 실제 펀딩을 적용한다. 정답은 실제 진입 명목금액 대비 순손익 bp다. 수익·손실 모두 보존한다.
- 정답의 31개 실행 봉 전체가 존재해야 하며 마지막 학습일은 24시간 비운다. 동일 기회의 시점별 종가 변화와 실행 순손익을 나란히 기록하되 종가 변화는 비교용이다. 정답용 미래 가격은 모델 특징에 넣지 않는다.
- 독립 거래의 일별·누적 위험 기준은 매 기회 초기화된다. 연속 포트폴리오의 계좌 상태를 완전히 예측하는 목표는 아니며 실제 검증에서는 기존 연속 위험 한도를 그대로 적용한다.

## 네 후보와 선택 기준

기존 시장 특징 14개, 방향을 곱한 14개, 방향 1개, 조건 충족 시 유리한 가격 변화 bp와 대기 분 2개를 사용한다. 모든 값은 진입 판단 시점에 이미 확정돼야 한다. 표준화는 학습 자료만 사용한다. 숫자 JSON으로 내보낸 ridge 회귀(alpha 10 또는 100)가 예측한 순손익이 0 또는 8bp 이상일 때 진입한다. 후보는 총 네 개며 예측치에 수수료를 중복 차감하지 않는다.

학습 기회 200개 이상, 양 방향 각각 20개 이상, 기회 시각 범위 180일 이상을 요구한다. 이는 수익성이나 독립 표본 수의 증명이 아니다. 조건 미달 시 기준을 낮추지 않고 중단 기록을 남긴다. 대기 조건 충족 시 필터에서 거부하면 그 대기를 종료하며 나중의 유리한 가격을 다시 골라 같은 기회를 재판정하지 않는다. 필터를 끄면 v7과 동일한 상태·체결이 나와야 한다.

2021년 BTC에서 종료 거래 20개 이상인 후보 중 `순수익 - 0.5 × 최대낙폭 절댓값`이 최대인 후보를 선택한다. 동점은 앞선 후보로 고정한다. 적격 후보가 없으면 선택하지 않는다. 선택 후 2022년 BTC에서 양수·20거래 이상·영구 중지 없음 여부를 별도 보고한다. 실패해도 이미 관찰한 다른 기간의 고정 탐색 비교는 가능하며 수익성 승인으로 취급하지 않는다.

## 고정 후 비교와 검증

1. 2023~2025년 및 2026년 1~9월 BTC·ETH·SOL에 같은 후보를 적용한다. 필터 없는 v7·현금·비용 2배·비용 3배·추가 1분 지연을 비교한다. 2023·2024·2025년의 자본 초기화도 별도로 실행한다.
2. 미래 시세 변경 시 과거 기회·특징 불변, 학습 경계와 겹친 정답 제거, 순손익 목표와 실제 엔진의 진입·손절·펀딩 일치, 모델 내보내기·비정상 입력 거부를 검사한다. 거절 신호·승인 신호·기존 대기·실제 진입 연결을 모두 보존한다.
3. 순손익·회계·수수료·펀딩·회전율·보유 시간·표본 수와 30일 블록 1,000회(seed 41) 조건부 구간을 기록한다. 겹치는 기회, 기존 후보 선택 및 이미 관찰한 기간의 불확실성은 별개다.
4. 같은 정책을 영속 오프라인 봇에 연결하고 대기·보유 상태의 실제 프로세스 종료와 한 달 중단·복원을 확인한다. 고정 후보가 해당 상태를 만들지 못하면 검증 미충족으로 기록하고 설정을 바꿔 성공으로 표시하지 않는다.
5. BTC 미연결 10건의 한계·기존 복원 근거·무거래 구간 검사와 실패 기록을 유지한다. 원자료·시장 자료·모델·실행별 결과는 로컬에만 저장한다. 작업별 한글 명사형 커밋 직후 푸시한다.
