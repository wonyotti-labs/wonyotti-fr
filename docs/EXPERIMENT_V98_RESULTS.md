이 진단은 매 시점 현재 원본 상태를 공급한 결과다. 아래 연속 실행에서는 해당 상태를 공급하지 않았으며, 초기 자본 10,000 USDT·포지션 0부터 봇 자신의 수량과 평가액만 사용했다. 예측 지표가 약하다는 이유로 여섯 경로를 생략하거나 대조 모형으로 후보를 교체하지 않았다.

## 검증과 남은 작업

변경량 학습 검사 15개와 별도 실행 검사 71개를 통과했다. 변경량 정답·독립 재학습·숫자 트리·월별 예측 지표를 대조했다. 매매 여섯 경로의 총 3,153,600분에 대해 독립 정책 계산, 이분 탐색 목표 수량, 현금 흐름 손익, 모든 체결·종료 거래·위험·요약 지표를 비교했다. 각 실제 실행 중 두 번 JSON 상태를 저장·복원했으며 독립 계산기는 최초 자본부터 중간 상태 주입 없이 재생했다. 무거래 대기·지연·출력 변조 탐지도 검사했다.

시세·펀딩·확정 특징은 검산 때 원래 입력에서 다시 읽어 전체 행을 대조했다. 원본 5개·운영 소스 245개·v93 검산 도구 24개는 그대로 유지했다. 별도 준비 구현의 실제 결과이며 운영 등록과 동일 결과 재현은 남아 있다. 실거래 연결은 없고, 이전 실패와 손실·입력 해시는 로컬에 유지한다. 수익성 문제 해결 goal은 계속 진행 중이다.
