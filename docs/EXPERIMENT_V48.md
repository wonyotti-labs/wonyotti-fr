# 실험 v48 사전 계획: 직접 청산 문턱의 자체 상태 실행

2026-10-04. v47의 원본 상태 진단은 청산 가산 제거 시 재현율·F2 개선과 다른 행동 요청 보존을 확인했다. 정밀도 하락과 적은 적중 수를 보존하며, 봇 자신의 상태에서 청산·후속 진입·순손익이 어떻게 달라지는지 별도로 검증한다. v46의 표본 부족·연도 손실·장기 최대 거래 집중 실패는 그대로 유지한다.

## 단일 변경

- 직접 기준은 v46이다. 관리 청산 문턱의 배율만 1.5에서 1.0으로 변경한다. v47에 보존된 상반기 선택값과 모델을 그대로 사용하고 새 학습·후보 탐색은 없다.
- 첫 추가·축소와 반복 관리 문턱, 실제 체결 이력, 축소 크기, 관리 우선순위·대기, 방향·진입 가격 대기, 최대 보유, 최초·추가 수량, 손절·손실 중지·비용·펀딩은 유지한다.
- v47 진단의 계획 지문·입력·모델·문턱·전체 통과 근거와 직접 부모 v46을 연결한다. 청산 외 변경은 거부한다. 원본 미래 상태를 실행 입력으로 사용하지 않는다.

## 실행과 사전 판정

2021년 후보와 원래 v46을 실행하며 원래 정책의 전체 출력·최종 상태 일치를 확인한다. 이후 2022년 순수익 양수·종료 거래 30개 이상·영구 중지 없음 조건을 적용한다. 실패하면 BTC 두 후속 기간·독립 세 연도만 진단해 총 여덟 실행을 보존한다.

통과하면 두 후속 기간·세 시장에 기본 여덟 조건과 원래 위험의 v14·v40·v46을 추가한 열한 조건을 적용하고 아홉 독립 연도를 비교한다. 총 78개 실행이다. 기본 조건은 후보·원래 v7·현금·추가 제거·30분 제한·비용 2배·3배·추가 1분 지연이다. v39 단독 대조는 이번 범위에서 제외하며 기존 결과는 보존한다.

기존 수익성 기준을 유지한다. BTC 두 후속 구간의 비용 반영 양수·각 30거래 이상·영구 중지 없음·비용 2배 양수와 두 독립 연도 이상의 양수를 요구한다. 다른 시장·비용 3배·지연·최대 거래 집중·불확실성을 함께 보고한다. 문턱 변경 후 거래 수가 늘었다는 이유로 성공을 선언하거나 기준을 낮추지 않는다.

## 구현 검증과 한계

기존 가산 문턱 사이의 청산 요청과 그 밖의 동일 판단, 첫·반복 추가·축소, 청산 우선순위와 지연·무거래 체결 대기·수수료·펀딩·보유 제한을 검사한다. 실제 청산 이후 새 진입·이력 초기화, 실제 프로세스 종료와 월간 재개, 원래 정책 대조·모든 후보의 실제 체결 이력과 회계를 확인한다.

모든 기간은 이미 관찰했으므로 새 미사용 검증으로 표시하지 않는다. 원본·파생 자료·개별 실행은 로컬에만 보존하며 실거래 연결은 없다. 원본 예측 개선과 봇 수익성은 서로 다른 판정이다.
