# 실험 v51 사전 계획: 청산 판단의 시간 범위 학습

2026-10-04. v50의 확인 구간은 양수지만 거래 수 기준에 미달했다. 청산 요청이 드물고 손절·시간 제한에 의존하는 문제가 남았다. 기존 시각 허용 폭 진단은 고정 점수를 넓어진 정답과 비교했으며 넓은 범위를 직접 학습하지 않았다. 이번에는 같은 원본 포지션에서 앞으로 15분 안에 기존 청산 사건이 있는지를 단일 목표로 학습한다. 15분은 기존 주문 이력의 시간 범위와 같게 고정하며 다른 범위·손익 탐색은 없다.

## 정답과 시간 경계

- 기존 1분 청산 정답의 의미를 유지한다. 경계 t의 정답은 같은 포지션의 기존 양성 경계가 [t, t+15분)에 하나 이상 있는지다. 중복 양성 분을 독립 포지션 수로 세지 않는다. 원래 정답·미래 사건 연결을 별도 원장에 보존한다.
- 원래 50개 특징·포지션·입력 값은 유지한다. 미래 사건은 정답과 검증 원장에만 쓰고 특징에 넣지 않는다. 전체 원본에서 정답을 만든 뒤 관찰 종료와 15분 정답 종료 경계를 반영한다.
- 기존 v35의 2020년 학습·2021년 상반기 보정·하반기 진단, 24시간 간격과 경계를 넘는 포지션 배제를 유지한다. 연장한 정답 때문에 제외된 행은 사유와 함께 보존한다. 원래 보존 행의 모든 특징과 비청산 정답이 같아야 한다.

## 학습과 사전 판정

동일한 무가중치 히스토그램 부스팅 설정으로 청산만 학습한다. 상반기 절편 보정은 기존 기울기 1·경계 확률·100회 이분법을 따른다. 기존 v35 청산 점수도 같은 상반기 15분 정답에 절편만 다시 보정해 공정한 기준으로 삼는다. 상수는 같은 상반기 양성 비율이다. 추가·축소 모델, 실행 정책과 위험은 바꾸지 않는다.

하반기에서 후보의 보정 로그 손실이 재보정 기준보다 1% 초과 개선되고, 평균 정밀도가 낮아지지 않으며, 상수와 자체 보정 전 로그 손실보다 나쁘지 않아야 한다. 상반기에서 각각 고른 F2 문턱(예측 양성 최소 20개)을 하반기에 고정 적용해 후보 F2와 사건별 포착률도 기준 이상이어야 한다. 사건 포착률은 지원하는 각 원래 양성 경계를 이전 15분 이내의 같은 포지션 요청으로 포착했는지 별도로 계산한다. 서로 겹치는 양성 분 수 증가만으로 통과하지 않는다.

모든 조건 통과 시에만 별도 사전 계획으로 자체 상태 매매 후보를 만든다. 이번 단계는 원본 상태 예측 진단이며 봇 순손익 평가가 아니다. 하반기는 이미 여러 실험에서 관찰한 기간이며 새 미사용 증거로 표현하지 않는다. 독립 정답 연결·재학습·절편·문턱·지표, 미래 자료 변경 시 학습 불변과 원본 보존을 확인한다. 실패한 시도와 개별 결과는 로컬에 남기고 실제 주문 연결은 없다.
