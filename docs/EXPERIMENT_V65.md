## 정답 변환과 보존하는 손실

v64 전체 결과를 원장 검증부터 다시 생성해 대조한다. 같은 56개 현재 입력·학습 및 진단 행·정답·시간 경계·원래 포지션 가중치·배제 원장을 유지한다. 현재 노출 e는 기존 입력인 절대 보유 수량 곱하기 현재 종가를 현재 순자산으로 나눈 값이다. 미래 가격·노출·종료 손익으로 계산하지 않는다.

원래 계좌 기준 청산 순효과 y를 e로 나눈 값 z를 학습한다. 모델의 계좌 기준 예측은 현재 e와 단위 노출 예측 f의 곱이다. 원래 포지션 가중치 w를 곱한 제곱 오차는 `w * (y - e*f)^2 = w * e^2 * (z - f)^2`와 같다. 따라서 학습 가중치는 `w * e^2`를 앞 학습 안에서 평균 1로 정규화한다. 전체 손실에 공통 상수가 곱해질 뿐 원래 계좌 기준 각 행의 상대 오차 비중은 같다. 개별 포지션 가중치가 그대로인 것처럼 주장하지 않고 원래 가중치와 변환 가중치를 둘 다 저장한다. 진단 지표에는 원래 w와 원래 y를 사용한다.

0·음수·비유한 노출, 변환 중 넘침·가중치 소실은 거부한다. 임의 최솟값·클리핑·좋은 표본 선택을 사용하지 않는다. 진단 자료로 정규화하거나 계수를 보정하지 않는다. 모든 손실·미확정·경계 제외를 보존한다.
