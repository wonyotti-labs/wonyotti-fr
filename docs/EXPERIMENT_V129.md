# 실험 v129 사전 계획: 관리 행동의 점수 순위와 문턱 이동 진단

2026-10-12. v128의 상태별 모델은 추가 재시작의 하반기 양성 123개 분을 하나도 맞히지 못했고 오신호는 늘었다. 다음 학습 설정을 고르기 전에, 기존 문턱의 이동과 점수의 구분 능력을 분리해 조사한다. 새 모형·운용 문턱·매매 정책을 선택하지 않는 진단이다. 이전 턴은 v128 실제 실행 종료 확인·결과 검산·공개·커밋·푸시를 완료한 진행으로 분류한다.

## 고정 입력과 범위

- 봉인된 v128과 v127 및 그 원본 교사·native 출처를 확인한다. 2020년 학습·2021년 상반기 보정·하반기 진단의 기존 1,018,460행과 모든 날짜·포지션·정답·과거 행동 문맥을 보존한다. 이미 관찰한 기간이다.
- 축소·추가 각각 first와 restart를 진단한다. first는 해당 행동 과거 이력이 없는 상태, restart는 이력이 있지만 `[t−15분,t)`의 해당 독립 첫 체결이 없는 상태다. 청산·recent의 변경은 없으며 이번 진단의 대상에 포함하지 않는다.
- 모델은 native 64회, quiet에서 사용하는 capacity 256회, v127 공통 모델+상태별 보정, v128 상태별 개별 모델의 네 개다. 각 모델에 이미 선택된 해당 상태 문턱과 요청을 그대로 사용한다. 자료·모형·문턱을 재적합하지 않는다.
- 단위는 독립 주문 건수·실제 포지션 종료가 아닌 기존 정답의 양성 분이다. 모든 48개 기간×행동×상태×모델 조합과 24개월의 384개 조합을 남긴다. 빈 집단과 양성 0개도 제외하지 않는다.

## 문턱·순위·집중도

1. 기존 문턱의 TP/FP/FN·요청 수와 기존 보고 수치를 대조한다. 전체·양성·음성 점수의 최소, 10/25/50/75/90/99백분위수, 최대를 선형 보간으로 남긴다. 양성 점수 최댓값과 기존 문턱의 관계도 확인한다.
2. 각 양성 분에 대해 같은 기간·상태의 전체 행 중 자신보다 높은 점수 수+1을 순위 시작, 같거나 높은 점수 수를 순위 끝으로 기록한다. 동점의 유리한 순서를 임의로 선택하지 않는다. 음성의 높은 점수 수와 동점 수도 별도로 기록한다. 전체 행의 순위이므로 시간순 실행 가능한 선별 규칙은 아니다.
3. 상반기의 해당 상태·모델 점수만 사용해 상위 0.1%, 0.5%, 1%, 5%에 대응하는 고정 절단점을 정한다. 내림차순 `ceil(행 수×비율)`번째 점수이며 같은 점수는 전부 포함한다. 정답을 이 계산에 사용하지 않는다. 실제 선택 행 수와 동점 초과량을 함께 기록한다. 그 값을 모든 기간과 월에 그대로 적용하고 TP/FP/FN, 기존 요청 대비 추가·제외 TP/FP를 계산한다.
4. 비교를 위해 각 기간·월 자체의 같은 상위 비율도 계산한다. 이는 그 기간 전체의 미래 점수를 사용한 **사후 순위 진단**이다. 운용 가능한 정책·수익·최적 문턱으로 해석하거나 봇에 적용하지 않는다. 상반기 고정 절단점과 현재 기간 순위의 차이는 점수 분포 이동의 근거이며, 성능 차이 하나로 원인을 확정하지 않는다.
5. 상태별 포지션 원장에 행 수·양성·TP/FP/FN·요청 수를 기록하고, 양성 및 FP의 상위 1개·3개 포지션 집중도를 계산한다. 포지션별 값은 로컬에만 남긴다. 집중도는 원인 확정이나 사후 포지션 제외에 사용하지 않는다.

## 독립 검산과 판정 범위

본 계산은 정렬·이진 검색으로 순위와 절단점을 구하고, 검산은 점수별 빈도·누적 수와 별도 혼동 집계·분위수 보간으로 수행한다. 원본 문맥·모델 대조·저장 요청과 기존 혼동표, 모든 순위·동점·집중도·기간 및 월별 절단점을 검산한다. 양성·음성 0개, 빈 월, 동점, 문턱 경계, 잘못된 확률·정답·시각·포지션, 원장 손상, 미래 정답 변경 시 상반기 절단점 불변을 검사한다.

실행 전후 코드·계획·입력 지문 및 출력 봉인을 보존한다. 개별 순위·포지션 원장과 원본·모델은 로컬에만 두고 코드·집계 보고만 공개한다. 새 자체 계좌·실거래 연결은 없다. 진단 완료를 수익성 해결로 표시하지 않으며 v10의 다년·다시장·비용·펀딩·지연·낙폭·표본 수 기준을 유지한다.
