# 실험 v2 사전 계획

2026-10-01. v1의 실패와 원자료 분석을 관찰한 상태에서 작성한다. 2022~2025년은 이미 관찰한 탐색·재현 구간이다. 새 후보를 그 기간에 적용한 결과를 독립적인 새 최종 평가로 주장하지 않는다.

## 가설과 자료

원자료의 실제 단위를 독립 주문으로 바꾸고 진입·추가·축소·청산을 나누면 전체 시간의 보유 방향을 모사할 때보다 의사결정을 더 잘 설명할 수 있는지 조사한다. 수익 개선을 보장하는 가설이 아니다.

원거래소의 2018-03~2021-12 공식 5분봉으로 원본 기간 전체의 시장 맥락을 연결한다. 공개 원거래소 캔들의 open은 이전 close이므로 실제 다음 봉 체결 가격으로 사용하지 않는다. 매매 평가는 공식 바이낸스 선물 5분봉과 펀딩을 사용한다. 거래소 차이는 별도 한계로 기록한다.

특징은 확정한 과거 수익률·추세·거래량·변동성과 당시 알려진 포지션 방향·평균 진입가 대비 움직임·보유 시간·추가 진입 횟수다. 손익 결과와 미래 최대 손실을 입력하지 않는다. 원본과 봇의 실제 자본 규모가 다르므로 원본 계약 수를 그대로 베팅 규모로 복제하지 않는다.

정답은 다음 5분 안에 처음 체결된 독립 주문의 의도다. 같은 주문의 후속 부분 체결은 새 판단으로 반복 학습하지 않는다. 최초 체결 행에 기록된 주문 수량과 직전 포지션으로 의도를 분류하고, 향후 실제 체결량이나 최종 손익으로 라벨을 고르지 않는다. 여러 사건이 있는 창과 상태가 맞지 않는 창의 건수·처리 방법을 보고한다.

## 시간 분리와 모델

- 2018~2019년은 초기 학습과 시간순 검증에 사용한다. 경계에 걸친 포지션 에피소드를 제거한다.
- 2020년은 정책·신뢰도·위험 설정 선택에 사용한다. 후보는 최대 12개로 제한하고 실행 전 조합을 파일에 기록한다.
- 2021년은 모사 정확도와 원자료 기간 내의 이후 구간 평가에 사용한다. 시세 특징 해석은 이미 관찰한 점을 명시한다.
- 2022~2025년 BTC·ETH·SOL은 고정 후보의 탐색적 이전 실험과 비교한다.
- 새로운 시장 평가용 2026-01~2026-08 자료는 후보 선택을 고정한 뒤 수집·개봉한다. 이 프로젝트에서 새로 여는 기간이라는 의미이며 모델 선택자의 외부 시장 지식까지 제거한 엄격한 이중맹검은 아니다.

첫 사건별 후보는 설명 가능한 선형 분류기다. 진입과 보유 중 관리를 따로 학습하며 상태와 맞지 않는 주문을 생성하지 않는다. 단순 단기 역추세·추세 기준 및 현금과 비교한다. 모사 신뢰도를 수익 확률로 해석하지 않는다.

## 위험과 채택 기준

총 목표 노출은 자본의 최대 50%로 제한하고 처음에는 그 일부만 진입한다. 추가 진입은 횟수·노출 한도를 두며 불리한 가격에서의 추가 진입 차단을 별도로 비교한다. 다음 봉 실행, 편도 수수료 5bp·슬리피지 3bp, 공식 펀딩을 적용한다. 위험 한도를 갭에서 보장하지 않는다.

개발 후보는 종료 거래 수를 함께 확인하며 수익에서 낙폭 비용을 차감한 기준으로 선택한다. 거래가 없어 우연히 손실이 없는 후보를 우수한 후보로 표시하지 않는다. 모든 후보가 부적격이면 기준을 사후 완화하지 않고 실패로 기록한다.

손절·시간 제한·추가 진입 제한을 제거한 실험, 비용 2~3배, 한 봉 추가 실행 지연, 연도별 초기화와 연속 운용을 구분한다. 새 평가 결과까지 모두 양호해야 수익성 검토 후보가 될 수 있으며 어떤 경우에도 실거래 자동 승인을 의미하지 않는다.

## 실행 검증

같은 엔진을 메모리 백테스트와 영속 저널 재생에 사용한다. 중복 사건은 한 번만 처리하고, 같은 ID의 다른 시세는 거부한다. 주문 의도·포지션·잔고·위험 상태를 같은 트랜잭션에 저장한다. 중단 전후 재생이 전체 실행과 일치하는지 합성 사례와 실제 과거 시세로 검증한다. 수동 중지는 다음 관측 가격에서 청산하고 재진입을 막는다.
