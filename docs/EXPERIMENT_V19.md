# 실험 v19 사전 계획: 잔여 수량과 관리 행동의 의미

2026-10-04. v17의 기회 확대와 v18의 누적 관리 반전도 손실을 해결하지 못했다. v17의 전체 71개 실행 검증을 완료했고, v18의 확인 실패와 후속 BTC 진단을 보존한다. 기존 사전 계획의 복원·종합 검증은 이어서 수행한다.

새 상태 진단에서 원본은 포지션을 크게 줄인 뒤에도 작은 잔량을 유지하는 구간이 있었고, 부분 축소 주문 중에는 당시 보유량의 99% 이상을 요청하는 주문이 있었다. 현재 상태는 수량이 0이 될 때만 보유를 종료하며, 모델에는 현재 수량 / 지금까지 최대 수량이 없다. 봇은 모든 `reduce`를 약 절반 축소로 실행한다. 원본의 작은 잔량 보유와 실제 위험이 큰 보유를 같은 상태로 학습했을 가능성을 확인한다. 잔량이 실제로 무위험이거나 의도상 평탄이었다고 단정하지 않는다.

## A. 성과 모델 이전의 원본 진단

- 회계 원장을 그대로 유지한다. 작은 잔량·손실·펀딩·부분 체결을 삭제하거나 원본 포지션 종료 시각을 덮어쓰지 않는다.
- 과거에 이미 관측한 최대 보유량에 대한 현재 수량 비율을 계산한다. 미래 최대 수량·최종 주문 수량을 과거 상태의 분모로 쓰지 않는다. 분 경계와 같은 시각의 원본 체결은 기존 규칙처럼 다음 상태에서만 반영한다.
- 연도별 잔여 비율 분포, 0.1%·1%·5% 이하에서 보낸 시간, 추가 횟수 상한에 묶인 비율, 실제 마지막 청산 직전의 잔여 비율을 집계한다. 이 구간 구분으로 수익이 좋은 문턱을 고르지 않는다.
- 축소 주문의 요청량 / 최초 체결 직전 보유량, 실제 총 체결량 / 요청량, 부분 체결 시간과 동시 주문 여부를 함께 기록한다. 요청량과 실제 체결량이 다르면 그 차이를 숨기지 않는다.
- 실제 실현 가격 손익을 추가·축소·마지막 청산·반전에 분해한다. 단위는 원본 정산 통화이며 계좌 수익률·실행 가능한 봇 수익으로 바꾸지 않는다. 수수료·펀딩과 열린 포지션 경계는 별도로 남긴다.
- 기존 봇에서 같은 과거 수량 비율·축소 전후를 연결해 차이를 진단한다. 원본과 봇의 단순 조건부 평균 차이를 인과 효과로 부르지 않는다.

## B. 구현·평가 계획의 고정 시점

A의 결과에 따라 수량 상태 추가, 축소 수량 예측, 작은 잔량의 학습 상태 구분 중 필요한 최소 변경을 구체화하고 성과 실행 전에 부록으로 고정한다. 데이터의 상대 잔량과 실제 계좌 위험을 동일시하지 않으며, 과거 실패의 재분류가 손실 제거가 되지 않게 원본 행 추적을 보존한다.

후보·학습·보정 기간·기준 대조·다년 평가 범위·수익성 기준은 부록 고정 후 구현한다. 원본 행동 자체를 알고 재생한 결과로 수익성을 주장하지 않는다. 관찰 기간 재사용과 선택 편향, 미체결 주문·호가 자료의 부재는 계속 기록한다. 실제 주문·인증 연결은 제외한다.

## B 부록: 잔여 수량 입력과 축소 크기 예측

A의 전체 원본·독립 주문·BTC 회계 대조를 완료한 뒤 성과 실행 전에 고정한다. 축소가 실현 가격 손익의 대부분을 차지했고, 축소 요청의 연도별 중앙값과 큰 축소 비중이 달랐다. 큰 축소 요청도 일부만 체결된 경우가 있어 요청량을 전량 체결로 바꾸는 정답은 사용하지 않는다. 작은 잔량 보유는 원본·학습·회계에서 유지한다.

- 기존 35개 관리 특징에 `현재 절대 수량 / 해당 포지션에서 과거 최대 절대 수량` 하나를 추가한다. 미래 최대 수량·원본 계좌 규모·원본 미래 상태는 실행 입력에 넣지 않는다. 초기 진입·반전 때 비율은 1이며 실제 체결된 추가·축소에 따라 갱신한다.
- 원본의 청산·축소·추가 행동 정답은 그대로 유지한다. 관리 모형은 기존 v14 기반과 같은 표준화 로지스틱 C=0.1 단일 모형이다. 2019년~2020년 상반기 학습과 2020년 하반기 빈도 보정을 유지하며 후보 선택이나 재학습 시기 탐색은 없다.
- 축소 크기는 같은 관리 입력으로 독립 회귀한다. 목표는 한 독립 축소 주문의 실제 총 체결량 / 최초 체결 직전 보유량이다. 최초 분 경계의 보유량과 최초 주문 직전 보유량이 같고, 그 분에 연결된 관리 주문이 해당 축소 하나이며, 주문 사이에 다른 주문이 끼지 않은 경우만 크기를 대응시킬 수 있다. 대응 불가 사유와 원본 행을 별도 원장에 남긴다. 해당 사례를 원래 행동 학습이나 손익 회계에서 삭제하지 않는다.
- 크기 정답의 종료 시각은 마지막 실제 체결까지 연장한다. 학습 기간·포지션 경계·마지막 24시간 제거를 이 종료 시각에도 적용한다. 부분 체결이 학습 창 밖으로 이어진 주문을 미리 완료된 정답으로 사용하지 않는다. 크기 모델은 학습 전용 표준화 Ridge alpha 100 하나이며 100개 이상·90일 이상 지원이 필요하다. 손익으로 사례나 가중치를 고르지 않는다.
- 축소 예측은 [0, 1]로 제한한다. 0이면 주문하지 않고, 양수면 판단 시점에 확정한 비율을 주문과 함께 저장한다. 이후 모델 점수가 바뀌어도 대기 주문 비율은 바꾸지 않는다. 추가 지연·무거래 대기·프로세스 종료·위험 중지에서 비율과 의도의 대응을 보존한다. 기존 정책에는 원래 고정 축소 비율을 계속 적용한다.
- 원래 여러 부분 체결의 총량을 봇은 다음 거래 가능 분봉의 시장가 가정으로 실행한다. 실제 지정가 대기열·체결 기간 복제는 아니며 비용·추가 지연 대조와 이 근사를 함께 보고한다. 원본의 마지막 잔량 보유를 자동으로 없애는 별도 규칙은 없다.

주 후보는 새 수량 입력과 예측 축소 크기를 함께 사용한다. 수량 입력만 추가하고 원래 고정 축소 비율을 쓰는 정책을 대조로 보존하며 성과를 보고 주 후보를 바꾸지 않는다. 모델 청산은 원래 v14처럼 평탄 청산이고, v18 반전과 v17의 확장 진입·순손익 필터는 적용하지 않는다. 최초 진입·추가 한도·손절·일별 및 누적 손실 한도·비용은 원래 v14와 같다.

2021년은 이미 기반 관리 선택에 사용한 개발 구간이다. 두 정책의 개발 결과와 주 후보의 2022년 확인을 기록한다. 확인 양수·30거래·중지 없음 실패 시 주 후보의 BTC 두 후속 기간·세 연도만 진단한다. 통과 시 세 시장·두 기간·열 조건(주 후보, 원래 v7, 현금, 추가 제거, 30분 제한, 비용 2배·3배, 추가 1분 지연, 원래 v14, 새 수량 입력의 고정 축소 대조)과 아홉 독립 연도를 평가한다. v10의 수익성 기준과 원본 보존·실제 중단 복원 검증을 유지한다. 반복 관찰·가설 선택 편향과 크기 학습의 지원 표본 제한을 보고한다.
