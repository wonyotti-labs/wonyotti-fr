# 실험 v19 사전 계획: 잔여 수량과 관리 행동의 의미

2026-10-04. v17의 기회 확대와 v18의 누적 관리 반전도 손실을 해결하지 못했다. v17의 전체 71개 실행 검증을 완료했고, v18의 확인 실패와 후속 BTC 진단을 보존한다. 기존 사전 계획의 복원·종합 검증은 이어서 수행한다.

새 상태 진단에서 원본은 포지션을 크게 줄인 뒤에도 작은 잔량을 유지하는 구간이 있었고, 부분 축소 주문 중에는 당시 보유량의 99% 이상을 요청하는 주문이 있었다. 현재 상태는 수량이 0이 될 때만 보유를 종료하며, 모델에는 현재 수량 / 지금까지 최대 수량이 없다. 봇은 모든 `reduce`를 약 절반 축소로 실행한다. 원본의 작은 잔량 보유와 실제 위험이 큰 보유를 같은 상태로 학습했을 가능성을 확인한다. 잔량이 실제로 무위험이거나 의도상 평탄이었다고 단정하지 않는다.

## A. 성과 모델 이전의 원본 진단

- 회계 원장을 그대로 유지한다. 작은 잔량·손실·펀딩·부분 체결을 삭제하거나 원본 포지션 종료 시각을 덮어쓰지 않는다.
- 과거에 이미 관측한 최대 보유량에 대한 현재 수량 비율을 계산한다. 미래 최대 수량·최종 주문 수량을 과거 상태의 분모로 쓰지 않는다. 분 경계와 같은 시각의 원본 체결은 기존 규칙처럼 다음 상태에서만 반영한다.
- 연도별 잔여 비율 분포, 0.1%·1%·5% 이하에서 보낸 시간, 추가 횟수 상한에 묶인 비율, 실제 마지막 청산 직전의 잔여 비율을 집계한다. 이 구간 구분으로 수익이 좋은 문턱을 고르지 않는다.
- 축소 주문의 요청량 / 최초 체결 직전 보유량, 실제 총 체결량 / 요청량, 부분 체결 시간과 동시 주문 여부를 함께 기록한다. 요청량과 실제 체결량이 다르면 그 차이를 숨기지 않는다.
- 실제 실현 가격 손익을 추가·축소·마지막 청산·반전에 분해한다. 단위는 원본 정산 통화이며 계좌 수익률·실행 가능한 봇 수익으로 바꾸지 않는다. 수수료·펀딩과 열린 포지션 경계는 별도로 남긴다.
- 기존 봇에서 같은 과거 수량 비율·축소 전후를 연결해 차이를 진단한다. 원본과 봇의 단순 조건부 평균 차이를 인과 효과로 부르지 않는다.

## B. 구현·평가 계획의 고정 시점

A의 결과에 따라 수량 상태 추가, 축소 수량 예측, 작은 잔량의 학습 상태 구분 중 필요한 최소 변경을 구체화하고 성과 실행 전에 부록으로 고정한다. 데이터의 상대 잔량과 실제 계좌 위험을 동일시하지 않으며, 과거 실패의 재분류가 손실 제거가 되지 않게 원본 행 추적을 보존한다.

후보·학습·보정 기간·기준 대조·다년 평가 범위·수익성 기준은 부록 고정 후 구현한다. 원본 행동 자체를 알고 재생한 결과로 수익성을 주장하지 않는다. 관찰 기간 재사용과 선택 편향, 미체결 주문·호가 자료의 부재는 계속 기록한다. 실제 주문·인증 연결은 제외한다.
