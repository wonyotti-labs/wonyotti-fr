# 실험 v142 사전 계획: 과거 기간 예측으로 정한 학습 난도

2026-10-12. v141은 원래 무가중 구간을 정확히 복원했지만 21/42개 조건으로 미채택했다. 학습의 순위 개선이 상반기에 유지되지 않았고 핵심 집단의 하반기 공통 예산은 TP/FP 0/8이었다. 구간 이동만으로 가중 학습 실패를 설명할 수 없다. 다음 비교는 같은 자료에 적합한 점수로 높은 점수 음성을 정한 절차를 점검한다.

이번에는 2020년 내부에서 앞선 기간으로만 학습한 보조 모델의 다음 분기 점수로 난도를 정한다. 준비 기간과 경계 행을 처리하는 방식도 바뀌므로, 같은 대상 행·분기·기본 비중을 쓰는 기존 점수 대조를 함께 학습한다. 단순히 v141과 비교해 차이를 전부 시간 분리 효과라고 해석하지 않는다. 보조 모델의 자료량과 시장 시점도 달라지므로 순수한 학습 낙관성 하나의 인과 효과라는 주장도 하지 않는다.

## 원본·고정 대조

v141 완료 증거와 이전 봉인에서 원본 1,018,460행·50개 입력·원래 1분 정답·과거 횟수·모형·예측·가중치를 확인한다. 2020년 최종 학습, 2021년 상반기 보정, 하반기 진단과 원래 24시간·포지션 경계는 유지한다. 모든 기간은 이미 관찰한 사후 연구이며 v10 최종 다년·다시장·비용·펀딩·지연·낙폭·표본·집중 기준도 그대로다.

v127, v140, v141 결과를 보존한다. 새 모델 식별자는 `v142matched`(대상 행을 맞춘 기존 점수 대조), `v142forward`(과거 기간 예측 후보)로 구분한다. 대조가 좋은 결과를 내더라도 후보로 바꿔 채택하지 않는다.

## 2020년 내부의 앞선 기간 예측

UTC 기준 다음 세 경계를 사용하며 날짜를 탐색하지 않는다.

| 다음 분기 | 보조 학습의 정답 종료 상한 | 점수 대상의 시작 | 점수 대상의 정답 종료 상한 |
| --- | --- | --- | --- |
| 2분기 | 2020-03-31 미만 | 2020-04-02 이상 | 2020-06-30 미만 |
| 3분기 | 2020-06-30 미만 | 2020-07-02 이상 | 2020-09-30 미만 |
| 4분기 | 2020-09-30 미만 | 2020-10-02 이상 | 2020-12-31 미만 |

보조 학습은 원래 2020년 학습 행 중 해당 상한보다 `label_end`가 이른 누적 행이다. 행동별 quiet에서만 학습한다. 점수 대상은 해당 분기 시작 이후 진입한 포지션이면서 표의 시작 이상인 `end`, 종료 상한 미만인 `label_end`를 가진 quiet 행이다. 학습과 점수 대상의 포지션 교집합이 비어 있고 학습 정답 종료가 대상 판단보다 앞서는지 직접 확인한다. 분기를 넘긴 포지션이나 경계 행을 최종 학습에서 삭제하지 않는다.

각 행동·분기의 보조 학습은 최소 1,000행·양성과 음성 각각 20개, 점수 대상은 최소 100행·양성과 음성 각각 20개를 요구한다. 하나라도 미달하면 이번 비교를 중단하고 지원 실패를 기록한다. 임의로 분기를 합치거나 과거 자료를 추가하지 않는다.

보조 모델은 같은 원시 50개 입력의 무가중 깊이 2·말단 4·256회 부스팅이다. 학습률 0.05·최소 말단 64·L2 1·255구간·seed 0·조기 종료 없음·별도 클래스 가중치 없음이다. 행동 두 개와 세 분기의 총 보조 트리는 1,536개다. 각 보조 모델의 구간 경계도 해당 과거 학습 자료로만 적합한다. 2020년 전체로 적합한 v141 구간을 보조 예측에 사용하지 않는다.

시간 순서를 지킨 분할이 필요한 이유는 [scikit-learn 시계열 분할 문서](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)의 설명과 같다. 원본 보유 상태 행은 중간 공백이 있으므로 행 수만으로 분할하거나 `gap`의 행 수를 하루로 간주하지 않고 위 달력 시각·포지션 경계를 직접 적용한다. 이 문서는 제안한 가중치의 효과를 보장하지 않는다.

## 같은 지원에서 비교하는 두 가중치

각 행동·점수 대상 분기의 음성 수 N0에서 k=ceil(N0/100)으로 정한다. 해당 점수의 내림차순 k번째 값 q 이상인 음성을 높은 점수 음성으로 지정하고 동점은 전부 포함한다. 분기별 경계를 고정해 서로 다른 보조 모델의 점수 크기를 직접 합쳐 순위를 정하지 않는다.

- `v142matched`는 같은 대상 행에서 기존 v126의 보정 전 점수로 경계를 정한다. 이 점수는 해당 분기를 포함한 2020년 전체에 적합한 점수이며, 앞선 기간 예측이라고 부르지 않는다.
- `v142forward`는 해당 분기보다 앞선 보조 모델의 보정 전 점수로 경계를 정한다.
- 두 방식 모두 대상 양성과 높은 점수 음성의 원시 비중은 1, 나머지 대상 음성은 0.1이다.
- 1분기 준비 행·경계·분기 이전 진입 등 점수 대상 밖의 quiet 행은 두 방식 모두 원시 비중 1이다. 지원이 없다는 이유로 제거하거나 쉬운 음성으로 간주하지 않는다.

각 방식·행동의 **전체 2020년 quiet**에서 평균 1로 정규화한다. 정수 단위 10 대 1을 이용해 기존처럼 누적 오차를 피한다. 모든 행은 유한 양수 가중치로 남고 전체 유효 표본은 1,000 이상이어야 한다. 최종 학습의 기존 상태 지원 조건도 그대로 적용한다.

대상/비대상과 그 이유, 분기별 점수·경계·동점·높은 점수 음성 교집합, 전체·상태·월·횟수·양성·높은 점수 음성·나머지 대상 음성·비대상 음성의 행 수·비중·최대 단일 행 비중·유효 표본을 보존한다. 중첩 집단을 독립 표본처럼 합산하지 않는다.

보조 예측 자체는 앞선 자료로 생성하지만, 높은 점수 음성의 선택은 그 분기 전체의 정답을 사용한 사후 학습 비중이다. 당시 각 분에 이미 알 수 있었던 운용 가중치라는 주장은 하지 않는다. 전체 2020년 정규화와 최종 모델이 이후 2020년 자료의 영향을 받는 것도 허용된 학습 범위다. 2021년 자료를 가중치나 학습에 사용하지 않는다.

## 최종 두 방식의 실제 학습·보정

두 방식 모두 v141이 복원한 v126의 원래 무가중 구간을 고정한다. 각 방식에 행동별 256개 트리와 가중 로지스틱 두 개를 적합한다. 최종 신규 트리는 총 1,024개, 신규 선형은 네 개다. 보조 1,536개 트리와 구분해 보고한다. 최종 모형의 설정은 v141과 같다. 선형은 원시 입력, 무가중 학습 StandardScaler, C=0.1·최대 2,000회·seed 0이며 각 방식의 행별 가중치를 받는다.

원래 구간·무가중 대조의 동등성과 모든 가중 학습의 수준 매핑을 검산한다. 최종 모형에는 전체 2020년 자료를 사용한다. 준비 기간 행을 삭제하거나 좋은 포지션·월·행동만 조합하지 않는다.

두 방식 각각 상반기 무가중 전체 quiet 보정과 first/restart 원시 점수의 별도 절편·문턱 절차를 적용한다. 범위 [-64,64]·100회 이분법·평균 오차 1e-12, 축소 F1·추가 F0.5·최소 요청 20개·동률 높은 문턱 우선은 유지한다. 청산·recent·native/capacity 보존과 모든 기간·월·횟수·선형 대조·한도 전 지표도 동일하게 검산한다.

## 42개 기준과 여섯 개의 같은 지원 대조 조건

각 방식에 기존 42개 조건을 같은 v127 기준으로 계산해 모두 공개한다. v142forward만 최종 연구 후보이며, 기존 42개를 모두 통과해야 한다. 같은 상반기 v127 FP 예산을 사용해 두 방식 각각 18집단의 문턱·동점·미지원·요청·겹침을 계산한다. 기존 v140/v141 예산 결과도 유지하고 하반기 문턱 조정은 하지 않는다.

v142forward의 추가 조건은 하반기에서 v142matched 대비 두 행동 quiet 로그 손실의 각각 1% 초과 개선(2개), 각각 평균 정밀도 보존(2개), 한도 전 재시작 추가의 공통 예산 TP 엄격 증가와 FP 보존(2개)다. 실수 비교는 기존 1e-12 경계를 쓰고 정수 혼동표는 그대로 비교한다. 총 48개 중 하나라도 미달하면 새 자체 계좌 확대를 하지 않는다.

기존 42개에서 점수 개선 조건이나 표본 조건을 제거하지 않는다. matched의 42개와 forward의 48개를 섞어 유리한 통과 수를 만들지 않는다. 통과해도 실행 정책·다년·다시장 수익성 검증은 별도다.

## 독립 검산과 이력

시각 비교와 별도 분기·포지션 순회로 지원 행과 이유를 대조한다. 모든 보조·최종 트리와 선형을 독립 재적합하고 전체 숫자 모형·점수·구간 경계·가중치·보정·문턱·집계·두 판정을 검산한다. 빈 월과 비대상 행도 보존한다. 공통 판정 코드가 일반화되면 실제 모델 식별자를 유지하며 v140/v141의 기존 42개 결과가 변하지 않는지 대조한다.

미래 분기의 입력·정답 변경으로 이전 분기의 보조 모형·원시 예측·분기 경계·원시 비중이 바뀌지 않는지 검사한다. 같은 분기 전체 정답에 의존하는 사후 비중과 전체 연도 정규화까지 실시간 불변이라고 잘못 검사하지 않는다. 2021년 보정·진단 변경은 모든 2020년 학습 산출물을 바꾸면 안 되며, 진단 변경은 보정·문턱을 바꾸면 안 된다.

원본·계획·설치 소스·잠금 의존성·코드 지문, 저장 후 재읽기, 숫자·모형·기간·포지션·경계 손상, 경계 동점·지원 부족·양수 비중을 검사한다. 별도 출력 폴더·실제 종료 기록을 보존하고 이전 실패를 덮어쓰지 않는다. 원본·시장·파생·가중치·모델은 로컬 전용, 코드·방법·집계는 작업별 명사형 커밋 직후 푸시다. 실제 주문 연결은 없다.
