# 실험 v93 조건부 사전 계획: 다른 시장과 관리 기능의 기여

2026-10-10. v92의 실제 실행과 독립 검산이 끝나기 전에 후속 비교를 고정한다. v92의 세 BTC 기간에서 기본·비용 2배 조건 모두 양수이고 영구 중지가 없다는 분기를 검산까지 확인한 경우에만 실행한다. 미달이면 이번 계획을 실행하지 않고 그 사유를 남긴다. 이미 알려진 v48의 2021년 손실과 확인·최근 거래 수 부족은 그대로다.

## 동일한 정책과 비교 목록

부모는 v92에서 재현한 v48이다. 모델·학습 구간·문턱·위험·수량·보유 한도는 고정하며 새 학습·설정 선택은 없다. v92의 완료·독립 검산과 출처를 호출자 지정 SHA-256으로 연결한다.

1. ETHUSDT·SOLUSDT 각각 2023-01-01~2026-01-01 미만과 2026-01-01~2026-10-01 미만에 기본·비용 2배·비용 3배·추가 지연 1분을 적용한다. 수수료·슬리피지 배율과 위험 청산 우선순위는 v92와 같다. 총 16개다.
2. BTCUSDT의 v92 세 기간 각각에 추가 매매 금지와 학습된 보유 관리 중지를 따로 적용한다. 추가 금지는 기존 위험 설정의 최대 추가 횟수만 0으로 바꾼다. 보유 관리 중지는 진입 모델과 실제 상태 갱신을 유지하고 관리 모델의 추가·축소·청산 요청만 없앤다. 손절·시간 제한·일별 손실·낙폭 중지·마지막 청산은 그대로다. 총 6개다.
3. ETHUSDT·SOLUSDT 각각 2023·2024·2025년을 기본 조건의 독립 초기 계좌로 실행한다. 재학습이나 연속 운용으로 표현하지 않는다. 총 6개다.

새 실행은 총 28개이며 결과와 무관하게 전체를 보존한다. BTC의 기본·비용·지연 12개와 기존 2021년·독립 세 연도는 검산된 파일 지문을 대조해 재사용하고 재실행했다고 표시하지 않는다. 모든 시장과 기간은 이전 연구에서 이미 관찰했다.

## 기여와 판정

보유 관리 중지는 장기 수익이 학습 관리의 요청에 의존하는지 확인하는 대조다. 관리 기능 제거로 좋아진 한 결과를 즉시 새 후보로 채택하지 않는다. 실제 종료·추가 이후에는 각 정책이 자기 계좌와 새로운 기회 경로를 만들므로 같은 거래의 부분 손익 합산과 구분한다.

각 실행의 비용·펀딩 포함 순손익, 가격 손익, 거래 수, 보유 시간, 낙폭·중지, 최대 이익 거래 제거 손익과 30일 순환 블록 1,000회·seed 41 구간을 보고한다. BTC의 기존 실패와 다른 시장 손실·비용 3배·지연 민감성도 포함한다. 재표집은 관찰한 경로에 조건부이며 반복 후보 선택의 불확실성을 해결하지 않는다.

최종 v10 기준을 유지한다. 확인·두 후속 BTC 기간의 거래 수 부족을 다른 시장 거래 수로 합쳐 통과시키지 않는다. 이번 비교만으로 수익성 채택·원전략 복원·재산 검증을 선언하지 않는다. 기여가 확인된 규칙의 개선은 별도 계획으로 다룬다.
