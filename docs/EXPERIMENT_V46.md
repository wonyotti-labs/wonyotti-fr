# 실험 v46 사전 계획: 신규 활동 관문의 단독 제거 대조

2026-10-04. 신규 활동 관문에서 방향 편중이 확대됐다는 v40 단계 진단을 보존한다. v42·v43의 활동 모형 변경과 v44·v45의 시장 전용 보유 방향 재구성은 사전 예측 기준에 미달했다. 대부분 보유 중 반전으로 구성된 원본 신규 사건을 봇의 무포지션 진입 조건으로 쓰는 의미 차이가 남았다. 해당 사건의 발생 여부 관문만 제거했을 때 실제 실행이 어떻게 달라지는지 비교한다. 활동 관문의 오류나 제거 후 수익성을 미리 단정하지 않는다.

## 단일 변경과 고정 범위

- 직접 기준은 v40이다. 기존 방향 부스팅과 .65 방향 문턱, 16bp·5분 진입 대기, 첫 관리 문턱과 반복 관리 배율, 자체 체결 이력, 축소 크기, 최대 보유 시간, 최초 투자 비중·추가 한도·손절·손실 중지·비용·펀딩을 그대로 유지한다.
- 무포지션 신규 진입 판단의 활동 확률 하한만 0으로 바꾼다. 새 모형·정답·특징·문턱 검색은 없다. 기존 활동 모델 파일은 그대로 보존하며 점수가 비정상이면 계속 진입을 거부한다. 방향 .65를 넘지 못한 봉은 대기다.
- 기존과 같이 확정 5분 경계에서 신규 의도를 만들고 가격 대기 통과 뒤 다음 거래 가능 분봉 시가에 실행한다. 보유 중 관리·수량·위험·중복 거부·미체결 대기·프로세스 종료 복원은 유지한다. 보유 중 반전 실행을 새로 넣지 않는다.
- 새 선택 형식과 원래 v40 선택의 파일 지문을 연결한다. 모든 모델·원래 설정의 불변과 활동 하한 외 변경 거부를 검사한다. v42~v45의 미채택 모형은 사용하지 않는다.

## 비교와 판단

2021년 후보와 원래 v40을 실행하고 원래 v40의 전체 체결·잔고·최종 상태 일치를 요구한다. 이후 2022년의 비용 포함 순수익 양수·종료 거래 30개 이상·영구 중지 없음 조건을 확인한다. 결과를 보고 방향 문턱·시기·위험·활동 하한을 다시 고르지 않는다.

조건을 통과하면 두 후속 기간·세 시장의 기본 여덟 조건에 원래 위험의 v14·v39·v40을 더한 열한 조건과 아홉 독립 연도를 평가한다. 총 78개 실행이다. 기본 조건은 후보·원래 v7·현금·추가 제거·30분 제한·비용 2배·3배·추가 1분 지연이다. v36 단독 대조는 이번 범위에서 제외하고 기존 결과는 보존한다. 확인에 실패하면 BTC 두 후속 기간·세 독립 연도만 진단해 총 여덟 실행을 보존한다.

기존 수익성 기준을 유지한다. 양방향 신호나 거래 수 증가만으로 개선을 선언하지 않는다. 순손익·비용·낙폭·최대 거래 집중도와 실제 방향별 거래를 함께 확인한다. 전체 조건 통과 전에는 수익성 문제를 해결한 것으로 표시하지 않는다.

## 검증과 한계

낮은 활동 점수에서 방향이 충분한 신규 요청, 방향 부족·비정상 입력·보유 중 요청 차단, 정상 가격 대기·시간 만료·무거래·지연·실제 부분 체결을 검사한다. 원래 모델·관리 문턱·위험과 최초 체결 수량을 대조한다. 모든 후보 보유 분봉의 실제 추가·축소 이력과 수량 상태·시간 제한·회계·원본 파일, 실제 프로세스 종료 복원과 월간 재개를 확인한다.

기존 방향 모델은 신규 사건이 실제 발생한 행에서 학습했으므로 관문 없이 더 넓은 시각에 적용할 때 분포 차이가 커질 수 있다. 거래 빈도·회전 비용·손실이 늘어날 가능성도 대조에 포함한다. 모든 기간은 이미 관찰했으며 원본·파생 자료·모델·개별 결과는 로컬에 보존한다. 실거래 연결은 없다.
