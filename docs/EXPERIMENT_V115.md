# 실험 v115 사전 계획: 반복 관리 가산 제거의 자체 계좌

2026-10-12. v114는 원본 반복 추가·축소의 재현율과 F점수, 전체 F점수 보존 조건을 통과했다. 원본 오탐은 늘었고 기존 봇 경로의 판단 변화는 BTC 3개·ETH 28개였다. 바뀐 체결 뒤에는 상태가 달라지므로 이번에는 단일 후보가 자기 계좌를 실제로 이어 가는 경로를 재생한다.

## 변경과 고정 요소

- 부모는 v48이다. 반복 추가·축소에만 적용되던 1.5배를 1.0으로 바꾼다. 청산·첫 행동·모델·절편·진입·수량 모델·위험 한도·보유 제한·비용·펀딩·추가 지연을 그대로 유지한다.
- 원본 상태나 v113의 이전 봇 상태를 새 후보에 공급하지 않는다. 모든 판단 입력·체결 이력·관리 대기·가격 경로는 새 후보의 계좌에서 생성한다. 원래 최대 추가 횟수와 위험 차단도 유지한다.
- 새 학습·문턱 검색·수량 조정·기간 선택·불리한 거래 제외는 없다. v114의 검산 완료·판정 통과와 모델·문턱·출처 지문이 같아야 한다.

## 첫 단계의 다섯 고정 실행

1. BTCUSDT 2021-01-01~2022-01-01 미만: 기존 학습·선택 영향이 있는 개발 구간. 미사용 검증으로 표시하지 않는다.
2. BTCUSDT 2022-01-01~2023-01-01 미만: 기존 확인 구간.
3. BTCUSDT 2023-01-01~2026-01-01 미만: 연속 계좌.
4. BTCUSDT 2026-01-01~2026-10-01 미만: 최근 연속 계좌.
5. ETHUSDT 2023-01-01~2026-01-01 미만: 기존 손실이 확인된 다른 시장.

이 다섯 실행은 결과와 무관하게 전부 보존한다. 각 실행은 기존 부모와 같은 초기 계좌·시세·비용으로 시작한다. 검산 완료된 부모 결과는 지문과 모델·위험·시세 출처를 확인해 재사용하고 새 재생으로 표시하지 않는다. 2021년은 원래 개발용 조정 시세와 5분 입력 출처를 보존한다. 모든 구간은 이미 관찰했다.

비용·펀딩 포함 순수익, 가격 손익, 수수료·펀딩, 종료 거래 수, 낙폭·영구 중지, 보유 시간·종료 사유와 거절 요청을 기록한다. 최대 이익 거래를 뺀 손익 및 30일 순환 블록 1,000회·seed 41의 구간도 보고한다. 그 구간은 관찰한 경로에 조건부이며 반복 연구의 선택 편향을 해결하지 않는다.

## 다음 단계와 판정

BTC 확인·후속 장기·최근 세 실행이 모두 양수, 각 30개 이상 종료 거래, 영구 중지 없음이면 비용·지연·연도·나머지 시장 검증으로 진행한다. 하나라도 미달하면 첫 단계의 실패를 기록하고 이 후보의 확대 실행은 하지 않는다. 개발 구간이나 다른 시장의 거래 수로 부족한 BTC 표본을 합산하지 않는다.

통과 시 다음 단계는 세 BTC 기간의 비용 2배·3배와 추가 지연 1분, BTC 2023·2024·2025 독립 초기 계좌, ETH의 장기·최근 및 SOL의 장기·최근 기본·비용·지연 비교다. 이미 수행한 같은 후보의 ETH 장기 기본은 지문 확인 후 재사용한다. 비용 2배 순수익, 독립 연도 2/3 이상 양수 등 기존 v10의 최종 기준과 불확실성 보고를 유지한다. 첫 단계나 일부 수익 개선만으로 수익성을 채택하지 않는다.

## 구현 검증과 보존

별도 정책 구현으로 각 새 계좌를 다시 순차 재생해 모든 판단 결과·체결·거래·분별 잔고·최종 상태와 직접 현금·수수료·펀딩을 대조한다. 합성 테스트는 첫·반복 경계, 행동 우선순위, 수량 0과 관리 대기, 실제 체결 뒤 이력, 재시작, 미래 시세 변경 전 판단 불변을 포함한다. 원본·기존 결과·시세·코드·계획 지문을 전후 확인하고 새 출력 폴더에만 저장한다. 실패·낙폭 중지·손실을 보존하며 실제 주문 연결은 없다.
