# 실험 v40 사전 계획: 관찰한 보유 시간 범위의 실행 한도

2026-10-04. v39는 첫 추가·축소 요청을 복원했지만 확인 조건에 미달했다. 별도 설명 진단에서 봇은 관리 모델의 학습·보정 기록에 나타난 최대 보유 시간보다 훨씬 오래 머물렀으며 해당 범위 밖에서 보유 판단이 이어졌다. 이 관찰은 시간 제한의 손익 개선을 입증하지 않는다. 학습·보정 상태의 범위를 넘는 보유를 제한하는 단일 위험 변경을 검증한다.

## 한도 산출과 단일 변경

- 기반은 v39다. 모든 진입·방향·관리·축소 모델·문턱·배율·자체 체결 이력과 투자 비중·손절·기타 위험·비용·펀딩을 유지한다.
- 관리 모델의 v35 학습·보정 행에서 경계 시각과 진입 시각의 차이를 직접 계산한다. 저장된 보유 시간 로그와 일치해야 한다. 두 구간에서 관찰한 최댓값의 정수 분 내림을 단일 최대 보유 분으로 고정한다. 마지막 하반기 진단·봇 손익으로 한도를 계산하지 않는다. 분위·배수·다른 한도 검색은 없다.
- v39의 최대 보유 시간 0(제한 없음)만 위 값으로 바꾼다. 기존 엔진의 시간 제한 청산을 사용하며 한도 시점에 거래가 없으면 다음 거래 가능 시점까지 청산 대기를 보존한다. 범위 밖에서 새 관리 판단을 이어가거나 무거래 봉에 체결을 만들지 않는다.
- 기존 모델·원본 행과 입력 지문, 숫자 한도·재현 가능한 산출 기록을 함께 고정한다. 학습·보정 지원 범위의 제한이며 원본 트레이더의 실제 최대 보유 규칙이라고 주장하지 않는다.

## 대조와 검증

2021년 후보와 원래 v39를 대조한다. 기존 v39 전체 출력·상태가 정확히 같아야 한다. 최초 체결·부분 매매·한도 직전 판단·한도 청산·지연·무거래 청산 대기·중단 복원을 검사한다. 한도가 생겨 이후 진입 기회가 달라지는 효과를 함께 기록한다.

2022년 순수익 양수·종료 거래 30개 이상·영구 중지 없음 조건을 확인한다. 통과하면 두 후속 기간·세 시장의 기본 여덟 조건에 원래 위험의 v14와 시간 제한 없는 원래 v36·v39를 더한 열한 조건, 아홉 독립 연도를 수행한다. 총 78개 실행이다. 실패하면 BTC 두 후속 기간과 세 독립 연도를 진단해 총 여덟 실행을 보존한다.

원본·회계·모델·실제 체결 이력과 프로세스 종료·월간 재개를 대조하고 기존 수익성 기준을 유지한다. 범위를 넘는 보유가 줄어들거나 거래가 늘어나는 현상만으로 해결을 표시하지 않는다. 모든 기간은 이미 관찰했으며 기존 실패와 개별 결과를 로컬에 보존한다. 실거래 연결은 제외한다.
