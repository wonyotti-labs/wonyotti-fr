# 실험 v142 중간 결과: 과거 분기 예측과 학습 비중

[사전 계획](EXPERIMENT_V142.md)의 첫 단계를 실행했다. 2020년 자료에서 과거 보조 모델 6개·1,536개 트리를 학습하고 별도 재적합으로 모두 검산했다. 동일한 분기 대상에 대해 기존 전체 학습 점수의 v142matched와 과거 예측의 v142forward 가중치를 생성했다. 최종 고정 구간 모델·선형·2021년 보정·성능·42/48개 조건은 아직 실행하지 않았으며, 이번 결과는 수익성 개선의 근거가 아니다.

원본 1,018,460행의 기간 경계와 지원을 검산했고 가중치 생성에는 2020년 학습 510,102행만 사용했다. 보조 학습과 예측 대상의 포지션 교집합은 모든 행동·분기에서 0이며 학습 정답 종료가 대상 판단보다 앞섰다. 표의 양성은 행동이 기록된 분의 수이며 독립 거래 횟수가 아니다.

분기별 음성 상위 1% 경계는 동점을 전부 포함한다. 대상 양성·높은 점수 음성·대상 밖 quiet 행의 원시 비중은 1이고 나머지 대상 음성은 0.1이다. 각 방식·행동의 전체 quiet에서 평균 1로 정규화했다. 지원 밖 행을 학습에서 삭제하거나 쉬운 음성으로 처리하지 않았다.

보조 모델의 입력과 구간 경계는 각 과거 학습 자료만 사용한다. 높은 점수 음성의 선정은 대상 분기 전체 정답을 이용한 사후 학습 비중이다. 분기 당시의 실시간 가중치로 해석하지 않으며, 최종 연도 정규화가 이후 2020년 자료에 따라 변할 수 있다.

두 방식이 고른 높은 점수 음성의 수와 전체 가중치 비중은 같지만 선택한 행은 다르다. 예를 들어 추가 2분기에서 각각 1,052분을 골랐고 교집합은 546분이다. 따라서 이후 최종 모델에서는 같은 지원·기본 비중에서 선택 대상이 달라진 효과를 비교할 수 있다. 보조 학습의 자료량과 시점도 다르므로 이를 단일 원인의 효과로 단정하지 않는다.

대상 밖 음성은 축소 가중치의 약 81.95%, 추가의 약 81.90%를 차지한다. 양성 비중은 각각 약 0.366%, 0.409%다. 지원 밖 원시 비중 1을 유지한 결과이며 양성 비중이 커지는 설계는 아니다. 이 수치를 보고 중간에 비율을 바꾸지 않고 두 방식의 최종 성능을 같은 사전 기준으로 비교한다.

## 검산과 다음 단계

신규 51개를 포함한 관련 381개 검사와 Ruff를 통과했다. 표본 부족 시 학습 차단, 엄격한 시각 경계, 미래 분기 변경 시 앞선 보조 모델·점수·원시 비중 불변, 동점·양수 비중·원장 손상·선행 증거 연결을 검사했다. 최초 검사에서 시험 자료의 유효 표본 부족과 예외 형식 기대 오류를 확인하고 시험 자료·기대를 수정했다. 해당 실패 로그를 보존했다. 전체 테스트 모음이나 원격 CI를 수행했다고 주장하지 않는다.

원본 실행에서는 모든 보조 트리의 독립 재적합, 구간 경계·숫자 노드·대상 확률, 별도 달력 순회에 의한 행·포지션 지원, 유리수 정규화, 상태·월·횟수·제외 이유별 집계와 저장 후 재읽기를 검산했다. 실행 종료 코드 0과 입력·코드·계획 지문의 불변을 확인했다. 모델과 행별 자료는 로컬에만 보존했다.

모든 상태·빈 월·횟수·대상 밖 이유를 포함한 [가중치 집계](EXPERIMENT_V142_WEIGHT_TABLES.md)를 공개한다. 두 가중치는 지원과 기본 비중을 맞춘 대조이며, 높은 점수 음성이 달라진 사실만으로 예측력 개선을 주장하지 않는다. 다음은 동일한 원래 구간으로 최종 트리 1,024개·선형 4개를 학습하고 원래 보정·공통 예산·42/48개 조건을 비교하는 단계다. v10의 다년·다시장·비용·펀딩·지연·낙폭·표본·집중 기준은 유지한다.
