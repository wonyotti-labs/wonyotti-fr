# 실험 v140 사전 계획: 높은 점수의 음성과 희소 양성에 대한 학습 비중

2026-10-12. v138에서 후보의 새 적중은 낮은 오신호 예산 아래 사라졌고, v139에서도 핵심 집단의 하반기 19개 요청 중 15분 일대일 대응은 2개뿐이었다. 단순한 문턱 완화나 시간 허용으로 문제를 해결하지 못했다. 이번에는 같은 입력·정답·용량에서 학습 비중 하나를 바꿔 높은 점수의 음성을 희소 양성과 더 잘 구분하는지 실제로 학습·비교한다. 직전 턴은 v139 구현·원본 실행·독립 검산·공개·푸시를 완료한 진행이다.

## 고정 출처·자료와 후보

v139 완료 증거와 v138→v137→v127→v126의 봉인에서 같은 원본 1,018,460행·50개 입력·정답을 확인한다. 2020년 학습·2021년 상반기 보정·하반기 진단, 24시간 간격·포지션 경계를 유지한다. 미래 15분 정답으로 바꾸지 않는다. quiet/first/restart/recent와 원본 추가 횟수의 정의·행·시각도 그대로다.

축소와 추가의 quiet 학습 행 각각에서 기존 v126 공통 quiet 부스팅의 **보정 전 2020년 점수**를 재구성한다. 기존 v127 상태 보정·문턱이나 상반기/하반기 성적을 가중치 선택에 사용하지 않는다. 이 점수는 같은 2020년 학습 자료에 적합한 모델의 점수이므로 시간순 외부 예측이나 독립적인 난도 추정이라고 부르지 않는다. 전체 학습 기간으로 정한 재학습 규칙이며, 학습 도중 각 시각에 이미 알 수 있었던 운용 입력이라는 주장도 하지 않는다.

## 단일 가중치 규칙

행동별 학습 quiet 음성 수를 N0라 하고 k=ceil(N0/100)으로 정한다. 음성 점수의 내림차순 k번째 값을 q로 잡고 점수 >= q인 음성을 높은 점수 집합으로 정한다. 동점은 모두 포함하며 실제 집합 비율도 보고한다. 경계나 비율을 탐색하지 않는다.

- 모든 양성과 높은 점수 음성의 원시 가중치는 1이다.
- 나머지 음성의 원시 가중치는 0.1이다.
- 원시 가중치 전체를 평균으로 나눠 최종 평균 1·합 N으로 정규화한다.
- 모든 행과 음성은 유한 양수 가중치로 남긴다. 음성·손실 거래 제거, 음성 임의 추출, 복제나 재표집을 하지 않는다.

전체·양성·높은 점수 음성·나머지 음성의 행 수·가중치 합·최대 비중·유효 표본 수를 기록한다. 전체 유효 표본 수 `(sum w)^2/sum(w^2)`는 1,000 이상, 원래 학습 양성/음성은 각각 20개 이상이어야 한다. 기존 상태별 지원 조건도 유지한다. v122의 양성/음성 총 비중 50:50이나 v41의 포지션 균등화와 다른 규칙이며 이전 실패를 변경하지 않는다.

## 동일 조건의 실제 학습·보정

기존 v126의 무가중 quiet 두 모델을 같은 전체 학습 행으로 재적합해 저장된 숫자 모델과 대조한다. 후보는 같은 깊이 2·말단 4·256회·학습률 0.05·최소 말단 64·L2 1·255구간·seed 0·조기 종료 없음의 두 부스팅으로 총 512개 트리다. 고정된 가중치를 sample_weight로 전달한다. 클래스 가중치는 중복 적용하지 않는다. 설치된 잠금 의존성은 유지한다.

각 행동의 선형 대조도 같은 가중치를 받는다. StandardScaler는 원래와 같이 해당 학습 quiet 행에서 무가중 적합하고, LogisticRegression은 C=0.1·최대 2,000회·seed 0·sample_weight를 사용한다. 원래 v127 선형 대조도 보존한다. 새로운 특징·기간·용량 검색은 없다.

현재 라이브러리의 표본 가중치는 손실뿐 아니라 히스토그램 구간에도 전달된다. 따라서 동일한 구간 경계를 가진 순수 손실 변경이라고 주장하지 않는다. 입력과 모델 설정을 고정한 표본 가중 학습 절차 전체의 비교다.

상반기 원래 quiet 분포의 기울기 1 절편 보정 뒤 first/restart에서 다시 절편·문턱을 정하는 v127 절차를 그대로 적용한다. 범위 [-64,64]·100회 이분법·평균 오차 1e-12, 축소 F1·추가 F0.5·예측 양성 최소 20개·동률 높은 문턱 우선을 유지한다. 평가와 보정은 학습 가중치로 다시 가중하지 않는다. 청산 전체·recent의 기존 native 확률과 요청은 보존한다. 일부 상태나 좋은 행동만 골라 결합하지 않는다.

## 42개 판정과 공통 오신호 예산

기존 v137의 40개 판정을 동일 산식으로 새 후보에 적용한다. 원래 35개 상태·품질·요청 보존 조건, 두 행동의 quiet 로그 손실이 v127보다 1% 초과 개선되는 조건 2개, 한도 전 재시작 추가의 재현율·F 엄격 개선 및 정밀도 보존 3개다. 개선 조건의 이름만 새 학습 절차에 맞추고 1e-12 경계나 비교 대상을 바꾸지 않는다. 기존 v137의 24/40 결과는 그대로 남긴다.

v138과 같은 상반기 v127 원래 FP 수를 집단별 공통 예산으로 사용하고, 음성 B+1번째 점수 바로 다음 부동소수점 값으로 두 모델의 문턱을 정한다. 18집단 전체의 기존 요청과 예산 요청·지원·겹침·직접 점수 지표를 보고한다. 미지원과 동점 규칙도 같다. 하반기 FP가 같을 것이라고 가정하지 않는다.

추가로 **한도 전 재시작 추가**의 하반기 공통 예산 요청에서 후보 TP가 v127보다 엄격히 많고 FP는 v127 이하이어야 한다(2개). 총 42개 조건이며 하나라도 미달하면 이번 후보의 자체 계좌 확대를 하지 않는다. 공통 예산 문턱은 이 단계의 진단이며 성적을 본 뒤 실행 문턱으로 교체하지 않는다. 통과해도 실행 정책과 다년·다시장·비용·펀딩·지연·낙폭·표본·집중을 별도 계획으로 검증한다. v10 최종 기준은 그대로다.

## 검산과 보존

원본 점수·행·상태의 일치, 학습 음성 순서통계량과 별도 점수 빈도 누적, 동점 집합·행별 가중치·합·유효 표본 수를 독립 대조한다. 새 512개 트리와 두 선형을 같은 라이브러리로 별도 재적합하고 모든 숫자 모형·전체 확률·절편·문턱·전체/상태/월/횟수 집계·42개 판정을 검산한다. 모든 정답은 원래 1분 기준이며 v139의 시간 대응으로 대체하지 않는다.

보정/진단 정답·입력 변경 시 학습 가중치와 모델 불변, 진단 정답 변경 시 보정·문턱 불변, 양성 점수만 바꿀 때 음성 경계·가중치 불변, 동점·정수 올림·극단 확률·손상 모델·행 순서·잘못된 모델 연결을 검사한다. 한도 전후·처음/재시작과 모든 월의 지원·가중치 영향·정밀도·재현율·로그 손실·평균 정밀도·Brier·원래/공통 예산 요청을 보존한다.

입력·계획·코드 지문과 저장 후 재읽기를 확인한다. 모든 기간은 이미 관찰한 사후 연구이며 수익성이 검증됐다는 주장은 없다. 원본·시장·파생·가중치·모델·개별 출력은 로컬에만 보존한다. 코드·방법·집계는 작업별 명사형 커밋 직후 푸시하며 실제 주문 연결은 없다.

가중 학습 API는 [scikit-learn 공식 문서](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.HistGradientBoostingClassifier.html)를 확인했다. 설치된 1.9.1의 학습 경로에서 표본 가중치가 구간 계산에도 전달됨을 확인했으며, 이 문서는 제안한 가중치의 효과나 수익을 보장하지 않는다.
