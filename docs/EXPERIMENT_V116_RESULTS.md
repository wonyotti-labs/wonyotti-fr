# 실험 v116 결과: 같은 행의 거래소 관리 모형 비교

2026-10-12. 사전 조건 18개 중 16개를 충족했다. 원본 행동 예측의 후속 자체 계좌 연구 조건에 미달했다. 이 모형을 매매에 연결하지 않는다. 수익성 문제는 미해결이다. [계획](EXPERIMENT_V116.md)과 [입력 검산](EXPERIMENT_V116_INPUTS.md)의 고정 비교를 유지했다.

## 동일 행과 시간 분리

학습 510,102행, 보정 256,179행, 진단 252,124행을 사용했다. 2020년 학습·2021년 상반기 절편 및 문턱 보정·하반기 진단을 분리했다. 원본 1,018,460행과 비유한 보정 55행은 입력 단계의 봉인 원장에 그대로 있다. 원본 보유 상태·정답·나머지 14개 입력은 같고 후보의 시장 관측 36개만 Binance로 대체했다. 세 기간은 이미 관찰했다.

원본 대조·정렬 후보의 고정 부스팅과 정렬 선형을 같은 학습 행으로 적합했다. 원본 대조 트리의 기존 v35 일치 여부는 True, 절편 일치 여부는 False다. 공동 학습은 기존과 같지만 보정에서 55행이 빠졌으므로 새 대조 절편과 기존 저장 절편을 구별했다. 기존 모형에 후보 입력만 넣은 결과도 별도 출처 진단으로 보존했으며 후보를 다시 선택하지 않았다.

로그 손실·Brier는 작을수록, 평균 정밀도(AP)는 클수록 좋다. 요청 문턱은 같은 보정 행에서 청산 F2·축소 F1·추가 F0.5와 최소 예측 양성 20개 규칙으로만 선택했다. TP·FP·FN은 원본의 행동 요청 정답과 비교한 수이며 실제 체결·수익 거래 수가 아니다.

청산 로그 손실 개선 0.2904%와 추가 개선 0.5445%는 사전 1% 초과 조건에 미달했다. 축소만 1.0546% 개선했다. 청산 AP는 0.02969에서 0.06279로 높아졌지만, 보정 구간에서 고른 문턱의 진단 TP는 4→6건, FP는 76→172건이었다. 축소 TP는 39→46건, FP는 202→203건이었고 추가 TP는 10→7건으로 줄었다. 점수 순위 개선과 실제 요청 오류를 구분해야 하며, 거래소 관측원을 바꾸는 것만으로 관리 재현이나 손실 문제가 해결되지는 않았다.

기존 모형에 정렬 입력만 넣으면 청산 로그 손실은 0.001047434, 축소는 0.006096961로 새 원본 대조보다 나빴다. 후보 재학습 없이 시세 출처만 바꾸는 접근도 전체 행동 개선의 근거가 되지 않았다.

## 구현 및 실제 검산

별도 라이브러리 재학습의 부스팅 384개 트리와 선형 세 행동의 표준화·계수·절편을 대조했다. 공동 지원 1,018,405행의 모든 원시·보정 확률과 기존 v35의 진단 예측, 별도 절편·문턱·전체 및 월별 지표·18개 판정을 검산했다. 이 행 수를 독립 거래 표본 수로 해석하지 않는다.

학습 단계 신규 16개와 관련 53개, 합계 69개 검사 및 Ruff를 통과했다. 입력 단계 신규 20개 검사가 관련 검사에 포함되며 두 단계의 실행 수를 단순 합산하지 않는다. 검사는 진단 입력·정답 변경 시 모델·보정값 불변, 동일 행·정답·상태 보존, 지원·시간·포지션 중첩 거부, 합성 전체 실행과 보정 행 제외를 포함한다. 실제 실행 시작에 고정한 325개 공개 모듈·계획·입력 지문이 종료까지 같았다. 전체 테스트 모음·최신 원격 CI 통과를 주장하지 않는다. 원본·시세·모델·개별 예측은 로컬에만 두며 실제 거래 연결은 없다.
