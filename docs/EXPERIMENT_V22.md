# 실험 v22 사전 계획: 같은 보유 상태에서 추가 주문의 순효과 학습

2026-10-04. v21은 2022년 확인 조건을 통과했지만 이후 BTC 두 기간과 ETH·SOL 장기 기본 조건에서 손실을 보였다. 사전에 정한 전체 대조는 끝까지 보존한다. 최근 BTC에서 추가 제거 대조의 손실이 줄었지만 이후 진입·청산 경로도 달라지므로 이를 개별 추가 주문의 인과 효과로 해석하지 않는다. 새 후보는 관리 행동 모사를 그대로 두고 추가 주문 하나의 실행 가치를 별도로 학습한다.

## 정답의 범위

- 고정 v21의 2021년 연속 계좌를 다시 실행한다. 모델과 빈도 보정이 같은 연도 일부를 사용하므로 전체 시스템의 학습 적합 구간으로 표시한다.
- 실제 정책이 추가를 요청한 모든 시점을 원장에 남긴다. 해당 결정 직후 계좌·보유·위험·정책 상태를 복제하고 다음 대기 추가만 유지하거나 취소한 두 경로를 만든다. 과거 손익·계좌 상태를 새 초기 자본으로 바꾸지 않는다.
- 두 경로 모두 이후 고정 v21의 관리·위험·비용·펀딩을 적용한다. 현재 포지션이 자연 종료되면 그 경로는 현금 상태로 멈추며 새 진입은 하지 않는다. 두 경로가 모두 종료했을 때 현금 차이를 비교한다. 이는 현재 포지션 관리의 시뮬레이터 내 순효과이며 전체 전략의 장기 인과 효과가 아니다.
- 정답은 `(추가 유지 최종 현금 - 추가 취소 최종 현금) / 결정 당시 순자산 × 10,000`이다. 손실·0·엔진 거절·무거래 지연·위험 종료를 모두 남긴다. 마지막 학습일 전까지 어느 한 경로라도 종료하지 않으면 경계 미확정으로 보존하며 강제 청산 정답을 만들지 않는다.
- 판단 입력은 그때 확정된 기존 44개 특징이다. 미래 가격·실제 체결 여부·정답의 종료 시각은 예측 입력에 넣지 않는다. 추가 유지 경로는 기존 연속 계좌의 해당 포지션 체결·종료와 대조한다.

## 고정 학습과 실행

단일 표준화 Ridge alpha 100을 사용한다. 같은 원래 포지션의 여러 결정은 포지션별 총 비중이 같도록 가중한 뒤 전체 평균 가중치를 1로 맞춘다. 이는 경로 의존을 제거하거나 독립 표본을 만드는 조치가 아니다. 지원 조건은 확정 정답 100개 이상, 서로 다른 원래 포지션 30개 이상, 판단 시각 범위 180일 이상이다. 부족하면 기준을 낮추지 않고 정답 진단 결과를 남긴다.

예측 순효과가 0bp를 초과할 때만 기존 추가 의도를 유지한다. 거절 시 기존 정책의 누적량 초기화와 관리 대기는 그대로 보존해 같은 신호를 반복 재시도하지 않는다. 신규 진입·축소 크기·청산·위험·추가 크기와 최대 횟수는 v21 그대로다. 이익을 보고 모델·문턱·지원 기준을 다시 선택하지 않는다. 무효 입력은 추가를 거절하며 원래 위험 청산은 계속 적용한다.

2021년 적합 재생과 필터 제거 v21의 전체 출력 일치를 확인한 뒤 2022년을 고정 확인한다. 양수·30거래·영구 중지 없음 실패 시 BTC 후속 두 기간·세 독립 연도만 진단한다. 통과 시 세 시장·두 기간·열한 조건·아홉 독립 연도를 평가한다. 열한 조건은 새 정책, 원래 v7, 현금, 추가 제거, 30분 제한, 비용 2배·3배, 추가 1분 지연, 원래 v14, 원래 v20, 필터 제거 v21이다. 전체 수익성 기준은 v10과 같고 모든 평가 기간이 이미 관찰되었다는 한계를 유지한다.

## 검증

- 동일 시작 상태·같은 미래 시세·단일 대기 의도 차이와 양쪽 회계·비용·펀딩을 수기 합성 사례로 검증한다.
- 포지션 종료 후 재진입 금지, 다른 종료 시점, 무거래 대기, 위험 종료, 경계 미확정과 0효과를 검사한다.
- 원본 5개 파일과 v21 모델·정답 지문, 2021년 기준 체결·계좌 재생을 대조한다.
- 미래 시세 변경 전까지 입력·결정 불변, 저장 모델 숫자·가중치·학습 경계·내보내기 예측을 검사한다.
- 추가 거절·허용·지연 중 실제 중단 복원과 월간 재개를 검증한다.

이미 관찰한 실패에서 만든 가설이며 사후 탐색과 원본 모사 상태의 분포 차이가 남는다. 이 실험을 수익성 확보나 원전략 복제로 표현하지 않는다. 원본·개별 정답·모델·실행 결과는 로컬에 보존하고 실제 거래를 연결하지 않는다.
