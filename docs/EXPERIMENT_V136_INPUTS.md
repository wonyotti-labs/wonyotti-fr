# 실험 v136 입력 검산 결과

[사전 계획](EXPERIMENT_V136.md)의 첫 단계 완료. 원본 1,018,460행과 정답을 보존하며 상대 가격 입력 10,184,600개를 별도 시간 검색·가격 비율 계산으로 대조했다. 예측력과 계좌 수익성은 아직 검증하지 않았다.

| 기간 | 원본 행 | 검산 입력 |
| --- | --- | --- |
| training | 510102 | 5101020 |
| calibration | 256234 | 2562340 |
| diagnosis | 252124 | 2521240 |

두 시장 각각 208,265개 확정 5분봉을 사용했다. 사용한 봉 종료 범위는 2020-01-01 00:05부터 2021-12-24 03:25 UTC까지다. 판단 이후 시세는 잘랐고, 두 시장의 동일 시각·연속성·양수 종가와 연결 지연 0 이상 300초 미만을 검증했다. 각 창 시작 행까지 연결 원장과 저장 후 재읽기를 대조했다.

기존 시세 보정 증거는 시장별 429,696개 중첩 봉의 일치를 기록한다. 이 증거가 2020~2021년 전체 학습 시세를 1분봉에서 독립 복원했다는 뜻은 아니다. 이 범위 한계를 출처 기록에 명시했다.

신규 53개를 포함한 관련 139개 검사와 Ruff 통과. 가격 단위 변경·방향 반전·동시각 포함·미래 제외·누락 및 오래된 봉 거부를 검사했다. 전체 검사 통과를 주장하지 않는다. 실제 입력 실행은 한 번이며 완료 봉인과 입력 지문 불변을 확인했다. 프로세스 핸들은 남아 있지 않아 종료 코드는 재확인하지 못했고 추정해 기록하지 않았다.

학습 단계는 기존 v127의 50개 입력에 검산한 10개만 추가한다. 기존 실패와 v10 최종 수익성 조건을 유지한다. [전체 지원·분포](EXPERIMENT_V136_INPUT_TABLES.md)에 모든 기간과 월, 행동·상태·입력의 집계를 보존했다. 원본·시세·개별 연결 자료는 로컬에만 유지한다.
