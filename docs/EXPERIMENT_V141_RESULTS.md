# 실험 v141 결과: 구간 경계를 고정한 가중 관리 학습

2026-10-12. 고정한 42개 조건 중 21개를 충족해 후속 자체 계좌 연구 조건에 미달했다. 기존 무가중 구간을 고정해도 가중 학습의 오신호 증가와 낮은 예산에서의 적중 소실이 남았다. 새 계좌 실행은 없으며 수익성 문제는 미해결이다.

무가중 동등성 대조의 512개 트리는 모든 분기를 원래 경계로 되돌렸을 때 v126의 기존 모형과 정확히 같았다. 새 가중 512개 트리도 별도로 재적합했으며, 원래 입력·정수 구간 입력의 전체 확률과 경계 주변 63,353개 사례를 대조했다. 따라서 이번 결과를 구간 변환 구현 오류나 다른 무가중 기준 모형의 성적으로 해석하지 않는다.

핵심 집단인 하반기 한도 전 재시작 추가는 47,962행·양성 35분이다. TP/FP/FN은 v127의 0/1/35, 직전 v140의 1/18/34에서 이번 후보의 2/52/33으로 변했다. 요청 54분 중 적중은 2분이며 정밀도는 3.7037%였다. 직전 후보보다 재현율은 높아졌지만 정밀도와 F0.5는 낮아졌다. 평균 정밀도도 v140의 0.02422530000에서 0.02213229343으로 낮아졌다. 기존 v127의 0.01808798777보다 높은 부분만으로 개선을 주장하지 않는다.

상반기 FP 예산 15를 고정하면 이번 후보의 상반기 TP/FP/FN은 4/156/56에서 0/15/60으로, 하반기는 2/52/33에서 0/8/35로 변했다. 하반기 기존 v127은 0/1/35, v140은 0/7/35였다. 새 적중을 모두 잃고 오신호는 두 대조보다 많아 공통 예산의 두 조건 모두 미달했다. 원래 적중은 7·8월에 각각 1분 있었으나 예산 문턱에서는 사라졌다. 예산 오신호는 7월 5분·9월 3분이며 11·12월 빈 집단도 보존했다.

하반기 축소 quiet의 TP/FP/FN은 v127 2/14/138, v140 3/334/137, 이번 후보 5/517/135였다. 로그 손실은 직전 0.004454858557에서 0.004423718394로 조금 낮아졌지만 기존 0.004035078862보다 나빴고, 평균 정밀도도 기존 수준에 크게 못 미쳤다. 추가 quiet는 직전 5/73/141에서 3/101/143으로 변했다. 두 행동 전체 상태의 F도 v127과 v140보다 모두 낮았다. 최초 축소 등 좋아진 일부 상태만 선택해 다른 상태의 실패를 숨기지 않았다.

학습 핵심 집단의 평균 정밀도는 v127 0.04308138989, v140 0.06125318459, 이번 후보 0.06296160041이었다. 상반기는 각각 0.02832797889, 0.01897552175, 0.01431599673으로 순서가 뒤집혔다. 구간 고정만으로 가중 학습의 이후 기간 구별력이 개선됐다는 근거를 얻지 못했다. 같은 학습 자료의 점수로 높은 점수 음성을 정한 방식과 시기별 차이의 영향은 아직 분리하지 못했다.

행동별 가중치·전체 행·선형 대조·보정 절차를 그대로 유지한 비교다. 구간 이동이 성적에 영향을 주지 않았다는 뜻은 아니며, 이번 고정만으로 가중 학습의 실패가 해결되지 않았다는 결론이다. 양성·적중의 단위는 분으로 독립 주문이나 계좌 종료 거래가 아니다. 모든 기간은 반복 관찰한 사후 연구이며 기존 실패를 보존한다.

[사전 계획](EXPERIMENT_V141.md)의 자료·정답·가중치·42개 조건을 유지했다. 양성·TP·FP·FN은 분 단위이며 독립 거래 횟수가 아니다. 모든 평가 기간은 이미 관찰한 사후 연구다. 공통 예산은 상반기 v127의 FP로 정하고 하반기에서 다시 조정하지 않았다.

학습 시 원래 음성의 상위 1% 경계(동점 포함)와 모든 양성에 1, 나머지 음성에 0.1을 부여한 뒤 평균 1로 정규화했다. 원본 행은 모두 유지했다. 가중치의 기준 점수는 같은 2020년 자료에 적합한 기존 모델의 점수다. 독립 난도 추정이나 당시 실시간 가용 점수로 해석하지 않는다. 2021년 상반기 보정과 하반기 평가는 무가중이다.

기존 v126의 무가중 모델을 재적합해 행동별 구간 경계를 복원했다. 이 경계로 정수 구간을 만들고 다시 학습한 무가중 512개 트리의 분기를 원래 경계로 되돌렸을 때 기존 모형과 정확히 일치했다. 같은 정수 구간과 v140의 행별 가중치로 새 가중 512개 트리를 학습했다. 구간 경계의 선택과 가중치의 선택에 보정·진단 자료를 사용하지 않았다.

무가중 대조와 가중 후보의 실제 구간 매핑이 같음을 검산했다. 새 모형의 정수 분기는 원래 경계의 분기로 되돌려 저장했으며 변환 입력의 예측과 원래 입력의 예측을 모두 대조했다. v140 선형 두 개는 원시 50개 입력 그대로 재현·사용했고 추가 선형 후보는 학습하지 않았다. 상반기 절편·문턱은 v127과 같은 절차로 적합했고 청산·recent의 확률과 요청도 그대로다.

## 검산과 실행 이력

새 검사 32개를 포함한 관련 329개 검사(32.32초)와 Ruff를 통과했다. 전체 테스트 모음이나 원격 CI를 실행했다고 주장하지 않는다. 기존 무가중 모형과 직전 가중 모형의 전체 예측을 재현하고, 고정 구간의 무가중 512개 트리와 새 가중 512개 트리를 각각 독립 재적합했다. 기존 가중 선형 두 개도 독립 재적합해 일치를 확인했다. 가중치·경계 주변·전체 확률·보정·문턱·모든 상태·월·횟수·공통 예산·42개 판정, 저장 후 재읽기와 입력 지문을 대조했다.

저장 공간을 확인한 뒤 새로운 출력 폴더에서 실행해 정상 종료와 독립 검산 완료를 확인했다. 이전 v140의 공간 부족과 모든 기존 실패 기록도 보존했다. 원본·시장·기존 연구 증거는 삭제하지 않았다.

전체 대조·상태·월·횟수·가중치·오신호 예산과 요청 겹침은 [집계 부록](EXPERIMENT_V141_TABLES.md)에 수록했다. 원본·파생·모델·행별 출력은 로컬에만 보존한다. 실제 주문 연결은 없고 v10의 최종 다년·다시장 수익성 기준을 유지한다.
