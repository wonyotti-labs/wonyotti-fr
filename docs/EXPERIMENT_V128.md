# 실험 v128 사전 계획: 최초·재시작 관리 행동의 별도 모델

2026-10-12. v127에서 최초·재시작 평균 빈도를 따로 보정해도 추가 재시작 123개를 하나도 맞히지 못했다. 단조 보정은 상태 내부 순위를 바꾸지 못했다. 이번에는 최초와 재시작을 함께 학습한 v126 모델 대신 각 상태를 별도로 학습해 발생 시점의 구분이 개선되는지 검증한다. v119의 최초 상태 64회 모델과 달리 두 상태 모두를 같은 256회 설정으로 학습하고, v127의 상태별 보정 대조와 비교한다.

## 고정 입력·학습·결합

- v127→v126→원본 교사의 출처·봉인을 확인한다. 2020년 학습·2021년 상반기 보정·하반기 진단의 원래 모든 행·50개 입력·정답·24시간 경계·포지션 분리를 유지한다. 기간은 모두 이미 관찰했다.
- 행동별 quiet는 과거 `[t−15분,t)`의 해당 독립 첫 체결이 없는 상태다. quiet 중 과거 행동 자체가 없으면 first, 있으면 restart다. 과거 정보만으로 선택하며 미래 정답·손익을 사용하지 않는다. 두 상태 각각 학습 1,000행·보정/진단 100행, 양성·음성 각 20개 이상을 요구한다. v126의 quiet/recent 및 최초 상태 지원도 유지한다.
- 축소/추가×first/restart의 4개 부스팅과 4개 선형을 독립 적합한다. 부스팅은 v121에서 고정한 깊이 2·말단 4·256회, 학습률 0.05·최소 말단 64·L2 1·255구간·seed 0·무가중·조기 종료 없음이다. 선형은 해당 학습 상태만으로 표준화하고 C=0.1·최대 2,000회·seed 0을 사용한다. 설정 검색은 없다.
- 해당 상태의 상반기에서 기울기 1·[-64,64]·100회 이분법·오차 1e-12로 절편을 정한다. 같은 상반기 상태에서 축소 F1·추가 F0.5, 최소 예측 양성 20개·높은 문턱 동률 우선으로 원시/보정 부스팅·선형 문턱을 선택한다. 상태별 상반기 빈도 상수도 같은 상태에서 계산한다. 진단 자료는 적합·보정·문턱 함수에 전달하지 않는다.
- quiet의 first/restart에 각 모델을 적용하고 청산 전체·recent 축소/추가는 기존 native 점수·요청을 정확히 보존한다. native·capacity 대조는 v127과 같다. capacity는 quiet에만 기존 256회 모델을 적용한 결합이다. 새 상수는 각 first/restart 상반기 빈도를 쓰고 recent에서 native를 유지한다.
- v127의 원래 공통 quiet 모델+상태별 보정 결과를 별도 대조로 유지한다. 후보의 성능을 보고 좋은 상태·행동만 골라 결합하지 않는다. v119·v126·v127의 실패 기록도 변경하지 않는다.

## 판정: 기존 기준과 31개 조건

v126의 27개 기준을 같은 방식으로 적용한다. 두 행동 각각 quiet에서 native·동일 크기 capacity·새 선형보다 로그 손실이 1% 초과 개선되고 평균 정밀도가 낮지 않아야 한다(6개). 보정 전보다 로그 손실이 나쁘지 않고 상태별 빈도 상수보다 개선해야 한다(2개). quiet 재현율과 F점수가 native보다 엄격히 개선하며(2개), 전체와 최초 F점수가 각각 native 이상이어야 한다(2개). 청산 전체·두 recent 행동의 점수와 요청 보존 3개를 더한다.

추가로 두 행동의 quiet 로그 손실과 평균 정밀도가 각각 v127보다 나쁘지 않아야 한다(4개). 총 31개 조건이며 기존 1e-12 허용 오차와 엄격 경계를 유지한다. 하나라도 미달하면 이번 후보의 자체 계좌 확대를 하지 않는다. 통과해도 수익성 채택이 아니며 별도 자기 상태의 비용·펀딩·지연·낙폭·표본·다년·다시장 검증과 v10 최종 기준을 요구한다.

## 독립 검산과 결과 보존

4개 부스팅의 1,024개 트리와 4개 선형을 독립 재적합하고 모든 원시/보정 확률·절편·문턱·상태별 상수·결합·31개 판정을 검산한다. 전체·quiet·recent·first·restart와 모든 월의 지원, 로그 손실·평균 정밀도·TP/FP/FN·정밀도·재현율·F를 남기고 빈 집단·양성 0개를 보존한다. 진단 정답 변경 시 학습·보정·문턱 불변, 상태·모형 연결 손상, 원본 점수·청산/recent 보존을 검사한다.

v127의 고정 모델·입력·보정·문턱을 복원해 기존 점수·요청·상태·월별 결과가 같은지 확인한다. 원본·개별 출력·모형은 로컬에만 보관하며 코드·입력·계획의 실행 전후 지문, 저장 후 동일성, 실패 기록을 유지한다. 실제 거래 연결은 없다.
