# 실험 v112 사전 계획: 동일 관리 표본의 계좌 크기 입력 비교

2026-10-11. [v111 지원 결과](EXPERIMENT_V111_RESULTS.md)에서 계좌 크기와 원래 관리 상태를 동시에 관측할 수 있는 표본을 확인했다. 아직 새 예측 성적은 확인하지 않았다. 상대 잔량을 다시 시험하거나 원본 총 BTC 순노출을 USDT 봇의 단일 포지션과 동일시하지 않는다.

## 고정 자료와 비교

v111의 전체 창·계좌 지원·v108 정답과 기간 분리를 그대로 유지한다. 학습은 공동 지원 90,736행, 보정 42,513행, 진단 46,738행이다. 실제 학습 지원은 2020년에만 있으며, 2018~2019년 계좌 값을 앞 채움하지 않는다. 각 기간의 에피소드는 서로 겹치면 안 되고 학습 정답 종료는 보정 시작보다 앞서야 한다. 기존 24시간 제거·기간 경계 포지션 제거를 변경하지 않는다.

정답은 같은 보유 에피소드의 다음 5분 전체 독립 관리 요청 세 가지다. 반전 요청의 청산 의미를 유지한다. 행을 계좌 크기·손익·정답에 따라 추가 제외하지 않는다. 과거 최대 수량 대비 상대 잔량, 미래 잔고·종료 노출·실현 손익, 절대 날짜·연도·에피소드 번호·원본 계약 수·자산 금액을 예측 입력에 넣지 않는다.

| 모형 | 입력 | 학습 행 |
| --- | --- | --- |
| 기존 입력 부스팅 대조 | v108 시장·방향·관리 상태 32개 | 동일 공동 지원 행 |
| 주 후보 | 같은 32개 + `log1p(절대 XBTUSD 명목 가치 / 계좌 자산 USD)` | 동일 공동 지원 행 |
| 선형 대조 | 주 후보와 같은 33개 | 동일 공동 지원 행 |
| 빈도 상수 | 학습의 세 행동 빈도 | 동일 공동 지원 행 |

v108 원래 모델은 더 긴 기간으로 학습했으므로 주 비교 대조로 사용하지 않는다. 이번 대조를 같은 행에서 새로 학습해 입력 추가와 학습 범위 축소를 구분한다. 새 크기는 양의 자산과 지원된 현재 가격·현금 흐름에서만 계산하며, 진단에서도 원본 상태를 공급한 조건부 행동 재현이라는 한계를 유지한다.

## 고정 학습과 평가

두 부스팅은 행동별 이진 HistGradientBoostingClassifier 세 개다. 기존과 같은 log_loss, 64회, 학습률 0.05, 깊이 2, 말단 4, 최소 말단 64, L2 1, 최대 구간 255, 전체 특징, seed 0, 조기 종료 없음, 클래스 가중치 없음이다. 선형 대조는 학습 전용 표준화·LogisticRegression C=0.1·최대 2,000회·seed 0이다. 행 1,000개와 행동별 양성·음성 각 20개 이상을 요구한다. 학습 빈도는 학습에서만 계산한다. 용량·가중치·보정 오프셋 탐색은 없다.

모든 모형의 문턱은 같은 보정 정답에서 청산 F2·축소 F1·추가 F0.5 기준으로 한 번 선택한다. 기존 선택·동률 규칙을 유지한다. 청산·축소·추가 요청을 각각 직접 계산하며 겹치면 이 순서로 선택한다. 활동 관문을 추가하지 않는다.

전체·12개월과 고정 크기 구간 0, (0,0.5], (0.5,1], (1,2], (2,5], 5 초과에서 행·에피소드·양성 수, 로그 손실·AP·정밀도·재현율·F 점수·요청 수·오탐·적중을 모두 남긴다. 부분집합에서 문턱을 다시 고르지 않는다. 특히 (0,0.5]의 성적을 전체와 나란히 보고하여 원본의 더 큰 포지션 상태에서만 얻은 개선을 숨기지 않는다. 양성이 없는 구간은 그 사실과 기존 지표 정의를 보존한다.

후속 후보 판정은 v108·v110의 17개 조건을 그대로 사용한다. 세 행동 각각에서 동일 행 부스팅 대조와 선형 대조 대비 로그 손실 1% 초과 개선, AP 비열등, 빈도 상수보다 낮은 로그 손실을 요구한다. 청산 재현율·F2는 동일 행 부스팅 대조보다 높아야 한다. 조건·주 후보·문턱을 진단 성적을 보고 바꾸지 않는다. 이 관문 통과는 수익성 증명이 아니며 범위별 성적과 표본 한계를 함께 기록한다.

## 독립 검산과 실제 운용의 분리

기존 모든 열·공동 지원·분할을 독립 확인하고, 두 부스팅 384개 트리와 선형 계수를 별도 학습으로 대조한다. 전체·단일 상태 점수, 보정 문턱, 모든 부분집합의 집계와 17개 조건을 별도 계산한다. 모델 형식·특징 순서·비정상 입력·미래 변경 불변성·저장 복원을 검사한다. 원본·선행 산출물·공유 소스의 실행 전후 지문을 유지한다.

예측 관문을 통과하면 후속 계획에서 자체 계좌의 명목 가치 / 자산으로만 새 특징을 계산하는 실행 경로를 고정하고 비용 후 손익을 검증한다. 실제 봇에 원본 계좌 값을 공급하지 않는다. 원본 BitMEX와 기존 Binance 검증 시세의 시장 차이, BTC 담보와 USDT 계좌의 구조 차이는 남아 있다. 자체 계좌의 다년·다시장·비용·펀딩·지연·낙폭·거래 수에 대한 기존 v10 최종 기준을 유지한다. 모든 관측 기간과 실패를 보존하며 실제 주문·인증 연결은 없다.
