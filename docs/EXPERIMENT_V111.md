# 실험 v111 사전 계획: 관리 상태와 계좌 대비 포지션 크기

2026-10-11. v110의 주기 입력은 트리·예측을 바꾸지 못했다. v19의 잔존 수량 비율과 v35 이후의 과거 체결 이력은 이미 시험했으므로 새 가설로 취급하지 않는다. v108의 관리 입력 32개에는 계좌 자산 대비 포지션 크기가 없다. v98~v101의 총 BTC 순노출은 담보·다른 계약을 포함하며, USDT 봇의 단일 선물 수량과 다른 의미다.

## 먼저 확인할 지원 범위

v108의 전체 403,776개 창을 보존하고, v96에서 별도로 검산한 계좌 평가 원장의 **같은 창 시작 경계**만 연결한다. 다른 경계 보간·앞 채움·창 종료 계좌 값의 사용을 금지한다. 계좌 평가는 경계보다 엄격히 이전인 원본 체결·펀딩과 경계까지 종료된 가격 봉을 사용한다. 기존 입출금 날짜 앞뒤 하루 확장 가정과 무거래 가격 미지원 규칙을 유지한다. 가격과 날짜 창은 실제 마크 가격·입출금 완료 시각의 보증 범위가 아니다.

현재 계좌의 XBTUSD 수량은 v108 상태 수량과 정확히 같아야 한다. 모든 열린 계약의 가격 지원, 실제 거래 발생, 확정된 외부 현금 흐름, 양수 자산을 요구한다. 불일치는 실행 실패, 부족한 지원은 명시한 사유로 보존한다. 원래 관리 학습 지원과 추가 계좌 지원을 별도 열로 기록한다. 미래 정답의 지원 여부로 현재 계좌 특징을 결정하지 않는다.

새 크기의 정의는 `abs(XBTUSD 계약 수) / 계좌 자산(USD)`다. XBTUSD는 계약당 1 USD인 역선물이며, 계좌 자산은 모든 열린 계약을 평가한 BTC 자산에 현재 XBTUSD 가격을 곱한 값이다. 전체 BTC 순민감도나 증거금 비율과 혼동하지 않는다. USDT 선형 봇에서는 같은 단위의 `abs(수량 × 가격) / 자산`이다. 이 일치는 단일 포지션의 명목 크기에 한정되며 담보·다른 자산 위험의 일치를 뜻하지 않는다.

학습 이전에 연도·v108 분할별 전체/지원 행, 에피소드, 세 행동 양성 수와 크기 분포를 집계한다. 고정 구간은 0, (0, 0.5], (0.5, 1], (1, 2], (2, 5], 5 초과다. 0.5는 기존 봇의 주문 목표 한도이며 보유 중 가격 변동 후의 엄격한 상태 상한으로 간주하지 않는다. 이 범위의 반복 5분 행과 독립 에피소드 수를 함께 공개한다. 어떤 구간도 원본 손실 제거·표본 선택으로 사용하지 않는다.

이번 단계에서는 모델·수익률을 평가하지 않는다. 2018~2019년 계좌 가격 지원의 실제 범위와 2020·2021년 겹치는 상태·행동 표본을 확인한 후, 가능하면 동일 행의 기존 입력 대조와 새 크기 입력 후보를 비교하는 학습 계획을 성적 확인 전에 고정한다. 수익성 판정은 기존 v10 기준을 유지하며, 불충분한 지원을 통과로 바꾸지 않는다.

## 검산과 공개

별도 딕셔너리 연결과 Decimal 계산으로 모든 행의 연결·사유·크기를 검산한다. 기본 계산의 부동소수 자산과 사토시 원장의 가격 환산도 대조한다. 동일 경계 수량 불일치, 미래 행 변경, 현재 값과 미래 정답의 분리, 중복·비정상 시각·가격·현금 흐름, 0.5 경계를 합성 검사한다. 모든 집계는 별도로 계산한다.

새 실행 폴더, 입력·원본·소스 지문, 실패와 미지원 행을 보존한다. 원본·파생 자료·개별 계좌 상태는 로컬에만 저장한다. 공개 대상은 코드·합성 검사·방법·집계 결과다. 실제 주문·인증 연결은 없으며 모든 시세 기간은 이미 관찰했다.
