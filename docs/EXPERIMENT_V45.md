# 실험 v45 사전 계획: 보유 방향의 다일 시장 맥락 보완

2026-10-04. v44는 시장 입력만으로 다음 보유 방향을 재구성하는 데 실패했다. 작은 잔량이 남는 시각은 존재하지만 그 비중만으로 방향 편중을 설명할 수 없었다. 원본 진단의 상당 부분은 하루 이상 지속된 보유인 반면 기존 입력의 직접 가격 변화 범위는 하루까지였다. 이번 가설은 원본 상태·시간 구분자 대신 더 긴 과거 시장 맥락을 추가하는 단일 변경이다.

## 고정 변경

- v44의 모든 학습·진단 행, 현재와 다음 경계의 상태 정답·포지션·배제 원장·2020년 학습과 2021년 진단을 그대로 사용한다. 보유 수량·손익·미래 사건으로 행을 다시 선택하지 않는다. 각 시점에서 실제 존재하는 과거 원거래소 5분봉만 사용한다.
- 기존 14개 시장 입력에 8개를 추가한다. 종가의 4일·16일·64일 변화율, 1일/4일·4일/16일·16일/64일 지수이동평균 비율에서 1을 뺀 값, 16일 로그 수익률 표준편차에 sqrt(16×288)을 곱한 값, 현재 봉 거래량 / 과거 16일 평균 거래량이다. 1일은 288개 확정 5분봉이다. 기존 15분·1시간·4시간·16시간의 4배 간격 구조를 더 긴 창으로 확장하며 다른 창을 탐색하지 않는다.
- 이동평균은 기존과 같은 adjust=False·span과 동일한 최소 행 수다. 시간 공백 후 평균 상태를 새로 시작하고 64일 연속 이력이 확보되기 전에는 새 입력을 지원하지 않는다. 원래 14개 특징을 원거래소 시세로 다시 계산해 정확히 일치하는지 확인한다.
- 기존 행 하나라도 새 입력이 불완전하면 실행을 실패로 보존한다. 성과에 유리한 행만 남기거나 대체값을 채우지 않는다. 모델은 22개 입력의 학습 전용 StandardScaler와 다항 LogisticRegression C=.1·lbfgs·2,000회·seed 0·가중치 없음 하나다. 원본 보유 방향·잔량·주문·달력 시각은 입력에 포함하지 않는다.
- 직접 기준은 원래 v44 숫자 모델·진단 점수와 학습 빈도 상수다. 후보 학습과 같은 2020년만 사용하는 비교이며 정답·지원 행·확률 순서·요청 문턱 .65를 보존한다. 기존 형식과 확장 형식을 구분한다.

## 모든 사전 통과 조건

2021년 전체 다중 클래스 로그 손실이 v44와 상수 각각보다 1% 초과 낮아야 한다. long·short 평균 정밀도는 두 기준 각각 이상이어야 한다. 12개월 중 적어도 8개월에서 상수보다 월별 로그 손실이 낮아야 한다. 기존과 같은 Brier·클래스 지원·혼동행렬·고정 요청·월별 결과를 기록하며 개별 좋은 달로 전체 실패를 바꾸지 않는다. 모든 조건 통과 후에만 별도 계획으로 봇 적용과 비용 포함 수익성을 검증한다.
