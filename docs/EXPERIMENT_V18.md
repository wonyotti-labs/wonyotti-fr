# 실험 v18 사전 계획: 누적 관리 빈도에서 방향 반전의 실행

2026-10-04. v17은 기회 확대와 재학습 후 확인 선행 조건을 통과했지만 BTC 두 후속 기간의 고정 정책에서 다시 손실을 보였다. 회계와 진입 연결을 확인했으며 예정한 전체 조건 평가는 계속한다. 실패한 확대 기회를 삭제하거나 새 이익 문턱을 탐색하지 않는다.

원본의 최근 포지션 시작은 대부분 방향 반전이다. v13은 매 분 문턱 방식에서 모델 청산을 반전으로 바꿨고 과도한 짧은 거래와 손실을 보였다. v14는 누적 사건 빈도로 실행 시점을 바꿨지만 청산 후 평탄 상태로 돌아가는 의미를 유지했다. 따라서 두 실험은 누적 빈도로 정한 시점의 반전을 평가하지 않았다. 이번에는 이미 고정된 v14를 기반으로 이 실행 의미 하나를 검증한다.

## 고정 변경

- 원래 v14의 진입 활동·방향·대기, 관리 모델·가격 경로·배율·누적 규칙·수량·위험·비용을 유지한다. v17의 기회 확대와 v15~v17 순손익 필터를 사용하지 않는다. 관리 경로가 달라지므로 기존 전체 거래 정답도 재사용하지 않는다.
- 관리 누적량이 선택한 `exit`만 반대 방향 최초 진입으로 바꾼다. 다음 거래 가능한 분봉에 기존 수량을 비용을 내고 닫은 뒤 기존 최초 진입 한도 안에서 반대 방향을 연다. 위험 중지나 수동 중지·시간 종료는 평탄 청산이며 자동 반전하지 않는다.
- 반전이 실제 체결된 뒤 보유 시간·평균가·추가 횟수·가격 경로·행동 누적량을 새 포지션으로 초기화한다. 관리 신호 시각부터 3분인 기존 대기를 새 방향에 적용한다. 대기 주문은 체결로 간주하지 않으며 추가 지연과 무거래 구간에서도 순서와 상태를 보존한다.
- 단일 후보이며 재학습·배율 보정·문턱 선택을 하지 않는다. 원본의 소수 평탄 청산을 따로 예측하지 못하는 근사다. 반전이 잦아지면 비용과 위험이 커질 수 있으며 원전략 복제나 단독 원인 해결로 표현하지 않는다.

## 평가와 완료 기준

2021년 개발 재생과 2022년 확인을 기록한다. 2022년 양수·30거래 이상·영구 중지 없음 통과 시 세 시장·두 기간·아홉 조건과 아홉 독립 연도를 평가한다. 아홉 조건은 고정 후보, 원래 v7, 현금, 추가 제거, 30분 제한, 비용 2배·3배, 추가 1분 지연, 원래 v14다. 같은 입력에서 원래 v14 전체 출력·상태의 일치를 확인한다. 확인 실패 시 BTC 두 후속 기간과 세 독립 연도만 진단한다. v10의 전체 수익성 기준을 그대로 적용한다.

반전의 양쪽 비용·이전 거래 종료·새 거래 수량, 실제 체결 뒤 상태 초기화, 위험 종료의 평탄 유지, 지연·무거래 대기·영속 중단 복원, 원본과 고정 모델 지문을 검증한다. 원래 v13·v14 정책의 동작을 변경하지 않는다. 이미 본 기간의 반복 연구이며 이 조합의 선택에도 이전 실패가 영향을 주었다. 모든 실패와 개별 결과는 로컬에 보존하고 실제 거래 연결 없이 연구를 지속한다.
