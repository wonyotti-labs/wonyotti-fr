# 실험 v21 사전 계획: 매분 판단과 시장 입력의 해상도 일치

2026-10-04. v20은 원본 관리 학습을 최근 구간으로 옮겼지만 2022년 확인에서 실패했다. 지원 주문의 축소 크기 오차가 줄어도 봇의 수익으로 이어지지 않았다. 현재 관리 판단은 매분 수행하지만 시장 입력 14개는 마지막 확정 5분봉에서 계산된다. 현재 보유 손익과 가격 경로가 1분 종가를 사용해도 직전 1~3분 변화와 거래량을 직접 나타내지는 않는다. 이 누락을 보완하는 단일 후보를 성과 실행 전에 고정한다.

## 고정 입력

기존 v20의 36개 입력에 아래 네 개와 각 값에 현재 보유 방향을 곱한 네 개를 추가해 총 44개로 구성한다. 후보 특징 조합을 탐색하지 않는다.

- 확정 1분 종가의 1분 수익률
- 확정 1분 종가의 3분 수익률
- 해당 1분의 `(고가 - 저가) / 종가`
- 해당 1분 거래량 / 직전 60개 확정 1분 거래량 평균. 분모에 현재 분을 넣지 않는다.

신호 시각까지 닫힌 봉만 사용한다. 시간 중복·누락·잘못된 가격과 음수 거래량은 거부한다. 거래량 기준이 부족하거나 분모가 0이면 입력을 이용할 수 없다고 표시하며 값을 미래에서 채우지 않는다. 실행 자료에 이전 60분이 있으면 준비 구간으로 사용한다. 자료의 첫 60분 등에서 입력이 부족하면 관리 모델은 주문하지 않지만 기존 위험 청산은 계속 적용한다. 신규 진입의 기존 모델과 입력은 변경하지 않는다.

원본 1분 시세와 기존 원본 정답의 시각·종가·지문을 대조한다. 관리 행동과 축소 크기 원장·대응 불가 사유·손실을 유지한다. 추가 입력으로 기존 지원 행이 달라지는지는 따로 검증하고 바뀌면 원인 없이 삭제하지 않는다.

## 학습·실행·대조

관리 로지스틱 C=0.1, 실제 축소 크기 Ridge alpha 100, 2020년~2021년 상반기 학습과 2021년 하반기 빈도 보정, 포지션 경계·24시간 제거는 v20과 같다. 지원 기준도 그대로 유지한다. 원래 v14의 진입·위험 한도·추가 크기·평탄 청산·비용을 바꾸지 않는다. 예측 축소 비율의 지연 주문 보존과 다음 거래 가능 시가 체결도 유지한다.

주 후보는 새 44개 입력과 예측 축소 크기를 사용한다. 같은 모델의 고정 축소 대조를 보존하되 손익으로 재선택하지 않는다. 원래 v20의 모델·빈도 배율도 그대로 보존해 추가 입력의 대조로 사용한다.

2021년 두 재생은 학습·보정과 겹치는 적합 진단이다. 2022년 확인 양수·30거래·영구 중지 없음 실패 시 BTC 후속 두 기간과 세 독립 연도를 진단한다. 통과 시 세 시장·두 기간·열한 조건과 아홉 독립 연도를 평가한다. 조건은 주 후보, 원래 v7, 현금, 추가 제거, 30분 제한, 비용 2배·3배, 추가 1분 지연, 원래 v14, 새 모델의 고정 축소 대조, 원래 v20이다. v10의 전체 수익성 기준과 모든 기간이 이미 관찰되었다는 한계를 유지한다.

미래 시세 변경 시 과거 입력·결정 불변, 일괄 계산과 실행 입력 일치, 준비 구간·무거래 분봉·시간 경계, 모델 숫자·입력 지문, 원래 v19·v20 실행 불변, 실제 종료 복원과 월간 재생을 검사한다. 호가·미체결 주문·대기열을 새로 관측했다고 가정하지 않는다. 원본·모델·개별 결과는 로컬에 보존하고 실거래는 연결하지 않는다.
