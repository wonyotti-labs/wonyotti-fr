# 실험 v50 사전 계획: 검증한 관리 모형의 최신 원본 재학습

2026-10-04. v48은 청산 판단 변경 후 장기 연속·독립 세 연도의 양수를 보였지만 확인·최근 거래 수가 부족했고 개발 적합 구간은 손실이었다. v49의 더 오래된 학습 이력 추가는 원본 예측을 악화시켰다. 기존 v35에서 허용한 모형은 2020년 학습·2021년 상반기 보정 상태로 매매에 사용되고 있다. 같은 모형과 선택법을 유지한 채 사용 가능한 마지막 원본까지 학습·보정 창을 전진시키는 단일 후보를 고정한다.

## 변경 범위와 입력 보존

- 직접 대조는 v48이다. v35의 50개 입력·부스팅 설정·무가중치·조기 종료 없음 조건을 유지한다. v49의 확장 모형과 2018~2019년 추가 행은 사용하지 않는다.
- 학습은 2020-01-01 이상 2021-07-01 미만, 절편·문턱 보정은 2021-07-01 이상 2022-01-01 미만이다. v33에 이미 저장된 두 분할의 모든 열·정답을 그대로 사용하고 기존 24시간·포지션 배제·원본 지문을 확인한다.
- 절편은 기존 기울기 1·확률 경계·[-64,64] 100회 이분법과 평균 오차 기준을 유지한다. 공통 문턱은 청산 F2·축소 F1·추가 F0.5, 첫 축소·추가는 과거 해당 체결이 없는 보정 행에서 같은 선택법으로 계산한다. 최소 정답 지원과 예측 양성 20개 조건은 유지한다.
- v48의 적용법을 그대로 쓴다. 청산·첫 관리 문턱은 직접 적용하고 반복 추가·축소는 공통 문턱의 1.5배다. 문턱·보유 시간·위험 값을 손익으로 다시 고르지 않는다.
- 진입 방향·활동 조건·가격 대기·실제 체결 이력·축소 크기 모형·최초 및 추가 수량·최대 보유·손절·손실 중지·비용·펀딩은 원래 v48과 같다. 원래 모델 파일을 보존하고 새 관리 모델·절편·문턱을 별도 파일로 저장한다.

## 시간순 해석과 실행 판정

2021년 하반기는 이제 새 모형의 보정 자료다. 이 구간에서 새 예측 우위를 주장하거나 이전 v35·v47의 독립 진단을 새 모델의 증거로 재사용하지 않는다. 기존 진단은 모형 계열·실행 방식의 선택 근거이며 새 재학습 결과는 2022년 이후 매매로 별도 판단한다. 2021년 재생은 전부 적합 진단이다.

2021년 후보·원래 v48을 비교하고 원래 정책의 전체 출력·상태 일치를 요구한다. 2022년 순수익 양수·종료 거래 30개 이상·영구 중지 없음 실패 시 BTC 후속 두 기간·독립 세 연도만 진단해 총 여덟 실행을 보존한다.

통과 시 두 후속 기간·세 시장에 기본 여덟 조건과 원래 위험의 v14·v46·v48을 더한 열한 조건, 아홉 독립 연도를 평가해 총 78개 실행을 수행한다. 기본 조건은 후보·원래 v7·현금·추가 제거·30분 제한·비용 2배·3배·추가 1분 지연이다. v40 단독 대조는 이번 범위에서 제외하고 이전 결과는 보존한다.

기존 수익성 기준과 표본·비용·낙폭·시장별 안정성·최대 거래 집중·불확실성 보고를 유지한다. 이미 관찰한 2022년 이후를 새 미사용 자료로 표시하지 않는다. 독립 재학습·수기 절편 및 문턱·자체 체결·회계·실제 종료와 월간 복원·원본 보존을 확인한다. 원본·파생 자료·개별 결과는 로컬에만 보존하며 실거래 연결은 없다.
