# 실험 v94 사전 계획: 보유 방향의 비선형 시장 모형

2026-10-10. v93의 고정 매매 대조와 별개로, 기존 보유 방향 예측의 한계를 조사한다. v44는 당시 시장 정보만으로 다음 경계 직전 원본의 flat·short·long을 예측했지만 선형 모형이 상수보다 나빴다. v45의 장기 시장 입력 확장도 실패했다. 신규 포지션 사건을 예측하는 현재 v28 방향 모형과 보유 상태를 예측하는 목표는 다르다. 이번에는 v44의 행·정답·14개 입력을 고정하고 모형의 비선형성만 바꾼다. 기존 실패가 선형성 때문이라고 미리 단정하지 않는다.

## 고정 학습과 대조

- 완료한 v44와 독립 검산을 호출자 SHA-256으로 연결한다. 원본 상태의 엄격한 이전 시각 연결, 기간 경계의 포지션 제거와 양쪽 24시간 배제는 검산된 기존 행·원장으로 재사용한다. 이를 이번에 원본부터 재실행했다고 표시하지 않는다. 기존 모형·전체 예측·지표·월별 결과는 다시 계산해 저장값과 대조한다.
- 학습은 2020년, 진단은 2021년의 기존 전체 지원 행이다. 학습 1,000행·진단 100행과 각 클래스 20개 이상, 시간·포지션 분리를 유지한다. 수익·보유량·새 정답에 따른 행 선택은 없다. 원본 상태·수량·주문·달력 시각은 예측 입력에 넣지 않는다.
- 후보는 HistGradientBoostingClassifier 하나다. 기존 관리 부스팅의 설정인 log_loss·64회·학습률 .05·깊이 2·최대 말단 4·최소 말단 64·L2 1·구간 255·전체 특징·범주형 없음·seed 0을 사용한다. 표본·클래스 가중치, 조기 종료, 추가 확률 보정, 설정 검색은 없다. 세 클래스의 라이브러리 초기 점수와 회차별 세 트리를 숫자로 내보낸다.
- 직접 대조는 v44 선형 모형과 같은 학습 클래스 빈도의 상수다. v45 실패는 별도 기존 결과로 보존하며 새 모형에 긴 입력을 혼합하지 않는다. 요청 문턱 .65와 flat·short·long 순서를 유지한다.

## 판정과 후속 범위

2021년 전체 다중 클래스 로그 손실이 선형 모형과 상수 각각보다 1% 초과 낮아야 한다. short·long 각각의 평균 정밀도도 두 대조 각각 이상이어야 한다. 월별 로그 손실이 상수보다 낮은 달은 12개월 중 8개월 이상이어야 한다. 전체 Brier·혼동행렬·요청 수·월별 손실·실제 클래스와 포지션 지원을 기록한다. 좋은 달·방향만으로 전체 실패를 바꾸지 않는다.

이번 연구는 행동 예측 진단이며 봇의 비용 포함 수익을 계산하거나 새 정책을 채택하지 않는다. 통과하더라도 v93의 전체 실행·독립 검산 이후 별도 매매 적용 계획이 필요하다. 실패하면 이번 모형의 매매 적용을 차단한다. 지속된 보유 행은 독립 거래가 아니고 모든 기간은 이미 관찰했다. v10의 최종 수익성·표본·다년·비용 조건을 그대로 유지한다.

## 구현과 검증

v93가 사용하는 소스·계획·검산 도구는 변경하지 않는다. 그동안 이 계획과 별도 로컬 준비 코드·합성 검사만 진행하며, 운영 소스 등록과 실제 원본 학습은 v93의 전체 독립 검산 이후 수행한다.

합성 자료에서 세 클래스·숫자 내보내기·안정적인 softmax·분기 경계·비유한 입력 거부·직렬화와 변조 거부를 확인한다. 독립 재학습으로 64회×3개 트리와 초기 점수, 전체 예측·모든 지표·월별 판정을 대조한다. 진단의 미래 정답·입력 변경이 학습 모형에 영향을 주지 않아야 한다. 원본·시세·모형·개별 결과는 로컬에만 보관하고 실거래 연결은 제외한다.

다중 클래스의 회차별 클래스 트리와 softmax 구조는 [scikit-learn 공식 API](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.HistGradientBoostingClassifier.html)를 따른다. 라이브러리의 지원 기능을 수익성 근거로 해석하지 않는다.
