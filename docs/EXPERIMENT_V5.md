# 실험 v5 사전 계획: 보유 시간과 비용을 고려한 진입

2026-10-01. v4의 개발·2021년 및 2026년 1~8월 결과를 관찰한 후 작성했다. v4의 2022~2025년 다년 비교는 이 계획 작성 시 진행 중이며 먼저 관찰한 BTC 결과도 탐색 이력에 포함한다. 이후 해당 결과를 보고 아래 후보를 바꾸지 않는다.

## 가설과 한계

v4는 추가 진입의 방향 판단을 학습했지만 보유 시간은 기존 후보의 최대 6시간을 유지했다. 원본 이익 구간의 보유 중앙값과 큰 차이가 있다. 개발 구간에서는 수수료 차감 전 가격 손익도 음수였고, 2021년에는 가격 이익이 수수료를 감당하지 못했다. 단순히 수수료를 낮춰서 결과를 바꾸지 않고, 예상 가격 움직임이 비용보다 큰 상황만 선택하는지 검증한다.

이 후보는 원본에 없는 새로운 의사 결정 규칙이다. 원전략을 복원했다는 뜻이 아니다. 미래 가격은 학습 정답과 평가에만 쓰며 미래 손실 거래를 삭제하지 않는다. 이미 관찰한 2020~2026년 8월은 새 미사용 평가가 아니다.

## 고정 설계

v4에서 고정한 활동·방향 모형과 진입 기준을 유지한다. 2018~2019년의 독립 노출 확대 창에서 직전 확정 시세와 주문 방향을 입력으로, 30·60·120분 뒤 종가의 방향별 로그 변화(bp)를 학습한다. 실제 원본 체결 가격이나 리베이트는 정답에 넣지 않는다. 봉 기준 가격 변화는 실행 가능한 손익과 다르며, 실행 평가는 계속 다음 봉 시가·비용·펀딩을 사용한다.

특징은 기존 시장 특징 14개, 각 특징과 매매 방향의 곱 14개, 방향 1개다. 표준화와 ridge 회귀를 사용한다. 학습 경계를 넘는 포지션 에피소드와 마지막 24시간을 제외하고, 정답의 끝도 학습 경계 안인지 검사한다. 손실 표본을 제거하거나 승률로 가중하지 않는다.

후보는 12개다: 관찰·최대 보유 시간 {6, 12, 24}봉 × ridge alpha {10, 100} × 예상 비용 초과분 {0, 8}bp. v4 진입 조건을 만족하면서 예상 방향별 가격 변화가 왕복 수수료·슬리피지 근사 16bp에 초과분을 더한 값 이상일 때만 진입한다. 펀딩은 예상 점수에 추정해서 넣지 않고 실제 백테스트 현금 흐름에 반영한다.

진입 뒤에는 방향 신호로 반전하지 않고 선택한 시간까지 보유한다. 4% 손절·일별 손실·누적 낙폭 중지는 먼저 적용한다. 추가 진입은 없고 초기 노출 25%, 재진입 대기 3봉을 유지한다. 고정 보유 시간과 비용 조건이 함께 달라지므로 v4와의 전체 비교를 단일 원인의 효과로 해석하지 않는다.

## 평가 순서

1. 입력 해시·정답 시간 경계·열두 후보를 저장한다. 2020년 BTC에서 종료 거래 20개 이상, `순수익 - 0.5 × 최대낙폭 절댓값` 최대로 선택한다. 적격 후보가 없으면 조건을 완화하지 않는다.
2. 선택을 고정한 뒤 2021년 BTC에서 확인한다. 개발·확인 모두 양수·각 20거래 이상·영구 중지 없음 조건을 새 자료 개봉 전에 다시 계산한다.
3. 고정 후보를 2022~2025년과 2026년 1~8월 BTC·ETH·SOL에 적용한다. v4 고정 후보, 같은 보유 시간에서 비용 예측 조건만 제거한 후보, 현금, 비용 2·3배, 한 봉 지연과 비교한다. 관찰 구간 평가로 기록한다.
4. 2026년 9월은 선행 조건 실패 시 계속 수집하지 않는다. 양수 결과만 선별하거나 새 미사용 평가로 이미 본 구간을 재포장하지 않는다.
5. 숫자 JSON 회귀 모델의 학습 라이브러리 일치, 미래 가격의 입력 차단, 정답 경계, 비용 조건과 위험 청산, 영속 실행 복원을 검증한다. 원본과 파생 결과는 로컬에만 보존한다.

공통 실행·보고 기준은 [v4 계획](EXPERIMENT_V4.md)과 같다. 실제 주문·인증·출금은 연결하지 않는다.
