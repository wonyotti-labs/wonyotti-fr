# 실험 v60 사전 계획: 보유 중 청산 순효과의 시간순 예측

2026-10-04. v59 전체 정답의 실제 관리 기회·50개 입력·청산 현금 흐름·유지 경로·원래 전체 계좌 재생을 대조했다. 조기 청산의 이익과 포기한 이익이 모두 존재하며, 전체 평균만으로 청산 정책을 바꾸지 않는다. 현재 상태로 청산 순효과를 구분할 수 있는지 단일 비선형 후보를 진단한다. 매매 적용은 이번 단계에 포함하지 않는다.

## 자료·분리·가중치

- 완료한 v59 전체 원장·원래 v54 연결·시세·생성 코드 사본·저장 연결·전체 재생 대조를 검증한다. 원자적 저장 파일은 읽기 전용으로 검사하며 상태·체결·비용·펀딩·정답을 다시 대조한다. 확정 행은 전체 원장의 자연 종료 행과 정확히 같아야 한다.
- 입력은 v59에서 실제 기록한 기존 50개 특징 그대로다. 순효과 정답·현재 순자산·미래 종료 시각·종료 사유·원래 최종 손익을 새 특징으로 넣지 않는다. 목표는 판단 당시 순자산 대비 청산 순효과 bp다.
- 학습은 포지션 시작과 판단이 2021년 1월 1일 이상이고 양쪽 정답이 9월 30일 00:00 UTC 전에 종료한 행이다. 진단은 포지션 시작과 판단이 10월 2일 이상이며 양쪽 정답이 12월 31일 전에 종료한 행이다. 포지션과 정답이 경계를 넘으면 그 포지션을 섞어 쓰지 않으며 모든 배제 사유를 보존한다.
- 학습 1,000행·100개 원래 포지션·방향별 20개 포지션·180일 범위, 진단 100행·30개 포지션·방향별 20개 포지션 이상을 요구한다. 지원 부족 시 조건을 낮추지 않는다.
- 각 구간 안에서 원래 포지션별 전체 비중이 같도록 행 가중치를 부여한 뒤 평균을 1로 맞춘다. 손익·승패로 가중하지 않는다. 긴 보유가 여러 판단을 만든다는 의존성은 남으며 가중치나 행 수를 독립 표본 수로 해석하지 않는다.

## 고정 모형과 판정

앞 구간에서 가중 표준화 Ridge alpha 100을 기준으로 학습한다. 후보는 v57과 같은 제곱 오차 히스토그램 회귀 하나다. 64회·학습률 0.05·깊이 2·최대 말단 4·최소 말단 64·L2 1·최대 구간 255·전체 특징·범주형 없음·조기 중지 없음·seed 0을 고정한다. 비교 상수는 앞 구간의 가중 평균이다. 후속 진단에 따른 모형·반복 수·문턱 탐색은 없다.

모든 행에서 금액 오차를 계산한다. 추가 청산의 진단 선택은 예측 순효과가 0bp보다 크고 원래 의도가 청산이 아닌 경우다. 양쪽 비용이 이미 정답에 포함됐으므로 양수 순효과를 사용하며, 원래 청산 요청은 그대로 유지할 대조다. 해당 행도 학습·오차·원장에서 삭제하지 않는다.

다음 조건을 모두 통과해야 별도 후속 매매 연구를 허용한다.

1. 진단 가중 평균 제곱 오차가 Ridge와 학습 평균 상수 각각보다 1% 초과 개선.
2. 진단 무가중 평균 제곱 오차가 Ridge보다 악화하지 않음.
3. 추가 청산 선택이 100행 이상이며 서로 다른 원래 포지션 30개 이상.
4. 선택한 행의 가중·무가중 실제 청산 순효과 평균이 모두 양수.

전체·방향별·월별 오차·선택 행·포지션·실제 순효과를 모두 기록한다. 같은 포지션의 여러 선택 이익을 더해 계좌 수익으로 표시하지 않는다. 진단 통과 뒤 전체 학습·매매 적용은 별도 계획을 고정하고 원래 위험·비용·다년 검증 기준을 유지한다. 실패 시 적용하지 않는다.

## 검증과 한계

독립 가중 평균·표준화·정규방정식과 숫자 내보내기, 라이브러리 회귀의 학습·진단 예측, 모든 분리·가중치·지표·판정을 대조한다. 후속 가격·정답·포지션 종료를 바꿔도 앞 구간의 행·가중치·모델이 변하지 않아야 한다. 저장 자료 변조·미완료·부모 불일치와 경계 교차를 거부한다.

정답은 기존 정책이 방문한 상태에서 기존 정책을 계속할 때와 청산할 때의 차이다. 새 정책이 다른 상태를 방문하고 다음 진입·거래 빈도도 달라지는 문제는 실제 연속 재생에서 따로 검증한다. 기존 전체 시스템이 2021년을 학습했고 이미 여러 가설을 관찰했으므로 새 미사용 평가가 아니다. 원본·파생 자료는 Git 제외, 실제 거래 연결은 제외하며 전체 수익성 기준은 v10 그대로다.
