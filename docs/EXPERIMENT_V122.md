# 실험 v122 사전 계획: 원본 관리 행동의 이진 빈도 균형 학습

2026-10-12. v121의 2020년 내부 선택은 깊이 2·256회를 선택했고, 2021년 하반기 세 행동의 로그 손실과 전체 F를 개선했지만 청산·축소 AP 보존에 실패했다. 같은 내부 비교에서 세 행동 AP도 이 설정이 가장 높았으므로 선택 지표만 AP로 바꾸는 재시도는 하지 않는다. 희소한 사건의 학습 기여를 바꿨을 때 순위와 요청이 함께 나아지는지 단일 가설을 검증한다. 개선을 전제하지 않는다.

## 단일 변경과 이전 실험의 구분

v35의 원본 50개 입력·전체 2020년 학습·2021년 상반기 보정·하반기 진단을 보존한다. v121에서 선택한 깊이 2·말단 최대 4·256회·학습률 .05·최소 말단 64·L2 1·255구간·전체 특징·범주형 없음·seed 0·조기 종료 없음 설정을 사용한다. 새로운 크기·기간·특징·손익 문턱 탐색은 없다.

각 행동은 별도 이진 모형이다. 원래 학습 행 N, 해당 행동의 양성 수 N1과 음성 수 N0에서 각각 가중치 N/(2N1), N/(2N0)를 적용한다. 세 행동을 하나의 다중 출력 가중치로 곱하지 않는다. class_weight는 None, sample_weight만 한 번 전달한다. 손실 거래·보유 행 제거와 재표집은 없다. 가중치는 전체 2020년 해당 행동 정답만 사용한다.

v41의 포지션별 총 기여 균등화와 다른 가중치다. v105는 자체 상태 없는 14개 시장 입력·5분 체결 기여분의 세 방향 분류와 최대 점수 실행이었으며 이번 50개 원본 보유 상태·세 독립 이진 행동·절편 보정·F 문턱과 다르다. 두 이전 실패는 유지한다. 이번에도 양성 비중 증가가 오탐·비용을 악화할 수 있어 요청 증가를 성공으로 간주하지 않는다.

## 가중치·대조·보정

각 가중치는 유한 양수이며 평균 1·총합 N·양성과 음성 각각 N/2를 검증한다. 각 행동의 전체 유효 표본 수 (sum w)^2/sum(w^2)는 1,000 이상이어야 한다. 원래 양성·음성 각각 20개 이상, 클래스별 유효 표본 수와 가중치·지원·최대 비중도 보존한다. 기존 전체·첫/반복 지원 조건을 유지한다.

새 모형은 한 묶음의 세 이진 모형이다. 기존 v121의 native64, capacity256, linear50을 변경 없이 복원해 대조한다. 이미 독립 재학습으로 검산한 대조의 완료 증거·전체 원본·모형·절편·예측·요청·문턱을 다시 정확히 대조한다. v121 후보는 미채택 상태의 설명 대조이며 기존 매매 정책으로 승격하지 않는다.

새 모형의 원시 점수는 바뀐 학습 비중에서 나온 값이다. 원래 모집단의 행동 확률이라고 바로 주장하지 않는다. 실제 2021년 상반기 원래 빈도로 기울기 1·기계 정밀도 확률 경계·[-64,64]·100회 이분법·평균 오차 1e-12의 절편 보정을 적용한다. 학습 가중치로 보정·평가를 다시 가중하지 않는다. 청산 F2·축소 F1·추가 F0.5, 전체 및 첫 축소/추가 문턱, 최소 예측 양성 20개·동률 높은 문턱·배율 1.0을 유지한다.

## 판정과 보존

v121과 동일한 25개 조건을 새 후보에 적용한다. 세 행동 각각 기존 native64 및 linear50 대비 로그 손실 1% 초과 개선(1e-12 경계 제외)·AP 보존, 자체 보정 전 손실 보존·상반기 상수 개선의 18개, 전체 세 행동 F 보존 3개, 첫 축소·추가 재현율·F 보존 4개다. 미채택 capacity256의 모든 동일 지표도 함께 공개하되 사후 좋은 행동만 섞지 않는다.

세 기간의 모든 확률·전체/첫/반복/네 이력 조합·모든 월·요청·문턱·정답을 보존한다. 작은 집단과 양성 0개도 남긴다. 모든 기간은 이미 관찰했다. 조건 미달은 그대로 기록하고 새 계좌로 확대하지 않는다. 통과해도 계좌 수익성은 별도 고정 계획의 다년·다시장·비용·펀딩·지연·낙폭·표본 검증이 필요하다. v10 최종 기준과 미해결 goal을 유지한다.

## 검산

각 이진 모형의 내보낸 숫자 형식·초기값·256개 트리·노드·유한성·깊이·차원을 검사한다. 총 768개 새 트리를 별도 라이브러리와 sample_weight 계산으로 재적합해 모든 트리·모든 확률을 대조한다. 본 구현의 벡터 가중치와 별도로 행별 클래스 빈도를 계산하고 공식 라이브러리 균형 가중치도 대조한다. 노드별 행 집합 분할 추론·단일/묶음 추론·절편·문턱·월별 지표·25개 판정을 검산한다. 소스·계획·원본·대조 지문을 실행 전후 확인하고 실패를 보존한다.

2021년 정답을 변경해도 2020년 가중치·새 학습 모형은 같아야 한다. 상반기 정답을 바꾸면 보정·문턱이 변할 수 있고, 하반기 정답만 바꾸면 보정·문턱도 같아야 한다. 가중치 중복 적용·행 순서 혼동·잘못된 행동 모형 연결·가중치 및 예측 변조를 검사한다. 원본·파생·모형·개별 결과는 로컬에만 유지하고 실제 주문·인증 연결은 없다.

가중치 정의는 [scikit-learn compute_sample_weight](https://scikit-learn.org/stable/modules/generated/sklearn.utils.class_weight.compute_sample_weight.html), 가중 학습은 [HistGradientBoostingClassifier](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.HistGradientBoostingClassifier.html)의 공식 API를 확인했다. 원시 점수의 확률 보정이나 수익 개선을 이 문서로 보장하지 않는다. 설치된 잠금 의존성은 유지한다.
