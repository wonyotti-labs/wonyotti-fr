# 실험 v33 사전 계획: 과거 독립 관리 주문의 맥락

2026-10-04. v32의 빈도 보정도 기존 청산 예측 기준을 넘지 못했다. 기존 점수의 사건 전후 진단에서는 이전 두 분까지 문턱 통과를 허용해도 같은 분 대조보다 포착 사건이 늘지 않았다. 단순한 몇 분의 시점 이동만으로 원본 행동 모사 실패를 설명하지 못한다.

현재 44개 입력은 누적 추가 횟수를 최대 다섯 번으로 자른 값과 잔량을 포함하지만 최근 독립 추가·축소가 언제 있었는지는 표현하지 않는다. 원본의 후속 주문 맥락을 알려진 과거 체결로만 추가하는 단일 특징 가설을 검증한다. 주문 제출·미체결·취소 시각을 복원했다고 주장하지 않는다.

## 고정 특징과 원본 연결

- 입력은 기존 44개에 증가·축소 각각 세 개, 총 여섯 개를 더한 50개다. 직전 해당 사건 존재 여부, 직전 사건 이후 분의 log1p(없으면 0), 직전 15분 독립 사건 수의 log1p다. 15분은 기존 시장 입력에 사용하는 한 구간으로 고정하며 기간을 검색하지 않는다.
- 원본 수량 원장의 주문별 첫 체결만 센다. 첫 체결에서 이미 관측한 증가·축소 행동을 사용하며 주문 전체의 마지막 수량·미래 최종 의도로 첫 행동을 바꾸지 않는다. 신규 진입·최종 청산·반전·펀딩은 이 두 과거 사건 종류에 포함하지 않는다. 같은 주문의 나중 부분 체결은 중복 사건이 아니다.
- 판단 경계보다 엄격히 이전이고 현재와 같은 포지션의 사건만 사용한다. 경계와 같은 시각의 체결은 입력에서 제외한다. 최근 구간은 [경계−15분, 경계)다. 포지션이 바뀌면 다른 포지션의 이력을 넘기지 않는다.
- 기존 원본 행·입력·지원 여부·정답·축소 크기와 학습·진단 구간은 보존한다. 미래 체결의 가격·수량·행동 변경이 과거 여섯 입력을 바꾸면 실패다. 원본 감사와 정답의 지문을 연결한다.

## 진단과 판정

새 모델은 기존과 같은 표준화 로지스틱 C=0.1 하나다. 2020년~2021년 상반기 학습, 2021년 하반기 진단과 기존 포지션·24시간 경계를 유지한다. 원래 44개 모델·학습 행·진단 행을 그대로 대조하며 특징 여섯 개 외에 모형·가중치·정답·기간을 바꾸지 않는다. 기존 최소 표본 기준도 유지한다.

각 행동의 로그 손실·Brier·평균 정밀도·ROC AUC·예측 평균과 실제 빈도를 비교한다. 후속 연구 허용에는 세 행동 모두의 로그 손실이 기존보다 1% 초과 개선되고(1e-12 경계 제외), 학습 빈도의 상수보다 좋으며 평균 정밀도가 기존 이상이어야 한다. 일부 행동 선택이나 기준 완화는 없다.

이 단계는 원본 과거 상태의 예측 진단이며 매매 실행이 아니다. 통과하더라도 봇 자신의 실제 체결에서 같은 이력을 재구성하는 영속 상태·복구·시점 검증과 별도 사전 매매 계획이 필요하다. 모든 기간을 이미 관찰했다. 기존 실패·원본·개별 결과는 로컬 보존하며 실거래 연결은 제외한다.
