# 실험 v92 사전 계획: 기존 보유 정책의 거래 비용·지연 검증

2026-10-10. v91에서 조건부 조기 청산 이득은 연속 계좌의 이득으로 이어지지 않았다. 두 기간 모두 재진입 증가와 짧은 보유 뒤 손실 한도에 도달했다. v54에 청산 예측기를 계속 붙이기 전에, 이미 보존한 v48의 양수 구간이 실행 비용 변화에도 유지되는지 확인한다. v48은 2021년 손실, 2022년 및 최근 구간의 거래 수 부족으로 탈락한 정책이며 이 실패를 취소하지 않는다. 과거 결과를 보고 연구 대상을 정한 사후 선택이다.

## 변경 없는 정책과 고정 실행

v48의 모든 숫자 모델·문턱·진입·추가·축소·청산·수량·보유 한도·위험 설정을 유지한다. 재학습·문턱 탐색·후보 선택은 없다. 아래 세 BTC 구간마다 네 조건을 처음부터 독립 계좌로 재생한다. 결과와 무관하게 열두 실행을 완료한다.

| 구간 | 시작 이상 | 종료 미만 |
| --- | --- | --- |
| 기존 확인 | 2022-01-01 | 2023-01-01 |
| 기존 장기 | 2023-01-01 | 2026-01-01 |
| 기존 최근 | 2026-01-01 | 2026-10-01 |

조건은 기본 수수료 5bp·슬리피지 3bp, 두 비용 각각 2배, 두 비용 각각 3배, 기본 비용에 추가 체결 지연 1분이다. 펀딩은 각 시각의 기존 값을 그대로 사용한다. 지연은 신호 체결에 적용하고 기존 위험 청산의 우선순위를 변경하지 않는다. 비용을 기존 손익에서 사후 차감하지 않고 계좌·수량·정책 판단을 다시 계산한다.

기본 조건 세 개는 과거 전체 분별 계좌·체결·거래·최종 상태와 정확히 같아야 한다. 기존 2021년 손실 및 2023·2024·2025년 독립 초기화는 검산된 파일 지문과 연결해 함께 보고하며 다시 실행했다고 표시하지 않는다. 모든 기간은 이미 관찰했다.

## 기록과 검증

원래 선택·모델·기존 검산의 호출자 지정 지문과 사용 시장 manifest를 고정한다. 누락·변조·다른 정책·기간·위험 설정을 거부한다. 실행마다 새로운 정책 객체와 계좌를 사용하고 전체 출력·실패·입력 검증을 별도 폴더에 남긴다.

합성 사례에서 비용 배율·지연·원래 위험 보존과 현금 회계, 과거 원장 대조, 독립 실행 간 상태 분리, 불완전 실행의 성공 판정 차단을 확인한다. 실제 열두 실행은 별도 엔진 순차 재생으로 모든 체결·거래·분별 계좌·최종 상태 및 현금·수수료·펀딩을 검산한다. 기존 원본 다섯 파일도 대조한다.

각 실행의 순손익·가격 손익·수수료·펀딩·거래 수·보유 시간·낙폭·중지를 보고한다. 최대 이익 거래 제거 후 손익과 기존 30일 순환 블록 1,000회·seed 41의 조건부 구간도 기록한다. 재표집은 후보 선택 불확실성이나 미래 수익 확률을 나타내지 않는다.

## 후속 판단
