# 실험 v79 사전 계획: 분별 이후 청산 대비 현재 청산 학습

2026-10-10. v78은 별도 보정 구간의 일곱 문턱 중 무조건 첫 적격 청산을 이기는 후보가 없었다. 사후 선택·시각 분해에서는 기본 문턱이 청산을 생략한 기여는 양수였지만, 실제 선택한 모든 포지션의 청산이 늦어지면서 그 이점을 잃었다. 이는 고정 개발 경로의 설명이며 새 후보의 수익성 근거가 아니다.

현재 분류기는 자연 종료와 비교한 청산 효과를 학습한다. 이번에는 이후 보조 정책의 최초 청산과 비교한 현재 청산 효과를 학습해, 기다리는 판단의 경제적 결과를 정답에 반영한다. v73의 같은 정답 구성을 분별 원장과 v78의 앞 학습·보정 분리에 적용하는 새 비교다. v73의 기존 실패·37개 조건과 v78의 실패를 소급 변경하지 않는다. 새 문턱 탐색은 하지 않는다.

## 기준과 시간 분리

v78의 모든 입력·모델·일곱 보정 문턱·선택 실패·진단 차단과 v77 이하의 기존 결과를 먼저 재현한다. 전체 분별 원장·74개 입력·원래 자연 종료 정답·비중·시간 배제 원장은 그대로다.

- 앞 학습: 진입·판단 2021-01-01 이상, 원래 정답 종료 2021-07-31 미만. 적합 시각 2021-08-02.
- 내부 보정: 진입·판단 2021-08-02 이상, 원래 정답 종료 2021-09-30 미만.
- 마지막 진단: 진입·판단 2021-10-02 이상, 원래 정답 종료 2021-12-31 미만. v78이 보존한 전체 진단 행과 정확히 같아야 한다.

전체 포지션 분리·이틀 간격·모든 미확정 및 경계 배제 기록을 유지한다. 부모 방향 모델이 2021년 말까지 학습한 개발 적합 경로이므로 이 내부 분할을 전체 봇의 당시 가용 성과로 표시하지 않는다. 모든 평가 기간은 이미 관찰했다.

## 같은 포지션을 제외한 다섯 보조 모델

v73과 같은 UTC 진입 시각의 나노초 십진 문자열 SHA-256 정수를 5로 나눈 나머지로 포지션을 분할한다. 각 보조 모델은 해당 분할 전체 포지션을 제외하고 원래 자연 종료 대비 정답으로 학습한다. 각 부분집합의 포지션 역빈도 비중을 평균 1로 정규화하고 비용 `w × |y|`를 사용한다.

모든 모델의 74개 입력·깊이 2·64회·학습률 0.05·말단·규제·seed·조기 종료 미사용 설정은 기존과 같다. 보조 학습마다 1,000행·100포지션·방향별 20포지션·180일, 비용 있는 1,000행·양쪽 부호별 64행 조건을 요구한다. 미달 시 실패를 보존하고 대체 모델을 사용하지 않는다.

각 학습 행의 보조 점수는 그 포지션 전체를 학습하지 않은 모델에서 얻는다. 교차 적합은 앞 학습 정답 구성용이며 보조 점수를 당시 실제로 사용할 수 있었던 거래 신호로 해석하지 않는다. 보조 점수·분할·미래 값은 최종 실행 입력에 추가하지 않는다.

## 이후 최초 선택에 따른 정답과 후보 하나

같은 포지션에서 현재 시각보다 엄격히 뒤에 있는 행 중 보조 점수 `q > 0.5`이고 원래 의도가 exit가 아닌 최초 행을 찾는다. 미래 최대 이익 시점을 선택하지 않는다. 그 행이 있으면 해당 청산 현금을 비교 현금으로 사용하고, 없으면 원래 자연 종료 현금을 사용한다.

`현재 청산 효과(bp) = (현재 청산 현금 − 이후 정책의 비교 현금) / 현재 순자산 × 10000`

v73의 미래 첫 선택 탐색을 재사용하되 이번 앞 학습의 더 이른 종료 경계를 별도로 강제한다. 원래 전체 행·행 번호·정답·비중과 새 정답·보조 모델·현재 점수·미래 첫 선택 시각·비교 현금·대체 사유·정답 가용 시각을 모두 보존한다. 정답 가용 시각은 원래 포지션 종료를 포함하며 7월 31일 경계를 넘지 못한다. 음수·0·원래 청산 의도·선택 없음 행을 지우지 않는다.

다섯 보조 모델 뒤 최종 분류기 하나를 원래 앞 학습 전체 행·74개 입력·원래 앞 학습 비중과 새 정답으로 한 번 적합한다. 0 비용의 학습 기여만 0으로 두고 비용·정규화·상수를 새 원장에 남긴다. 학습 구간을 방문 구간으로 줄이지 않으며 보정 후 다시 적합하거나 정책 개선을 반복하지 않는다.

내보내기 숫자 검증에는 앞 학습과 내부 보정 입력만 사용한다. 후보의 실행 문턱은 고정 `q > 0.5`다. 원래 청산 요청을 보존하며 문턱·모델 수·반복 횟수를 탐색하지 않는다.

## 내부 보정과 실패 분기

원래 자연 종료 대비 효과·같은 첫 가용 순자산·모든 포지션·선택 없음 0을 사용해 다섯 정책을 기록한다. 새 후보, 기존 v78 앞 모델의 0.5, 무조건 첫 적격 청산, 추가 청산 없음, 새 학습 상수다. 상수 정책이 앞의 두 단순 정책 중 하나와 같아도 점수와 정책을 모두 남긴다.

새 후보 하나가 최초 선택 30포지션 이상·전체 최초 평균 양수·기존 앞 모델 0.5보다 높은 전체 최초 평균·무조건 첫 청산보다 높은 전체 최초 평균을 모두 만족해야 다음 단계로 간다. 동률은 실패다. 새 후보 자체의 0.5 문턱은 고정이며 보정 구간은 후보 통과 여부 확인에만 사용한다.

실패하면 모델·정답·다섯 정책·모든 손실·지원·탈락 사유를 보존하고 새 마지막 진단 예측을 차단한다. v78에서 실패한 문턱을 대체 후보로 선택하거나 기준을 낮추지 않는다.

## 통과한 경우의 마지막 비교

내부 보정을 통과한 경우에만 새 후보와 기존 v78 앞 모델을 마지막 구간에 적용한다. v78에서 막혔던 앞 모델의 마지막 점수는 이번 비교의 대조로 처음 계산하는 것이며, v78의 판정이나 당시 실행 범위를 바꾸지 않는다.

기존 아홉 정책에 새 후보·기존 앞 모델 0.5·무조건 첫 청산·추가 청산 없음·새 학습 상수를 더한 열네 정책을 같은 모집단에서 평가한다. 전체·방향·월별 선택·가중 기회손실·최초 현금 효과·선택 없음과 모든 이전 결과를 보존한다.

후보와 기존 앞 모델 0.5·v75 분별 1분·v77 원래 비중 1분·무조건 첫 청산·추가 청산 없음·새 상수의 여섯 비교는 기존 13개 달력 주·1,000회·seed 63의 같은 추출을 사용한다. 새 점수는 이후 보조 정책 대비 비용 점수이며 원래 자연 종료 정답의 수익 확률로 해석하지 않는다. 원래 정답에 대한 비용 분류 지표는 비교용으로 남기되 서로 다른 정답의 확률 보정 개선으로 주장하거나 채택 조건으로 사용하지 않는다.

v78과 같은 실행 효과의 열두 조건을 적용한다.

1. 내부 보정의 네 조건 통과.
2. 마지막 구간 선택 기회 100개 이상.
3. 마지막 구간 최초 선택 포지션 30개 이상.
4. 선택 기회의 가중 평균 효과 양수.
5. 선택 기회의 무가중 평균 효과 양수.
6. 선택 포지션의 최초 평균 효과 양수.
7. 전체 포지션의 최초 평균 효과 양수.
8. 후보 최초 효과 구간 하한 양수.
9. 기존 v78 앞 모델 0.5 대비 차이 구간 하한 양수.
10. v75 분별 1분 정책 대비 차이 구간 하한 양수.
11. v77 원래 비중 1분 정책 대비 차이 구간 하한 양수.
12. 무조건 첫 적격 청산 대비 차이 구간 하한 양수.

추가 청산 없음 대비 차이는 후보 자체 효과와 같아야 하며 새 상수의 대응 관계도 대조한다. 기존 모든 실패는 그대로다. 최종 v10의 다년·다시장·비용·펀딩·지연·낙폭·표본·집중 조건을 바꾸지 않는다. 이 연구는 추가 청산 전 고정 경로의 조건부 효과이며 자체 상태의 재진입·연속 계좌 수익을 대신하지 않는다.

## 검증과 보존

변조한 이전 입력·모델·가중치·보정 결과·선택 실패·중첩 재현을 다시 봉인해도 새 보조 적합 전에 거부해야 한다. 앞 구간 분리·보조 모델의 전체 포지션 제외·원래 행 번호·비중·비용·모든 384개 새 트리를 대조한다.

미래 첫 선택은 별도 순방향 탐색으로 검산한다. 현재 행 제외·다른 포지션 연결 차단·원래 exit 제외·미래 선택 없음·음수·0·현금 환산·7월 말 경계를 검사한다. 보정 정답·마지막 입력과 정답을 바꿔도 보조 모델·앞 학습 정답·최종 모델은 바뀌지 않아야 한다. 마지막 자료는 내부 통과 여부도 바꾸지 않아야 한다.

선택 실패 뒤 마지막 예측이 호출되지 않는지, 선택 성공의 열네 정책·여섯 같은 추출·열두 판정을 검증한다. 코드가 같은 기존 검사와 봉인된 과거 입력 검산을 재사용하면 재사용 범위·파일 지문·새 검사 범위를 명시한다. 준비 오류와 실패는 보존한다. 원본·가공 자료·모델·개별 실행은 로컬에만 남기고 실제 거래 연결은 추가하지 않는다.
