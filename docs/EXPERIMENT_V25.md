# 실험 v25 사전 계획: 신규 포지션 시작과 추가 매수의 진입 활동 구분

2026-10-04. v23은 신규 진입에 사용하는 모델을 최근 원본으로 학습했지만 정답은 신규 시작·반전·기존 포지션 추가를 합친 노출 확대였다. v24의 실제 보유 종료 정답은 청산 의미를 맞췄지만 확인·후속에서 손실을 보였다. 손실과 모든 비교를 보존한다.

새 모델 학습과 손익 계산 전 원본 정답의 구성을 진단했다. 실제 신규 포지션은 대부분 보유 중 반전이며 무포지션의 신규 진입만으로 학습하기에는 지원 표본이 부족하다. 이번 가설은 실제 신규 포지션 시작을 활동 목표로 삼는 단일 변경이다. 실제 체결 시각을 판단·주문 제출 시각의 복원으로 해석하지 않으며, 원본의 보유 중 반전을 봇의 무포지션 진입에 적용하는 한계를 명시한다.

## 고정 변경

기준은 v23이며 v24 청산 변경은 혼합하지 않는다. 원본 수량 원장의 `open`·`reverse`가 실제 0에서 보유 또는 반대 방향의 새 보유로 이어졌는지 확인한다. 원래 5분 경계에서 다음 창 `[경계, 경계+5분)`의 첫 실제 신규 포지션이 있으면 활동 1, 없으면 0이다. 같은 시각 사건은 기존 원본의 안정된 순서를 사용한다. 여러 사건의 개수와 양방향·에피소드 원장을 보존한다. 기존 추가 사건은 신규 활동 정답에서 제외하되 원자료·손익·별도 원장에서는 삭제하지 않는다.

당시 14개 시장 입력과 원래 지원 행을 유지한다. 2020~2021년, 양쪽 24시간과 현재·새 목표 에피소드의 경계 제거를 그대로 적용한다. 활동 모델은 표준화 로지스틱 C=0.1·기존 최소 지원 1,000행/양쪽 20개·학습 점수 .975 분위로 고정한다. 새 포지션 방향의 지원 표본은 기존 1,000개 기준에 못 미치므로 방향 모델은 v23 그대로 유지한다. 지원 기준을 낮추거나 다른 학습 기간으로 대체하지 않는다.

v23의 방향 문턱 .65, v21의 44개 관리 입력·모델·축소 크기·빈도·진입 대기·수량·위험·비용·펀딩·지연을 그대로 보존한다. 후보는 하나이며 수익을 보고 기간·모형·문턱을 다시 선택하지 않는다. 활동 모델 이외의 파일 지문과 숫자 모델을 대조한다.

## 고정 검증

2021년 새 정책과 원래 v23을 적합 대조하고 원래 v23 전체 출력·상태 일치를 요구한다. 이후 고정한 2022년 확인이 양수·30거래·영구 중지 없음이면 전체 평가를 진행한다. 실패하면 BTC 두 후속 기간·세 독립 연도만 진단한다.

전체 평가는 세 시장·두 기간·열한 조건·아홉 독립 연도다. 조건은 새 정책, 원래 v7, 현금, 추가 제거, 30분 제한, 비용 2배·3배, 추가 1분 지연, 원래 v14, 원래 v21, 원래 v23이다. 직접 기준인 v23을 포함하고 이전 v20 단독 조건은 이번 비교에 포함하지 않는다. 전체 수익성 기준은 v10과 같으며 이미 관찰한 기간을 미사용 검증으로 부르지 않는다.

합성 사례에서 추가만 있는 창·즉시 반전·같은 분 여러 새 포지션·정확한 경계·불완전 마지막 창·경계 에피소드 제거를 검사한다. 실제 원본의 새 보유 수량 전이와 첫 사건 목표를 독립 재구성하고 시간 경계·모델 숫자·원래 방향 및 관리 모델·회계·프로세스 종료 복원·월간 재개를 대조한다. 미래 사건은 정답에만 사용하고 당시 신호 입력에는 넣지 않는다.

원본·파생 자료·모델·개별 결과는 로컬에 보존하고 실제 거래를 연결하지 않는다. 일부 정답의 의미를 좁히는 변경이며 원전략 복제나 수익 보장을 뜻하지 않는다.
