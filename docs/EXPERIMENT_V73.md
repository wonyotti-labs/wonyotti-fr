# 실험 v73 사전 계획: 이후 청산 정책을 반영한 정답

2026-10-09. v72 주간 갱신은 v71 대비 최초 효과를 개선했으나 최초 평균 효과가 여전히 음수였고 선택 전체의 기회손실은 커졌다. 서른두 조건 중 열세 개만 만족해 미채택했다. 이번에는 최초 청산 선택과 학습 정답의 차이를 조사한다. 이후 청산을 비교하는 목표가 개선을 만든다는 가정은 아직 검증되지 않았다.

## 기준과 시간

v72와 이전 결과를 재현하고 원래 전체 원장·학습·진단 행·가중치·제외 이력·모든 기존 모델 결과를 보존한다. 최종 후보는 v71과 같은 고정 학습 구간·74개 입력·분류기 설정으로 한 번 적합한다. v71 대비 학습 정답의 차이를 비교하며, 주간 갱신 v72도 추가 대조로 유지한다. 새 후보 자체는 주간 갱신하지 않으며 주간 갱신과 정답 변경의 효과를 혼동하지 않는다.

원래 학습은 2021-01-01 이상 진입·판단과 2021-09-30 미만의 정답 종료를 만족하는 전체 행이다. 새 청산 모듈 분할의 기준 시각은 2021-10-02로 고정한다. 진단은 기존 2021-10-02 이상부터 2021-12-31 미만의 고정 행이다. 새 정답과 보조 모델은 학습 자료 안에서만 구성한다. 진단의 결과나 이후 자료는 보조 모델·새 정답·문턱·설정 선택에 사용하지 않는다.

2026-10-09 실제 v73 적합 전 범위 명시: 원래 경로의 v54 진입 방향 모델은 v28 계획에 따라 2018~2021년 전체로 재학습됐고 마지막 정답 종료는 2021-12-24다. 따라서 2021년 원장은 개발 적합 경로이며 10월 2일 경계는 새 청산 모듈 내부의 분할이다. 봇 전체가 당시 가용한 모델로 생성한 검증 경로가 아니다. 기존 개발 구간 해석을 명확히 한 것이며 입력·정답 계산·조건은 변경하지 않는다. 최종 수익성 판단에는 이후 2022년부터의 연속 매매 검증이 필요하다.

## 포지션을 제외한 보조 정책

학습 포지션 진입 시각의 UTC 나노초 정수를 십진 문자열로 바꾼 뒤 SHA-256 전체 바이트를 부호 없는 큰 정수로 읽고 5로 나눈 나머지를 고정 분할 번호로 사용한다. 같은 포지션의 모든 행은 같은 분할에 속한다. 분할·개수·seed·문턱을 탐색하지 않는다.

다섯 보조 모델을 각각 해당 분할 전체 포지션을 제외하고 원래 자연 종료 대비 청산 효과로 학습한다. 각 학습 집합의 포지션 역빈도 비중을 평균 1로 다시 정규화한다. 원래 비용 `w × |y|`, 양수 비용의 평균 정규화, 0 기여 보존, 같은 74개 입력과 깊이 2·64회·학습률 0.05 등의 고정 설정을 사용한다. 최소 1,000행·100포지션·방향별 20포지션·180일과 비용 양수의 양쪽 부호별 64행 조건을 유지한다. 분할별 학습 원장·원래 행 번호·비중·비용·모델·지원과 제외된 포지션의 예측 연결을 남긴다.

각 학습 행의 보조 점수는 그 포지션 전체를 학습하지 않은 모델에서만 얻는다. 이는 앞 학습 구간의 고정 개발 경로에서 정답을 만드는 교차 적합이다. 보조 모델을 그 이전 시점에 실제 사용할 수 있었던 신호나 과거 매매 성과로 표시하지 않는다. 보조 점수는 최종 후보의 입력으로 추가하지 않는다.

## 이후 정책의 최초 청산과 새 정답

같은 원래 포지션 안에서 현재 판단보다 엄격히 뒤의 행만 살펴본다. 보조 정책이 `q > 0.5`이고 원래 의도가 `exit`가 아닌 최초 미래 행에서 추가 청산한다고 가정한다. 미래 선택이 없으면 원래 자연 종료까지 따른다. 미래 최대 현금이나 가장 이익인 시점을 고르지 않는다. 반복 정책 개선은 하지 않는다.

현재 판단 i에서 선택할 정답은 다음과 같다.

`stopping_advantage_bps = (close_cash_i - continuation_policy_cash_i) / decision_equity_i × 10000`

미래 최초 선택 j가 있으면 비교 현금은 `close_cash_j`이고, 없으면 원래 `continue_cash_i`다. 같은 포지션의 자연 종료 현금·시각 일치와 현재 현금 차이·순자산 환산을 검사한다. 현재 행 자체를 미래 선택으로 쓰지 않으며 포지션 사이를 연결하지 않는다. 원래 경로는 추가 청산하기 전까지만 유효하다.

새 정답 원장에는 원래 판단·진입·행 번호·원래 정답·가중치, 보조 분할·현재 점수, 미래 최초 선택 시각·행 번호·점수·비교 현금, 자연 종료 대체 여부, 새 손익·bp와 정답 가용 시각을 남긴다. 미래 값은 정답·검산 열에만 저장하고 74개 실행 입력에는 넣지 않는다. 정답 가용 시각은 원래 포지션의 종료를 포함하며 학습 경계를 넘지 못한다. 0 효과·음수·선택 없음과 원래 청산 의도 행을 제거하지 않는다.

## 최종 후보와 평가

다섯 보조 모델 이후 최종 비용 분류기 하나를 원래 전체 학습 행·74개 입력·원래 포지션 가중치와 새 정답으로 적합한다. 새 비용·정규화·학습 상수·0 기여는 별도 원장에 저장하고 기존 원래 비용 원장은 보존한다. 후보 형식과 점수 의미를 이후 정책 대비 청산 비용으로 구분한다. 고정 기준은 `q > 0.5`이며 원래 청산 의도를 덮어쓰지 않는다. 최종 적합은 한 번이고 모델·문턱·반복 횟수를 선택하지 않는다.

실제 개선 평가는 이전과 같은 원래 자연 종료 대비 정답·평가 비중·모든 포지션의 최초 효과로 수행한다. 새 목표가 낮아졌다는 이유만으로 채택하지 않는다. 원래 기준의 비용 로그 손실·Brier는 새 목표에 대한 확률 보정 지표가 아니며, 비교와 보수적 채택 조건으로 유지한다. 점수를 수익 확률로 해석하지 않는다.

v72의 서른두 조건을 모두 유지하고 고정 후보와 v72 사이의 다음 다섯 조건을 추가해 총 서른일곱 조건으로 평가한다.

1. 원래 비용 로그 손실이 v72보다 1% 이상 개선.
2. 원래 비용 Brier가 v72보다 악화되지 않음. 허용치 1e-12.
3. 원래 가중 기회손실이 v72보다 작음.
4. 전체 포지션의 최초 평균 효과가 v72보다 큼.
5. 후보와 v72 최초 효과 차이의 짝지은 주간 95% 구간 하한 양수.

후보와 v64·v69·v70·v71·v72의 다섯 비교는 기존 13개 달력 블록·1,000회·seed 63의 같은 추출을 쓴다. 원래 전체·방향·월 지표와 최초 선택·진입 월별 결과, 모든 기존 상수·손실·선택 없음을 보존한다. 원래 서른두 조건의 절대 양수·표본·비용 조건도 변경하지 않는다.

## 검증과 범위

각 보조 모델의 학습·제외 포지션 분리, 다섯 모델의 모든 트리·점수·학습 비중·비용을 독립 재구성한다. 각 학습 행의 미래 첫 선택을 별도 순방향 탐색으로 검산하고 자연 종료 대체·0·음수·원래 의도·현재와 같은 시각 제외·다른 포지션 연결 거부를 검사한다. 학습 이후 자료 변경은 보조 학습과 새 정답·최종 모델을 바꾸지 않아야 한다.

최종 모델의 모든 트리·점수와 원래 기준의 모든 지표·최초 선택·다섯 주간 비교·서른일곱 판정을 검산한다. 이전 출력과 원본 지문은 보존한다. 포지션 단위 교차 적합은 보조 정책의 같은 포지션 학습을 막는 장치이며 후속 기간의 일반화를 보장하지 않는다.

원래 추가 청산 전 경로의 연구이고 자체 상태의 재진입·계좌 복리 검증을 대신하지 않는다. 이미 관찰한 기간의 제한과 최종 v10 다년·다시장·비용·낙폭·표본 기준을 유지한다. 통과 전 실제 매매 정책에 적용하지 않고 주문·인증·출금 연결도 추가하지 않는다.

방법적 참고는 현재 행사와 계속 보유의 조건부 현금 흐름을 비교하는 [Longstaff·Schwartz (2001)](https://people.math.ethz.ch/~hjfurrer/teaching/LongstaffSchwartzAmericanOptionsLeastSquareMonteCarlo.pdf)다. 옵션 평가 방법의 참고이며 이 봇의 수익성 근거는 아니다.
