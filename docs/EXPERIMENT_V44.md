# 실험 v44 사전 계획: 다음 경계의 보유 방향 재구성

2026-10-04. v43의 결합 진입 예측은 기존 분해 모형을 넘지 못했다. 별도 수량 원장 진단에서 신규 포지션 정답의 대부분이 보유 중 반전이며 원본은 대부분의 시각에 포지션을 보유했다. 반전 방향을 무포지션 진입에 적용한 상태 의미 차이는 남아 있다. 이번에는 시장 정보로 원본의 절대 보유 방향을 재구성할 수 있는지 확인한다. 사건 발생 시각 예측과 다른 목표이며 원전략 또는 수익성 복원의 증거로 간주하지 않는다.

## 고정 정답과 입력

- v42의 2020년 학습·2021년 진단 행과 14개 시장 입력을 출발점으로 유지한다. 원본의 실제 수량 원장에서 각 다음 경계 label_end 직전 마지막 상태를 찾는다. 창은 기존과 같은 [end, label_end)이며 정확히 label_end의 체결은 제외한다. 정답은 flat=0, short=1, long=2다. 같은 시각의 마지막 원장 상태를 사용한다.
- 현재 경계 직전 상태도 별도 복원해 기존 방향·포지션 번호와 일치해야 한다. 현재와 다음 경계의 포지션이 기간 경계를 통과하면 제외하고 사유를 보존한다. 양쪽 24시간 제거와 원본 행의 기존 지원 제한을 유지한다. 새 정답·실제 손익에 따른 행 선택은 없다.
- 원본 수량·포지션 방향·시간·주문 이력은 정답 연결과 검증에만 사용한다. 예측 입력은 당시 확정된 14개 시장 특징뿐이다. 향후 봇이 원본의 과거 포지션을 조회하는 구조를 만들지 않는다.
- 단일 후보는 학습 전용 StandardScaler와 다항 LogisticRegression C=.1·lbfgs·최대 2,000회·seed 0·가중치 없음이다. v43과 숫자 학습 설정은 같고 정답 의미만 다르다. 모델 형식·클래스 이름을 구분해 잘못 불러오지 못하게 한다.
- 학습 1,000행·진단 100행, 각 클래스 20개 이상을 요구한다. 보유 방향의 시계열 지속으로 행들이 독립 표본이 아니라는 한계를 명시하고 월별·포지션별 지원을 기록한다. 새 모델 학습 전 클래스 지원 집계만 확인했다.

## 사전 고정 판단

학습 클래스 빈도 상수와 비교한다. 2021년 전체 다중 클래스 로그 손실이 상수보다 1% 초과 낮고 long·short 각각의 평균 정밀도가 해당 상수 이상이며, 월별 로그 손실도 12개월 중 적어도 8개월에서 상수보다 낮아야 한다. 세 클래스 Brier·혼동행렬·월별 손실과 실제 빈도·각 방향의 요청·적중을 기록한다. 요청은 p_long 또는 p_short가 .65 이상일 때만 해당 방향, 그 외에는 대기로 고정한다. 문턱 최적화는 없다.

이전 진입 사건 모델의 hold 확률은 신규 사건 없음이며 이번 flat은 실제 수량 없음이므로 같은 정답인 것처럼 손실을 비교하지 않는다. 새 모델을 정답과 무관한 상수보다 낫다는 이유만으로 수익 전략으로 채택하지 않는다. 모든 조건 통과 시에만 별도 사전 계획으로 무포지션 진입의 변경과 실제 비용 포함 손익을 검증한다. 실패하면 이번 모델의 매매 적용을 차단한다.

## 재현과 한계

독립 시각 검색과 수량 원장·현재 및 목표 포지션·전체 배제 원장을 대조한다. 별도 표준화와 다항 재학습·수기 softmax·로그 손실·평균 정밀도·Brier·혼동행렬·월별 판정을 확인한다. 같은 시각 복수 체결·정확한 경계·보유 지속·중간 반전·무포지션과 기간 경계를 합성 검사한다. 미래 진단 정답·입력 변경은 학습 모델과 학습 빈도를 바꾸지 않아야 한다.

모든 기간은 이미 관찰했다. 원본의 보유 방향이 수익성 있는 진입 방향이라는 가정은 입증되지 않았다. 지속된 원본 보유를 여러 행으로 관찰한 것이 새로운 독립 거래를 추가하지 않는다. 기존 지원 행의 선택과 거래소·실행 차이도 남는다. 원본·파생 자료·모델·개별 결과는 로컬 전용이며 실제 주문 연결은 없다.
