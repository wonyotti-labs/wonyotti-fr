# 실험 v26 사전 계획: 신규 포지션 방향의 학습 빈도 차이 보정

2026-10-04. v25는 활동 목표에서 추가 매수를 분리했으나 방향 모델은 원래 v23의 전체 확대 사건 모형이다. 2022년 확인 통과 후 시작한 장기 기본 조건은 세 시장에서 손실을 보였다. 나머지 사전 대조와 실패도 완료·보존한다.

새 학습·성과 실험 전 원본 방향 진단에서 전체 확대 사건과 실제 신규 포지션의 롱·숏 빈도가 다르고, 같은 신규 사건의 기존 방향 점수가 한쪽으로 치우친 것을 확인했다. 이 결과는 기존 학습 기간 안의 조건부 진단이다. 조건부 특징 분포까지 같다고 확인한 것은 아니며, 평균 빈도 보정이 조건부 확률이나 수익성을 보장하지 않는다.

## 단일 고정 보정

기준은 v25이다. 신규 활동 모델과 관리·청산·축소·진입 대기·위험·비용·펀딩·지연을 유지한다. 방향 분류기의 표준화·14개 계수와 방향 문턱 .65는 고정하고 절편에 아래 값 하나만 더한다.

`log(신규 롱 수 / 신규 숏 수) - log(기존 확대 롱 수 / 기존 확대 숏 수)`

기존 수는 v23 방향 학습에 실제 사용한 원본 행의 집계와 저장된 학습 메타데이터를 대조한다. 신규 수는 v25의 동일 2020~2021년 학습 정답 중 활동 1인 행만 사용한다. 양쪽 경계·지원 행·목표 에피소드 제거를 그대로 유지한다. 학습 기간 밖의 방향이나 손익은 보정에 사용하지 않는다.

이는 고정 분류기의 경험적 사전 오즈 이동이며 새 특징 계수의 재학습이 아니다. 기존 전체 방향 모형의 1,000행 지원 기준은 유지한다. 빈도 추정은 원래·새 목표 각각 롱·숏 최소 50개와 신규 사건 전체 최소 200개를 요구한다. 부족하면 멈추고 학습 기간·기준을 바꾸지 않는다. 후보는 하나이고 절편 이동에 배수·추가 최적화·손익에 따른 문턱 선택을 적용하지 않는다.

이 방식이 정확한 확률 보정이 되려면 레이블별 특징 분포가 유지되어야 한다. 진단에서 분포의 동일성을 입증하지 못했으므로 이 가정은 한계로 남긴다. 신규 사건 대부분이 원본의 보유 중 반전이라는 무포지션 실행과의 차이도 그대로다.

## 고정 검증

새 정책과 원래 v25의 2021년 적합 재생, 원래 v25 전체 출력·상태 일치를 먼저 확인한다. 고정 후 2022년 양수·30거래·영구 중지 없음이면 전체 평가를 진행한다. 실패하면 BTC 후속 두 기간·세 독립 연도만 진단한다.

전체 평가는 세 시장·두 기간·열한 조건·아홉 독립 연도다. 조건은 새 정책, 원래 v7, 현금, 추가 제거, 30분 제한, 비용 2배·3배, 추가 1분 지연, 원래 v14, 원래 v21, 직접 기준인 원래 v25다. 이전 v23 단독 조건을 v25로 대체한다. 전체 수익성 기준은 v10과 같고 모든 기간은 이미 관찰했다.

합성 사례의 오즈 항등식·계수 불변·지원 부족 거부·원본 빈도 집계·잘못된 변경 및 모델 계층 거부를 검사한다. 실제 원본 집계를 독립 대조하고 보정 숫자·수량·기준 정책·회계·프로세스 종료 복원·월간 재개를 검증한다. 실패와 원본·파생 자료는 로컬에 보존하고 실제 거래를 연결하지 않는다.
