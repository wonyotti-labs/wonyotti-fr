# 실험 v61 사전 계획: 청산 순효과 금액의 시간순 보정

2026-10-04. v60은 청산 순효과의 가중 예측 오차를 줄였지만 양수 예측으로 선택한 상태의 실제 평균 효과가 음수였다. 해당 모델의 매매 적용은 차단했다. 금액 예측의 수준과 크기가 이후 구간에서 어긋나는 문제를 독립 보정 구간으로 수정할 수 있는지 진단한다. 실패한 진단 구간에서 문턱을 고르거나 바로 매매에 적용하지 않는다.

## 동일 자료와 세 구간

완료한 v60의 필수 출력·계획·입력 지문을 확인하고 원래 v59 전체 검증부터 v60 학습·예측·지표까지 다시 실행해 정확히 재현한다. 원래 50개 입력·청산 순효과 정답·전체 원장을 보존한다. 포지션 시작과 판단 시각이 각각 아래 시작 이상이며 정답 종료가 끝 시각 미만인 확정 행만 포함한다.

- 학습: 2021년 1월 1일~6월 30일. 1,000행·100포지션·방향별 20포지션·150일 판단 범위 이상.
- 보정: 7월 2일~9월 30일. 100행·30포지션·방향별 20포지션 이상.
- 진단: 10월 2일~12월 31일. 100행·30포지션·방향별 20포지션 이상. v60의 진단 행과 정확히 같아야 한다.

시간·포지션·정답 경계를 넘는 사례와 미확정을 전체 배제 원장에 보존한다. 각 구간 내부에서 포지션별 총 비중을 같게 하고 행 평균 가중치를 1로 맞춘다. 보정이나 진단 자료가 앞 구간 가중치·표준화·모델에 영향을 주지 않아야 한다. 학습 범위가 반년으로 짧아진 영향은 같은 앞 구간으로 다시 학습한 모든 비교 모형에 공통이다.

## 단일 보정과 비교

학습 구간에서 v60과 동일한 가중 표준화 Ridge alpha 100과 히스토그램 회귀 하나를 학습한다. 부스팅 설정 64회·0.05·깊이 2·최대 말단 4·최소 말단 64·L2 1·구간 255·전체 특징·범주형 없음·조기 중지 없음·seed 0은 고정한다. 후보는 그 부스팅의 금액 예측에 보정 구간에서 한 번 맞춘 선형 보정 하나다.

보정식은 `a * 예측 + b`다. 포지션 가중 공분산을 예측 분산으로 나눈 기울기를 구하고 0 이상으로 제한한다. 예측 분산이 0이면 기울기는 0이다. 절편은 보정 정답 평균에서 기울기와 보정 예측 평균의 곱을 뺀 값이다. 이는 순위를 뒤집지 않는 가중 최소제곱 보정이며 수익 최적화나 문턱 검색이 아니다. 후보는 하나이며 방향·월마다 따로 보정하지 않는다.

비교는 같은 학습 구간의 미보정 부스팅·Ridge·학습 정답 가중 평균 상수와 보정 정답 가중 평균 상수다. 보정 평균 상수를 추가해 단순한 전체 수준 이동을 학습된 구분 능력으로 주장하지 않는다. 원래 청산을 포함한 모든 행의 오차를 계산한다. 추가 청산은 보정 예측이 0bp보다 크고 원래 청산 의도가 아닌 경우이며 원래 청산은 학습·오차·원장에서 유지한다.

## 고정 통과 조건

다음 열 가지 조건을 모두 요구한다. 진단 후 완화하거나 새 보정 모형을 검색하지 않는다.

1. 가중 평균 제곱 오차가 네 비교 각각보다 1% 초과 개선: 네 조건.
2. 무가중 평균 제곱 오차가 미보정 부스팅과 Ridge 각각보다 악화하지 않음: 두 조건.
3. 추가 청산 선택 100행 이상·원래 포지션 30개 이상: 두 조건.
4. 선택한 실제 순효과의 가중·무가중 평균이 모두 양수: 두 조건.

전체·방향·월별 오차와 선택 수·포지션 수·실제 평균 효과, 각 구간 지원과 보정 계수를 남긴다. 같은 포지션의 선택 효과를 합산해 계좌 수익으로 표시하지 않는다. 실패 시 매매 적용을 차단한다. 통과 시에도 전체 학습·정책 적용은 별도 계획과 기존 다년·다시장·비용·위험 기준의 연속 재생을 요구한다.

## 검증과 한계

독립 구간 분리·포지션 가중치·가중 정규방정식·부스팅 재학습·보정 계수·전체 지표·열 가지 판정을 검산한다. 상수 예측·음의 상관·비유한 값·잘못된 가중치와 입력 변경을 검사한다. 보정 구간 변경은 앞 모델을 바꾸지 않고, 진단 입력·정답·종료 변경은 앞 학습·보정 행과 가중치·모델·보정 계수를 바꾸지 않아야 한다.

전체 시스템은 이 기간을 이미 사용했고 v60의 실패도 관찰했다. 새로운 미사용 평가가 아니며 보정 개선이 다른 시장·향후 상태의 수익성을 보장하지 않는다. 원본·파생 자료·개별 결과는 로컬에 보존하고 Git에서 제외한다. 실제 거래 연결은 포함하지 않으며 전체 수익성 기준은 v10 그대로다.
