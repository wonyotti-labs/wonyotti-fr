# 실험 v123 사전 계획: 일간 변동성 단위의 보유 가격 경로

2026-10-12. v121의 모델 크기 선택은 원본 로그 손실과 일부 요청을 개선했으나 청산·축소 순위 품질에 미달했고, v122의 이진 균형 학습은 이 문제를 해결하지 못했다. 현재 50개 입력은 과거 변동성과 보유 가격 경로를 각각 제공한다. 얕은 트리가 두 값의 비율을 직접 표현할 수 있도록 네 개 입력을 추가하는 가설을 검증한다. 기존 상태 차이(v113)가 손실의 원인이라고 확정하거나 새 입력의 개선을 전제하지 않는다.

## 원본 보존과 네 입력

원본 v35의 50개 특징·2020년 전체 학습 510,102행·2021년 상반기 보정 256,234행·하반기 진단 252,124행, 정답·포지션·24시간 경계를 유지한다. 새 시세·주문·미래 상태를 추가하지 않고 이미 그 시점에 확정된 입력만 변환한다. 보유 방향 d는 +1 또는 -1이다.

- σ는 기존 `vol_1d`다. 이는 확정 5분 로그 수익률 288개의 표본 표준편차 × sqrt(288)이며 사용 가능한 마지막 확정 5분봉까지다. 분모는 max(σ, 1e-8)로 고정한다. 이 하한은 0 변동성의 계산 정의이며 검증 성적으로 선택하지 않는다. 하한 적용 행을 별도 집계한다.
- 기존 유리한 변화 m을 방향 보정 로그 변화 L(m)=d×log1p(d×m)로 변환한다. `favorable_move`, `best_close_move`, `worst_close_move` 각각의 L(m)/분모가 세 입력이다.
- 네 번째는 최선 가격에서 현재 가격까지 되돌림의 방향 보정 로그 변화 / 분모다. 작은 차이의 소거 오차를 피하기 위해 d×log1p(d×giveback_from_best/(1+d×favorable_move))/분모로 계산한다. 이는 L(best)-L(current)와 대수적으로 같다.

입력 이름은 `vol_path_current`, `vol_path_best`, `vol_path_worst`, `vol_path_giveback`이다. 원래 50개는 제거·교체하지 않고 합계 54개를 사용한다. 이는 일간 변동성 크기를 단위로 쓴 설명 변수이며 정규분포의 z 점수·손실 확률·포지션 위험 한도라고 해석하지 않는다. 변동성 관찰창·분모·특징 목록의 탐색은 없다.

방향, 음수 변동성, 가격 비율 1+d×m의 양수·유한성, best≥current≥worst, 원래 giveback=best-current를 확인한다. 범위 밖 행을 조용히 제거하거나 임의 값을 채우지 않고 실패로 기록한다. 분모 하한 외 새 특징의 절단은 없다. 계획 전 계산 지원 확인에서 전체 1,018,460행의 `vol_1d`가 양수였고 최솟값은 학습 0.00551835·보정 0.01709021·진단 0.01736176이었다. 세 가격 비율의 최솟값도 각각 0.720796·0.656162·0.690918로 양수다. 아직 새 입력의 모델을 학습하지 않았다.

## 고정 학습과 대조

새 후보는 54개 입력의 무가중 부스팅 한 묶음이다. v121에서 2020년 내부 비교로 선택한 깊이 2·최대 말단 4·256회·학습률 .05·최소 말단 64·L2 1·255구간·전체 특징·범주형 없음·seed 0·조기 종료 없음·클래스/표본 가중치 없음 설정을 유지한다. v122 가중치와 미채택 모형은 사용하지 않는다. 54개 입력의 StandardScaler(학습 행만 적합)·로지스틱 C=.1·2,000회·seed 0·무가중 대조도 학습한다.

기존 native64·capacity256·linear50은 v121의 봉인된 모형·절편을 복원하고 전체 확률·요청·문턱·모든 월 지표를 정확히 재현한다. 같은 크기의 capacity256과 새 후보의 차이가 네 입력 추가인지 구분한다. v121 후보를 기존 매매 정책으로 승격하지 않는다. v122 완료·실패 근거도 연결하고 이전 실패를 보존한다.

절편은 2021년 상반기에서 기울기 1·기계 정밀도 확률 경계·[-64,64]·100회 이분법·평균 오차 1e-12를 유지한다. 전체 문턱은 청산 F2·축소 F1·추가 F0.5, 첫 축소/추가는 해당 과거 체결이 없는 행에서 같은 기준이다. 최소 예측 양성 20개·동률 높은 문턱·배율 1.0과 원래 전체·첫/반복 지원을 유지한다. 상반기 성적·하반기 성적·순손익으로 입력이나 모델을 다시 선택하지 않는다.

## 사전 판정: 31개 조건

기존 25개 구조를 유지하되 선형 비교는 같은 54개 입력의 새 선형이다. 세 행동 각각 native64 및 새 linear54 대비 로그 손실 1% 초과 개선(1e-12 경계 제외)·AP 보존, 자체 보정 전 손실 보존·상반기 상수 개선의 18개, 전체 세 행동 F 보존 3개, 첫 축소·추가 재현율·F 보존 4개다. 추가로 같은 크기 capacity256의 세 행동 로그 손실과 AP를 각각 보존하는 6개 조건을 요구한다. 모든 보존 경계는 1e-12다. 이전 linear50도 설명 대조로 남긴다.

세 기간의 전체·첫/반복·네 이력 조합·모든 월·확률·요청을 보존한다. 원래 변동성의 학습 전용 사분위 경계로 네 구간을 고정해 각 기간의 모든 행동·모형 지표도 기록한다. 중복 경계는 병합하지 않고 비어 있는 구간을 유지하며 경계와 같은 값은 낮은 구간에 넣는다. 이 집계는 설명 자료이고 주 판정을 대체하지 않는다. 적은 표본·양성 0개도 남기고 좋은 구간만 고르지 않는다.

미달은 그대로 기록하고 새 계좌로 확대하지 않는다. 통과해도 자기 상태 경로와 비용·펀딩·지연·낙폭·다년·다시장·표본 검증은 별도 고정 계획이 필요하다. 모든 기간은 이미 관찰한 자료이고 v10 최종 수익성 기준과 미해결 goal을 유지한다.

## 독립 검산

원래 열·행·정답·순서를 정확히 대조하고 새 4,073,840개 값을 행별 스칼라 계산으로 확인한다. 합성 가격의 롱/숏 포지션, 같은 가격, 작은 되돌림, 0 변동성 하한, 비정상 방향·가격 비율·경로·비유한 값과 변조를 검사한다. 로그 변환의 안정적인 계산에는 NumPy의 `log1p`, 독립 대조에는 Python 스칼라 `math.log1p`를 사용한다. 계산 정의가 미래 가격이나 정답을 읽지 않음을 입력 변경 검사로 확인한다.

새 부스팅 768개 트리·선형 표준화와 계수를 별도 라이브러리 적합으로 검산한다. 전체 확률·보정·문턱·행동별 지표·모든 월·변동성 구간·입력 분기 수·31개 판정을 별도 계산과 대조한다. 2021년 정답 변경 시 학습 모델·변동성 경계는 같아야 하며, 하반기 정답만 바꾸면 보정·문턱도 같아야 한다. 상반기 정답 변경은 보정을 바꿀 수 있다. 코드·계획·입력·대조의 시작/종료 지문과 실패를 보존한다. 원본·파생·모형·개별 결과는 로컬에만 두고 실제 주문·인증 연결은 없다.
