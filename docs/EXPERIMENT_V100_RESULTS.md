# v100 희소 체결 학습과 자기 계좌 실행 결과

2026-10-11. [고정 계획](EXPERIMENT_V100.md)에 따라 [가격 보완](EXPERIMENT_V100_PRICES.md) 후 체결·정산의 노출 기여분만 학습했다. 2020년 지원 92,748행의 감소·거래 없음·증가 정답은 각각 1,255·90,372·1,121개였다. 방향별 크기 지원 128개 기준을 모두 충족해 사전 고정한 세 행동 분류와 두 크기 모형을 함께 사용했다. 클래스 가중치·재표집·사후 문턱 변경은 없었다.

## 원본 상태를 사용한 한 단계 진단

2021년 전체 연결 행 104,448개를 보존했고, 현재 상태가 지원되는 92,003개에 예측을 저장했다. 그중 현재·다음 회계 분해가 지원되는 동일 89,563개 행으로 모든 대조를 채점했다. 감소·거래 없음·증가 정답은 1,214·87,208·1,141개다. 이미 관찰한 진단 기간이며 실제 연속 운용 성과와 구분한다.

## 자체 계좌의 연속 실행

원본 계좌 상태 없이 봇의 수량·종가·평가액으로 현재 노출을 계산했다. 거래 없음은 목표 재제출 없이 수량을 유지하는 명령이다. v98의 실행기·위험·비용·펀딩 및 두 시장 입력을 유지하고, 기존 여섯 대조의 설정·입력·전체 파일 해시를 연결했다.

## 검산과 남은 작업

학습·숫자 모형·지표 검사 22개, 실행·기록·변조 거부 검사 15개를 통과했다. 학습 단계는 별도 라이브러리 재학습의 320개 트리·선형 대조·전체 예측·모든 단일 상태 추론과 월별 지표를 비교했다. 실행 단계는 두 경로의 1,051,200분과 호출된 5분 판단 210,238개의 확률·크기·행동·목표를 별도 회계와 순차 실행으로 대조했다. 각 경로의 두 JSON 상태 복원도 확인했다.

원본 5개·공유 소스 245개·v93 검산 도구 24개의 해시를 유지했다. 원본·파생 자료·모형·개별 실행·저널은 Git 제외 상태다. 준비 구현의 운영 등록 및 동일 결과 재현은 남아 있으며, 이 검사 수를 운영 전체 테스트 수로 표시하지 않는다. 실제 거래 연결은 없다.
