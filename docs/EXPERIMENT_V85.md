# 실험 v85 사전 계획: 과거 첫 기회 추가 학습

2026-10-10. v84의 실제 자료 생성·독립 검산을 완료했다. 기존 2021년 첫 행·현금·입력이 정확히 같았고, 2020년 추가 확정 정답 414개를 확보했다. v81~v83의 반복 내부 실패를 유지한 채 학습의 시간 범위를 확장한다. 새로운 모델 적합 전에 이 계획을 고정하며 보정 성과를 보고 학습 기간·행을 선택하지 않는다.

변경은 학습 포지션의 추가로 제한한다. v84의 2020-04-01 이상, 2021-01-01 미만 경로에서 첫 적격 기회이면서 2020-12-31 미만 자연 종료 확정인 모든 정답을 기존 v82의 2021년 앞 학습 첫 적격 기회에 시간순으로 결합한다. 2020년 전체 포지션·원래 모든 관리 기회·기회 없음·미확정·0·손실은 별도 원장에 보존한다. 원래 2021년 첫 행·현금·74개 입력과 기존 비용 원장은 정확히 대조한다. 추가 연도나 좋은 월·방향·수익 부호에 따른 표본 선택은 없다.

입력 74개, 첫 가용 순자산 기준 bp 정답, 포지션 비중 1, 0 비용 포함 표준화, 양의 절대 비용 정규화, L2 로지스틱 C=0.1·lbfgs·tol=1e-9·max_iter=2000, 엄격한 0.5 문턱, 첫 거절 후 재선택 금지를 v82와 유지한다. 과거 자료 추가로 평균·척도·비용 정규화와 계수가 바뀌는 것은 허용하되 설정·수렴 한도는 바꾸지 않는다. 모델은 하나이며 비용 상수 대조 하나를 함께 기록한다.

자료 출처·포지션을 연결한 통합 첫 원장과 비용 원장을 저장한다. 원본 전체 행을 복제 학습하지 않고 같은 포지션의 첫 기회만 한 번 쓴다. 날짜·시각·원래 의도와 확정 경계로 선정하고 현금 부호로 선정하지 않는다. 지원 조건은 적격 500포지션·양쪽 방향별 20·양쪽 비용 부호별 64·180일을 유지한다.

보정은 2021-08-02 이상 진입·판단, 2021-09-30 미만 확정의 같은 전체 96포지션을 사용한다. v83의 기존 열한 정책을 저장된 점수에서 다시 계산해 보존하고 새 확장 모델·확장 비용 상수를 더한다. 새 후보의 조건은 선택 30포지션 이상, 전체 최초 평균 양수, 그리고 기존 고정 선형·주간 선형·첫 트리·직접 회귀·이후 정책 분류·자연 종료 분류·항상 첫 청산·확장 상수 각각보다 엄격한 개선, 총 열 조건이다. 기존 모델 재적합·문턱 탐색·보정 후 갱신은 없다.

이 모든 조건을 통과해야 별도 고정 마지막 진단과 연속 계좌 검증으로 진행한다. 내부 평균은 실제 계좌 수익이 아니며 2020년 경로의 부모는 2021년까지 학습했으므로 당시 이용 가능한 정책 수익으로 해석하지 않는다. 같은 이미 관찰한 보정에 대한 반복 연구라는 제한을 유지한다. 최종 v10의 다년·다시장·비용·펀딩·지연·낙폭·거래 수·집중 조건은 유지한다.

독립 검산은 추가 전체 첫 행과 제외 원장, 기존 원장 동일성, 별도 라이브러리 적합의 평균·척도·계수·절편·수렴, 모든 숫자 예측, 원래 열한 정책·새 두 정책·모든 조건·원본 다섯 파일 보존을 확인한다. 실제 추가 자료의 이전 검산 지문을 검증하고 시세 생성 엔진을 이번 모델 검산에서 다시 실행했다고 주장하지 않는다.

추가 원장과 기존 비교의 독립 검산 JSON은 각각 호출자가 지정한 SHA-256으로 신뢰 지점을 고정한다. 봉인된 입력·원장·전체 경로·생성 코드·사전 계획의 지문과 검사 범위를 확인한 뒤 재사용한다. 후속 보정·마지막 정답·출처 변경이 적합 전에 거부돼야 한다. 합성 계약 검사를 실제 이전 모델 재현으로 표시하지 않는다. 실제 적합 전 별도 검산 도구와 테스트 근거도 고정한다. 원본·가공·시장·모델·개별 결과는 로컬에 유지하고 실제 거래 연결은 없다.
