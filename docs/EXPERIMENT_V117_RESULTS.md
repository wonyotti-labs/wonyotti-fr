## 검증과 제한

부스팅 384개 트리와 선형 세 적합의 표준화·계수·절편을 별도 라이브러리 재학습과 대조했다. 전체 1,018,460행의 원시·보정 확률과 문턱·전체 및 월별 지표·18개 판정·특징 사용 수를 검산했다. 원본 대조는 v35 모델·절편·진단 점수와 정확히 일치했다.

학습 단계 신규 14개와 관련 40개, 총 54개 검사 및 Ruff를 통과했다. 관련 검사에는 입력 단계 신규 24개가 포함되며 입력 단계의 65개 실행 수와 단순 합산하지 않는다. 진단 입력·정답 변경 시 학습·절편 불변, 원본 보존, 입력 범위·포지션 중첩 거부, 정확히 1%인 경계 및 단일 행동 실패, 합성 전체 실행과 독립 재학습을 포함한다. 실제 시작 시 고정한 공개 모듈 331개와 총 338개 파일 지문은 종료까지 같았다. 전체 테스트 모음·최신 원격 CI 통과는 주장하지 않는다.

입력 첫 실행의 합산 오차와 수정은 입력 보고서에 보존했다. 모델 설정·기간·정답·지원 행·예측 기준은 바꾸지 않았다. v115의 손실·최대 수익 거래 집중·최근 BTC 8거래와 v116의 기준 미달은 별도 결과로 남는다. v10의 다년·다시장·비용·펀딩·지연·낙폭·표본·집중 기준을 유지하며 실제 거래 연결은 없다. 원본·시세·모델·개별 출력은 로컬에만 보존한다.
