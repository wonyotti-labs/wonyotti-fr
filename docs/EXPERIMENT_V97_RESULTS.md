# 실험 v97 결과: 계좌 노출의 시장 정보 예측

2026-10-11. [사전 계획](EXPERIMENT_V97.md)의 2020년 학습·2021년 진단을 완료했다. 담보 포함 BTC 부분 민감도를 계좌 평가액으로 나눈 정답을 사용했다. 고정 비선형 후보는 학습 평균 상수보다 MSE가 0.20%, 선형 대조보다 2.48% 낮았지만 2021년 예측이 모두 양수였다. 매도 방향 재현율은 0%이며 원본의 방향 전환을 재현했다고 볼 수 없다.

지표는 같은 지원 행 92,000개에서 계산했다. 전체 104,448개 행에는 모두 예측을 남겼다. 학습에는 전체 104,148개 중 92,836개를 사용했다. 입출금 시각 불확실성·해당 봉의 실제 거래가 없는 가격·그 중복 사유를 각각 보존했으며 정답 크기나 수익으로 행을 제외하지 않았다. 미지원 행에 가짜 정답을 대입하지 않았다.

월별 MSE가 학습 평균 상수보다 낮은 달은 6/12개, 선형 대조보다 낮은 달은 9/12개였다. 매수 방향이 많은 기간의 방향 적중률 약 83.75%만으로 양방향 전략이 학습됐다고 주장하지 않는다. 노출 1 상수가 더 낮은 오차를 보인 사실도 함께 남긴다. 후보를 이 상수나 선형 대조로 사후 교체하지 않았다.

현재 원본 노출을 다음 경계까지 그대로 유지한 진단 기준은 양쪽 정답이 지원되는 89,563개 행에서 MSE 0.001415였다. 같은 행의 비선형 후보 MSE는 1.068466다. 원본 계좌 상태는 실제 봇이 조회할 수 없으므로 이 낮은 오차를 실행 가능한 전략의 성적으로 표시하지 않는다. 다만 시장 정보만으로 절대 노출을 맞추기보다 현재 노출에 따른 변경량을 다룰 필요를 보여준다.

## 검증과 후속 작업

합성 검사 42개를 통과했다. 전체 현재·목표 정답을 별도 Decimal 계산으로 검산했고, 숫자 트리 64개를 독립 재학습 결과와 비교했다. 선형 대조는 별도 폐쇄형 릿지 해와 일치했다. 전체 예측·월별 지표·현재 원본 유지 기준의 같은 분모 대조를 독립 계산으로 확인했다. 미래 진단 입력을 바꿔도 학습 모형과 학습 상수가 변하지 않는 검사를 포함한다.

원본 5개·운영 소스 245개·v93 검산 도구 24개는 유지했다. 별도 준비 코드로 실행했으며 운영 등록과 동일 결과 재현은 남아 있다. 이번에는 실제 거래나 비용 포함 매매 성과를 검증하지 않았다. 계좌 방향의 의미를 바로잡았다고 시장 정보만으로 원본 행동을 예측할 수 있는 것은 아니다. 다음은 현재 노출에서의 변경량 학습과 봇 자신의 상태를 이용한 연속 실행 대조다. 모든 기존 손실과 v10의 최종 수익성 기준을 유지하며 연구를 계속한다.
