# 실험 v57 사전 계획: 신규 진입 손익의 비선형 예측 진단

2026-10-04. v56은 개발·확인 손실을 줄였지만 확인 수익 조건에 실패했다. 개발 구간의 비교 가능한 모든 실제 거래에서 독립 정답과 실행 순손익이 일치했다. 별도 회귀 계산과 실제 진입 점수도 일치했으나 양수 예측을 통과한 거래의 평균 실현 순손익은 음수였다. 계산 오류와 분리해 예측 모형의 표현력을 진단한다. 진행 중인 v56 후속 평가와 실패 기록은 끝까지 보존한다.

## 고정 자료와 시간 분리

- 완료·검증된 v55 전체 정답과 v56의 학습 원장·가중치·부모 v54 연결을 대조한다. 다른 관리 정책 정답, 손실 삭제, 순손익 절단이나 새 특징은 없다.
- 2021년 1월 1일 이상에 판단하고 9월 30일 00:00 UTC 전에 자연 종료한 기회를 학습한다. 10월 2일 00:00 UTC 이상에 판단하고 12월 31일 00:00 UTC 전에 자연 종료한 기회를 진단한다. 10월 1일 경계 양쪽에 24시간을 배제하며, 경계를 넘는 정답·미확정·학습 밖 기회는 원장에 배제 사유를 남긴다.
- 학습은 200개·방향별 20개·180일 이상, 진단은 100개·방향별 20개 이상의 지원을 요구한다. 각 구간 안에서만 동시 정답 수 역수의 평균과 정규화 가중치를 재계산한다. 진단 종료 시각·정답은 학습 가중치나 모델에 사용하지 않는다.
- 같은 자료에 기존 가중 표준화 Ridge alpha 100, 단일 히스토그램 부스팅 회귀, 학습 가중 평균 상수를 비교한다. 기존 전체 2021년 학습 모델을 진단 구간의 공정한 기준으로 재사용하지 않고 앞 구간에서 다시 학습한다.

## 단일 비선형 모형과 판정

히스토그램 부스팅 회귀는 제곱 오차, 64회·학습률 0.05·깊이 2·최대 말단 4·최소 말단 64·L2 1·최대 구간 255·전체 특징·범주형 없음·seed 0으로 고정한다. 같은 양수 표본 가중치를 사용하고 조기 중지·후속 구간에 따른 반복 수 선택·설정 탐색은 없다. 관리 부스팅에서 사용해 온 고정 복잡도를 회귀 목표에 적용하는 단일 가설이다.

진단 구간에서 다음 조건을 모두 만족해야 후속 매매 연구 후보로 인정한다.

1. 가중 평균 제곱 오차가 같은 구간의 Ridge와 학습 평균 상수 각각보다 1% 초과 개선.
2. 무가중 평균 제곱 오차가 Ridge보다 악화하지 않음.
3. 기존 8bp 기준을 통과한 기회가 30개 이상이며, 해당 기회의 가중·무가중 평균 순손익이 모두 양수.

모든 모형의 전체·방향별·월별 오차와 고정 진입 기준의 선택 수·실현 순손익을 기록한다. 표본 수와 가중치 불균형을 독립 거래 수로 해석하지 않는다. 이 조건을 통과해도 실제 연속 계좌 수익성이 입증되는 것은 아니며, 전체 정답 재학습과 매매 적용은 별도 계획으로 고정한다. 실패 시 모형을 봇에 적용하지 않는다.
