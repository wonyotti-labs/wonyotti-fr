# 실험 v4 사전 계획: 노출 확대 시점과 방향의 분리

2026-10-01. v1~v3와 전체 기간 주문 맥락 결과를 관찰한 뒤, 아래 후보를 실행하기 전에 고정한 계획이다. 2020~2026년 8월은 이미 관찰한 자료다. 수익성 있는 전략은 아직 확보하지 못했다.

## 진단

기존 진입 모델은 무포지션 상태만 학습했다. 원본의 긴 보유 구간에는 독립 추가 주문이 많지만 이 방향 판단은 봇의 새 진입 학습에 쓰이지 않았다. 새 후보는 추가 진입을 포함한 노출 확대의 시점과 매수·매도 방향을 분리해 배운다. 추가 진입의 의도가 새 진입과 같다는 보장은 없으며 이번에 검증할 가설이다.

별도 설명 연구에서는 독립 주문 최초 체결의 5·15·60·240분 이후 가격 변화를 연도·행동·유동성 공급 여부로 분해한다. 직전 확정 5분봉부터 최초 체결까지의 가격 차이와 이후 가격 변화를 구분한다. 미래 가격은 결과 열에만 사용하며 신호 입력에 넣지 않는다. 봉 가격이므로 호가 스프레드·대기열·취소 주문을 관측한 것으로 해석하지 않는다. 최초 체결 수수료와 전체 체결 비용도 구분한다. 주문 수 기준 평균과 일별 블록 재표집 구간을 함께 남기고 해당 결과로 아래 후보 수를 늘리지 않는다.

## 학습과 후보

- 원거래소 2018~2019년의 직전 확정 5분봉 특징 14개만 사용한다. 학습 경계를 넘는 포지션 구간과 마지막 24시간을 제외한다.
- 다음 5분 안의 첫 독립 노출 확대 주문(새 진입·반전·추가 진입)을 목표로 한다. 여러 주문 창의 건수와 양방향 창을 기록한다. 실제 주문 제출 시각 대신 최초 체결 시각을 사용하는 한계가 있다.
- 활동 모델은 전체 유효 창의 주문 유무, 방향 모델은 해당 주문이 있는 창의 매수 여부를 학습한다. 사후 손익·승패는 학습 필터로 사용하지 않는다.
- 모형 두 종류: 표준화 로지스틱 회귀(C=0.1)와 깊이 2의 경사 부스팅 64개 트리(학습률 0.05, 최소 말단 표본 32, 초기 점수 0, 시드 0). 모두 클래스 가중치 없이 학습한다. 확률 보정·수익 확률을 보장하지 않는다.
- 후보 12개: 모형 2종 × 학습 활동 점수 분위수 {0.90, 0.95, 0.975} × 방향 점수 기준 {0.55, 0.65}. 분위수 수치는 2018~2019년 학습 자료에서만 산출한다.
- 활동·방향 기준을 모두 넘을 때 해당 방향 진입. 같은 방향은 보유, 반대 방향은 최소 12봉 보유 이후 반전. 물타기·추가 진입·부분 축소는 하지 않는다. 원본 행동을 그대로 복제한다는 뜻은 아니다.
- 위험 설정은 4% 손절, 최대 72봉 보유, 3봉 재진입 대기, 초기 노출 25%, 기존 일별 손실·누적 낙폭 제한. 편도 수수료 5bp·슬리피지 3bp와 펀딩, 다음 봉 시가 실행을 유지한다. 지정가 리베이트는 봇에 가산하지 않는다.

## 선택·확인·비교

1. 입력 지문과 학습 지원 표본, 후보 12개를 먼저 저장한다. 2020년 BTC에서 종료 거래 20개 이상인 후보 중 `순수익 - 0.5 × 최대낙폭 절댓값` 최대를 선택한다. 동점은 후보 순서이며 기준을 사후 완화하지 않는다.
2. 선택 파일과 모델 지문을 고정한 뒤 2021년 BTC 확인과 원거래소 행동 예측 진단을 수행한다. 이 기간도 기존에 관찰한 자료다.
3. 2022~2025년 및 2026년 1~8월 BTC·ETH·SOL에 고정 후보를 적용한다. 현금·기존 v3, 비용 2배·3배, 한 봉 지연, 활동 조건 제거, 연도별 자본 초기화를 비교한다. 연도별 초기화는 재학습이 아니다.
4. 개발·2021년 순수익이 모두 양수이고 두 구간 종료 거래가 각각 20개 이상이며 영구 중지가 없을 때만 2026년 9월 개봉 조건을 검토한다. 실패하면 해당 자료는 수집하지 않는다. 이전 실패 후보로 열지 못한 자료를 우회해서 읽지 않는다.
5. 원본 손익과 별개인 시장 예측·비용 문제를 보고한다. 한 조건의 양수만 골라 성공으로 선언하지 않는다. 실제 거래 연결은 범위 밖이다.

## 구현 검증

숫자 배열만 포함하는 JSON 모델로 저장한다. 트리의 순환·범위·크기·비정상 숫자를 거부한다. 학습 라이브러리와 내보낸 예측의 일치, 학습 시간 경계, 미래 자료 변경 시 과거 특징 불변, 신호 다음 봉 실행, 최소 보유와 위험 청산 우선순위, 영속 저널 재시작을 검증한다. 모든 실패 실행과 과거 평가 기록을 보존한다.
