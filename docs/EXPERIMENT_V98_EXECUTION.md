# v98 자기 계좌 실행·검산 명세

2026-10-11. [사전 계획](EXPERIMENT_V98.md)의 후보·기간·위험 설정을 유지하는 실행 명세다. 세 정책의 실제 시세 매매 결과를 계산하기 전에 고정한다. v93 공유 소스의 독립 검산 동안 준비 구현은 Git 제외 영역에 격리하며, 운영 등록 시 동일 결과 재현이 필요하다.

## 분봉 처리 순서

1. UTC 날짜가 바뀌면 시가 평가액으로 일일 기준을 갱신한다. 기존 규칙과 같이 자정 갭은 새 일일 기준에 반영되며, 전체 고점 대비 낙폭에는 계속 포함된다.
2. 신규 체결 전 보유 수량에 시가 대용 가격과 실제 펀딩률을 적용한다. 일일 손실·전체 낙폭 한도를 확인한다.
3. 무거래 때문에 대기 중인 위험 청산, 시가 갭 손절, 최대 보유 종료, 위험 한도 청산 순서로 처리한다. 무거래 봉에서는 체결하지 않는다.
4. 직전 확정 봉에서 대기한 목표를 현재 시가로 실행한다. 위험 중지·재진입 대기 중이면 거절한다. 무거래로 남은 목표는 새 목표로 교체하지 않는다.
5. 체결 후 평균 진입가를 기준으로 봉 내 손절을 확인한다. 마지막 봉에서는 종가에 잔여 포지션을 청산한다. 해당 봉에 거래가 없으면 결과를 성공으로 저장하지 않는다.
6. 종가 평가·고점·낙폭을 기록한다. 확정 5분 경계에서만 다음 목표를 계산한다. 변경량 모형의 현재 노출은 봇 수량·종가·자체 평가액으로 계산한다. 위험 중지·미체결 위험 청산 중에는 신규 목표를 만들지 않는다.

펀딩·슬리피지·수수료는 매번 기장한다. 증가는 평균 진입가에 반영하고 부분 감소는 기존 보유 구간을 유지한다. 포지션이 완전히 닫히거나 반전될 때만 종료 거래 수를 늘린다. 반전 수수료는 청산 수량과 신규 수량으로 나눈다. 손절·시간 종료 후 대기는 15분이다. 추가 지연 대조는 목표 생성과 기본 다음 시가 실행 사이에 분봉 한 개를 더 둔다.

## 수량·손익 검산

실행기는 비용 차감 후 평가액을 분모로 하는 목표 수량 방정식의 해를 사용한다. 독립 계산기는 같은 목표 관계를 이분 탐색으로 풀며, 종료 거래 손익은 모든 진입·부분 청산·반전의 현금 흐름과 수수료·펀딩으로 구한다. 평균 진입가에 의존한 실행기 손익과 별도로 비교한다.

각 정책·연도에서 전체 분봉 평가액, 부호 있는 수량, 목표 생성·대기·실행, 위험 중지, 체결, 종료 거래, 거절 내역을 시간순으로 검산한다. 저장한 요약 지표와 최종 계좌도 재계산한다. 실행 중 두 지점에서 JSON 상태를 저장·복원하고 같은 연속 경로를 끝까지 처리한다. 별도 검산은 최초 자본부터 중간 상태 주입 없이 전부 재생한다.

2021·2022년 분봉·5분봉은 v48에서 사용한 입력 명세의 해시를 유지한다. 실제 실행과 검산에서 다시 읽은 시세·펀딩·확정 특징의 전체 행을 비교한다. 각 경로의 입력·코드·모형·출력 해시와 실패 내역을 로컬에 보존한다. 원본 거래 계좌 상태는 실행 신호에 공급하지 않는다.

## 공개 상태의 한계

합성 자료 검증은 실제 수익성 근거가 아니다. 현재 준비 구현의 수량 방정식·부분 청산·반전·펀딩·손절·일일 갱신·지연·무거래·재개·출력 변조 탐지 검증을 마친 뒤, 사전 계획의 여섯 경로와 전체 독립 검산을 실행한다. 예측 진단이 부진해도 실행 경로를 생략하거나 대조 모형으로 후보를 교체하지 않는다.
