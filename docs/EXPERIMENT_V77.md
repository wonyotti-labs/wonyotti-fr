# 실험 v77 사전 계획: 방문 구간에서 기존 행 비중 유지

2026-10-09. v76은 최초 평균 효과와 비용 분류 지표가 악화됐고 스무 조건 중 표본 수 두 조건만 충족했다. 독립 검산의 시각 단위 오류와 수정 후 전체 재검산을 보존했다. 학습 비용 분해에서 방문 구간 제한과 구간별 포지션 균등화가 서로 다른 분포 변화를 만들었다. 같은 방문 구간에서 행 비중만 바꾸는 후보 하나로 후자의 영향을 분리한다.

## 고정 자료와 범위

v76의 전체 분별 원장·74개 입력·원래 자연 종료 대비 현금 정답·학습과 진단 분리·보조 다섯 모델·제외 포지션·점수·최초 선택·방문 구간을 그대로 재현한다. 원래 전체 학습 비중과 v76의 방문 구간 비중을 모두 보존한다. 새 후보의 선택으로 방문 구간을 다시 정하지 않는다.

학습은 2021-01-01 이상 진입·판단과 09-30 미만 정답 확정, 적합 시점은 10-02다. 진단은 10-02 이상 진입·판단과 12-31 미만 정답 확정이다. 포지션 전체 분리·미확정·기간 경계 밖 기록을 유지한다. 2021년 경로는 2021년 말까지 적합한 부모 모델의 개발 경로이고 평가 기간도 이미 관찰했다. 전체 봇의 과거 가용 성과나 미사용 평가로 표시하지 않는다.

분류기의 64회·깊이 2·학습률 0.05·말단·규제·seed·조기 종료 미사용 설정, 비용·위험과 `q > 0.5` 기준을 유지한다. 보조 점수·분할·방문 표식은 예측 입력에 넣지 않는다. 기존 모델 재현과 구별되는 새 적합은 최종 후보 하나이며 설정 탐색·보조 정책 갱신·정답 변경은 없다.

## 한 가지 변경: 유지한 원래 행의 상대 비중

원래 전체 학습의 포지션 균등 비중을 `w_i`, v76의 고정 방문 여부를 `I_i`로 둔다. 방문 행에만 다음 비중을 적용한다.

```text
retained_weight_i = w_i / mean(w_j for I_j = true)
cost_i = retained_weight_i * abs(original_close_advantage_bps_i)
```

정규화는 모든 유지 행에 같은 상수를 곱하므로 유지 행 사이의 원래 상대 비중을 바꾸지 않는다. 포지션별로 남은 행 수를 이용해 각각 비중을 다시 키우지 않는다. 모든 포지션은 최소 한 행을 유지하지만 최종 학습에서 포지션별 총 기여가 같다는 주장은 하지 않는다.

원래 포지션 `j`의 행 수를 `n_j`, 방문 행 수를 `k_j`, 전체·방문 행 수를 `N`, `M`, 포지션 수를 `K`라 하면 기존 원래 비중은 `N/(K*n_j)`, v76 비중은 `M/(K*k_j)`에 해당한다. v76에서 두 비중의 비율은 `(M/N)*(n_j/k_j)`이므로 일찍 청산한 긴 포지션의 일부 행이 크게 확대될 수 있다. 이번 대조는 그 포지션별 확대만 제거한다. 어느 가중 목표가 수익을 개선하는지는 미리 단정하지 않는다.

같은 방문 행·원래 정답으로 후보 하나를 학습한다. 비용이 0인 방문 행은 보존하되 학습 기여는 0이다. 최초 선택 이후 행도 원래 값·비중·행 번호·보조 점수·제외 사유와 함께 남기며 새 학습 기여만 0으로 기록한다. 원래 비중·v76 비중·새 비중·실제 비용 기여를 구분해 저장한다.

최종 학습은 기존 1,000행·100포지션·방향별 20포지션·180일 지원과 비용 있는 1,000행·양쪽 정답 각 64개 조건을 유지한다. 비유한 값·잘못된 구간·원래 비중 불일치·지원 부족은 실패로 기록하며 다른 비중이나 모델로 대체하지 않는다.

## 전체 동일 모집단 평가

후보는 원래 비중을 유지한 분별 청산 정책 하나다. v76의 기존 일곱 정책과 원래 모든 결과를 보존하고 후보·새 학습 상수를 추가해 아홉 정책을 기록한다. 진단 행·포지션·평가 비중·최초 가용 분의 순자산은 기존과 같다. 학습의 방문 표식으로 진단 행을 거르지 않는다.

모든 행의 선택·기회손실·비용 로그 손실·Brier, 최초 선택·선택 없음·방향·월별 결과를 보고한다. 같은 13개 달력 주·1,000회·seed 63으로 후보와 기존 모델 1분·기존 모델 5분·v75 분별 학습 1분·v75 분별 학습 5분·v76 방문 구간 균등 학습 1분·새 상수의 여섯 짝지은 비교를 기록한다. 후보 자체의 구간도 같은 추출에서 계산한다. v75의 5분 정책은 설명 대조이며 후보로 재선택하지 않는다.

## 후속 매매 연구 조건

v76의 조건 구조에 직전 방문 구간 모델의 최초 효과·기회손실·비용 로그 손실·Brier 대조를 추가해 다음 스물네 조건을 모두 요구한다. 누락·비유한 지표는 실패다.

1. 선택 기회 100개 이상.
2. 선택 포지션 30개 이상.
3. 선택 기회의 가중 평균 효과 양수.
4. 선택 기회의 무가중 평균 효과 양수.
5. 선택 포지션의 최초 평균 효과 양수.
6. 전체 포지션의 최초 평균 효과 양수.
7. 후보 최초 효과 구간 하한 양수.
8. 기존 모델 1분 정책 대비 최초 효과 차이 구간 하한 양수.
9. 기존 모델 5분 정책 대비 최초 효과 차이 구간 하한 양수.
10. v75 분별 학습 1분 정책 대비 최초 효과 차이 구간 하한 양수.
11. v76 방문 구간 균등 학습 정책 대비 최초 효과 차이 구간 하한 양수.
12. 새 학습 상수 대비 최초 효과 차이 구간 하한 양수.
13. 가중 기회손실이 기존 모델 1분 정책보다 작음.
14. 가중 기회손실이 v75 분별 학습 1분 정책보다 작음.
15. 가중 기회손실이 v76 방문 구간 균등 학습 정책보다 작음.
16. 가중 기회손실이 새 학습 상수보다 작음.
17. 비용 로그 손실이 기존 모델보다 1% 이상 개선.
18. 비용 로그 손실이 v75 분별 모델보다 1% 이상 개선.
19. 비용 로그 손실이 v76 방문 구간 균등 모델보다 1% 이상 개선.
20. 비용 로그 손실이 새 학습 상수보다 1% 이상 개선.
21. 비용 Brier가 기존 모델보다 악화되지 않음.
22. 비용 Brier가 v75 분별 모델보다 악화되지 않음.
23. 비용 Brier가 v76 방문 구간 균등 모델보다 악화되지 않음.
24. 비용 Brier가 새 학습 상수보다 악화되지 않음.

Brier 허용치는 1e-12이며 나머지 개선·양수 조건은 엄격한 부등식이다. 이전 모든 실패 판정을 보존한다. 이는 같은 고정 경로에서의 조건부 청산 효과이며 연속 계좌 수익률이 아니다. 최종 v10의 다년·다시장·비용·펀딩·지연·낙폭·표본·집중 조건은 변경하지 않는다.

## 검증과 보존

새 후보 적합 전에 기존 분별 입력·보조와 최종 모델·방문 구간·가중치·모든 정책·평가·실패를 재현한다. 원본 결과와 코드 사본의 지문도 대조한다. 과거 점수·모델·방문 표식·비중을 바꾸고 지문을 다시 써도 거부해야 한다.

합성 자료에서 같은 유지 행·원래 행 번호·전체 포지션 보존·비중의 상대 비율·전체 평균 1·0 효과·이후 0 기여·지원 부족을 검사한다. 원래 정답·보조 선택을 손익에 따라 다시 고르지 않는다. 뒤 진단의 정답·입력 변경은 학습·모델을 바꾸지 않아야 한다. 명시적인 마이크로초·나노초 입력에서 같은 판단 시각을 비교한다.

실제 자료에서 같은 보조 구간·원래 상대 비중·비용·새 64개 트리·모든 점수·아홉 정책·여섯 구간·스물네 조건을 독립 대조한다. 기존 봉인된 입력·모델 검산 근거를 재사용할 때는 파일과 값의 동일성을 확인하고 그 범위를 명시한다. 원본·파생 자료의 Git 공개와 실제 거래 연결은 없다.
