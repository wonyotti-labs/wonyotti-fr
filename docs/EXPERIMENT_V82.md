# 실험 v82 사전 계획: 첫 기회 비용 판단의 선형 규제

2026-10-10. v81은 첫 기회에서만 판단하도록 바꿔 지연을 제거했지만 선택 효과가 음수였다. 학습 비용 로그 손실·Brier와 최초 효과는 상수보다 좋았으나 보정에서는 유지되지 않았다. 이 차이를 표현력 과다의 확정 증거로 단정하지 않고, 같은 표본·목적·판단 시점에서 규제된 선형 모델 하나를 대조한다.

## 변경하지 않는 자료와 실행

봉인된 v81의 독립 검산 기록과 소비 파일·코드 사본·보정 결과를 검산 지문으로 확인해 재사용한다. 원래 v80까지의 재현 근거와 실패는 보존하며 이전 모델 재적합이나 외부 중첩 재현을 다시 수행했다고 주장하지 않는다.

앞 학습 2021-01-01 이상 진입·판단 및 2021-07-31 미만 정답 확정, 보정 2021-08-02 이상 진입·판단 및 2021-09-30 미만 확정을 유지한다. 원래 전체 행·포지션 분리·가중치·배제 사유를 그대로 둔다. 각 포지션의 첫 적격 행·첫 가용 순자산·자연 종료 대비 현금 정답·포지션 비중 1·절대 비용 정규화·0 비용 제외 원장은 v81과 같아야 한다. 손실·0 정답·기회 없음과 후속 행을 모두 보존한다.

기존 74개 특징을 그대로 사용하며 특징 선택·변환 후보·손익 절삭·최근 구간 가중·문턱 탐색은 없다. 적격 500포지션·방향별 20·180일·양쪽 비용 부호별 64개 지원을 유지한다. 마지막 진단 입력·정답은 새 모형에 전달하지 않는다.

## 고정 선형 모델 하나

평균과 표준편차는 앞 학습의 모든 첫 적격 입력에 동일 포지션 비중으로 한 번 적합한다. 0 정답도 표준화에는 포함한다. `StandardScaler`의 상수 특징 처리와 숫자를 저장하고 보정으로 다시 적합하지 않는다.

표준화한 입력에 L2 로지스틱 회귀 하나를 적합한다. 기존 프로젝트 선형 행동 모델의 C=0.1을 재사용하며 `l1_ratio=0`, `solver=lbfgs`, `fit_intercept=True`, `class_weight=None`, `random_state=0`, `warm_start=False`, `max_iter=2000`, `tol=1e-9`로 고정한다. 표본 비용은 v81과 동일한 양의 정규화 절대 bp이며 0 비용은 적합에서 제외한다. 클래스 균등화는 하지 않는다. 수렴 경고나 반복 한도 도달은 실패로 보존하고 실제 결과를 본 뒤 설정을 바꾸지 않는다.

평균·척도·계수·절편·설정을 숫자 JSON으로 저장한다. 학습과 보정 첫 입력 전체에서 라이브러리와 내보낸 점수를 대조한다. 실행 시 첫 적격 기회의 비용 점수가 엄격히 0.5보다 클 때만 청산하며 첫 거절 뒤의 예측과 재선택은 없다. 학습 상수는 같은 정답·비용으로 산출한 기존 v81 상수와 같아야 한다.

## 아홉 정책과 일곱 내부 조건

기존 v81의 여덟 정책·선택·현금 효과·그룹·비용 확률 지표·실패를 그대로 보존하고 새 선형 첫 기회 정책 하나를 추가한다. 기존 첫 기회 트리와 상수의 보정 점수로 정책 산식을 다시 대조하되 모형을 다시 적합하지 않는다. 새 모델의 확률 지표는 같은 첫 기회와 공통 정답에서 기존 첫 기회 트리·상수와 비교하는 설명용이다.

모든 보정 포지션을 포함한 같은 최초 평균 효과를 사용한다. 새 후보는 최초 선택 30포지션 이상, 전체 최초 평균 양수, 그리고 v81 첫 기회 트리·v80 직접 회귀·v79 이후 정책 분류·v78 자연 종료 분류·항상 첫 청산 각각보다 엄격한 개선, 총 일곱 조건을 모두 만족해야 한다. 동점은 실패다. 표본과 손실을 유지하고 상수 대체·문턱 변경·추가 모형 탐색을 하지 않는다.

이번 단계도 학습과 내부 보정으로 한정한다. 통과하면 별도 고정 계획에 따른 마지막 진단과 연속 계좌 검증으로 즉시 이어가고, 실패하면 근거를 남기고 연구를 계속한다. 어느 경우도 단계 완료를 수익성 해결로 표시하지 않는다. 이전 모든 실패와 최종 v10의 다년·다시장·비용·펀딩·지연·낙폭·표본·집중 조건은 그대로다.

## 검증과 보존

첫 행·포지션·현금·비중·비용 원장은 v81과 정확히 대조한다. 평균·척도·계수·절편·수렴과 전체 숫자 예측을 별도 적합·수기 시그모이드로 검산한다. 보정 입력·정답을 바꿔도 앞 학습 표준화와 모델은 변하지 않아야 한다. 0 비용의 표준화 참여, 한 번의 판단, 정확히 0.5, 손실·기회 없음·후속 NaN을 검증한다.

검산 지문·입력·가중치·원장·보정·코드 사본 변조와 재봉인을 적합 전에 거부한다. 아홉 정책·일곱 조건·이전 판정 보존·마지막 예측 부재를 확인한다. 이전 검증을 재사용한 범위와 새 계산을 구분하고 오류를 보존한다. 원본·가공·모델·개별 실행은 로컬 전용이며 실제 거래 연결은 없다.
