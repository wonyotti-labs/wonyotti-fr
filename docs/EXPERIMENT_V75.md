# 실험 v75 사전 계획: 분별 청산의 판단 빈도와 학습 효과 분리

2026-10-09. v74에서 매분 관리 판단에 대응하는 정답을 복원했다. 복원·독립 검산·실제 중단 재개 대조를 모두 완료한 원장만 입력으로 허용한다. 판단 횟수 증가가 손익 개선인지 확인하기 위해 기존 모델의 실행 주기 변경과 동일 구조의 새 학습을 분리한다.

## 고정 자료와 입력

v74의 같은 v54 개발 경로·2021년 BTC·원래 비용·위험·자연 종료 정답을 사용한다. 원래 50개 실제 입력에 현재 계좌 상태의 경제 입력 2개·대기 의도 4개와 확정 5분 시세의 다일 입력 8개·체결 방향 입력 10개를 연결한다. 기존 v71의 74개 입력·순서·정의와 같다. 미래 가격·자연 종료 현금·정답은 입력에 포함하지 않는다.

시장 추가 입력은 판단 시각 이하의 마지막 확정 5분 종료 시각으로 연결한다. 시세의 종료 시각과 판단의 차이는 0 이상 300초 미만이어야 한다. 누락·오래된 봉·미래 봉·연속 준비 부족·원래 시장 입력 불일치를 거부한다. 방향 값은 현재 분의 포지션 방향을 사용한다. 연결 종료 시각·경과 시간은 별도 검산 자료이며 새 모델 입력으로 추가하지 않는다. 5분 경계의 모든 원래 56개 입력과 추가 18개 값, v71의 학습·진단 74개 값이 기존과 정확히 같아야 한다.

시간 분리는 기존과 같은 2021-01-01~09-30 미만 학습과 10-02~12-31 미만 진단이다. 원래 진입 시각·정답 확정 시각·포지션 전체 분리를 유지한다. 0 효과·손실·미확정·기간 경계 밖 기록과 제외 사유를 보존한다. 분별 행의 포지션별 균등 비중을 다시 계산하며 5분 비중을 복사하지 않는다. 표본·방향·기간의 기존 학습 지원 조건을 유지한다.

2021년 경로는 2021년 말까지 학습한 진입 부모 등의 개발 적합 경로다. 이번 청산 모듈의 시간 분리를 전체 봇의 당시 가용 검증으로 해석하지 않는다. 모든 평가 기간은 이미 관찰한 자료다.

## 고정 모델과 네 정책

기준은 v71의 고정 학습 비용 분류기다. 현재 입력 74개를 사용하는 기본 모델이며, 성과 순위로 고른 기준이 아니다. v72 주간 갱신과 v73 보조 정책 정답은 이번 후보에 추가하지 않는다. 모든 이전 실패를 유지한다.

새 적합 모델은 하나다. v71과 동일한 64회·깊이 2·학습률 0.05·말단·규제·seed·조기 종료 미사용, 비용 `포지션 비중 × |자연 종료 대비 효과|`를 사용한다. 0 효과는 학습 기여만 0이며 원장·평가에 유지한다. 기존 5분 학습 자료로 v71을 다시 적합해 모든 트리·초기 값·점수를 대조하고, 새 후보는 분별 학습 자료로 같은 구조를 적합한다. 진단 구간으로 문턱·구조·가중치를 선택하지 않는다.

| 정책 | 모델 학습 자료 | 선택 가능한 판단 시각 |
| --- | --- | --- |
| 기존 5분 | 기존 v71 고정 모델 | 5분 경계 |
| 기존 1분 | 같은 v71 고정 모델 | 모든 적격 분 |
| 새 5분 | 새 분별 학습 모델 | 5분 경계 |
| 새 1분 | 같은 새 분별 학습 모델 | 모든 적격 분 |

후보는 **새 1분 정책 하나**로 고정한다. 네 정책 중 사후 성과가 좋은 것을 고르지 않는다. 모든 정책은 비용 가중 점수 `q > 0.5`와 원래 exit 의도 제외를 공유한다. 기존 의도를 늦추는 청산 유예, 새 추가·축소·진입 규칙은 없다. 점수는 비용 가중 선택 점수다.

## 공통 모집단의 비교

네 정책 모두 같은 분별 진단 행·포지션과 최초 가용 판단 당시 순자산을 사용한다. 5분 판단 기회가 없는 포지션도 선택 없음·0 효과로 남긴다. 원래 5분 결과의 포지션·선택 시각·효과 금액·점수는 그대로 대조하며, 새 공통 분모로 환산한 결과와 원래 분모 결과를 구분한다.

원시 모델 점수와 실행 가능 시각의 마스크를 별도로 기록한다. 분별 동일 행에서 두 모델과 새 학습 상수의 비용 로그 손실·Brier를 계산한다. 네 정책과 상수의 선택·가중 기회손실, 최초 선택·선택 없음·방향별·월별 결과를 기록한다. 최초 효과는 포지션당 한 번만 계산한다.

기존과 같은 13개 달력 주·1,000회·seed 63의 동일 추출로 후보 자체와 후보-기존 1분·후보-기존 5분·후보-새 5분의 짝지은 95% 구간을 계산한다. 기존 1분과 기존 5분의 차이도 같은 추출로 기록한다. 이는 고정 포지션 경로의 조건부 효과이며 연속 계좌 수익률이 아니다.

## 후속 매매 적용 연구의 조건

다음 열다섯 조건을 모두 요구한다. 누락·비유한 지표는 실패다.

1. 후보 선택 기회 100개 이상.
2. 후보 선택 포지션 30개 이상.
3. 선택 기회의 가중 평균 효과 양수.
4. 선택 기회의 무가중 평균 효과 양수.
5. 선택 포지션의 최초 평균 효과 양수.
6. 전체 포지션의 최초 평균 효과 양수.
7. 후보 최초 효과 구간 하한 양수.
8. 후보와 기존 1분 정책의 최초 효과 차이 구간 하한 양수.
9. 후보와 기존 5분 정책의 최초 효과 차이 구간 하한 양수.
10. 후보의 가중 기회손실이 기존 1분 정책보다 작음.
11. 후보의 가중 기회손실이 새 학습 상수보다 작음.
12. 후보 비용 로그 손실이 기존 모델보다 1% 이상 개선.
13. 후보 비용 로그 손실이 새 학습 상수보다 1% 이상 개선.
14. 후보 비용 Brier가 기존 모델보다 악화되지 않음.
15. 후보 비용 Brier가 새 학습 상수보다 악화되지 않음.

Brier 비교 허용치는 1e-12이며 나머지 개선·양수 조건은 엄격한 부등식이다. 새 5분 정책은 두 변화의 효과를 분리하기 위한 대조이며 채택 대상으로 바꾸지 않는다. 원래 v71의 스물네 조건과 실패 판정은 별도로 보존한다. 새 모집단 비교의 통과가 기존 실패를 취소하지 않으며 최종 v10 다년·다시장·비용·지연·낙폭·표본 기준을 바꾸지 않는다.

## 검증과 결과 보존

v59·v74·v71의 입력·실행·지문 연결, 전체 분별 정답·실제 계좌·원자 기록을 검증한다. v71의 해당 기준 모델·학습 비중·비용·점수는 독립 재현하고 기존 모든 파일을 변경하지 않는다. 과거의 다른 후보를 새로 선택하거나 재학습하지 않는다.

합성 자료로 분별 확정 시세 연결·원래 5분 동일성·준비 부족·시간 오류·미래 값 변경 불변·모델 적합·0 효과·같은 포지션 비중·네 정책의 공통 분모·선택 없음·구간과 판정을 검사한다. 실제 자료의 모든 추가 입력을 별도 계산하고 두 모델·비용·점수·정책·최초 효과·모든 구간·열다섯 조건을 독립 대조한다. 입력이나 기존 점수를 변조한 뒤 지문을 다시 써도 관련 재현 검증에서 거부해야 한다.

실제 계좌의 재진입·복리·다년 검증은 조건 통과 후 별도 사전 계획으로 수행한다. 실패 시에도 모든 결과와 사후 관찰 이력을 보존한다. 실제 거래 연결과 원본·파생 자료의 Git 공개는 없다.
