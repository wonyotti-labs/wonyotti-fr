# 실험 v132 사전 계획: 과거 관리 주문의 가격 기준 복원

2026-10-12. v131은 39개 조건 중 24개만 통과했으며 수익성은 미해결이다. 다음 후보를 학습하기 전에 기존 50개 입력에 없는 직전 추가·축소 주문 가격 기준을 원본에서 복원하고 시간 경계와 출처를 검산한다. 이전 턴은 v131 결과 검산·공개·커밋·푸시를 완료한 진행이다.

## 가격의 정의와 출처

`actions.price`는 개별 최초 체결 한 건의 가격이 아니다. 원본 XBTUSD 체결을 동일 시각·주문 키·체결 유형·방향·주문 유형으로 묶은 수량 가중 가격이다. 같은 주문의 후속 시각 체결과 전체 주문의 최종 평균 가격은 사용하지 않는다. funding을 제외한 각 주문의 첫 관측 묶음에서 이미 증가 또는 축소로 관측된 경우만 기존 주문 이력과 동일하게 선택한다.

v131 완료 증거에서 기존 v127·원본 교사 표로 이어지는 봉인을 확인한다. 교사 표의 기존 이력 출처에 기록된 executions/actions/episodes 지문을 확인하고, 원본 체결 행을 사건 키에 연결해 수량·수량 가중 가격·최초 원본 행 순서를 별도 합산한다. 저장된 XBTUSD 사건과 actions의 시각·주문·가격·수량 변화가 일치해야 한다. 출처 연결을 증명하지 못하면 학습 단계로 넘어가지 않는다.

## 입력과 시간 경계

2020년 학습·2021년 상반기 보정·하반기 진단의 원래 1,018,460행을 전부 유지한다. 기존 50개 입력·정답·포지션·24시간 경계는 변경하지 않는다. 현재 가격은 이미 원본 표에 있는 같은 시장의 확정 1분 종가다. 판단 시각과 정확히 같은 체결은 제외한다.

같은 포지션에서 각 행동의 가장 최근 첫 관측 묶음 중 시각이 현재보다 작은 가격을 p, 현재 종가를 c로 둔다. 행동별 `log(c)−log(p)`와 여기에 포지션 방향을 곱한 값, 총 네 입력을 만든다. 과거 해당 행동이 없으면 0이며 기존 존재 여부 입력이 부재와 가격 동일을 구분한다. 초기 진입·평균 진입 가격은 이미 다른 입력에 포함되어 있으므로 이를 새 정보라고 주장하지 않는다. 포지션을 넘어 이전 가격을 이어 붙이지 않는다.

첫 관측은 같은 주문의 나중 체결로 갱신하지 않는다. 동시각의 서로 다른 주문은 기존 원본 사건 순서를 유지하고, 현재 이전의 같은 시각 사건 중 마지막 순서를 선택한다. 원본에 없는 시간을 채우거나 같은 시각 자료를 미래에서 가져오지 않는다.

## 독립 검산·출력

기존 이력 함수로 6개 입력과 주문 원장을 재계산해 저장된 교사 표와 정확히 비교한다. 새 가격 연결은 일괄 시각 이진 검색으로 만들고, 별도 시간순 사건 순회에서 현재보다 이른 사건만 상태에 반영해 모든 원장 인덱스·가격·네 입력을 대조한다. 확률·거래 결과로 행이나 가격 정의를 선택하지 않는다.

미래 가격·주문 변경 시 과거 불변, 같은 시각 제외, 동시각 순서, 나중 부분 체결 가격 무시, 포지션 초기화, 롱·숏 방향, 나노초·마이크로초 단위, 비유한·비양수 가격, 출처·시간·수량·존재 이력 손상 거부를 합성 사례로 검사한다. 모든 기간·월·행동 상태의 지원 수와 양성 수, 가격 기준 존재·부재 수, 새 입력 분포를 공개 집계한다. 원장·가격·개별 입력은 로컬에만 저장하고 기존 실험은 삭제하지 않는다.
