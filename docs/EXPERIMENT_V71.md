# 실험 v71 사전 계획: 체결 방향을 반영한 청산 비용 학습

2026-10-05. v70은 v69보다 최초 효과를 개선했으나 효과가 음수였고 비용 분류 지표도 악화돼 열아홉 조건 중 일곱 개만 만족했다. 장기 가격 상태 추가만으로 해결되지 않았다. 현재 청산 모델에는 총거래량이 있지만 매수·매도 어느 쪽이 호가를 받아 체결했는지 나타내는 입력이 없다. 보관 시세의 매수 taker 거래량을 이용한 고정 입력 확장 하나를 검증한다. 해당 거래량은 호가창 잔량이나 트레이더 개인의 주문이 아니다.

## 자료와 열 개 입력

v70과 이전 모든 모델·행·가중치·정답·점수·최초 효과·판정을 재현한다. v59 정답 생성에 사용한 같은 BTCUSDT 5분 특징 시세와 고정된 지문을 사용한다. 기존 파일에는 총 기본자산 거래량과 매수 taker 기본자산 거래량이 함께 있다. [Binance 공식 공개 자료 설명](https://github.com/binance/binance-public-data/blob/master/README.md#klines-1)의 USD-M 열 정의를 확인했다. 기존 초기 특징의 매수 체결 비율 사용 이력과 현재 청산 특징에서의 부재를 구분하며 새 수익 근거로 해석하지 않는다.

원래 64개 입력 뒤에 다음 열 개만 추가한다.

- 확정된 5분·15분·1시간·4시간·1일의 매수 체결 불균형 다섯 개. 각 기간은 5분 봉 1·3·12·48·288개로 고정한다. 값은 `2 × 합계 매수 taker 거래량 / 합계 총거래량 − 1`이다. 봉별 비율의 단순 평균을 사용하지 않는다.
- 위 다섯 값에 당시 포지션 방향 `−1 또는 +1`을 곱한 다섯 개.

거래량은 유한하고 `0 ≤ 매수 taker 거래량 ≤ 총거래량`이어야 한다. 창 안 거래량 전체가 정확히 0이면 값 0으로 기록하며 존재하지 않는 체결을 만들지 않는다. 각 창은 같은 연속 5분 구간 안에서만 계산한다. 입력 계산의 부동소수점 오차가 1e-12 이내인 범위 초과만 경계로 제한하고 그보다 큰 초과는 실패한다. 기존 64일 준비 조건도 유지한다. 지원 부족이나 비유한 원래 행을 삭제·미래 값으로 채우지 않는다.

원래 14개 시장 입력과 여덟 다일 입력을 같은 시세에서 다시 계산해 일치하는지 검사한다. 원래 64개 값·열 순서·정답·비용·포지션을 보존하고 판단 시각에 정확히 종료된 봉만 연결한다. 기간·방향·창의 추가 탐색, 호가창 추정, 거래량 문턱, 새 시장·새 자료 선택은 하지 않는다.

## 고정 학습과 비교

v70과 같은 앞 학습과 마지막 진단, 포지션 분리·정답 종료 경계를 사용한다. 후보는 74개 입력의 비용 가중 분류기 하나다. 깊이 2·64회·학습률 0.05·말단·규제·seed·조기 종료 미사용과 `w × |y|` 정의를 그대로 둔다. 0 효과의 학습 기여만 0으로 유지하고 원래 원장·평가를 보존한다. 비용 정규화·학습 상수·평가 가중치는 v70과 정확히 같아야 한다.

같은 고정 점수 `q > 0.5`에서 추가 청산을 선택하며 원래 청산 요청을 제외한다. 점수는 비용 가중 선택 점수이고 일반 수익 확률이나 예상 bp가 아니다. 기존 모델·문턱을 바꾸지 않으며 재보정·주간 갱신·후보 선택을 하지 않는다. 모든 기간은 이미 관찰한 자료다.

v70의 열아홉 조건을 새 후보에도 유지하고 다음 다섯 개를 더한다.

1. 비용 가중 로그 손실이 v70보다 1% 이상 개선.
2. 비용 가중 Brier가 v70보다 악화되지 않음.
3. 원래 가중 평균 기회손실이 v70보다 작음.
4. 전체 최초 평균 효과가 v70보다 큼.
5. 후보와 v70의 최초 효과 차이의 짝지은 주간 95% 구간 하한 양수.

Brier 허용치는 1e-12, 다른 비교는 엄격한 부등식이다. 후보와 v64·v69·v70의 세 주간 비교는 같은 13개 달력 블록·1,000회·seed 63의 동일 추출을 사용한다. 손실·선택 없음·전체 포지션을 보존하고 전체·방향·월별 행 지표와 최초 효과를 기록한다. 스물네 조건이 모두 충족돼야 후속 매매 적용 연구를 허용한다.

## 검증과 범위

비율의 거래량 가중 계산, 방향 부호, 0 거래량, 부정 거래량·범위·끊김·준비 부족·확정 시각을 검사한다. 미래 시세·미래 매수 거래량 변경이 과거 입력을 바꾸지 않아야 한다. 기존 64개 입력·비용 원장·학습 상수·모델·점수·판정이 동일해야 한다.

실제 자료의 열 개 입력을 별도 창 합계로 검산한다. 독립 분류기 재학습의 모든 트리·초기 값·점수·선택, 전체 행·최초 효과·세 주간 비교·스물네 판정과 원본 지문을 대조한다. 실제 손실을 삭제하거나 기존 실패를 취소하지 않는다. 통과해도 연속 계좌·재진입·다년 다시장 검증이 별도로 필요하며 최종 v10 수익성·표본·비용·낙폭 기준을 유지한다. 실제 거래 연결과 원본·파생 자료의 Git 공개는 없다.
