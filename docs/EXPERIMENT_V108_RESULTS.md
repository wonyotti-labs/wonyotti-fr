# 실험 v108 결과: 같은 입력에서 첫 주문과 복수 관리 정답의 비교

2026-10-11. [사전 계획](EXPERIMENT_V108.md)에 따른 실제 학습과 전체 검산을 완료했으나 후속 후보 조건은 17개 중 6개만 충족했다. 복수 관리 정답의 청산 적중은 3개에서 5개로 늘었지만 오탐은 307개에서 646개로 증가했다. 세 행동 모두 첫 주문 대조보다 로그 손실·평균 정밀도가 나빴다. 정답 복원만으로 예측·수익성 문제가 해결되지는 않았으며 새 후보를 매매에 연결하지 않았다.

## 고정한 비교와 지원

v107 전체 403,776개 창을 유지했다. 원본 평균 진입가·추가 주문 수·보유 시간을 창 시작의 엄격한 이전 사건에서 연결했다. 원거래소 확정 시세 14개와 방향을 곱한 14개, 방향·진입가 대비 변화·로그 보유 시간·추가 횟수의 4개가 같은 32개 입력이다. 종료 특징·현재 창 체결·원본 수량·잔고·수익은 학습 입력에서 제외했다.

A는 첫 정상 독립 주문 하나의 관리 정답, B는 같은 시작 에피소드에 속한 모든 요청의 양성 여부다. 두 방식 모두 반전 요청을 기존 포지션의 청산으로 취급하므로 그 의미 변경은 비교 요인이 아니다. A는 특정 과거 정책 전체를 재현한 결과가 아니다.

## 검산과 해석 범위

전체 403,776개 창과 510,172개 사건의 원가·상태를 독립 재생했다. 상태 계산은 허용 차이 `1e-12 + |기준값| × 1e-12`로 비교했고 최대 상태 절대 차이는 1.45519152284e-11였다. 원본 열은 정확히 보존하고 시작 특징·첫/전체 정답·분할 사유를 모든 행에서 확인했다.

384개 트리와 선형 계수·표준화를 독립 재학습해 비교했다. 보정·진단 101,665개 행의 모든 확률을 1e-12 이내로 비교하고 세 모형의 단일 상태 추론 304,995건, 문턱·요청·우선순위 행동·기간/월별 지표·채택 판단을 별도 계산으로 검산했다.

신규 25개와 이전 관련 76개, 총 101개 검사 및 Ruff 통과. 전체 프로젝트 최신 검사 통과를 뜻하지 않는다. 최초 합성 검사에서 선형 표준화의 C/F 배열 합산 차이 약 1e-16을 발견해 새 모형의 배열 순서와 계산 스레드를 고정했다. 검사 추가 중 발생한 테스트 변수 참조 오류도 수정하고 최종 전체 관련 검사를 다시 통과했다. 실패 로그를 보존했다.

첫 실제 실행의 모형과 문턱은 재실행에서도 정확히 같았다. 선형 대조를 단일 출력씩 계산할 때 최대 약 6e-16 차이가 보정 구간의 문턱과 같은 추가 요청 1개를 바꿔 검산이 중단됐다. 저장 숫자 모형의 연산으로 요청을 비교하도록 수정했고, 학습·문턱·판정 기준 변경 없이 실패 산출물과 당시 소스도 보존했다. 실행 전후 원본 5개·당시 공개 소스 299개·v107 전체 복원과 추가 집계의 해시를 확인했다. 현재 분별 관리 코드도 이미 공통 활동 관문 없이 청산을 판단한다. 이번 비교는 남은 정답 선택 효과를 진단하며, 관문 제거 하나로 과거 손실이 해결됐다고 주장하지 않는다.
