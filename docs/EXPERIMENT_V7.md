# 실험 v7 사전 계획: 확정 시세에 따른 진입 대기

2026-10-01. v6의 전체 집계 대조와 같은 주문의 1분·5분 비교를 확인한 뒤 고정했다. v1~v5의 결과와 2026년 9월까지 이미 관찰했다. 이번 연구에 미사용 최종 평가 구간은 없다.

## 가설과 범위

원본 최초 체결과 이전 종가의 차이는 1분 기준에서 줄었지만 남아 있다. 원본 체결 가격을 봇의 진입 가격으로 주입할 수 없으며 주문 대기열·미체결 주문·제출 시각도 모른다. 따라서 가격이 유리해지는지를 확정된 1분 종가로 확인한 다음 시장가로 진입하는 후보를 검증한다. 지정가 체결이나 maker 수수료를 가정하지 않는다.

이 규칙은 원본을 설명하는 새로운 가설이다. 가격을 기다리면 거래 수가 줄거나 불리한 추세에서만 진입할 수 있다. 대기 조건 통과 후 다음 시가가 다시 불리해지는 경우도 그대로 포함한다. 결과가 나쁘면 체결 기준이나 비용을 사후 완화하지 않는다.

## 고정 후보와 상태 규칙

- v4에서 고정한 활동·방향 모형과 두 진입 기준을 재사용한다. 추가 학습이나 기준 재선택은 없다. 입력은 기존의 확정 5분 시장 특징이며, 특징 이름과 실제 시간 길이를 유지한다.
- 포지션이 없고 진입 대기가 없을 때만 새 5분봉 종료 시각에 활동·방향 신호를 계산한다. 신호가 나오면 그때의 종가·방향·시각을 대기 상태에 저장한다.
- 이후 확정 1분 종가가 기준 가격에서 매매 방향에 유리하게 {8, 16, 32}bp 이동하면 다음 1분봉 시가에 시장가 진입한다. 매수는 가격 하락, 매도는 가격 상승이다. 조건은 방향 × log(기준 가격/현재 종가) × 10,000으로 계산한다.
- 대기 유효 시간은 {5, 15}분이다. 신호 시각보다 늦고 만료 시각 이하인 종가만 판정한다. 만료 시각에서도 조건이 충족되지 않으면 대기를 취소한다. 대기 중 새 방향 신호는 무시하고, 같은 시각에 취소·재설정하지 않는다.
- 후보 수는 3 × 2 = 6개다. 대기 중 상태도 엔진의 영속 상태에 포함한다. 포지션 보유·중지·최종 종료 시 대기를 비운다. 실패한 처리에서는 매매 상태와 대기 상태를 함께 되돌린다.
- 진입 후 방향 반전이나 추가 진입 없이 최대 30분 보유한다. 4% 손절·일별 손실·누적 낙폭 제한을 우선한다. 초기 노출 25%, 재진입 대기 15분, 편도 수수료 5bp·슬리피지 3bp, 공식 펀딩을 적용한다.

대기 해제 조건을 충족한 가격은 체결 가격이 아니다. 다음 봉 시가와 비용으로 실행한다. BitMEX의 이전 종가인 open을 실행 가격으로 쓰지 않는다. 원거래소 1분 자료는 설명 연구에만 사용하고 실행 연구는 공식 Binance USD-M 1분 시세와 펀딩을 사용한다.

## 자료와 평가 순서

1. 공식 1분 시세를 별도 폴더로 수집하고 체크섬·봉 경계·누락·펀딩을 검사한다. 같은 시장의 1분 집계와 기존 5분 자료를 대조한다. 특징은 기존 5분 자료의 확정 시각에만 연결하고 미래 5분봉을 1분 입력으로 앞당기지 않는다.
2. 여섯 후보와 기반 모형 해시를 실행 전에 저장한다. 2020년 BTC에서 종료 거래 20개 이상인 후보 중 `순수익 - 0.5 × 최대낙폭 절댓값` 최대를 고른다. 동점이면 앞선 후보를 사용한다. 적격 후보가 없으면 기준을 완화하지 않고 실패로 남긴다.
3. 선택을 고정한 뒤 2021년 BTC에서 확인한다. 개발·확인 양수·각 20거래 이상·영구 중지 없음 여부를 보고하되, 충족 자체를 수익성 증명으로 해석하지 않는다.
4. 고정 후보를 2022~2025년과 2026년 1~9월 BTC·ETH·SOL에 적용한다. 현금, 같은 30분 보유의 대기 없는 신호, 비용 2·3배, 추가 1분 지연을 비교한다. 2022~2025년 연도별 자본 초기화도 별도 실행한다. 모든 기간은 이미 관찰한 구간이다.
5. 시각별 대기 시작·충족·취소, 실제 체결까지의 가격 변화, 매매 회계와 표본 수를 남긴다. 대기 통과율과 수익률을 구분하고, 30일 블록 재표집의 조건부 구간을 기록한다.
6. 합성 경계 사례, 미래 시세 변경에 대한 이전 신호 불변, 기존 정책 호환, 중단·재개, 진입 대기 중과 보유 중의 실제 프로세스 종료 후 복구를 검증한다. 원자료·모델·시세·개별 결과는 로컬에만 보존한다.

이번 범위에 실제 주문·인증·출금 연결은 없다. 원본과 실행 시장의 계약 구조 차이, 봉 시가 체결 근사, 시장 충격·호가 미관측의 한계를 유지한다.

## 실행 전 자료 보완

개발 후보 실행 전에 일부 공식 1분 자료와 5분 집계의 불일치를 발견했다. 월별·일별 파일을 대조하고 공식 개별 체결을 다시 집계해 확인했다. 기존 파일은 보존하며 원체결 집계가 5분 OHLC·거래량·건수와 일치하고 수정할 분봉의 ID가 연속적인 경우만 별도 정규화 파일로 복원한다. 다른 분봉의 ID 공백과 최초 검사 실패도 기록한다. 거래량만 다른 것으로 보여도 중간 분봉의 종가가 다를 수 있으므로 집계 허용 오차를 키워 통과시키지 않는다. 후보 수·규칙·비용·평가 기준의 변경은 없다.

공식 자료의 개별 체결 형식·체크섬·과거 파일 수정 안내는 [Binance 공개 자료 설명](https://github.com/binance/binance-public-data)에 따른다. 공식 파일끼리 일치한다는 것이 전체 시장 기록의 완전성을 인증하지는 않는다.

### 공개 체결 ID 공백의 추가 대조

다년 후보 실행 전 ID 연속성 검사에서 중단된 구간을 조사했다. [공식 시장 자료 명세](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/rest-api/market-data)는 공개·집계 체결에 보험기금·ADL 거래를 포함하지 않는다고 설명한다. ID 공백 하나가 곧 공개 시장 체결 누락이라는 최초 검사 가정은 충분하지 않다. 특정 공백의 원인이 ADL이라고 단정하지 않는다.

ID 공백이 있는 수정 대상에는 공식 체크섬을 확인한 집계 체결을 추가로 요구한다. 수정할 분봉의 개별 체결 모두가 집계의 첫·마지막 ID에 의해 정확히 한 번씩 연결되고, 가격·수량 합계·매수자 maker 여부·첫 시각·100ms 이내 시간 범위가 일치해야 한다. 연결 누락·중복·경계 불확실성은 거부한다. 원체결의 5분 OHLC·거래량·건수 대조도 그대로 유지한다. 두 형식 대조가 없으면 종전처럼 복원을 중단하며 최초 실패를 보존한다. 이는 데이터 검증 근거의 보완이며 후보·비용·선택 기준의 변경이 아니다.

### 두 해상도 자료의 동시 복원

다년 후보 실행 전 조사에서 원체결과 집계 체결이 서로 일치하지만 공식 5분봉도 다른 구간을 발견했다. 5분봉을 항상 정답으로 취급하는 기존 복원은 해당 구간에서 중단하고 실패 기록을 보존했다. `paired-repair`는 불일치 5분 구간 전체의 개별 체결을 별도 집계 체결과 정확히 한 번씩 대조한 뒤 1분·5분 자료를 각각 복원한다. ID 공백 유무와 관계없이 모든 대상 체결의 가격·수량·방향·시각 검증을 요구한다. 집계가 대상 경계를 걸칠 때를 위해 전후 5분 원체결을 함께 읽고, 날짜 경계를 넘는 경우에는 자동 복원을 거부한다.

두 원본과 펀딩은 보존하고 새 두 폴더에 정규화 파일·전후 값·근거 해시를 저장한다. 전체 집계가 일치해야 완료 매니페스트를 생성한다. 모델·선택·비용은 그대로이며 기존 연구 결과도 덮어쓰지 않는다. 이번 검사는 두 해상도 불일치로 찾은 구간에 한정된다. 두 봉 자료가 같은 오류를 공유하는 경우나 전체 시장 기록의 완전성까지 검증한 것은 아니다.
