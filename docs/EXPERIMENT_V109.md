# 실험 v109 사전 계획: 청산 요청과 실제 종료의 시간 대응

2026-10-11. v108의 세 행동 모두 복수 요청 정답의 평균 정밀도가 첫 주문 대조보다 나빴다. 같은 모형의 재보정이나 이미 수행한 분별 관리·장기 학습 확대를 반복하기 전에 정답과 실행의 의미를 확인한다. v19의 축소 주문 체결량 연구와 구분해, 청산·반전 요청이 시작 에피소드를 실제로 끝낸 사건과 연결되는지 조사한다.

## 고정 진단

- v106의 전체 사건 원장, v107의 독립 주문·창·실제 체결 귀속, v108의 지원 창·저장 예측을 그대로 사용한다. 신규 학습·문턱 선택·매매 실행은 없다.
- 첫 체결에서 관측한 `orderqty`를 요청량으로 부른다. 제출 시각이나 최종 의도를 뜻하지 않는다. 정상 XBTUSD 주문을 전부 유지하고 최초·마지막 관측 시각, 관측 체결량, 요청량 변경, 마지막 관측 상태, maker/taker 체결 수를 보존한다. 불완전 체결을 취소로 추정하지 않는다.
- 청산·반전 요청마다 최초 체결 직전 에피소드의 실제 종료 사건을 연결한다. 같은 주문이 종료했는지, 다른 주문이 종료했는지, 기록 안에 종료가 없는지 구분한다. 시간 차이와 첫 체결 5분 창 안의 종료 여부를 기록한다. 창의 오른쪽 경계와 정확히 같은 사건은 다음 창이다. 원본 선언 순서를 유지하며 같은 시각 내부의 실제 거래소 순서까지 증명하지 않는다.
- 실제 종료 사건에서도 연결을 거꾸로 확인한다. 같은 주문이 처음부터 해당 에피소드의 청산·반전 크기를 요청했는지, 최초에는 다른 행동이었는지, 다른 에피소드에서 시작했는지, 특수 주문인지 구분한다. 요청 기준 통계와 종료 사건 기준 통계를 혼합하지 않는다.
- v107 지원 보유 창과 v108 학습·보정·진단 창에서 요청 청산과 실제 종료 정답의 2×2 대응을 집계한다. 동일 시작 에피소드라는 기존 정의를 유지하며 후속 에피소드 종료를 끌어오지 않는다.
- v108 A·B·선형 대조의 저장 청산 요청을 그대로 두고, 원래 요청 정답 및 같은 창 실제 종료 정답에 대한 TP·FP·FN·정밀도·재현율·F2를 함께 계산한다. 기간·월별 결과를 모두 남기며 대체 정답에서 좋은 모형을 사후 채택하지 않는다.
- 주문·종료 원장과 창 집계를 독립 순회 계산으로 전수 대조한다. 부분 체결, 주문 변경, 동시각 순서, 다른 주문의 종료, 기록 말미 미종료, 정확한 5분 경계를 합성 검사에 포함한다. 입력·기존 결과의 해시를 전후 확인하고 실패 실행은 보존한다.

## 해석과 후속 결정

시점 불일치가 크면 청산 요청을 즉시 시장가 종료로 바꾸는 근사의 수정 범위를 정한다. 작으면 v108의 낮은 예측력을 이 문제로 설명하지 않는다. 실제 체결은 미래 시장과 당시 주문 실행에 조건부인 결과이므로 대체 정답의 우수함이 실행 가능한 전략을 증명하지 않는다. 미체결 주문·호가·대기열 부재를 임의의 maker 체결이나 비용 인하로 메우지 않는다.

원본·모델·개별 원장은 로컬에만 보존한다. 공개 범위는 코드·방법·집계 결과다. 실제 주문·인증 연결 없이 최종 수익성 기준과 미해결 goal을 유지한다.
