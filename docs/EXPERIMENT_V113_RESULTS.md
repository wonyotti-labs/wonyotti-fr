# 실험 v113 결과: 원본과 봇의 관리 입력 지원 범위

2026-10-12. 기존 v48의 두 실행을 바꾸지 않고 실제 관리 판단 입력을 관찰했다. 이번 결과는 입력 분포의 설명이며 손실 원인 확정이나 수익성 개선이 아니다. [사전 계획](EXPERIMENT_V113.md)의 기간·정책·집계를 유지했다.

## 확인한 차이

유효 입력 중 학습 범위 밖 비중은 BTC 60.78%, ETH 44.59%였다. 원본 보정 22.35%, 진단 27.04%보다 높았으며 주된 차이는 보유 시간·유리한 가격 경로·과거 체결 이후 경과 시간이었다. 시장 14개 입력 자체의 범위 초과는 BTC 0.29%, ETH 0.19%였다.

범위 밖 317,305개 BTC 입력과 698,841개 ETH 입력은 모두 보유 판단이었다. 추가·축소·청산 요청은 각각 총 12개·64개였으며 모두 학습 범위 안에서 나왔다. 이 요청 수는 실제 종료 거래 수나 적중 수와 다르다. 정의한 다섯 이산 상태의 미관찰 조합은 두 봇에서 0개였지만, 이를 50차원 상태 분포의 동일성으로 해석하지 않는다.

양수인 BTC의 범위 초과가 손실인 ETH보다 많았다. 따라서 이 비중 하나로 손익 차이를 설명하거나 범위 밖을 일괄 청산·제외할 근거를 얻지 못했다. 원본과 봇의 상태 차이는 확인했지만 원인이나 수정 규칙은 아직 확정하지 않았다. 이미 했던 최대 보유 제한 연구와 별개로, 이후 변경은 상태 차이가 실제 관리 판단·순손익에 미치는 영향을 검증해야 한다.

## 검증과 한계

신규 27개와 관련 66개 검사, 합계 93개 및 Ruff 검사를 통과했다. 최초 합성 검사 한 건의 소수 표현 비교 오류를 허용 오차 1e-15로 수정한 이력을 보존했다. 실제 입력은 현재 시세·계좌와 저장 경로·과거 체결 상태의 별도 수식으로 매 호출 검산했고, 학습 분위수는 정렬 후 보간으로 대조했다. 모든 집계는 Parquet 저장 후 별도 열 연산으로 다시 확인했다.

원본 다섯 파일, 참조 파일 100개, 공개 모듈 314개의 실행 전후 지문을 대조했다. 전체 테스트 모음이나 원격 CI의 최신 통과를 주장하지 않는다. 원본·개별 입력·모델은 로컬에 보존하며 실거래 연결은 없다.

학습 범위 밖이라는 사실은 행동의 정답이나 기대손익을 알려주지 않는다. 원본의 이후 기간 자체도 상태 범위가 달라졌다. BTC와 ETH의 기간·시장·거래 경로가 서로 다르므로 두 실행 간 차이로 단일 원인을 확정할 수 없다. 새 학습·문턱·매매 규칙을 선택하지 않았고 v10의 표본 수·비용·지연·다년·다시장 기준과 이전 실패를 유지한다.
