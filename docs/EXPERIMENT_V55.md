# 실험 v55 사전 계획: 현재 정책의 독립 진입 효용 정답

2026-10-04. v54는 현재 가격 이동 하한을 지켰지만 2022년 확인에서도 손실이었다. 실제 체결과 펀딩을 최초 진입·유리한 추가·불리한 추가 물량에 비례 배분한 결과 최초 진입 물량 자체도 비용 전후 모두 손실이었다. 이 배분은 원래 경로의 회계 설명이며 추가를 제거한 가상 전략의 성과가 아니다. 청산 기준이나 추가 위험만 반복 변경하기 전에 현재 관리 정책에 맞는 신규 진입의 경제적 정답을 만든다.

## 고정 범위

- 부모는 v54이며 진입 방향·대기·관리 모델·현재 비용 조건·가격 이동 하한·수량·위험·보유 한도와 모든 비용을 보존한다. 이 단계에서 새 필터·문턱·모델을 학습하거나 매매에 적용하지 않는다.
- 2021년 BTC의 모든 독립 진입 대기 충족 기회를 기존 확정 특징·5분 경계·16bp·5분 대기로 생성한다. 연속 봇이 보유 중이었던 기회도 포함한다. 미래 수익을 보고 기회를 추출하거나 승리 사례만 남기지 않는다.
- 각 기회는 독립 초기 계좌에서 다음 거래 가능한 1분 시가에 진입하고 같은 v54 정책으로 자연 종료될 때까지 재생한다. 실제 추가·부분 축소·비용·펀딩·지연 및 무거래 대기를 적용한다. 포지션 종료 뒤 재진입은 막는다. 고정 보유 한도와 손절·위험 중지에 따른 종료는 정상 정답에 포함한다.
- 2021년 종료 전 24시간의 배제 경계에 도달해도 종료되지 않은 기회는 미확정으로 보존한다. 경계 강제 청산으로 수익 정답을 만들지 않는다. 경계 밖 기회도 제외 사유를 남긴다.
- 정답은 실제 순손익을 최초 체결 명목액으로 나눈 bp다. 최초 체결까지의 기다림과 실제 정답 종료 시각·부분 거래·최대 회계 오차·종료 사유를 보존한다. 이 미래 결과는 이후 학습의 목표와 시간 배제에만 쓰며 현재 판단 특징에 넣지 않는다.

## 검증과 재개

기존 v15~v17의 전체 거래 정답 방식과 같은 회계를 유지하되 현재 자체 체결 이력·현재 비용 조회·원본 가격 이동 하한·시간 제한을 지원한다. 이전 정책의 결과를 바꾸지 않는다. 원래 v54 연속 실행의 첫 진입에서 독립 재생한 정답은 실제 첫 종료 거래와 정확히 일치해야 한다.

입력·고정 정책·코드·기회 목록의 지문과 완료 기회의 시간순 위치를 저장한다. 중단 시 이미 완료된 기회를 보존하고 검증한 다음 이어서 처리한다. 중간·실패·미확정 자료를 삭제하지 않는다. 반복 재개에 따른 중복·누락, 입력이나 정책이 바뀐 재개, 경계나 손익이 잘못된 원장을 거부한다.

롱·숏·손실·추가·축소·펀딩·무거래·보유 한도·경계 미확정 사례와 전체 중단 없는 실행 대비 재개 결과를 검사한다. 실제 자료에서는 기회와 모든 종료·미확정 상태, 종료 시각·방향·월별 집중·겹치는 정답 구간을 보고한다. 원본 다섯 파일은 불변이어야 한다.

2021년은 기존 모델·문턱에도 사용한 전체 시스템의 내부 적합 구간이다. 이 정답 생성 완료나 평균 정답 수익을 일반화 성과로 표시하지 않는다. 겹친 독립 초기 계좌의 기회는 독립 표본이나 연속 계좌 성과가 아니다. 후속 진입 모델과 시간순 평가는 별도 사전 계획으로 고정한다. 원본·정답·개별 결과는 로컬에 보존하고 실제 거래 연결은 없다.
