# 실험 v41 사전 계획: 포지션별 학습 기여 균등화

2026-10-04. v40의 보유 한도 매매 대조와 독립적으로, 관리 모델의 학습 표본 구성을 진단한다. 기존 원본 분봉은 긴 보유 포지션에서 많은 행을 생성하므로 소수 포지션이 학습·진단을 지배할 수 있다. 설명 진단에서 이러한 집중을 확인했지만 가중 학습의 예측·수익 개선은 아직 검증하지 않았다.

## 단일 학습 변경

- v35의 2020년 학습·2021년 상반기 보정·하반기 진단 행, 50개 입력과 모든 정답·포지션·24시간 경계를 그대로 유지한다. 손실·짧은 포지션·보유 행을 제거하지 않는다.
- 학습 행 i의 가중치는 N / (E × n_e)다. N은 학습 행 수, E는 학습 포지션 수, n_e는 해당 학습 포지션의 행 수다. 가중치의 평균은 1이며 각 포지션의 총 기여는 같다. 미래 구간의 포지션 길이·행동 정답·손익은 가중치에 쓰지 않는다. 지수·상한·혼합률 검색은 없다.
- v35의 히스토그램 부스팅 설정을 유지한 세 행동 모델에만 이 가중치를 적용한다. 입력·64회·깊이 2·학습률·말단·L2·seed·조기 종료 설정은 모두 유지한다. 유한 양수·평균 1·총합·포지션별 총합과 유효 표본 수를 검증하며 전체 유효 표본은 기존 학습 최소 1,000개 이상이어야 한다. 각 행동의 원래 양성·음성 20개 기준도 유지하고 가중 유효 양성·음성 수를 별도로 보고한다.
- 새 모델의 절편은 기존 방식으로 상반기 원래 분별 빈도에 보정한다. 보정과 평가 행에는 새 학습 가중치를 적용하지 않는다. 수익성·봇 문턱·위험·실행 정책은 바꾸지 않는다.

## 기준과 독립 검증

하반기에서 새 보정 모델이 기존 v35 보정 이력 부스팅, v21 원래 관리, v35 보정 이력 로지스틱, v32 보정 부스팅 각각에 대해 세 행동 모두 로그 손실을 1% 초과 개선하고 평균 정밀도를 유지해야 한다. 상반기 상수 기준보다 좋아야 하며 자체 보정 전 로그 손실보다 나빠지지 않아야 한다. 한 행동·기준이라도 실패하면 후속 매매 적용을 차단한다. 포지션별 평균 로그 손실은 설명 자료로 함께 기록하되 주 판정을 대체하지 않는다.

원래 기준 점수·행·파일 지문을 재현하고 별도 학습 라이브러리와 숫자 내보내기·가중 합·절편·수기 지표를 대조한다. 하반기 정답 변경이 가중치·학습 모델·절편을 바꾸지 않는지 검사한다. 실제 매매 성과는 평가하지 않으며 통과하더라도 다음 매매 적용은 별도 계획이 필요하다. 이미 관찰한 기간이며 원본·파생 모델·개별 결과는 로컬에 보존한다.

구현은 고정된 scikit-learn의 [공식 표본 가중 학습 API](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.HistGradientBoostingClassifier.html)를 사용한다. 이번 가설은 포지션별 학습 기여를 바꾸는 연구 선택이며 라이브러리 문서가 거래 성과를 보장하는 것은 아니다.
