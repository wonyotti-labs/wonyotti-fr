# 실험 v125 결과: 관리 요청의 시간 군집과 일대일 대응

2026-10-12. [사전 계획](EXPERIMENT_V125.md)의 27개 기간·모델·행동 조합을 모두 검산했다. 원본 1,018,460행과 기존 정확한 분 TP/FP/FN, 문턱 통과를 보존했다. 새 학습·정책 변경·계좌 실행은 없다. v124 미채택과 수익성 미해결 상태를 유지한다.

## 해석

- 하반기 극값 시계 모델의 축소 오탐 453개 중 329개(과거만 227 + 양쪽 102)는 이전 14분 안에 이미 축소 정답이 있었다. 동일 크기 모델은 359개 중 323개다. 행동 후속 시점에 높은 점수가 집중되는 현상이며 그 요청을 성공 예측으로 다시 채점하지 않는다.
- 극값 시계 축소의 정확한 분 적중은 64개다. 아직 연결되지 않은 정답을 1~14분 일찍 포착한 일대일 대응은 40개이며, 합계 104/247개다. 늦은 요청을 허용하면 별도로 112개가 추가된다. 선행과 후행은 독립 비교이므로 서로 더하지 않는다.
- 동일 크기 대비 극값 시계의 축소 FP는 359→453개, 앞뒤 14분 정답이 없는 FP는 22→90개로 증가했다. 오탐 증가를 모두 같은 사건 주변의 중복 요청으로 설명할 수 없다. 두 모델이 새로 낸 개별 요청의 차집합을 뜻하는 수치는 아니다.
- 극값 시계 청산은 정확한 분 1/34개, 1~14분 선행까지 포함해도 3/34개다. FP 41개 중 35개는 앞뒤 14분 안에 정답이 없다. 단순한 몇 분 시점 이동을 청산 실패의 해결책으로 볼 근거는 부족하다.
- 추가의 양방향 비교에서는 동일 크기 모델의 느슨한 잔여 정답 포착 33개가 일대일 제약에서 24개로 줄었다. 하나의 요청을 여러 정답에 재사용하면 포착 수가 과장될 수 있다.
- 세 모델의 하반기 요청은 군집을 이루지만, 군집을 하나의 실제 주문으로 바꾸거나 제거한 실험이 아니다. 반복 청산·축소·추가의 우선순위, 기존 3분 대기, 크기 제한과 봇 자신의 상태는 별도 실행에 필요하다.

정답은 기존 독립 주문 첫 체결에서 만든 양성 **분**이다. 실제 계좌 종료 건수·독립 주문 건수와 같다고 가정하지 않는다. 1~14분 근접성은 관찰된 원본 상태의 설명적 지표이며 수익 개선의 원인 증명이 아니다. 모든 기간을 이미 관찰했다.

## 표 읽기

모든 수치는 행동별 독립 문턱 통과다. 정확한 분 적중을 먼저 고정하고 남은 요청·양성 분만 대응한다. 선행·후행·양방향 표의 `일대일/느슨`은 **추가** 포착 수이며, 정확한 분 TP를 더하면 해당 조건의 총 포착 수다. 느슨한 수치도 정확한 분 대응을 제거한 뒤 계산한다. 원래 정답과 기존 F점수는 변경하지 않는다.

FP 시간 분류의 미래·과거는 같은 포지션의 1~14분 범위다. `범위 밖`은 같은 포지션에 양성 분은 있지만 해당 범위에 없고, `정답 없음`은 같은 포지션에 양성 분 자체가 없음을 뜻한다. 군집은 연속 요청 간격 3분 이하의 연결 집합이며 최대 지속 시간이 3분을 넘을 수 있다.

## 검산 범위와 재현 근거

- 시간순 두 포인터의 최대 대응 건수를 별도 이분 그래프 증대 경로로 전수 대조했다. 요청·정답의 중복 사용과 시간 범위, 포지션 경계를 각각 검사했다.
- FP 분류는 모든 같은 포지션 정답과의 시간 차이로, 군집은 별도 순회로 재계산했다. 원장의 저장 후 값과 기존 혼동 수를 대조했다.
- 검산 누계: 행·모델·행동 9,166,140개, 요청 원장 20,189개, 세 시간 조건의 추가 대응 원장 10,850개, 군집 원장 7,813개. 동일 원본 행이 모델·행동마다 반복 계산되므로 독립 표본 수가 아니다.
- 신규 30개와 관련 32개, 총 62개 검사가 7.01초에 통과했다. Ruff 검사도 통과했다. 전체 검사 묶음이나 최신 원격 CI의 통과를 주장하지 않는다.
- 원본은 정수 값을 가진 float64 포지션 번호를 사용한다. 입력 스키마 확인 뒤 유한·양수·정수 값·안전한 표현 범위를 검사하도록 처리했다. 분 번호는 명시적으로 나노초에서 변환하며 ns/us/ms/s 동일 결과를 검사했다.
- 실행 전후 모든 입력·계획·코드 지문이 같다. 실행 중 오류 없이 종료 코드 0을 확인했다. 원본·예측·원장은 로컬에만 보관한다.

## 다음 연구에 남긴 제약

현재 결과는 청산의 사건 밖 오탐과 축소의 후속 반응·사건 밖 오탐을 구분한다. 새 가설은 기존 포지션 최초 행동 분리(v119), 빈도 가중(v122), 시간 범위 정답(v51)과의 차이를 먼저 명시해야 한다. 정답 이후 요청을 성공으로 바꾸거나 하반기에 유리한 문턱·모델만 합치는 수정은 허용하지 않는다. 실제 자기 상태의 비용 포함 계좌와 v10의 다년·다시장 검증 전에는 수익성 해결로 표시하지 않는다.
