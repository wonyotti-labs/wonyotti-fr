# 실험 v116 사전 계획: 관리 모델의 거래소 입력 정렬

2026-10-12. v115의 다섯 계좌 재생은 계속하며, 이미 검산한 BTC 2022년은 26거래로 확대 기준에 미달했다. 다음 비교는 반복 문턱을 더 낮추는 방식이 아니다. 현재 v35 관리 모델의 시장 특징은 BitMEX XBTUSD에서 만들었고 자체 계좌 실행은 Binance USD-M 시세에서 같은 산식을 계산한다. 기존 v104는 이 출처 차이를 총 노출 변경량 모형에서 다뤘다. 이번에는 원본 보유 상태를 사용하는 50개 입력 관리 모형에서 같은 학습 행·정답의 비교를 수행한다. 출처 차이가 손실 원인이라고 미리 단정하지 않는다.

## 원본 보존과 변경 범위

검산된 v35의 2020년 학습, 2021년 상반기 보정, 하반기 진단 표를 사용한다. 기존 24시간·포지션 경계 제거와 모든 열·정답·원본 지문을 보존한다. 세 기간은 이미 관찰했다. v113 검산 출처를 따라 기존 표와 고정 v48 모델의 연결을 확인하며 v115 실행 중인 코드·계획·입력은 변경하지 않는다.

50개 중 시장 관측에서 오는 36개 값만 대체한다. 기존 14개 5분 시장 특징과 방향을 곱한 14개, 직전 확정 1분의 네 특징과 방향을 곱한 네 특징이다. 후보는 기존에 검산한 Binance BTCUSDT 개발용 1분·5분 시세를 사용한다. 새 자료 다운로드·기간 탐색·특징 추가는 없다.

방향, 유리한 가격 변화, 보유 시간, 추가 횟수, 최선·최악 가격 변화, 되돌림, 잔여 비중, 과거 체결 이력 여섯 값은 원래 원본 상태 그대로다. 원본 상태를 Binance에서 실제로 발생한 계좌라고 해석하지 않는다. 원본의 진입가·수량을 재작성하거나 모델의 실제 매매에 공급하지 않는다.

## 첫 단계: 관측 시각과 지원 검산

먼저 원래 BitMEX 1분·5분 자료에서 36개 값을 다시 계산하고 모든 원본 표의 값과 정확히 일치하는지 확인한다. 이미 확정된 가장 최근 5분 특징만 연결하며 판단 시각과 그 특징 종료의 차이는 0~4분이어야 한다. 1분 특징은 판단 시각에 정확히 끝난 봉에 연결한다. 분모 거래량 평균은 이전 60분이며 현재 분을 제외한다.

Binance도 같은 두 계산 함수를 사용한다. 시세 파일·manifest 지문, UTC·연속성·OHLC·거래량·1분과 5분 집계의 일치를 확인한다. 앞 준비 자료는 사용하지만 판단 뒤의 봉을 과거 입력에 연결하지 않는다. 미래 값 채우기나 임의 시각 보간은 없다.

원래 모든 행을 보존한 연결 원장에 원본·후보 값, 원천 종료 시각, 유한성·지원 사유를 기록한다. 원본은 유한하지만 후보가 비유한인 행도 보존한다. 학습·지표 비교는 두 입력이 모두 유한한 동일 행만 사용하고, 기간·행동별 전체·포함·제외 지원과 특징별 차이를 공개 집계한다. 제외는 손익이나 정답 크기를 사용하지 않는다. 각 분할의 각 행동에서 양성·음성 20개 이상을 요구한다. 미달하면 학습 없이 지원 실패를 기록한다.

별도 시각 이진 검색, 직접 1분 산식·5분 특징 대응과 방향 곱, 원본의 나머지 열 불변, 전체 행 수·포지션 경계를 대조한다. 미래 봉 변경·추가 시 이전 입력 불변, 잘못된 시각·누락·비유한·변조를 합성 사례로 검사한다. 실제 입력 검산 뒤에만 학습 단계로 넘어간다.

## 두 번째 단계: 동일 행의 고정 학습

같은 지원 학습 행에 세 모형 계열을 한 번씩 적합한다.

1. 원본 50개 특징의 부스팅 대조.
2. 시장 36개를 Binance 값으로 바꾼 50개 특징의 부스팅 후보.
3. 후보와 같은 50개 특징의 표준화 로지스틱 대조.

행동은 청산·축소·추가 세 개다. 부스팅은 기존 v35의 64회·학습률 0.05·깊이 2·최대 말단 4·최소 64행·L2 1·255구간·seed 0·조기 종료 및 가중치 없음이다. 로지스틱도 기존 C=0.1·학습 전용 표준화·무가중치 설정을 유지한다. 후보별 설정·행 선택·모형 용량 탐색은 없다.

각 모형의 절편은 상반기 공동 지원 행에서만 v35의 기울기 1·기계 정밀도 경계·[-64,64] 100회 이분법으로 보정한다. 하반기 정답은 적합·보정·선택에 사용하지 않는다. 기존 v35의 저장 모델·절편·점수도 보존한다. 공동 지원이 원래 학습·보정 행 전부와 같으면 새 원본 대조가 기존 모델과 정확히 같아야 한다. 다르면 동일 행 재학습 대조와 기존 저장 모형을 구분한다.

모든 모형의 원시·보정 확률과 기존 v35 점수를 같은 행에서 기록한다. 기존 모델에 후보 입력만 공급한 점수도 출처 차이 진단으로 보존하며 새 후보로 선택하지 않는다. 비교 상수는 같은 보정 행의 행동 빈도다. 전체·월별 로그 손실·Brier·평균 정밀도와 청산 F2·축소 F1·추가 F0.5의 보정 전용 문턱, 진단 TP·FP·FN을 보고한다. 문턱은 기존 최소 예측 양성 20개 조건을 유지한다.

## 진단 관문과 후속 범위

세 행동 모두에서 후보 보정 부스팅의 하반기 로그 손실이 동일 행 원본 보정 부스팅과 후보 보정 로지스틱보다 각각 1% 초과 개선되고, 평균 정밀도가 두 대조 이상이어야 한다. 자체 보정 전보다 로그 손실이 나쁘지 않고 보정 빈도 상수보다 좋아야 한다. 수치 경계는 기존 1e-12다. 일부 행동만 채택하거나 실패 후 기준·특징·기간을 바꾸지 않는다.

독립 라이브러리 재학습의 트리·계수·표준화, 별도 추론과 절편 계산, 전체 확률·문턱·지표·판정을 대조한다. 지원 실패·오탐 증가·동일 예측·모든 이전 손실을 보존한다. 이 관문은 원본 행동 예측의 후속 연구 허용 조건이며 자체 계좌 수익성 채택이 아니다. 통과할 때만 별도 실행 계획에서 새 모델·문턱과 자체 상태를 고정해 BTC 다년·ETH·SOL·비용·펀딩·지연·낙폭·표본·집중을 검증한다. 기존 v10 최종 기준은 그대로다. 원본·시세·모델·개별 출력은 로컬에만 두며 실제 거래 연결은 없다.
