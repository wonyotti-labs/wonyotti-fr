# 실험 v17 사전 계획: 노출 확대 활동과 신규 진입 기회의 분리

2026-10-04. v16은 중첩 비중을 줄인 학습으로 2022년 확인을 개선했지만 후속 BTC 손실과 최근 거래 수 부족이 남았다. 기존 활동 정답은 새 진입과 이미 보유한 포지션의 추가 주문을 함께 포함한다. 이 관문을 초기 진입에 적용한 결과 학습 기회가 급변 월과 높은 변동성에 집중된다. 2020년 기회 범위 조사도 급락 월 집중을 보였다. 단순한 학습 연도 추가가 해결책이라고 가정하지 않는다.

별도 기회 수 진단에서는 기존 방향 모델·0.65 기준·5분 신호 경계·16bp 대기·5분 만료를 유지하고 활동 관문만 제거했다. 2021년의 모든 월과 낮은 변동성 구간에 기회가 늘었다. 이 진단에서는 거래 손익이나 새 모델을 계산하지 않았다. 늘어난 거래 기회를 수익성 근거로 사용하지 않는다.

## 고정 변경

- 노출 확대 활동 점수로 신규 진입 기회를 막지 않는다. 원본에서 학습한 방향 모델과 방향 문턱은 그대로다. 방향 확신이 부족하면 여전히 진입 대기를 시작하지 않는다.
- 새 기회 집합의 2021년 전체 거래 정답을 같은 v14 관리·수량·위험·비용으로 다시 만든다. 진입 이후의 관리 모델과 빈도 누적은 바꾸지 않는다.
- 모든 독립 기회를 재생하고 손실·위험 종료·학습 경계 미확정 원장을 보존한다. 미래 손익을 보고 기회를 추리거나 원래 정답만 골라 섞지 않는다.
- v16과 같은 중첩 가중치·표준화 Ridge alpha 100·8bp 진입 기준을 사용한다. 가중치 평균은 1이며 행 수 변화에 따른 전체 학습 비중도 보고한다. 단일 모델이고 새로운 후보 탐색·월별 균등화·손익 가중치는 없다.
- 2021년 전체 시스템 학습과 같은 구간의 재생은 학습 적합 진단이다. 2022년에서 모델·문턱을 재선택하지 않는다. 새 학습 기간이나 미사용 검증 구간으로 바꾸지 않는다.

## 비교와 검증

2022년 양수·30거래·낙폭 중지 없음 실패 시 사전에 정한 BTC 두 후속 기간·세 독립 연도 진단만 수행한다. 통과하면 세 시장·열 조건·아홉 독립 연도를 평가한다. 열 조건은 고정 정책, 원래 v7, 현금, 추가 제거, 30분 제한, 비용 2배·3배, 추가 1분 지연, 원래 v14, 새 기회 집합에서 순손익 필터만 제거한 정책이다. 원래 v7·v14 대조에는 바뀐 진입 관문을 적용하지 않는다. 이미 완료한 고정 v16 결과와도 같은 기간·입력으로 비교한다.

기존 활동 관문이 있는 정책의 숫자·행동 불변, 방향 판단·대기·관리 규칙의 보존, 새로운 기회와 실제 필터 판단의 연결, 필터 제거 기준의 정확한 의미, 시간 경계·학습 모델 지문·원본 보존·회계·실제 중단 복원을 검사한다. 자료 규모가 늘어나도 부분 진행과 실패를 보존한다.

전체 수익성 기준은 v10과 같다. 더 잦은 기회가 비용·낙폭을 악화시킬 수 있으며, 진입 패턴 변경이 원본 전략의 완전한 복제를 뜻하지 않는다. 기회 생성 방식 변경과 그에 필요한 재학습을 묶은 정책 비교이며 손실의 단일 인과 원인으로 단정하지 않는다. 이미 관찰한 기간의 반복 연구·선택 편향을 남기고 기준 미달 시 원인 연구를 계속한다. 원본·파생 자료·모델은 Git에 올리지 않고 실제 거래를 연결하지 않는다.

## 첫 정답 생성에서 발견한 실행 오류 수정

확장 기회의 첫 재생은 거래 수·거래량이 0인 분봉의 청산 가정을 검출해 중단됐다. 실패·부분 원장은 보존한다. 기존 엔진 입력이 거래 활동 열을 전달하지 않아 사후 검사에서만 발견된 오류다. 손실 정답이나 해당 분봉을 삭제하지 않고 실행 계층을 수정한다.

활동 정보가 있는 입력에서는 무거래 봉에 체결하지 않는다. 제출된 주문은 다음 거래 가능 봉의 실제 첫 가격으로 미루고 대기 의도·추가 지연 순서를 상태에 보존한다. 위험 청산도 체결 가능한 가격이 없을 때 완료로 간주하지 않으며, 거래가 재개되면 우선 실행한다. 이 동안 펀딩·시간·평가 손익은 계속 반영한다. 마지막 봉이 무거래이고 포지션이 남으면 임의 가격으로 마감하지 않고 실패 상태를 보존한다. 거래 활동은 체결 가능성에만 사용하며 진입 신호가 미래 거래량을 미리 보도록 하지 않는다.

합성 무거래 진입·부분 매매·청산·펀딩·날짜 경계·위험 중지·추가 지연·실제 중단 복원을 검사한다. 발견 사례를 새 코드로 재현하고 활동이 있는 기존 체결 결과의 일치 여부와 변화를 명시한다. 원래 시세의 무거래 봉은 그대로 유지한다. 호가 잔량·시장 충격까지 모델링했다는 뜻은 아니다.
