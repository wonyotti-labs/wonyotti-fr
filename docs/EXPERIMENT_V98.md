# 실험 v98 사전 계획: 현재 노출의 변경량과 자기 계좌 실행

2026-10-11. v97은 계좌 노출의 의미를 반영했지만 시장 정보만으로 절대 노출을 예측하면 매도 방향을 재현하지 못했다. 현재 원본 상태 유지 기준의 낮은 오차는 상태 지속성이 크다는 뜻이며 실행 가능한 봇의 성적이 아니다. 이번에는 현재 노출에서 다음 노출까지의 변경량을 학습하고, 실제 재생에서는 봇 자신의 현재 계좌만 입력한다. 아직 이 모형의 학습·정책 손익을 계산하지 않았다.

## 학습과 예측 대조

v97의 전체 행과 정답·미지원 사유를 그대로 연결한다. 현재와 다음 경계의 노출이 모두 지원되는 2020년 행에서 `다음 노출 - 현재 노출`을 학습한다. 다른 행도 현재·목표 중 어느 쪽이 미지원인지 보존한다. 2021년에는 같은 규칙으로 예측을 진단하며, 기존 포지션·24시간 배제와 시간순 분리를 유지한다. 이 변경량에는 수동 주문뿐 아니라 가격·수수료·펀딩에 따른 노출 변화도 포함되므로 주문 의도라고 명명하지 않는다.

입력은 확정 시장 특징 14개와 현재 부호 있는 BTC 노출 한 개다. 학습에서 원본의 현재 상태를 쓰는 것과, 실행에서 원본의 상태를 답처럼 공급하는 것은 구분한다. 실행 입력은 봇 자신의 `수량 × 현재 확정 종가 / 계좌 평가액`으로만 계산한다. 입출금·다음 원본 노출·실제 미래 체결은 입력으로 사용하지 않는다.

단일 후보는 v97과 같은 깊이 2·64회·학습률 0.05·말단 4개·최소 표본 64·L2 1·최대 구간 255·조기 종료 없음·seed 0의 제곱 오차 회귀다. 예측 대상만 변경량으로 바꾸고 현재 노출 입력을 추가한다. 대조는 변경량 0, 학습 변경량 평균, 학습 전용 표준화와 Ridge(alpha=1, svd)다. 후보를 결과에 따라 대조 모형으로 교체하지 않는다.

전체·월별 변경량 MSE·MAE와 다음 절대 노출의 방향·크기를 함께 기록한다. 원본 상태를 매번 공급한 한 단계 예측은 설명용 지표로만 표시한다. 해당 성적이 좋아도 자기 계좌 연속 실행이 같은 결과라고 가정하지 않는다. 정답 연결·독립 재학습·숫자 모형·직접 지표·미래 변경 불변을 검산한다.

## 고정 실행 정책

초기 계좌는 USDT 10,000, 포지션 0이다. 5분 경계에서 다음 목표 노출을 `현재 봇 노출 + 예측 변경량`으로 정하고 [-0.5, 0.5]로 제한한다. 별도의 활동 확률로 축소·청산을 차단하지 않는다. 목표 노출에 맞는 수량은 다음 거래 가능한 분봉 시가와 그 시점 계좌로 계산한다. 이미 닫힌 봉만 신호에 쓰며, 실제 주문·인증·출금 연결은 없다.

재조정에 경제적 크기 문턱을 새로 맞추지 않는다. 부동소수점의 1e-12 노출 차이만 동일 상태로 취급한다. 체결 비용을 차감한 계좌와 목표 노출의 관계를 풀어 수량을 계산하며, 반전의 청산·신규 수량과 비용을 각각 기장한다. 부분 재조정을 모두 독립 종료 거래로 세지 않는다. 무거래 봉에는 체결하지 않고 주문 대기를 보존한다.

위험 설정은 기존 v48의 노출 상한 0.5, 손절 4%, 최대 보유 77,699분, 손절·시간 종료 후 대기 15분, 일일 손실 한도 3%, 최대 낙폭 25%를 유지한다. 수수료 5bp·슬리피지 3bp와 실제 펀딩을 차감한다. 위험·갭·펀딩·일자 변경·반전·종료 처리 순서를 명시하고, 중단 후 재개가 같은 결과를 내야 한다. 계좌 회계·비용·수량은 별도 순차 계산으로 검산한다. 단일 코인의 선형 계약 재생으로 다른 자산의 원본 손익을 복원했다고 주장하지 않는다.

대조 정책은 v97의 고정 절대 노출 예측과 v97 학습 평균 노출 0.40897540251397235다. 두 대조도 같은 노출 상한·비용·실행·위험 규칙을 사용한다. v97 모형을 다시 학습하거나 기존 v48 결과와 실행 규칙 차이를 숨기지 않는다.

## 실제 손익 검증 순서

예측 지표 결과와 관계없이 세 정책을 BTC 2021년과 2022년의 독립 초기 계좌에서 모두 재생한다. 총 여섯 경로의 전체 손실·체결·수수료·펀딩·낙폭·중지·종료 거래 수를 남긴다. 원본 상태를 실제 봇에 주입한 경로는 이 비교에 포함하지 않는다.

v10의 최종 수익성 기준과 기존 실패·사후 관찰 이력은 유지한다. 진행 중인 v93 공유 소스는 검산 완료까지 그대로 두고 새 준비 코드는 격리한다. 운영 등록 시 동일 결과 재현이 필요하다. 원본·시세·정답·모형·개별 실험 결과는 Git에 넣지 않는다.
