# 실험 v15 사전 계획: 현재 관리 정책에 맞춘 진입 순손익

2026-10-04. v14는 관리 시간·빈도를 바꿨지만 2022년 비용 후 손실과 후속 BTC 손실이 남았다. 2022년의 수수료 전 가격 이익만으로 채택하지 않는다. v8의 순손익 필터는 추가가 없는 30분 거래를 정답으로 사용했으므로 수 시간 보유·추가·축소를 하는 현재 정책과 목표가 다르다. 이번에는 현재 고정 관리 정책의 전체 거래 결과에 맞춰 진입을 거른다.

## 정답과 학습

- v14의 관리 모델·빈도 배율·진입 대기·수량·위험·편도 5bp 수수료와 3bp 슬리피지를 고정한다. 체결 비용을 낮추거나 지정가 체결을 가정해 손실을 이익으로 바꾸지 않는다.
- 2021년의 모든 독립 진입 대기 충족 기회를 생성한다. 실제 연속 계좌가 이미 보유 중이었던 기회도 분리된 초기 계좌에서 재생한다. 다음 1분 시가에서 최초 진입하고 같은 v14 관리로 자연 청산될 때까지 수행한다. 닫힌 뒤의 새 진입은 금지한다.
- 마지막 24시간 전까지 자연 청산되지 않은 기회는 미확정 정답으로 남기고 학습하지 않는다. 손실·손절·위험 중지 거래는 제거하지 않는다. 경계를 넘는 거래를 강제 청산해 학습 정답으로 바꾸지 않는다. 계산 도중 실패·부분 결과·미확정 포지션도 보존한다.
- 정답은 추가·축소·슬리피지·수수료·펀딩을 포함한 거래 순손익 / 최초 진입 명목액의 bp다. 독립 초기 계좌의 값이며 연속 계좌의 기존 보유·일별 위험 상태와 다르다. 겹친 기회·월별 집중·방향·양수/음수 표본·보유 시간을 기록한다.
- 입력은 기존 v8의 확정 시장 특징·방향·방향 상호작용·진입 대기 가격 변화·대기 분이다. 실제 미래 청산·추가 횟수·최종 손익·보유 시간은 입력에 넣지 않는다.
- 단일 표준화 Ridge alpha=100, 진입 기준 순손익 예측 8bp 이상으로 고정한다. v8에서 정의한 규제·여유 폭 중 이 설정 하나만 사용하며 새 성과로 값을 고르지 않는다. 최소 200개·방향별 20개·180일 범위의 기존 지원 기준을 유지한다.

## 시간순 검증

v12~v14 관리 모델 선택에 이미 2021년을 사용했으므로 이번 2021년은 전체 시스템의 학습 구간이다. 같은 구간 재실행은 학습 적합 진단으로 표시하고 일반화 성과나 후보 선택 근거로 사용하지 않는다. 고정된 단일 순손익 필터는 2022년에서 확인한다. 다른 후보·문턱으로 2022년을 재탐색하지 않는다.

관리 중에는 필터를 호출하지 않는다. 평탄 상태에서 기존 진입 대기가 충족될 때만 판단한다. 거절한 기회는 종료하며 미래 가격으로 같은 기회를 반복 심사하지 않는다. 중단 복원·반복 사건·필터 거절과 실제 체결 연결·모델 및 기반 정책의 지문을 검사한다.

2022년 양수·30거래·중지 없음 실패 시 기존 규칙처럼 BTC 두 후속 기간·세 독립 연도 진단만 수행한다. 통과하면 세 시장·여덟 조건·아홉 연도와 필터 제거 대조를 검증한다. 수익성 기준은 v10을 유지하며 이미 관찰한 기간의 반복 연구·선택 편향을 보존한다. 원본·개별 정답·모델·결과는 로컬에 유지하고 실거래를 연결하지 않는다.
