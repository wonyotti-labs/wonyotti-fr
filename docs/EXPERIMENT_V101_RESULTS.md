# v101 과거 체결 이력의 효과와 최근 무체결 구간의 한계

2026-10-11. [사전 계획](EXPERIMENT_V101.md)의 1시간 체결 이력 진단을 완료했다. 원본 상태에서 과거 이력은 다음 체결 예측에 정보를 더했지만, 최근 체결이 없는 구간의 행동 예측과 선형 대조 개선 조건은 통과하지 못했다. 새 모형을 매매에 연결하지 않는다.

## 지원 범위와 비교 조건

원본 연결 행 2020년 104,148개·2021년 104,448개를 모두 보존했다. 현재 정답과 직전 12개 연속 창의 이력이 지원되는 학습 행은 92,025개다. 감소·거래 없음·증가는 각각 1,252·89,657·1,116개였다. 현재 정답 창은 과거 이력에 포함하지 않았다. 누락·분해 미지원 창은 거래 없음으로 채우지 않았다.

진단 예측은 82,064개, 모든 모형의 공통 채점은 81,751개였다. 공통 정답은 감소 1,038개·거래 없음 79,777개·증가 936개다. 이력 지원 제한 때문에 v100의 전체 채점 집합과 다르므로 과거의 전체 점수와 직접 비교하지 않았다. 이력 없는 부스팅도 새 후보와 정확히 같은 학습 행·정답·설정으로 학습해 행 변화의 효과를 분리했다. 기존 v100 모형은 그대로 두었다.

이력 부스팅의 로그 손실은 동일 학습 행의 15개 특징 부스팅보다 29.82%, 같은 채점 행의 기존 v100보다 30.23% 개선됐다. 반면 이력 선형 대조보다 0.32% 나빴다. 전체에서 맞힌 감소 38개·증가 30개는 원본 과거 체결을 공급한 진단의 결과다.

## 최근 체결이 없는 구간

직전 1시간에 양방향 체결 기여분이 모두 0인 공통 진단 행은 72,619개였다. 이 안에는 감소·증가 정답이 각각 236개 있었지만 이력 부스팅은 전부 거래 없음을 선택했다. 두 방향 재현율은 0%이며, 고정한 각 10개 적중 기준에 미달했다. 이력 선형 대조도 이 부분집합에서는 두 방향 적중이 0개였다.

최근 체결 없음은 실제 최초 진입이나 평탄 계좌와 같은 뜻이 아니다. 이 진단에도 원본의 현재 노출은 공급된다. 따라서 이를 자체 계좌 초기 행동이나 연속 운용 성과로 주장하지 않는다. 관찰된 전체 개선은 원본에서 체결이 이미 이어진 구간에 의존하며, 매매 시작 문제를 해결했다는 근거는 없다.

14개 조건 중 11개 통과·3개 미달이었다. 선형 대조 대비 1% 넘는 로그 손실 개선과 최근 무체결 구간의 양방향 적중 조건이 실패했다. 다른 대조나 문턱으로 후보를 바꾸지 않았고 수익률 실험은 실행하지 않았다. v14·v26·v31의 이전 빈도·누적 실패도 유지한다.

## 검산

합성 검사 24개를 통과했다. 전체 208,596개 연결 행에 대해 과거 12개 참조 창·경계·지원·여섯 특징을 별도 순회로 대조했다. 현재·미래 정답을 변경해도 이전 특징이 바뀌지 않는 검사를 포함한다. 후보·동일 학습 행 대조의 384개 숫자 트리와 선형 모형을 각각 다시 학습하고, 전체 예측·단일 상태 예측·전체/12개월/최근 체결 유무 지표·판정을 독립 계산했다.

원본 5개·공유 소스 245개·v93 검산 도구 24개의 해시를 유지했다. 원본·파생 자료·모형·개별 예측은 Git 제외 상태다. 준비 구현의 운영 등록·동일 결과 재현, 자체 계좌 수익성 검증과 최종 v10 기준은 남아 있다. 이미 관찰한 기간이며 실제 거래 연결은 없다.
