# 실험 v42 사전 계획: 신규 진입 활동 모형의 시간순 진단

2026-10-04. v40의 보유 한도는 장기 실행의 범위 이탈을 줄였으나 확인·최근 손실은 남았다. v41의 포지션별 균등 관리 학습은 예측 조건에 미달해 매매에 적용하지 않았다. 새 설명 진단에서 약세 확인 구간의 롱 편중은 가격 대기보다 활동 관문 전후에서 크게 증가했다. 이는 활동 모델 변경의 개선을 입증하지 않으므로 원본의 시간순 행동 예측부터 검증한다.

## 고정 자료와 단일 모형 비교

- v25의 실제 수량 전이에 따른 open·reverse, 다음 5분 창의 첫 신규 포지션 정답과 14개 확정 시장 입력을 유지한다. 활동은 방향과 무관하게 신규 포지션이 있으면 1이다. 추가 주문·뒤늦은 사건·원본 손실을 원장에서 삭제하지 않는다. 대부분 보유 중 반전인 원본을 무포지션 진입에 적용하는 한계도 유지한다.
- 2020-01-01~2021-01-01 미만을 학습, 2021-01-01~2022-01-01 미만을 진단한다. 양쪽 24시간과 현재·목표 포지션 경계를 제거한다. 시간과 포지션 교집합을 검사한다. 학습 1,000행·진단 100행, 각 양성·음성 20개 이상이며 부족하면 조건을 낮추지 않는다.
- 기준은 같은 과거 구간에서 재학습한 표준화 로지스틱 C=0.1·최대 2,000회·seed 0과 학습 활동 빈도 상수다. 기존 v25의 2021년 포함 모형을 2021년의 과거 학습 기준으로 사용하지 않는다.
- 새 후보는 이진 HistGradientBoostingClassifier 하나다. 기존 관리 부스팅과 같은 로그 손실·64회·학습률 .05·깊이 2·말단 최대 4개·최소 64행·L2 1·구간 최대 255·전체 입력·seed 0이다. 표본·클래스 가중치와 조기 종료·추가 보정·설정 검색은 없다. 초기 점수는 라이브러리의 학습 클래스 빈도 추정이다.
- 각 모형의 학습 점수 .975 분위 문턱을 진단용으로 고정하고 양성 정밀도·재현율·월별 지원을 기록한다. 진단 정답으로 문턱을 선택하지 않는다. 실제 방향·관리·위험·보유 한도·거래 비용과 매매 정책은 변경하지 않는다.

## 사전 판단과 검증

진단의 분별 활동 로그 손실이 로지스틱보다 1% 초과 개선되고 상수보다 낮으며 평균 정밀도가 로지스틱 이상이어야 한다. 주 판정은 세 조건 모두다. Brier·ROC AUC·학습 문턱의 혼동행렬·월별 오류와 양성 표본을 함께 보고한다. 신호가 늘거나 롱·숏 수가 비슷해지는 현상을 개선 기준으로 삼지 않는다.

원본 수량 전이·첫 사건·학습 경계·배제 원장과 입력 지문을 검증한다. 숫자 내보내기를 별도 학습 라이브러리와 대조하고 마지막 구간의 입력·정답 변경이 학습 모델과 문턱을 바꾸지 않는지 확인한다. 기존 세 행동 관리 모형의 형식·숫자 예측을 보존한다. 통과하더라도 후속 매매 적용은 별도 계획으로 고정하며, 실패 시 미채택과 원인을 보존한다. 모든 기간은 이미 관찰했고 원본·파생 자료·모델·개별 결과는 로컬 전용이며 실거래 연결은 제외한다.
