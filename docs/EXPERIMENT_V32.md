# 실험 v32 사전 계획: 시간순 행동 빈도 보정 진단

2026-10-04. v30은 관리 부스팅의 세 행동 전체 개선 기준에 미달했으며 해당 실패를 유지한다. v31의 관리 판단 방식 변경도 2022년 확인에서 손실을 보여 후속 BTC 진단 중이다. 원본의 청산 빈도는 2020년·2021년 상반기·하반기에 감소했고, v30의 하반기 부스팅 평균 점수는 실제 빈도보다 높았다. 이 차이가 보정만으로 해결되는지는 별도 진단한다. 단순 평균 일치는 조건부 확률이나 수익성의 보장이 아니다.

## 시간 분리와 고정 모형

- 기존 v21의 44개 입력과 독립 주문 요청 정답을 그대로 사용한다. 정답 기간·포지션 경계·양쪽 24시간 제거를 전체 원본 상태열에서 적용한다.
- 기본 모형 학습은 2020년, 절편 보정은 2021년 상반기, 최종 진단은 2021년 하반기다. 세 구간의 포지션 교집합은 없어야 한다. 마지막 구간은 모델·절편·문턱 학습에 사용하지 않는다.
- 학습 구간 최소 1,000행, 나머지 각 100행과 각 구간·행동별 양성·음성 최소 20행을 요구한다. 독립 포지션·사건 수와 분별 표본 수를 구분해 기록한다. 지원 부족 시 완화하지 않는다.
- 기본 모형은 기존 표준화 로지스틱 C=0.1과 v30의 고정 히스토그램 부스팅 두 개다. 부스팅 설정·학습 가중치·조기 종료·특징은 바꾸지 않는다. 기존 18개월 학습을 12개월 학습과 6개월 보정으로 분리한 변경도 명시한다.
- 각 행동에 대해 `sigmoid(logit(p) + b)`의 절편 b 하나만 보정 구간 로그 손실을 최소화하도록 학습한다. 기울기는 1로 고정하고 행을 제거하거나 가중하지 않는다. 기계 정밀도 경계로 확률을 잘라 유한 로그 오즈를 구성하고, [-64, 64]의 100회 이분법으로 평균 예측과 실제 빈도의 오차가 1e-12 미만인지 검사한다. 표본 순위는 보존한다.

## 비교와 판정

같은 2021년 하반기 행에서 로지스틱·부스팅 각각의 보정 전후, 기존 v21 로지스틱, 보정 구간 행동 빈도의 상수 기준을 모두 보고한다. 로그 손실·Brier·평균 예측과 실제 빈도·평균 정밀도·ROC AUC를 기록한다. 진단 입력은 v30과 모든 열이 정확히 같아야 하며 기존 모델의 예측도 재현한다.

후속 연구 허용에는 세 행동 모두에서 보정 부스팅의 로그 손실이 기존 v21과 새 보정 로지스틱보다 각각 1% 초과 개선되고(1e-12 경계 제외), 보정 전 부스팅보다 악화하지 않으며 상수보다 좋아야 한다. 평균 정밀도도 기존 v21과 새 보정 로지스틱 이상이어야 한다. 일부 행동 선택·기준 완화는 없다. 통과하더라도 매매 문턱·정책·위험의 별도 사전 계획 전에는 새 매매 후보를 실행하지 않는다.

모든 기간은 이미 관찰한 자료다. 기존 v30·v31의 실패를 바꾸거나 독립 미사용 검증으로 부르지 않는다. 원본·개별 결과는 로컬 보존, 실거래 연결 제외, 작업별 한글 명사형 커밋 직후 푸시를 유지한다.

방법 근거: [scikit-learn 확률 보정 문서](https://scikit-learn.org/stable/modules/calibration.html)의 모형 학습과 보정 자료 분리 원칙. 여기서는 두 계수의 sigmoid 보정 대신 순위를 유지하는 절편 하나만 학습한다.
