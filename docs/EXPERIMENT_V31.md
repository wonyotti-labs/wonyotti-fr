# 실험 v31 사전 계획: 누적량과 현재 상태의 관리 판단 비교

2026-10-04. v30 관리 부스팅은 청산 로그 손실의 사전 기준을 통과하지 못했다. 해당 모형을 매매 후보에 적용하지 않는다. 별도 원본 상태 진단에서는 v21 로지스틱 점수의 전체 합을 사건 수에 맞춰도 포지션 종료 때 남은 누적량이 소실됐고 원본 사건 시각을 재현하지 못했다. 이 진단은 원본 상태를 고정하고 대기·우선순위·실제 청산을 생략했으므로 실제 봇 손익 또는 단일 손실 원인의 증명이 아니다.

## 고정 변경과 대조

- 기반은 v29다. 진입·방향·관리·축소 모형, 최초 투입·추가 예산·손절·낙폭·거래 비용·펀딩을 모두 보존한다. 새 학습이나 문턱 검색은 없다.
- 현재 44개 특징의 관리 점수가 기존 저장 문턱 × 기존 배율 1.5 이상일 때 해당 행동을 요청한다. 과거 점수를 누적하거나 포지션 사이로 넘기지 않는다. 문턱은 v21에서 이미 고정한 값이다.
- 청산·축소·추가 우선순위, 3분 관리 대기, 미체결 요청 중복 방지, 다음 봉 체결, 과거 확정 종가 경로와 학습한 축소 크기를 유지한다. 기존 누적 상태를 새 정책에 잘못 연결하면 실패 처리한다.
- 이전 v29를 동일 위험 설정으로 실행해 전체 출력·최종 상태의 정확한 일치를 확인한다. v30의 개선된 일부 행동만 골라 섞는 비교는 제외한다.

## 실행과 판정

2021년 후보·v29 두 실행은 이미 학습·관찰한 적합 진단이다. 2022년 양수·종료 거래 30개 이상·영구 중지 없음 조건을 확인한다. 통과하면 세 시장 두 후속 기간의 기본 여덟 조건과 원래 위험 설정의 v14·v28 및 동일 위험 설정의 v29, 총 열한 조건과 아홉 독립 연도를 평가한다. 실패하면 BTC 두 후속 기간과 세 독립 연도만 진단한다. 실패 시 총 여덟 손익 실행, 통과 시 총 78개 실행을 보존한다.

한 구간 개선·손실 감소·거래 수 변화는 수익성 해결로 판정하지 않는다. 모든 기간을 이미 관찰했으며 미사용 평가로 주장하지 않는다. 원본 상태의 동시점 점수와 요청 기회를 별도로 기록하되 문턱 재선택에 사용하지 않는다. 행동 우선순위·대기·축소 크기·파일 불변·회계와 실제 프로세스 종료 복원을 검사한다. 원본과 개별 연구 결과는 로컬에 보존하며 실거래 연결은 제외한다.
