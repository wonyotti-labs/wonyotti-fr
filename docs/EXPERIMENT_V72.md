# 실험 v72 사전 계획: 확정 결과의 주간 청산 비용 재학습

2026-10-09. v71 체결 방향 입력은 최초 효과를 개선하지 못했고 스물네 조건 중 다섯 개만 충족했다. 앞서 v69·v70의 고정 모델은 학습에 사용한 앞 구간에서는 양의 최초 효과를 보였으나 뒤 진단에서 음수였다. 학습 성과를 일반화 근거로 해석하지 않는다. 이번에는 현재 74개 입력의 비용 분류기를 시간에 따라 갱신하는 효과만 분리한다. v67의 주간 회귀 실험은 56개 입력·회귀 목표였으므로 그 실패도 유지한다.

## 시간과 자료

v71과 모든 이전 결과를 재현한다. 원래 v64의 전체 판단 원장에 v70·v71의 같은 시세·같은 다일 및 체결 방향 계산을 적용한다. 원래 56개 값과 전체 원장·상태·제외 이력을 보존하고, 기존 학습·진단의 74개 값과 정확히 대조한다. 실제 매수·매도 체결량이 없는 새 자료·종목·기간을 선택하지 않는다.

진단은 기존 2021-10-02 이상부터 2021-12-31 미만의 고정 행·정답·평가 가중치다. 2021-10-02부터 7일마다 총 13회 갱신하고, 해당 주 시작 이틀 전보다 엄격히 앞서 정답이 종료된 거래만 학습한다. 학습 진입·판단 시작은 2021-01-01로 고정한 누적 구간이다. 해당 주의 미확정 정답이나 이후 입력·결과는 해당 주 모델을 바꾸지 못해야 한다.

기존 v67의 최소 1,000행·100포지션·방향별 20포지션·180일 지원 조건과 v69의 양쪽 부호별 최소 64개 비용 양수 학습 행을 그대로 요구한다. 정답이 없는 행은 원장에서 보존하며 학습에 쓰지 않는다. 갱신마다 포함된 원래 행 번호·판단·진입·정답 종료·원래 포지션 가중치·비용 가중치·0 효과 기여를 모두 기록한다. 학습 포지션과 해당 주 예측 포지션은 교차하지 않는다.

## 모델과 대조

주간 후보는 v71과 같은 74개 입력·깊이 2·64회·학습률 0.05·고정 말단·규제·seed·조기 종료 미사용의 비용 가중 분류기다. 매주 원래 포지션 비중의 평균을 1로 정규화하고 `w × |y|` 비용과 양수 비용의 평균 정규화를 다시 계산한다. 정확한 0 효과 행은 학습 기여만 0이고 원장·평가에는 남긴다.

첫 주 모델·학습 행·원래 가중치·비용 원장·정규화·학습 상수는 v71과 정확히 같아야 한다. 뒤 주는 그때까지 확정된 결과만 추가한다. 판단이 없는 주도 모델·지원·학습 원장을 보존한다. 13개 모델의 설정과 고정 점수 `q > 0.5`를 변경하지 않으며 문턱·창·모델 선택·최근 자료 감쇠·추가 보정을 하지 않는다. 점수는 비용 가중 선택 점수다.

각 주의 비용 양수 비중만 출력하는 주간 상수 대조를 함께 만든다. 주간 모델과 정확히 같은 과거 학습 자료·비용을 사용하고 조건부 입력은 사용하지 않는다. 원래 고정 상수와 모든 기존 모델의 점수·효과도 그대로 보존한다. 이를 통해 단순한 비용 부호 비중 갱신과 조건부 예측의 차이를 비교한다.

## 서른두 조건

v71의 스물네 조건을 주간 후보에도 유지하고 다음 다섯 개를 추가한다.

1. 비용 가중 로그 손실이 고정 v71보다 1% 이상 개선.
2. 비용 가중 Brier가 고정 v71보다 악화되지 않음.
3. 원래 가중 평균 기회손실이 고정 v71보다 작음.
4. 전체 최초 평균 효과가 고정 v71보다 큼.
5. 주간 후보와 고정 v71의 최초 효과 차이의 짝지은 주간 95% 구간 하한 양수.

추가로 주간 상수 대비 비용 로그 손실의 1% 이상 개선, Brier 비악화, 원래 가중 기회손실 감소의 세 조건을 요구한다. Brier 허용치는 1e-12이며 다른 비교는 엄격한 부등식이다. 후보와 v64·v69·v70·v71의 네 비교는 기존 13개 달력 블록·1,000회·seed 63의 동일 추출을 사용한다. 전체·방향·월별 행 지표, 전체 포지션의 최초 효과와 진입 월별 결과, 선택 없음과 음수 선택을 보존한다. 주간 상수의 같은 행·최초 효과도 기록한다.

## 검증과 범위

첫 모델과 v71 동일성, 모든 갱신의 엄격한 이틀 경계·정답 성숙·행 번호·포지션 비중·비용 정규화·0 효과, 모델과 예측 주의 연결을 검사한다. 미래 입력·정답 변경이 이전 주의 학습·모델·점수를 바꾸지 않아야 한다. 지원 부족·경계 오류·원래 입력 또는 결과 변조를 거부한다.
