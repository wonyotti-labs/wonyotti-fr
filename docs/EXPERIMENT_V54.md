# 실험 v54 사전 계획: 원본 청산의 가격 이동 폭

2026-10-04. v53의 2022년 확인에서 작은 이익의 빈번한 확정과 큰 손절 손실이 함께 나타났다. 현재 비용 조건과 기존 손실 청산은 의도대로 작동했지만 순손실은 남았다. 추가 조기 청산에 원본 청산 당시의 가격 이동 폭을 반영하는 단일 후보를 비교한다. 승률을 높이는 것을 채택 기준으로 삼지 않는다.

## 고정 추정과 적용

- 부모는 v53이다. 모든 모델·점수 보정·문턱·진입·추가·축소·수량·보유 한도·위험·거래 비용을 보존한다. 변경은 낮은 문턱으로 추가 허용한 청산의 조건 하나다.
- 원본 v35와 연결이 검증된 v51의 2020년 학습 사용 행에서 `original_y_exit == 1`이고 당시 `favorable_move > 0`인 사건을 사용한다. 미래 거래 손익이나 이후 최고가는 사용하지 않는다. 기존 1분 청산 정답의 범위와 시간·포지션 배제 경계를 유지한다.
- 각 포지션에서 위 가격 이동 폭의 중앙값을 구한 뒤, 포지션별 중앙값의 중앙값을 하나의 고정 하한으로 사용한다. 반복 사건이 많은 포지션의 과도한 가중을 막기 위한 동일 포지션 기여다. 양수 사건과 서로 다른 포지션이 각각 20개 이상이고 하한이 유한한 양수여야 한다. 조건 미달 시 후보 생성을 실패로 기록한다.
- 추가 조기 청산은 현재 추정 총 순손익이 0 이상이며 현재 평균 진입가 대비 방향을 반영한 가격 이동이 고정 하한 이상일 때만 허용한다. 이외에는 원래 v48의 높은 청산 문턱을 사용한다. 기존 강한 청산·손절·시간 종료·손실 중지와 다른 관리 판단은 그대로 유지한다.
- 원본의 손실 청산 사건을 학습 자료에서 지우지 않는다. 양수 가격 이동 표본은 추가 이익 청산의 하한을 산출하는 용도에만 쓴다. 전체 모델은 재학습하지 않는다. 가격 이동과 해당 포지션 전체 순손익의 의미 차이를 유지한다.

## 검증과 판정

하한은 2020년 자료만으로 한 번 산출한다. 상반기·하반기 원본과 봇 상태에서 적용 빈도를 설명하되 그 결과나 2021년 이후 매매 수익으로 하한을 재선택하지 않는다. 사용 사건·포지션별 요약·원자료 연결 지문을 저장하고 별도 정렬로 중앙값을 대조한다. 미래 분할·시세를 변경해도 하한·기존 모델·문턱이 같아야 한다.

2021년 후보와 원래 v53의 전체 결과·상태를 비교하고 2022년 수익 양수·종료 거래 30개 이상·영구 중지 없음 여부를 확인한다. 실패 시 후속 BTC 두 기간과 독립 세 연도를 포함한 여덟 실행을 보존한다. 통과 시 기본 여덟 조건에 원래 v14·v48·v53을 더한 두 기간·세 시장의 열한 조건, 독립 아홉 연도와 개발·확인 세 실행의 총 78개를 대조한다.

기존 비용 2배·표본·후속 두 기간·독립 연도·낙폭·집중·불확실성 기준을 유지한다. 실제 체결 이력·회계·무거래·지연·강제 종료 복원·원본 지문과 경계값을 검사한다. 모든 평가 기간은 이미 관찰한 자료다. 원본·파생 결과는 로컬에 보존하며 실제 거래 연결은 없다.
