# 실험 v69 사전 계획: 청산 오류의 손익 비용 학습

2026-10-04. v68의 실행 문턱은 같은 반년 모델 대비 최초 효과를 개선했지만 뒤 진단의 선택 효과는 여전히 음수였다. 문턱을 추가 탐색하지 않고, 손익 수치의 제곱 오차를 줄이는 학습과 청산 선택의 손익 비용을 줄이는 학습을 분리해 비교한다. 기존 회귀 실패를 새 기준으로 취소하지 않는다.

## 자료와 단일 후보

v68과 이전 전체 결과를 재현한다. 기존 56개 현재 입력·관리 의도, v64와 같은 전체 앞 학습과 마지막 진단, 포지션별 평가 가중치와 배제 원장을 보존한다. 학습은 2021-01-01 이상 진입·판단부터 정답 종료가 2021-09-30 미만인 행이다. 진단은 2021-10-02 이상 진입·판단부터 정답 종료가 2021-12-31 미만인 행이다. 포지션 교차와 미확정 정답 사용을 금지한다. 이미 관찰한 기간이라는 제한을 유지한다.

후보는 깊이 2·64회·학습률 0.05·최대 말단 4·최소 말단 표본 64·L2 1·최대 구간 255의 기존 관리 히스토그램 분류기 하나다. 조기 종료·클래스 빈도 보정은 사용하지 않고 seed 0을 유지한다. 특징 선택·복잡도 탐색·주간 갱신·문턱 보정은 추가하지 않는다.

## 오류 비용과 점수의 의미

기존 계좌 기준 추가 청산 효과를 y, 원래 포지션 균등 가중치를 w라고 둔다. 분류 정답은 y가 양수인지 여부이며 학습 비용 가중치는 w × |y|다. 양수 y를 놓치는 오류와 음수 y에서 청산하는 오류를 각각 그 손익 크기로 반영한다. 양수·음수 관측을 모두 보존하고 손실 크기를 자르지 않는다.

정확히 0인 y는 양쪽 선택의 비용이 같으므로 학습 기여만 0으로 기록한다. 해당 행을 원장·평가에서 제거하지 않는다. 숫자 모델 학습에는 양의 비용 행만 전달하고 이들의 비용 가중치 평균이 1이 되도록 공통 상수로 정규화한다. 원래 w, 부호, 절댓값, 비용 곱, 0 기여 사유와 적합 사용 여부를 모두 저장한다. 원래 비양수 가중치·비유한 값·곱의 넘침·양의 비용 소실을 거부한다. 적합 행 1,000개 이상과 양쪽 부호 각각 64개 이상의 지원을 요구한다.

출력 q는 비용 가중 손실로 학습한 선택 점수이며 일반적인 수익 발생 확률이나 bp 단위 예상 손익이 아니다. 고정 문턱 q > 0.5에서만 추가 청산을 선택하며 원래 청산 요청은 추가 선택에서 제외한다. 이 비용 정의에서 0.5는 이익을 놓치는 비용과 손실 청산 비용의 비교에 해당한다. 회귀 점수와 혼합하거나 q의 제곱 오차를 계좌 손익 예측 오차로 보고하지 않는다.

대조 상수는 앞 학습의 양수 비용 합을 전체 절대 비용 합으로 나눈 값 하나다. 기존 회귀·주간 모델의 원래 점수·선택·오차는 별도로 보존한다. 새 모델과 대조 상수의 비용 가중 로그 손실·Brier를 비교하고, 기존 정책과의 행동 비교에는 같은 원래 w의 순효과와 기회손실을 사용한다.

## 평가와 열네 가지 조건

선택 a는 추가 청산 여부의 0 또는 1이다. 행 단위 순효과는 a × y이며 기회손실은 max(y, 0) − a × y다. 모든 행을 포함한 원래 w의 평균과 무가중 평균, 선택 행·포지션 수와 선택 조건부 손익을 보고한다. 비용 가중 로그 손실·Brier의 분모는 w × |y|의 합이다. 0 비용만 있는 세부 집단의 비용 지표는 정의 불가로 남긴다.

같은 원래 포지션에서는 실제 최초 선택만 남기며 이후의 좋은 결과로 대체하지 않는다. 선택 없음은 0으로 남기고 기존 공통 순자산 기준·모든 손실·원래 포지션을 유지한다. 새 최초 선택의 점수 메타데이터에는 비용 점수임을 명시한다. v64와 v67 최초 효과를 대조하고 v68 결과도 있을 때 그대로 보존·보고한다.

다음 열네 가지 조건을 모두 요구한다.

1. 비용 가중 로그 손실이 학습 상수보다 1% 이상 개선.
2. 비용 가중 Brier가 학습 상수보다 악화되지 않음.
3. 원래 가중 평균 기회손실이 학습 상수의 행동보다 작음.
4. 원래 가중 평균 기회손실이 v64의 행동보다 작음.
5. 원래 가중 평균 기회손실이 v67의 행동보다 작음.
6. 선택 기회 100개 이상.
7. 최초 선택 포지션 30개 이상.
8. 선택 기회의 원래 가중 평균 실제 효과 양수.
9. 선택 기회의 무가중 평균 실제 효과 양수.
10. 선택 없음의 0을 포함한 전체 최초 평균 효과 양수.
11. 전체 최초 평균 효과가 v64보다 큼.
12. 전체 최초 평균 효과가 v67보다 큼.
13. 후보 최초 효과의 주간 블록 95% 구간 하한 양수.
14. 후보와 v64 차이의 짝지은 주간 블록 95% 구간 하한 양수.

Brier 비교의 숫자 허용치는 1e-12이며 나머지 부등식은 엄격하게 적용한다. 기존 13개 주간 블록·1,000회·seed 63·2.5 및 97.5 백분위를 유지한다. 전체·방향·월별 행 지표와 최초 선택·방향·진입 월별 결과를 보존한다. 마지막 결과로 부호·비용·문턱·모델을 바꾸지 않는다.
