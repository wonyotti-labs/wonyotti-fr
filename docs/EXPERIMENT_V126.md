# 실험 v126 사전 계획: 최근 관리 행동이 없는 상태의 분리 학습

2026-10-12. v125에서 축소 오탐은 과거 행동 직후에 집중됐고, 극값 시계 추가로 사건 밖 오탐도 늘었다. 전체 분포를 한 모델에 적합하면 연속 행동의 빈도가 시작 시점의 학습을 지배할 수 있다는 가설을 검증한다. 이 원인은 아직 확정되지 않았다.

v119의 포지션 최초 행동은 `past_*_exists == 0`이었다. 이번에는 원본 50개 입력 중 `past_*_log_count_15m == 0`인 상태를 행동별로 분리한다. 이전에 해당 행동을 했으나 최근 15분에는 하지 않은 상태도 포함한다. v101은 다른 5분 노출 정답에 과거 이력을 추가한 실험이며, v51의 미래 15분 청산 정답과 v122의 이진 빈도 가중도 이번 비교와 다르다. 미래 정답 범위·가중치·행동의 정의는 바꾸지 않는다.

## 입력·학습·결합 고정

- v125→v124→v35 출처와 봉인 지문을 검증한다. 원본 학습 2020년·보정 2021년 상반기·진단 하반기의 모든 행·정답·50개 입력, 포지션 분리·24시간 경계를 유지한다. 이미 관찰한 기간이다.
- 최근 없음(quiet)은 해당 행동의 엄격한 과거 독립 첫 체결 수가 `[t−15분, t)`에서 0인 상태다. 로그 횟수의 유한·비음수·정수 역변환과 첫 행동이면 횟수 0임을 검사한다. 양성·손익·미래 사건으로 상태를 선택하지 않는다. quiet 중 처음(first)과 재시작(restart), 나머지 최근 있음(recent)을 별도 보고한다.
- quiet/recent 각각 학습 1,000행·보정/진단 100행 및 양성·음성 각 20개 이상을 요구한다. 원래 포지션 최초 행동의 지원도 v119 기준으로 확인한다. 월별·재시작 하위 집단이 빈 경우 삭제하지 않는다.
- 축소·추가의 quiet 상태마다 부스팅 1개와 선형 대조 1개를 학습한다. 부스팅은 v121에서 학습 내부 선택한 깊이 2·말단 4·256회, 학습률 0.05·최소 말단 64·L2 1·255구간·seed 0·무가중·조기 종료 없음이다. 선형은 훈련 상태의 표준화와 C=0.1·최대 2,000회·seed 0이다. 새로운 설정 탐색은 없다.
- 상반기 quiet 행에서 절편만 보정한다(기울기 1, 기존 [-64,64] 100회 이분법, 오차 1e-12). 같은 상태의 축소 F1·추가 F0.5, 예측 양성 최소 20개로 문턱을 선택한다. 진단 행·정답은 적합·보정·문턱에 전달하지 않는다.
- quiet에서만 새 점수·문턱을 사용한다. 청산 전체와 축소·추가 recent 상태는 원래 native 64회 모델의 보정 점수와 첫/전체 문턱 통과를 그대로 유지한다. 기존 반복 배율은 v115의 1.0이다. 행동별 요청 마스크의 보존이며 충돌 우선순위까지 실행했다는 뜻이 아니다.
- quiet의 대조는 봉인된 native 64회, capacity 256회, 새 quiet 선형, 상반기 quiet 빈도 상수다. capacity 모델은 분리 학습의 이득을 같은 모델 크기와 비교하기 위한 대조다. 보정 전 부스팅·선형도 보고한다. 전체 상태 지표를 계산할 때 모든 새 대조는 recent에서 native를 사용하고, capacity 대조도 quiet만 capacity로 대체한다.

## 사전 판정: 27개 조건

축소·추가 각각 다음 12개를 모두 요구한다. 경계 허용 오차는 기존 1e-12다.

1. quiet 보정 부스팅 로그 손실이 native·capacity·quiet 선형 각각보다 1% 초과 개선(3개).
2. quiet 평균 정밀도가 위 세 대조 각각 이상(3개).
3. quiet 보정 후 로그 손실이 보정 전보다 나쁘지 않고, quiet 빈도 상수보다 개선(2개).
4. quiet 요청 재현율과 해당 F점수가 native보다 각각 엄격히 개선(2개).
5. 전체 상태와 포지션 최초 상태의 F점수가 각각 native 이상(2개).

위 24개와 청산 전체·축소 recent·추가 recent의 점수 및 요청 보존 3개를 합한다. 일부 행동만 선택하거나 진단 후 문턱·창·기준을 바꾸지 않는다. 미달이면 이번 후보의 새 계좌 실행을 하지 않는다. 통과하더라도 수익성 채택이 아니며 별도 자체 계좌 계획과 기존 v10 다년·다시장·비용·펀딩·지연·낙폭·표본 검증을 요구한다.

## 독립 검산과 출력

전체·quiet·recent·first·restart, 모든 월에 행·양성·음성·로그 손실·평균 정밀도·TP/FP/FN·재현율·F점수를 보고한다. 빈 집단과 양성 0개를 보존한다. 현재 정책에서 후속 요청을 지우는 실험이 아니므로 v125의 모든 오탐이 줄어야 한다고 가정하지 않는다.

새 512개 트리와 두 선형을 별도 적합하고 숫자 모형의 모든 확률·절편·문턱·지표·27개 판정을 검산한다. 입력 분할·상태 선택·원본 점수·청산/recent 보존·저장 후 동일성·진단 정답 변경 시 학습 불변을 검사한다. 원본·예측·모형·개별 결과는 로컬에 보존하고 실패 실행을 남긴다. 코드·계획·입력의 실행 전후 지문을 확인한다. 실제 거래 연결은 없다.
