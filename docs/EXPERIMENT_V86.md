# 실험 v86 사전 계획: 확장 첫 기회의 고정 트리 비교

2026-10-10. v85는 과거 확정 정답을 추가해 최초 평균 효과를 개선했으나 양수·상수 기준을 넘지 못했고 비용 확률 지표도 악화됐다. 자료 확대만으로 해결되지 않았으며, 같은 확장 자료에서 선형 관계의 제한을 기존 깊이 2 트리와 비교한다. 결과를 보기 전에 모델 하나와 비교 조건을 고정한다.

## 같은 자료·정답·판단

v85 독립 검산의 지문을 호출자가 지정한다. 그 근거와 봉인된 전체 입력·기존 첫 원장·추가 원장·통합 첫 원장·비용·모델·보정 정책·생성 코드를 확인해 재사용한다. 이전 자료 생성 엔진·선형 모델을 다시 실행했다고 주장하지 않는다.

통합 첫 판단 1,277개는 기존 앞 학습 863개와 2020년 확정 정답 414개로 그대로 유지한다. 74개 현재 특징, 첫 가용 순자산 기준 자연 종료 대비 현금 bp, 포지션 비중 1, 양의 절대 비용 평균 정규화와 0 비용 제외 원장이 v85와 정확히 같아야 한다. 추가 구간·좋은 월·방향·손익 부호·특징 선택은 없다. 기회 없음·미확정·손실과 모든 후속 관리 기회는 원래 원장에 보존한다.

첫 적격 기회에서만 엄격히 0.5를 넘으면 청산한다. 첫 거절 뒤 재예측·재선택은 없으며 원래 진입·청산·위험 규칙은 유지한다. 보정은 기존 2021-08-02 이상 진입·판단, 2021-09-30 미만 확정의 같은 전체 포지션이다. 마지막 진단은 적합·예측·선택에 사용하지 않는다.

## 고정 모델 하나

v81에서 사용한 `HistGradientBoostingClassifier` 설정을 그대로 재사용한다. 로그 손실, 64회, 학습률 0.05, 깊이 2, 최대 말단 4, 최소 말단 64, L2 1, 구간 255, 전체 특징, 범주형 없음, 조기 중지 없음, seed 0, 클래스 균등화 없음이다. 기존 선형 모델의 표준화는 그 모델의 기록으로 보존하며 새 트리는 원래 74개 특징을 사용한다. 별도 변환·초매개변수·문턱 탐색은 없다.

적격 500포지션·각 방향 20·각 비용 부호 64·180일의 기존 지원 조건을 유지한다. 새 64개 트리·초기값·모든 숫자 노드를 JSON으로 저장하고 학습·보정 첫 입력에서 라이브러리 예측과 대조한다. 학습 비용 상수는 v85와 정확히 같으며 기존 확장 상수를 재사용한다.

## 열네 정책·열한 조건

v85의 기존 열세 정책·점수·선택·효과·그룹·실패를 보존하고 새 확장 트리 정책 하나를 추가한다. 기존 정책의 저장된 점수로 산식을 대조하며 모델은 재적합하지 않는다.

새 후보는 최초 선택 30포지션 이상, 전체 최초 평균 양수, 그리고 확장 선형·원래 고정 선형·주간 선형·원래 첫 트리·직접 회귀·이후 정책 분류·자연 종료 분류·항상 첫 청산·확장 상수 각각보다 엄격한 개선, 총 열한 조건을 모두 충족해야 한다. 동점은 실패다. 실패 시 마지막 평가를 차단하고 성공 시 별도 고정 계획에 따른 마지막 진단과 연속 계좌 검증으로 이어간다. 조건부 개선을 계좌 수익으로 표시하지 않는다.

## 검증·제한

별도 라이브러리 적합으로 모든 트리·초기값·숫자 예측을 대조한다. 앞 원장·현금·비중·비용의 동일성, 미래 보정·후속 행·미확정 입력 변경의 앞 모델 불변성, 0·손실·기회 없음 보존, 첫 거절·후속 점수 부재, 열네 정책·열한 조건과 출처·봉인·코드 변조 거부를 검증한다. 실제 적합 전에 검산 도구·합성 검증 근거도 고정한다.

부모가 2021년까지 학습한 상태로 생성한 과거 경로이므로 2020년 당시 가용 성과가 아니다. 이미 관찰한 같은 보정 구간의 반복 연구라는 제한을 유지한다. 최종 v10의 다년·다시장·비용·펀딩·지연·낙폭·표본·집중 기준은 그대로며 수익성 문제는 미해결이다. 원본·가공·시장·모델·개별 결과는 로컬에 유지하고 실제 거래 연결은 없다.
