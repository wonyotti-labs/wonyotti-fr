# 실험 v133 사전 계획: 과거 주문 가격을 추가한 관리 모델

2026-10-12. v132에서 원본 전체의 과거 주문 가격 기준을 복원했다. 기존 v127의 50개 입력에 네 가격 입력을 더한 54개 후보가 quiet 상태의 추가·축소를 개선하는지 비교한다. 이전 턴은 실제 가격 복원·독립 검산·결과 공개와 푸시를 완료한 진행이다. 입력 복원 자체는 예측 개선이나 수익성 증거가 아니다.

## 동일 자료와 한 후보

- v132 완료 증거·봉인·원본 연결과 v127/v126 모형 출처를 확인한다. 원래 2020년 510,102행, 2021년 상반기 256,234행, 하반기 252,124행 및 모든 정답·24시간·포지션 경계를 보존한다. 세 기간 모두 이미 관찰했다.
- v132의 네 가격 입력을 재계산하고 저장된 가격·원장과 모든 행에서 대조한다. 같은 포지션의 현재보다 엄격히 이전인 각 주문 첫 관측 묶음 가격만 사용한다. 기존 50개 입력과 원래 행·정답은 그대로다. 과거 기준이 없는 행도 0과 기존 존재 여부로 포함한다.
- quiet는 해당 행동의 최근 15분 첫 관측 주문 수가 0인 상태다. first/restart 정의와 청산·recent의 기존 native 판단을 유지한다. 하반기 first 추가의 양성 23분은 두 과거 가격 기준이 모두 없음을 기록하며, 해당 상태를 제외하거나 사후 별도 모델로 교체하지 않는다.

## 학습과 보정

2020년 quiet에서 축소·추가별 부스팅 1개와 선형 1개, 총 두 부스팅·두 선형을 학습한다. 부스팅은 v126과 같은 256회·학습률 0.05·깊이 2·최대 말단 4·최소 64행·L2 1·255구간·seed 0이며 가중치·조기 종료가 없다. 새 트리는 총 512개다. 선형은 학습 행 전용 표준화, 로지스틱 C=0.1·최대 2,000회·seed 0·무가중치다. 모델 용량·학습 기간·특징 조합을 검색하지 않는다.

v126/v127의 보정 절차도 유지한다. 상반기 전체 quiet에서 기울기 1 절편([-64,64], 100회 이분법, 평균 빈도 오차 1e-12), 원시·보정 문턱과 빈도 상수를 정한다. 이어 상반기 first/restart별로 부스팅·선형 절편과 문턱을 정한다. 문턱은 축소 F1·추가 F0.5, 최소 예측 양성 20개·동률 시 높은 문턱이다. 원시 점수의 요청과 빈도 상수는 전체 quiet 절차를 유지한다. 상태별 문턱만 적용한 대조도 계산해 상태별 절편 후보와 요청이 같아야 한다.

기존 50개 대조는 v127이다. 기존 v126 모형을 독립 재적합하고 저장된 v126/v127 확률·요청을 재현해 동일 학습과 보정 출처임을 확인한다. native 64회·capacity 256회·새 54개 선형·원시 점수·상수 대조와 모든 상태·월을 함께 기록한다. 진단 정답은 학습·표준화·절편·문턱 함수에 전달하지 않는다. 2020년 표는 적합 진단이고 하반기도 새로운 미관찰 검증 자료가 아니다.

## 고정 판정 37개

v130의 35개 조건을 유지한다. 새 후보의 quiet 로그 손실은 native/capacity/새 선형보다 각각 1% 초과 개선되고 평균 정밀도가 낮지 않아야 한다. 원시 점수의 로그 손실 보존·상수 초과·native 대비 quiet 재현율과 F 개선·전체/first F 보존·청산/recent 보존이 필요하다. v127 대비 quiet 로그 손실과 평균 정밀도 보존, native quiet 정밀도 이상, v127 restart 재현율 초과도 유지한다.

추가 정보의 기여를 위해 두 행동 각각 v127 quiet 로그 손실을 1% 초과 개선해야 한다(2개 추가, 총 37개). 1e-12 수치 경계를 유지한다. 하나라도 미달하면 자체 계좌를 실행하지 않는다. 상태·행동별 좋은 결과만 사후 결합하거나 새 문턱을 탐색하지 않는다. 통과하더라도 수익성 채택이 아니며 다음 자체 계좌 연구에서 v10의 다년·다시장·비용·펀딩·지연·낙폭·표본·집중 기준을 검증해야 한다.
