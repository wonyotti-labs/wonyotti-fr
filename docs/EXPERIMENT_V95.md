# 실험 v95 사전 계획: BTC 담보와 선물 방향 정답의 의미 대조

2026-10-10. 원본은 BTC 담보 계좌지만 기존 방향 정답은 XBTUSD 선물 수량의 부호이고, 봇의 실행 계좌는 USDT 선형 계약이다. 두 방향이 같은 경제적 노출인지 먼저 검증한다. 계획 전에 마지막 기록에서 선물 숏과 담보를 합친 달러 기준 순롱이 공존하는 사례를 확인했다. 이 단일 사례로 전체 손실 원인을 확정하지 않는다. v44·v45·v94 방향 예측 실패와 v93 매매 대조를 보존한다.

## 회계와 지원 범위

원본의 초기 현금·포지션 0 가정과 모든 계약의 XBt 정산을 재검증한다. 다른 계약이 모두 청산된 시점에서 XBTUSD 잔량을 Q, BTC 현금을 C, 부호 있는 잔존 원가를 B라 하면, 담보와 선물을 같은 가격 P로 평가한 달러 순자산은 `E(P) = P(C+B)-Q`다. 따라서 가격 민감도는 `D = C+B`이며 선물 Q의 부호와 다를 수 있다. 이는 단일 가격 평가 가정으로, 실제 현물·마크 가격 차이나 계좌 밖 자산을 복원하는 식이 아니다.

정수 사토시 원장에서는 같은 지원 시점의 D가 `초기 현금 + 완료 외부 입출금 - Trade/Settlement의 signed execCost 합 - 모든 이벤트의 execComm 합`과 일치해야 한다. Funding의 execCost는 더하지 않는다. 취소 출금과 지갑 RealisedPNL을 다시 현금에 넣지 않는다. 모든 계약의 실현 현금과 수수료는 포함하되 XBTUSD 이외의 잔량이 있으면 단순 식의 방향 판정을 지원하지 않는 것으로 기록한다. 선형·콴토의 미실현 손익을 0으로 간주하지 않는다.

지갑 일중 시각은 복원하지 않는다. 완료 입출금은 기본적으로 기록된 UTC 날짜의 시작 이상·다음 날 시작 미만에 발생했다고 가정하고 그 안의 가능한 현금 하한·상한을 모두 계산한다. 추가로 양쪽 하루를 넓힌 3일 창도 고정 대조한다. 두 창은 실제 완료 시각의 증명이 아니며 범위 밖 지연은 포괄하지 않는다. 같은 날 여러 입출금은 합계만으로 상쇄하지 않고 각각 범위에 반영한다. 결과는 날짜 가정에 조건부인 방향과 미확정 방향으로 구분한다.

## 고정 자료와 비교

원본 5개 파일, 최초 감사의 체결·지갑, 전체 계약 복원, 검산된 v44 입력·정답을 SHA-256으로 연결한다. v44의 2020년 학습 및 2021년 진단 전체 행 각각에 현재 경계와 다음 정답 경계 직전 상태를 붙인다. 같은 시각의 이벤트는 포함하지 않는다. 포지션·기간 경계로 제외된 기존 행을 새로 채택하지 않으며 기존 모든 지원 행에 판정·미지원 사유를 남긴다. 전체 원본 기간의 UTC 일별 경계와 마지막 이벤트 직후도 추가로 대조한다.

기본 창과 3일 창 각각에서 다른 계약 보유, 입출금 시각으로 인한 방향 미확정, 확정 flat·short·long, 원래 선물 방향과의 교차표를 기록한다. 기간·월·원래 정답 클래스별 분모와 제외 수를 함께 보존한다. 연속된 5분 행을 독립 거래 수로 표현하지 않는다. 크기가 작거나 결과가 나쁜 노출을 사후 제거하지 않으며 0 판단은 정수 사토시의 정확한 0으로 고정한다.

## 독립 검산과 후속 조건

합성 자료에서 롱·숏·추가 진입·부분 청산·반전·수수료·펀딩·외부 입출금·취소·다른 계약·동시 시각·미래 행 변경을 검사한다. 별도 검산은 Decimal 잔존 원가와 실현 현금을 직접 순서대로 복원하고, 모든 조회 경계에서 정수 식의 구간과 대조한다. 일중 순자산이나 레버리지는 확정하지 않는다. 원본·입력·실행 코드 지문은 전후 일치해야 한다.

이번에는 정답의 의미만 진단한다. 모형 학습·신호 변경·매매 성과 개선을 주장하지 않는다. 차이가 입증되면 지원 범위와 입출금 가정을 반영한 새 정답 및 계좌 구조의 별도 사전 계획을 만든다. 기존 v10 수익성·표본·다년·비용 기준은 그대로 유지한다. 모든 기간은 이미 관찰했으며 원본 진위·총재산의 증명은 범위 밖이다.

v93 공유 소스와 검산 도구는 완료 때까지 변경하지 않는다. 별도 로컬 코드의 검사·실제 진단은 가능하며 운영 소스로 등록할 경우 동일 결과의 재현이 필요하다. 원본·파생 자료는 Git에 넣지 않고 실거래 연결은 제외한다. BTC와 역선물 숏의 결합 구조는 [BitMEX의 역선물 설명](https://www.bitmex.com/blog/dust-on-crust)을 참고하며 실제 원장 계산은 당시 체결 비용을 사용한다.
