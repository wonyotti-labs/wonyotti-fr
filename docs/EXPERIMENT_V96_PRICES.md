# 실험 v96 중간 결과: 동시 계약 가격 확보

2026-10-11. [v96 사전 계획](EXPERIMENT_V96.md)에 따라 2020·2021년 전체 비교 경계에서 필요한 16개 계약의 가격 363,605개를 확보했다. XBTUSD는 기존 원거래소 자료를 재사용했고, 나머지 15개 계약은 공식 공개 API의 221개 요청으로 수집했다. 필요한 계약·경계 전체에 양수 종가가 있었으며 누락 행은 없었다. 중단 전 검증 가능한 응답 23개는 지문을 대조해 재사용했다.

별도 파서는 저장한 응답 원문을 다시 읽어 주소·조회 범위·심볼·UTC 종료 시각·순서·중복·종가를 검사했다. 응답에서 재구성한 전체 가격, 재사용한 BTC 가격, 원본 보유 수량에서 독립 산출한 전체 필요 경계가 일치했다. 원본 5개와 진행 중인 v93 소스 245개·검산 도구 24개의 불변도 확인했다.

수집 코드 합성 검사 31개와 독립 응답 파서 검사 6개를 통과했다. 첫 준비 과정에서 역사적 심볼의 밑줄과 pandas 조회 인덱스 이름 처리 오류가 발견돼 수정했고, 두 실패 실행을 보존했다. 두 오류 모두 네트워크 요청 전 발생했다. 실제 응답·가격·파생 결과는 로컬에만 보관한다. 소스의 운영 등록과 동일 결과 재현은 진행 중인 v93 검산 이후 작업이다.

이번 완료 범위는 가격 확보와 원문 대조다. 종가는 마크 가격의 대용치이며 과거 증거금 평가를 정확히 복원한 것이 아니다. 계좌 평가액·BTC 부분 민감도·입출금 날짜 불확실성과 가격 ±1% 대조는 후속 계산 대상이다. 정답 변경·새 모형 학습·봇 정책 적용·수익성 개선을 완료했다고 해석하지 않는다.
