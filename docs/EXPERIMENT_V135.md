# 실험 v135 사전 계획: 누적 추가 횟수의 상한 제거 입력 비교

2026-10-12. v134에서 하반기 재시작 추가의 양성 123분 중 35분이 누적 추가 5회 미만인데도 두 고정 모델 모두 이를 놓쳤다. 원본 행의 59~72%는 실제 5회와 그보다 큰 횟수가 같은 입력으로 묶인다. 이번에는 학습 입력의 이 혼합만 해소해 비교한다. 원본 상태 혼합이 손실의 원인이라는 결론은 아직 없으며 이전 턴은 전체 복원·진단·공개·푸시를 완료한 진행이다.

## 같은 조건의 한 입력 변경

v134 증거와 원본 체결에서 복원한 실제 `adds`를 사용한다. v127의 50개 입력에서 `adds_capped` 한 열만 잘리기 전 `adds`로 교체한다. 0~5는 값이 정확히 같고 5회 초과만 달라진다. 로그 변환·횟수별 가중치·행 제외·가격 입력 추가는 하지 않는다. 기존 원본 열과 정답은 그대로 보존하며 모델의 입력 목록과 형식은 별도로 기록한다.

2020년 학습 510,102행, 2021년 상반기 보정 256,234행, 하반기 진단 252,124행과 24시간·포지션 경계를 유지한다. 최근 15분 같은 관리 주문이 없는 quiet에서 행동별 깊이 2·256회 부스팅 두 개와 선형 두 개(C=0.1, 최대 반복 2,000, random_state=0)를 학습한다. 선형 표준화는 학습 행에만 적합한다. 기존 v127과 기간·행·용량·설정이 같다.

상반기 전체 quiet 절편·문턱·빈도 상수 후 최초/재시작별 절편·문턱을 적용하는 v127 절차를 그대로 사용한다. 청산·recent·기존 native/capacity 대조는 모든 행에서 정확히 유지한다. 새 모델의 원시·보정 점수, 선형·빈도 대조와 전체 quiet 보정·문턱만 변경한 대조도 남긴다. 하반기는 이미 반복 관찰한 연구 구간이며 새 미관찰 검증으로 주장하지 않는다.

## 횟수 구간과 채택 조건

v134의 0/1/2/3/4/5/>5와 all을 고정하고 모든 기간·월·상태의 지원과 기존 v127·새 후보의 점수·요청 지표를 보존한다. 양성 0개와 빈 구간도 포함한다. 일곱 구간의 가산 지표와 로그 손실·Brier의 행 수 가중 합을 전체와 검산한다. 평균 정밀도·F의 평균은 사용하지 않는다.

후속 자체 계좌 연구의 조건은 40개다. v130의 기존 35개 조건(native/capacity/선형 대비 로그 손실·평균 정밀도, 원시·상수 대조, quiet 재현율·F, 전체·최초 F, v127 quiet 로그 손실·평균 정밀도, 정밀도·재시작 재현율, 청산·recent 보존)을 유지한다. 두 행동의 quiet 로그 손실이 v127보다 각각 1%를 초과해 개선되어야 하는 두 조건도 유지한다. 마지막 세 조건은 실제 `adds < 5`인 재시작 추가의 재현율·F가 v127보다 엄격히 높고 정밀도가 낮지 않은 것이다. 수치 허용 오차는 기존 1e-12다. 이 집단의 지표는 해당 원본 행으로 직접 다시 계산하며 구간 지표 평균으로 만들지 않는다.

이 조건은 같은 봇 포지션이거나 모든 실행 조건을 충족한다는 뜻이 아니다. 제한 전 집단의 새 적중이 전혀 없는 상태를 전체 지표 개선만으로 채택하지 않기 위한 조건이다. 봇의 최대 추가 5회와 청산·위험 제한은 바꾸지 않는다. 원본 5회 이상 행도 모두 학습·평가에 유지한다.

## 독립 검산과 후속 계좌

v134의 출처·입력·횟수 연결·전체 집계를 먼저 재현한다. 새 입력은 원본 실제 횟수와 정확히 같고 나머지 49개 입력은 기존과 같아야 한다. 별도 재적합으로 512개 트리와 두 선형을 검산하고, 독립 트리 순회·선형 합으로 모든 확률을 대조한다. 보정·문턱·기존 예측 보존·기간·월·횟수 집계·40개 판정을 검산한다. 잘못된 횟수, 바뀐 입력 이름, 형식·척도·확률 손상과 기존 청산·recent 변경을 검사한다.

모든 조건을 충족하면 별도 계좌 계획에서 자체 포지션의 실제 추가 체결 횟수를 입력으로 연결하고 원본 포지션 횟수는 사용하지 않는다. 기존 고정 계좌부터 시작해 v10의 다년·다시장·비용·펀딩·지연·낙폭·표본·집중 기준을 적용한다. 조건 미달과 모든 실패를 보존하며 이번 예측 비교를 수익성 해결로 표시하지 않는다. 원본·파생 입력·모델·개별 결과는 로컬에만 보존하고 실제 거래 연결은 하지 않는다.
