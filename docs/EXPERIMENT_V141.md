# 실험 v141 사전 계획: 구간 경계를 고정한 가중 관리 학습

2026-10-12. v140의 가중 학습은 20/42개 조건 충족으로 미채택했다. 하반기 축소 quiet 로그 손실과 평균 정밀도가 악화됐고, 한도 전 재시작 추가의 공통 예산 요청은 TP/FP 0/7로 기존 0/1보다 나빴다. 학습 비중을 바꾸는 과정에서 손실 함수뿐 아니라 히스토그램 구간 경계도 변했다. 이번에는 원래 무가중 구간을 고정해 같은 가중치의 효과를 비교한다.

v140의 선형 대조도 하반기 두 행동의 quiet 로그 손실·평균 정밀도가 악화됐다. 따라서 구간 이동만이 실패의 원인이라고 가정하지 않는다. 새 비율·기간·특징 탐색 없이, 구간 고정이 가중 부스팅의 악화를 줄이는지 확인하는 단일 비교다. 수익성 문제와 v10 최종 기준은 그대로다.

## 출처·행·가중치 고정

v140 완료 증거와 v139 이하 봉인에서 원본 1,018,460행·50개 입력·원래 1분 정답·과거 횟수·모든 모형과 요청을 확인한다. 학습은 2020년, 보정은 2021년 상반기, 진단은 하반기다. 24시간 및 포지션 경계와 전체 행을 보존한다. 모든 기간은 이미 관찰한 사후 연구다.

행동별 quiet의 가중치는 v140 행별 원장과 정확히 같아야 한다. 기존 v126 학습 점수의 음성 상위 1%·경계 동점 포함, 양성 및 높은 점수 음성 1 대 나머지 음성 0.1, 전체 평균 1 규칙을 다시 검산한다. 같은 학습 자료에 적합한 점수라는 한계도 유지한다. 구간을 바꾼 새 점수로 가중치를 다시 선택하지 않는다.

## 원래 무가중 구간 복원과 동등성 관문

v126 무가중 부스팅 두 개를 기존 전체 quiet 행과 고정 설정으로 독립 재적합한다. 모든 기존 숫자 모형·예측의 일치 뒤 해당 적합의 행동별·입력별 구간 경계를 추출한다. 새로운 분위수 설정이나 표본 추출을 하지 않는다. 경계는 해당 2020년 학습 자료에만 적합되며 보정·진단 자료로 확장하거나 변경하지 않는다.

경계의 형식·유한성·엄격한 증가·최대 254개, 입력 순서·행동·학습 출처를 검사해 숫자로 저장한다. 입력 값 x는 경계의 첫 `x <= 경계` 위치로 변환한다. 경계와 정확히 같은 값, 바로 양옆 값, 학습 범위 밖의 유한 값, 상수 입력을 별도로 검증한다. NaN·무한대는 기존과 같이 허용하지 않는다.

고정 경계로 변환한 각 입력은 최대 255개 정수 수준을 가진다. 설치된 잠금 버전의 구간 생성 경로는 고유 값이 최대 구간 수 이하일 때 이웃 값의 중점을 사용한다. 모든 가중치가 양수이므로 가중·무가중 적합에서 수준의 삭제도 없어야 한다. 실제 두 적합에서 동일한 수준·구간 매핑인지 전수 확인한다. 설치된 구현의 이 조건이 달라지면 중단하고 버전이나 알고리즘을 임의 교체하지 않는다.

먼저 고정 구간 입력으로 **무가중 동등성 대조**를 학습한다. 기존 v126과 모든 트리 구조·말단 값·기준 점수 및 세 기간 전체 원시 확률을 대조한다. 숫자 경계 표현이 정수 수준으로 바뀌므로 원래 경계로 대응시킨 분기와 값도 독립 확인한다. 확률 허용 오차는 기존과 같은 절대 1e-12, 노드·기준 값은 정확 일치다. 기존 모델을 재현하지 못하면 원인 기록 뒤 이번 비교를 중단하며 비슷한 대조를 같은 모델이라고 부르지 않는다.

## 새 후보와 보정

동등성 관문 뒤 고정 구간 입력과 원래 v140 가중치로 행동별 256개 트리, 총 새 512개 트리를 학습한다. 깊이 2·말단 4·학습률 0.05·최소 말단 64·L2 1·255구간·seed 0·조기 종료 없음·별도 클래스 가중치 없음은 그대로다. 무가중 동등성 대조의 512개 트리와 최종 가중 후보의 512개 트리를 구분해 보고한다.

선형 대조는 원시 50개 입력의 기존 v140 가중 선형 두 개를 그대로 재현·사용한다. 고정 구간 정수 값을 선형 입력에 넣지 않는다. 추가 선형 탐색이나 좋은 행동만 선택한 모델 결합은 없다. 원시 입력을 받는 추론 함수는 부스팅에만 저장된 경계를 적용하고 선형에는 기존 원시 입력을 전달한다.

기존 v127과 v140, 새 후보를 모두 보고한다. v127의 전체 quiet 보정·first/restart 원시 점수의 별도 절편·문턱 절차, 절편 범위 [-64,64]·100회 이분법·평균 오차 1e-12, 축소 F1·추가 F0.5·요청 최소 20개·동률 높은 문턱 우선을 유지한다. 평가와 보정은 무가중이다. 청산·recent·native/capacity의 기존 확률과 요청을 보존한다.

## 동일한 42개 판정과 보고

v140의 42개 조건을 같은 v127 기준으로 적용한다. 원래 상태·품질·보존 35개, 두 행동 quiet 로그 손실의 1% 초과 개선, 한도 전 재시작 추가의 재현율·F 엄격 개선 및 정밀도 보존, 공통 예산 하반기 TP 엄격 증가 및 FP 보존이다. 명칭만 후보에 맞추고 조건과 1e-12 비교 경계를 바꾸지 않는다.

상반기 v127 원래 FP 예산과 음성 B+1번째 점수 바로 다음 부동소수점 문턱, 18집단·미지원·동점 규칙을 유지한다. 예산 절차는 v127/새 후보 식별자를 사용하며 v140의 기존 예산 결과도 보존한다. 하반기에서 문턱을 바꾸거나 문턱별 성적을 보고 선택하지 않는다. 하나라도 미달하면 새 후보의 자체 계좌 확대를 하지 않는다.

전체·상태·모든 월·횟수·한도 전후·선형 대조의 직접 지표, 기존 및 예산 요청의 혼동표·교집합, 가중치 지원·비중, v127/v140 대비 차이를 기록한다. 구간 고정만으로 수익성이나 원본 전략을 재현했다고 주장하지 않는다. 통과하더라도 실제 계좌의 다년·다시장·비용·펀딩·지연·낙폭·표본·집중 검증은 별도다.

## 독립 검산과 보존

구간 변환은 라이브러리 변환·별도 순서 검색·경계 주변 직접 비교로 검산한다. 무가중 동등성 512개 트리와 최종 가중 512개 트리를 각각 독립 재적합하고 전체 추론·확률·보정·문턱·모든 집계·42개 조건을 대조한다. v140의 원장·가중치·선형·결과를 그대로 재현한다. 구간 설정·숫자·입력 열·행동 연결 손상, 상수·극단 입력, 미래 보정/진단 변경 시 학습 경계·가중치·모형 불변, 진단 변경 시 보정·문턱 불변을 검사한다.

사용한 설치 소스·잠금 의존성과 전체 입력·계획·코드 지문을 봉인한다. 충분한 디스크 공간을 확인하고 별도 로그·프로세스 종료·실패 기록을 보존한다. 원본·시장·파생·구간·가중치·모델은 로컬 전용이며 기존 증거를 삭제하지 않는다. 코드·방법·집계는 작업별 명사형 커밋 직후 푸시한다. 실제 주문·인증·출금 연결은 없다.
