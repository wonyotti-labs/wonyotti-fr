# 실험 v81 사전 계획: 첫 적격 기회의 단일 청산 판단

2026-10-10. v80의 직접 회귀는 같은 미래 첫 청산 정답을 사용했지만 기존 분류기보다 보정 최초 효과가 낮았다. 전체 포지션의 선택·시각 분해에서 청산 생략의 이익보다 늦은 선택의 손해가 컸다. 앞 학습에서 첫 적격 행은 원래 학습 비중과 절대 손익 비용의 작은 부분이었다. 첫 실행의 목적과 학습 단위를 맞추는 별도 가설을 검증한다. 이 관찰을 손실의 확정 원인으로 취급하지 않는다.

## 동일 자료와 검증 근거 재사용

v80의 전체 앞 학습·보정 행, 원래 포지션 경계와 제외 원장, 원래 비중, 여섯 보정 정책·내부 탈락·마지막 진단 차단을 보존한다. 앞 학습은 2021-01-01 이상 진입·판단이며 정답 종료는 2021-07-31 미만이다. 보정은 2021-08-02 이상 진입·판단, 정답 종료 2021-09-30 미만이다. 마지막 2021-10-02 이후 구간은 이번 단계에 전달하거나 예측하지 않는다.

이미 완료된 v80 전체 재현과 독립 검산의 근거를 재사용한다. 호출자가 지정한 검산 기록의 SHA-256을 먼저 확인하고, 그 기록에 고정된 v80 파일 봉인과 모든 소비 파일·코드 사본·보정 봉인을 확인한다. 새 결과에는 기존 입력과 검산 근거의 지문·사본·재사용 범위를 기록한다. 기존 전체 모델을 다시 적합하거나 중첩 재현을 새로 실행했다고 표시하지 않는다. 소비하지 않는 이전 외부 경로의 현재 무결성까지 새로 검증했다고 주장하지 않는다. 새 학습과 정책 계산은 독립 검산한다.

## 첫 기회와 고정 학습 단위

각 포지션에서 원래 의도가 `exit`가 아닌 가장 이른 분별 판단 하나를 적격 기회로 정한다. 시각과 원래 의도로만 선택하며 손익·미래 점수·종료 사유로 행을 고르지 않는다. 적격 기회가 없는 포지션도 전체 평가와 별도 위치 원장에 남기고 추가 청산 효과는 0이다. 원래 모든 후속 행과 손실은 보존한다.

입력은 해당 첫 기회의 기존 74개 특징이다. 정답은 그 시각의 추가 청산 현금과 원래 자연 종료 현금의 차이를 원래 전체 포지션의 첫 가용 순자산으로 나눈 bp다. 이후 보조 정책이나 미래 최대 수익을 기준으로 사용하지 않는다. 현재 선택하지 않으면 이 추가 모듈은 같은 포지션에서 다시 판단하지 않고 원래 정책이 계속 운용하기 때문이다. 기존 진입 필터와 달리 이미 진입한 연속 경로의 실제 첫 보유 상태·비용을 비교한다.

적격 포지션마다 학습 비중 1을 부여한다. 원래 모든 분별 행의 비중은 비교 근거로 보존하되 새 손실 함수에는 첫 기회만 참여한다. 양수·음수 정답을 모두 유지하고 0 정답은 비용 기여 0으로 명시한다. 적격 학습 500포지션·방향별 20포지션·180일, 비용이 있는 양쪽 부호별 64개 이상을 요구한다. 분별 행 수를 독립 표본 수로 부르지 않는다.

기존 비용 분류기의 설정을 유지한다. 로그 손실·64회·학습률 0.05·깊이 2·최대 말단 4·최소 말단 64·L2 1·구간 255·전체 특징·범주형 없음·조기 중지 없음·seed 0이다. 비용은 새 공통 기준 정답의 절댓값을 양의 비용 평균으로 정규화한다. 모형은 한 번만 적합하고 복잡도·비중·문턱을 탐색하지 않는다. 학습 양의 비용 비중을 상수 대조로 남긴다.

## 첫 기회 한 번의 정책과 내부 조건

새 모델은 첫 적격 기회에서만 예측한다. 비용 점수가 엄격히 0.5를 넘으면 추가 청산하고 그렇지 않으면 해당 포지션의 추가 모듈은 종료한다. 이후 행에 모델 점수를 만들지 않으며 예측하지 않은 행을 실제 점수 0으로 표시하지 않는다. 원래 청산·위험 규칙은 그대로다. 상수도 동일한 첫 기회에서만 적용한다.

같은 전체 보정 모집단에서 기존 여섯 정책과 새 첫 기회 모델·첫 기회 상수의 여덟 정책을 기록한다. 기존 정책의 저장된 행동·효과·그룹·실패는 그대로다. 모든 정책의 최초 효과는 같은 첫 가용 순자산을 사용하고 선택 없음은 0으로 포함한다. 새 후보는 다음 여섯 조건을 모두 만족해야 다음 단계 후보가 된다.

1. 최초 선택 30포지션 이상.
2. 전체 최초 평균 효과 양수.
3. v80 직접 회귀보다 전체 최초 평균 효과가 엄격히 큼.
4. v79 이후 정책 비용 분류보다 엄격히 큼.
5. v78 자연 종료 비용 분류보다 엄격히 큼.
6. 항상 첫 적격 청산보다 엄격히 큼.

동점은 실패다. 실패하면 여덟 정책·모든 손실·새 모델을 보존하고 적용을 차단한다. 상수로 교체하거나 문턱을 조절하지 않는다. 전체·방향·판단 월의 선택 효과와 전체 포지션·방향·진입 월의 최초 효과를 기록한다. 새 비용 확률 지표는 같은 첫 기회와 공통 정답에서 모델·상수만 비교하는 설명 자료이며 다른 모집단의 기존 확률 지표와 우열을 판정하지 않는다.

이번 단계는 첫 기회 학습과 내부 보정만 수행한다. 통과하더라도 마지막 진단과 연속 계좌 성과가 아직 검증되지 않았음을 명시하고 별도 고정 계획으로 이어간다. 통과 여부와 관계없이 수익성 연구는 계속하며 단계 완료를 전체 문제 해결로 처리하지 않는다. v80의 실패·기존 마지막 판정과 최종 v10의 다년·다시장·비용·펀딩·지연·낙폭·표본·집중 조건을 변경하지 않는다.

## 검증과 보존

시간·의도로 선택한 첫 행과 첫 순자산 환산을 수기로 대조하고 손실·적격 기회 없음·첫 거절 후 후속 양수 점수의 무시·정확히 0.5·원래 청산을 검사한다. 포지션당 한 표본·같은 양수 비중·모든 비용·상수·64개 트리와 숫자 내보내기를 독립 계산한다. 보정 정답·미래 입력을 바꿔도 앞 학습 모델과 첫 행 선택은 달라지지 않아야 한다.

검산 기록·참조 봉인·입력·비중·보정·코드 사본을 변조하거나 다시 봉인하면 신뢰한 검산 지문과 불일치해 학습 전에 거부해야 한다. 첫 기회의 정책·여덟 대조·여섯 조건·예측되지 않은 후속 행·마지막 평가 부재를 검증한다. 앞선 테스트를 재사용할 때 같은 지문과 새 변경 범위를 명시한다. 원본·가공·모델·개별 실행은 로컬에만 두며 실거래 연결은 추가하지 않는다.
