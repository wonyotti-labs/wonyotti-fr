# 실험 v124 결과: 보유 극값 갱신 후 경과 시간

2026-10-12. 사전 31개 조건 중 23개를 통과해 후속 계좌의 예측·요청 조건에 미달했다. 새 계좌 실험으로 확대하지 않았다. 수익성 문제는 미해결이다. [계획](EXPERIMENT_V124.md)에 따라 기존 50개 입력에 최선·최악 종가를 엄격히 갱신한 뒤 경과 시간 두 개를 추가했다. v123의 네 변동성 비율 입력은 사용하지 않았다. 원래 분할·정답·행·기존 세 모형을 보존했다.

하반기에서 축소 AP는 기존 0.0837554·같은 크기 0.0823914에서 새 모델 0.0852626으로, 추가 AP는 0.0590816·0.0614848에서 0.0651652로 높아졌다. 두 시간 입력은 세 행동의 분기에서 모두 사용됐다. 다만 청산 AP는 기존 0.0296945·같은 크기 0.0162614보다 낮은 0.0142485였고, 적중은 기존 4개에서 1개로 감소했다. 같은 크기 대비 로그 손실도 세 행동 모두 나빠졌다. 이 결과는 해당 진단 구간의 원본 행동 비교이며 일반적인 효과나 수익 개선의 증거로 확대하지 않는다.

전체 축소는 기존 적중 40개·오탐 215개에서 적중 64개·오탐 453개로 바뀌었다. 기존 대비 F1은 0.15936에서 0.16754로 개선됐지만 같은 크기의 0.17744에는 못 미쳤다. 첫 축소의 적중은 1개에서 4개로 늘고 재현율·F가 개선됐으나 오탐도 13개에서 90개로 늘었다. 추가의 전체 적중은 12개에서 9개로 줄었고, 첫 추가는 적중 2개를 유지하면서 오탐이 14개에서 15개로 늘어 F가 낮아졌다. 순위 개선과 선택한 문턱에서의 요청 품질을 구분한다.

미달 8개는 기존 대비 청산 AP·청산/추가 전체 F·첫 추가 F의 4개, 같은 크기 대비 세 행동 로그 손실과 청산 AP의 4개다. 좋은 행동만 사후에 골라 새 정책으로 합치거나 문턱을 다시 조정하지 않았다. 전체 교체 후보는 미채택 상태로 보존한다.
