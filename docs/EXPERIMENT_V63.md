# 실험 v63 사전 계획: 포지션당 첫 청산 선택의 조건부 효과

2026-10-04. v62의 현재 경제적 입력은 계산과 원장 대조를 통과했지만 기존 부스팅 대비 오차와 선택 효과 기준에 미달했다. 매매 적용은 차단한다. 지금까지의 선택 평균에는 한 포지션 안의 여러 양수 예측이 포함된다. 실제로 첫 청산을 실행하면 그 포지션의 뒤 판단은 방문하지 않으므로, 반복 선택 평균과 첫 선택 효과를 구분하는 원인 진단을 수행한다. 이전 실패를 취소하거나 채택 조건을 사후 완화하지 않는다.

## 고정 입력·행동

완료한 v62 전체 결과를 원래 v60·v59 입력 검증부터 다시 생성한다. 모든 필수 파일·원장·가중치·대조 모델·52개 입력·예측·지표가 정확히 같은지 검증한다. 재현 실행의 경로와 실행 시각은 별도로 연결한다. 새 학습 방식·입력·문턱은 추가하지 않는다.

v62와 v60 부스팅 두 개만 같은 진단 포지션에서 비교한다. v61 및 다른 후보를 선택에 추가하지 않는다. 기간·행은 기존 2021년 10월 2일~정답 종료 12월 31일 전의 진단 그대로다. 각 원래 포지션에서 시간순으로 읽어 `예측 > 0`이고 원래 의도가 청산이 아닌 최초 행을 선택한다. 첫 선택 뒤 더 큰 예측이나 더 좋은 실제 결과로 바꾸지 않는다. 선택이 없는 포지션은 기존 관리 유지로 기록하고 효과를 0으로 남긴다. 최초 선택의 손실도 그대로 보존한다.

현재 상태의 독립 청산 정답을 사용하므로 같은 포지션에서는 첫 선택까지 기존 정책의 상태가 같다. 이후 재진입·새 계좌의 복리·변경된 위험 상태는 계산하지 않는다. 원래 포지션의 종료 시각은 정답과 진단 묶음에만 쓰며 실행 신호에 넣지 않는다. 원래 포지션을 미래 종료까지 기다리게 하는 봇을 구현하지 않는다.

## 기록과 불확실성

전체 기회 원장과 두 모델별 모든 포지션을 보존한다. 포지션 시작·방향·첫 이용 가능 판단·전체 기회 수·전체 양수 선택 수·첫 선택 시각·예측·실제 금액 차이·기존 판단 시점 순자산 기준 bp를 기록한다. 원래 표의 반복 선택 평균도 함께 남기되 첫 효과와 합산하지 않는다.

두 모델의 첫 선택 시각이 달라도 비교 분모가 같도록, 각 포지션의 첫 이용 가능 판단 당시 순자산을 공통 기준으로 사용한 효과 bp도 계산한다. 선택이 없는 포지션의 공통 기준 효과는 0이다. 선택한 포지션의 평균과 모든 포지션의 평균, 이익·손실·0 차이 수, 방향별·포지션 시작 월별 분해를 기록한다. 금액이나 bp를 합산해 연속 계좌 수익으로 표시하지 않는다.

불확실성은 진단 시작 2021년 10월 2일을 기준으로 포지션 시작 시각의 고정 7일 블록을 사용한다. 마지막 불완전 주도 포함한다. 전체 13개 달력 블록을 13번 복원 추출하는 1,000회, seed 63을 고정하고 두 모델에 같은 추출을 적용한다. 선택이 없는 포지션도 포함한 평균 공통 기준 효과와 두 모델의 짝지은 차이에 대해 2.5·97.5 백분위 구간을 제시한다. 빈 블록과 유효 재표본 수를 보존하며 유효 값이 없으면 구간을 만들지 않는다. 짧은 기간과 블록을 넘는 의존성의 한계를 명시한다.

## 검증과 사용 제한

독립 반복문으로 첫 선택을 다시 찾고 원장·정답·공통 기준 순자산과 대조한다. 첫 선택 뒤의 예측·정답을 바꾸어도 최초 선택이 바뀌지 않아야 하며, 정답의 이익·손실을 바꿔도 선택 시각은 같아야 한다. 원래 청산 제외·선택 없음·음수 효과·시간 순서·포지션 경계·비유한 값과 같은 블록 추출의 재현성을 검사한다. 전체 지표·방향·월별 분해·블록 구간을 따로 검산한다.

이 단계에는 수익성 채택 판정이 없다. 조건부 최초 효과가 양수여도 거래 가능한 연속 계좌 결과가 아니며 후속 변경은 별도 계획을 요구한다. 이미 관찰한 기간의 사후 원인 진단이고 원래 실패·미확정·제외 기록을 보존한다. 실제 거래 연결은 제외하며 전체 다년·다시장·비용·표본·낙폭 기준은 v10 그대로다.
