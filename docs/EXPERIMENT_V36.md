# 실험 v36 사전 계획: 보정된 과거 주문 관리의 실제 체결 적용

2026-10-04. v35의 세 행동은 사전 고정된 세 비교 모형의 예측 조건을 모두 통과했고 독립 재학습·절편·지표·원본 대조도 완료했다. 이 예측 개선을 봇 자신의 체결 이력에 적용하는 단일 매매 후보를 검증한다. 기존 실패와 관찰한 모든 기간은 보존한다.

## 고정 모형과 문턱

- 기반은 v31이다. 신규 진입·방향·축소 크기 모형과 최초 투입·추가 예산·위험·비용·펀딩을 그대로 유지한다.
- 관리 모형만 v35의 2020년 학습 50개 입력 히스토그램 부스팅과 2021년 상반기 절편으로 바꾼다. 세 행동을 함께 사용하며 다시 학습하지 않는다. v35의 파일 지문과 세 기준 전체 채택 판단을 다시 검증한다.
- 행동 문턱은 같은 2021년 상반기 보정 행에서 기존 선택법인 청산 F2·축소 F1·추가 F0.5로 고정한다. 예측 양성 최소 20개와 동률 시 가장 높은 문턱을 유지한다. 보정과 문턱에 같은 행을 사용한 점을 기록하며 하반기 진단 정답·손익으로 문턱을 고르지 않는다.
- v31의 배율 1.5, 현재 점수 판단, 청산·축소·추가 우선순위, 3분 대기와 다음 봉 실행을 유지한다. 축소 크기는 원래 44개 입력의 기존 모형을 그대로 사용한다.

## 봇 자체 이력과 복원

같은 포지션의 실제 체결만 이력에 반영한다. 추가 횟수의 증가는 실행된 추가, 추가 횟수가 같고 잔여 수량 비율이 감소한 경우는 실행된 축소다. 엔진이 한 봉에서 부분 관리 체결을 하나만 수행하는 계약을 검증한다. 요청·거부·대기·무거래 봉은 체결 이력이 아니다. 신규 진입·반전·청산 이후 새 포지션에는 과거 이력을 넘기지 않는다.

여섯 입력은 행동별 과거 존재 여부·마지막 체결 이후 분의 log1p·[현재−15분, 현재)의 체결 수 log1p다. 체결은 현재 결정 시각보다 엄격히 과거여야 한다. 최근 15개 분은 제한된 비트 기록으로, 마지막 체결 시각과 이전 수량 상태는 숫자로 저장한다. 가격 경로의 포지션 식별·연속 분봉 검증을 함께 사용한다. 오래된 경로만 있는 기록·필드 누락·불가능한 수량 변화·중복 시각을 거부한다.

합성 검사에서 실제 체결·추가 한도 거부·지연·무거래·축소·반전·15분 경계와 재개·중복 처리·실패 시 원상 복원을 확인한다. 실제 프로세스 종료 후 대기·보유 복원과 월간 전체 출력 일치를 검사한다.

## 실행과 판정

2021년 후보와 원래 v31을 같은 위험으로 비교한다. v31의 전체 출력·최종 상태는 기존 실행과 정확히 일치해야 한다. 2022년 양수·종료 거래 30개 이상·영구 중지 없음 조건을 확인한다. 통과하면 두 후속 기간·세 시장의 기본 여덟 조건에 원래 위험의 v14와 동일 위험의 v29·v31을 더한 열한 조건, 아홉 독립 연도를 수행한다. 총 78개 실행이다. 확인 실패 시 BTC 두 후속 기간과 세 독립 연도를 수행해 총 여덟 실행을 보존한다.

후속 수익성은 기존 전체 평가의 순손익·비용·지연·낙폭·표본·독립 연도 기준을 그대로 적용한다. 이미 관찰한 구간을 미사용 평가로 부르지 않는다. 원본 상태의 예측 개선이나 한 구간 수익만으로 수익성 문제를 해결했다고 판정하지 않는다. 원본·파생 자료·모형·개별 결과는 로컬에 보존하며 실제 주문 연결은 제외한다.
