# 실험 v28 사전 계획: 신규 방향 모형의 시간순 예측 진단

2026-10-04. 실제 신규 포지션을 직접 학습한 v27도 2022년 확인에서 손실·중지를 보였다. 단순 빈도 보정과 전체 원본의 선형 학습만으로 후속 손익을 해결하지 못했다. 원자료의 다음 해 행동을 예측하는 능력을 분리해 검사하고 개선 근거 없이 다른 모형의 매매 결과를 반복 비교하지 않는다.

이번 단계는 원본의 내부 시간순 진단이다. 모든 원본 기간을 이전 연구에서 이미 관찰했으므로 새로운 미사용 평가나 미래 성과로 부르지 않는다. 실제 포지션 시작의 방향과 봇의 순손익은 별개다.

## 고정 자료·비교

- v27과 같은 실제 `open`·`reverse`의 다음 5분 첫 사건, 원래 지원 행·14개 확정 시장 특징을 사용한다. 분 경계·동일 시각 순서·원본 손실과 복수 사건 원장을 보존한다.
- 2018-01-01~2021-01-01 미만을 학습, 2021-01-01~2022-01-01 미만을 진단으로 고정한다. 양쪽 24시간을 제거하고 현재·목표 에피소드가 각 경계를 넘으면 제거한다. 학습과 진단 에피소드의 교집합은 없어야 한다.
- 학습은 기존 최소 1,000행·각 방향 20개, 진단은 최소 100행·각 방향 20개를 요구한다. 부족하면 실패를 보존하며 기간·기준을 바꾸지 않는다.
- 후보는 이미 구현된 두 모형뿐이다. 표준화 로지스틱 C=0.1·max_iter=2000과 GradientBoostingClassifier 64개 트리·학습률 .05·깊이 2·말단 최소 32·초기 점수 0·seed 0이다. 가중치·새 특징·문턱 최적화는 적용하지 않는다.
- 원래 v27의 전체 기간 모형은 비교 모형으로 사용하지 않는다. 두 모형 모두 이 진단의 과거 학습 행에서 새로 학습한다. 학습 롱 비율을 항상 출력하는 상수 예측도 함께 기록한다.

## 사전 판단 규칙

2021년 진단의 평균 이진 로그 손실을 주 지표로 고정한다. Brier·ROC AUC·균형 정확도·월별 표본·방향별 예측·.65/.35 의사결정도 함께 기록한다. 부스팅의 로그 손실이 로지스틱보다 절대 .01을 초과해 낮고 상수 기준보다 낮을 때만 후속 후보를 허용한다. 그 밖에는 새 매매 후보를 만들지 않고 기존 v27과 실패를 보존한다. 동점·경계에서는 기존 모형을 유지한다.

이 조건을 통과해도 수익성 입증은 아니다. 통과 시 동일한 부스팅 설정을 v27의 전체 2018~2021년 실제 신규 방향 정답으로 다시 학습하고, 원래 v27 활동·관리·위험을 고정한 단일 후보로 별도 비교한다. 2021년 적합과 원래 v27 전체 출력 일치, 고정 후 2022년 양수·30거래·영구 중지 없음 조건을 적용한다. 실패 시 BTC 두 후속 기간·세 독립 연도, 통과 시 세 시장·두 기간·열한 조건·아홉 독립 연도다. 열한 조건은 기본 여덟 조건과 원래 v14·v26·v27이다. 원래 v25 단독 조건을 v27로 대체한다.

입력·학습 및 진단 경계·교집합·숫자 모델 재생·점수 재계산을 검증한다. 진단 결과를 받은 후 규칙을 바꾸거나 최근 손익으로 모형을 재선택하지 않는다. 원본·파생 자료·모델·개별 결과는 로컬에 보존하고 실제 거래를 연결하지 않는다.
