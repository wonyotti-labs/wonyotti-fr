# 실험 v127 사전 계획: 최초·재시작 상태별 확률 보정과 문턱

2026-10-12. v126의 quiet 모델은 로그 손실을 개선했지만 최초 행동·추가 요청 기준에 미달했다. quiet 안의 최초(first)와 재시작(restart)에 하나의 절편과 문턱을 적용한 것이 요청 악화에 기여하는지 검증한다. v37~38은 원래 공통 모델의 최초 문턱·배율을 바꿨으며 별도 절편은 없었다. v119는 최초 상태에서만 별도 모델을 학습했다. 이번에는 v126의 quiet 모델을 고정하고 보정만 분리한다.

## 고정 입력과 비교

- v126의 전체 학습·보정·진단 행, 원본 50개 입력·정답, 512개 트리·두 선형과 원시 점수를 유지한다. 새 모델 학습·특징·가중치·기간·정답 변경은 없다. 세 기간은 이미 관찰했다.
- quiet는 과거 `[t−15분,t)`에 해당 독립 첫 체결이 없는 상태다. 그중 `past_*_exists == 0`은 first, 나머지는 restart다. 기존 원본 분할·24시간 경계·포지션 분리 및 v126 지원을 확인한다. 두 상태의 상반기·하반기에 각각 100행 및 양성·음성 각 20개 이상을 요구한다.
- 축소·추가 각각의 부스팅·선형 원시 확률에 대해 상반기 first/restart에서 독립 절편 1개씩을 적합한다. 기존 기울기 1·[-64,64]·100회 이분법·평균 오차 1e-12를 유지한다. 같은 상반기 상태에서 F1/F0.5, 예측 양성 최소 20개, 높은 문턱 동률 우선으로 문턱을 선택한다.
- 문턱만 분리하는 대조는 v126의 기존 quiet 보정 확률을 그대로 두고 상반기 first/restart에서 문턱만 선택한다. 후보와 이 대조의 상태 내부 순위·문턱 요청이 모든 기간에서 같은지 검사한다. 단조 절편 변환 뒤 상태별 문턱 선택은 일반적으로 같은 요청을 만들어야 하므로, 이 비교를 독립적인 두 성공 후보로 세지 않는다. 불일치가 있으면 수치 경계를 조사하고 자동 확대하지 않는다.
- 청산 전체와 recent 추가·축소의 점수·요청은 v126 및 원래 native와 정확히 같아야 한다. native·capacity·상수·원시 모델 대조는 v126 결과 그대로 보존한다. capacity와 새 후보의 전체 상태는 quiet만 바꾸고 recent에서 native를 사용하는 결합이다.
- 하반기 결과로 두 상태를 합치거나 좋은 행동만 고르지 않는다. 새 절편·문턱 함수는 상반기 자료만 받고 학습·진단 자료를 받지 않는다.

## 판정과 검산

v126의 27개 조건을 새 상태별 보정 부스팅과 상태별 보정 선형에 그대로 적용한다. 즉 quiet의 native·capacity·선형 대비 로그 손실 1% 초과 개선과 평균 정밀도 보존, 보정 전 로그 손실·상수 대조, quiet 재현율·F의 엄격한 개선, 전체/최초 F 보존 및 청산/recent 점수·요청 보존이다. 추가로 두 행동의 quiet 로그 손실과 평균 정밀도가 각각 v126의 단일 절편 모델보다 나쁘지 않아야 한다(4개). 총 31개이며 허용 오차 1e-12와 엄격 경계 규칙을 유지한다.

조건 하나라도 미달하면 새 계좌로 확대하지 않는다. 통과도 수익성 증명이 아니며 별도 자기 상태의 체결·위험·비용·펀딩·지연·다년·다시장·표본 검증과 v10 최종 기준을 요구한다. 앞선 실패를 변경하지 않는다.

모든 기간의 all/quiet/recent/first/restart와 모든 월에서 행·양성 분·로그 손실·평균 정밀도·TP/FP/FN·정밀도·재현율·F를 보존한다. 상태별 실제 빈도와 보정 전후 예측 평균도 기록한다. 빈 집단·양성 0개를 삭제하지 않는다. 단일 절편·문턱 대조와 문턱만 분리 대조도 별도 기록한다.

v126의 숫자 모델을 복원해 전체 원시/기존 보정 점수·요청을 재현하고, 별도 노드 분할·선형 수식으로 검산한다. 새로운 절편·문턱·예측·지표·31개 판정은 독립 계산한다. 원시/대조/청산/recent 보존, 진단 정답 변경에 대한 적합 불변, 상태 경계·손상 입력·빈 집단·저장 후 동일성을 검사한다. 입력·계획·코드 지문을 실행 전후 대조하며 실패 기록을 보존한다. 원본·모형·개별 출력은 로컬에만 보관하고 실거래 연결은 없다.
