# 실험 v34 사전 계획: 과거 주문 이력과 가격 상태의 비선형 결합

2026-10-04. v33의 과거 주문 이력 여섯 항목은 같은 로지스틱에서 세 행동의 예측을 개선했지만 청산 개선 폭이 사전 기준에 미달했다. 이 실패는 보존한다. 로지스틱은 경과 시간·최근 주문 수·잔량·가격 상태를 가산하므로 특정 상태 조합의 효과를 충분히 표현하지 못할 수 있다. 같은 50개 입력에 고정된 얕은 부스팅 하나를 적용해 이 가설을 진단한다.

## 고정 입력·모형

- v33의 학습 2020년~2021년 상반기, 진단 2021년 하반기와 모든 행·정답·50개 입력을 그대로 사용한다. 포지션·24시간 분리, 최소 양성·음성 기준을 유지한다. 이력 기간이나 정답을 변경하지 않는다.
- 모형은 v30의 히스토그램 부스팅 설정을 그대로 사용한다. 64회, 학습률 0.05, 깊이 2, 말단 최대 4개, 말단 최소 64행, L2 1, 구간 최대 255, seed 0이며 조기 종료·클래스 가중치·임의 검증 분할은 없다. 입력 50개 이외의 변경이나 설정 검색을 하지 않는다.
- v33 모형을 같은 학습 행에서 다시 적합해 숫자 모델과 미사용 문턱이 일치해야 한다. 새 부스팅의 숫자 내보내기는 학습·진단 전체에서 학습 라이브러리와 1e-12 이내로 일치해야 한다. 마지막 구간의 정답은 부스팅 학습에 사용하지 않는다.

## 비교·판정

새 부스팅을 기존 44개 로지스틱, v33의 50개 로지스틱, 학습 행동 빈도의 상수 기준과 같은 진단 행에서 비교한다. 각 행동의 로그 손실·Brier·평균 정밀도·ROC AUC·평균 예측과 실제 빈도를 모두 기록한다.

후속 연구 허용에는 세 행동 모두에서 두 로지스틱 각각보다 로그 손실이 1% 초과 개선되고(1e-12 경계 제외), 평균 정밀도가 두 기준 이상이며 상수보다 좋아야 한다. 일부 행동 선택이나 기준 완화는 없다. 통과하더라도 자체 체결 이력의 실행 상태·복원과 별도 매매 사전 계획 전에는 봇을 만들거나 손익을 실행하지 않는다.

이 진단은 이미 관찰한 원본 상태의 예측 비교다. v30·v32·v33의 실패를 수정하거나 새로운 미사용 평가로 부르지 않는다. 원본·파생 자료·모형·개별 결과는 로컬에 보존하며 실제 주문 연결은 제외한다.
