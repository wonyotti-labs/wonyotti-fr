# 실험 v110 사전 계획: 관리 요청의 하루·주간 주기

2026-10-11. v109의 실제 종료 대응에서도 v108 하반기 B 신호 651개 중 적중은 6개뿐이었다. 원래 주문을 더 많이 정답에 넣거나 체결 시점을 다르게 해석하는 것으로 현재 낮은 예측력이 설명되지 않았다. 과거 분별 입력·주문 이력·장기 학습·체결 방향 실험은 보존하고, 아직 입력에 없는 반복 시간 주기 하나를 시험한다. 시간대에 따른 행동 빈도가 안정적이거나 수익성이 있다는 사전 주장은 없다.

## 같은 자료와 네 값

v108의 전체 창·원본 상태·32개 입력·복수 요청 정답·지원 사유·기간 분리를 그대로 사용한다. 학습 2018~2020년, 보정 2021년 상반기, 진단 하반기다. 기존 24시간 및 에피소드 경계 제거를 유지하고 행·손실·기간을 다시 선택하지 않는다. 청산·축소·추가 각각의 독립 이진 정답이다.

창 시작 UTC 시각 t에서 하루 경과 비율 d와 월요일 00:00부터의 일주일 경과 비율 w를 계산한다. 기존 입력 뒤에 sin(2πd), cos(2πd), sin(2πw), cos(2πw) 네 값을 붙인다. 연도·월·날짜·경과 연수·절대 타임스탬프·개인 일정·미래 주문은 모형 입력이 아니다. UTC 기준을 바꾸거나 유리한 시간대·요일을 선별하지 않는다. 주기와 값 개수·위상·추가 조화항도 탐색하지 않는다.

주기를 삼각함수 두 값으로 표현하면 자정·주간 경계에서 연속적인 표현을 만들 수 있다. 방법은 [scikit-learn 공식 예제](https://scikit-learn.org/stable/auto_examples/applications/plot_cyclical_feature_engineering.html#trigonometric-features)를 참고한다. 이 방법 설명은 거래 수익의 근거가 아니다.

## 고정 학습과 대조

주 후보는 36개 입력의 기존 고정 부스팅이다. 행동별 HistGradientBoostingClassifier, 64회·학습률 0.05·깊이 2·말단 4·최소 말단 64·L2 1·구간 255·seed 0·조기 종료와 클래스 가중치 없음이다. 설정 탐색이나 주간 갱신은 없다.

직접 기준은 v108 B의 저장된 32개 입력 복수 요청 모형·예측·문턱이다. 같은 36개 입력의 표준화 로지스틱 C=0.1·최대 2,000회·seed 0·가중치 없음과 원래 학습 빈도 상수를 대조로 둔다. 새 두 모형은 학습 범위에서만 적합하고, 원래 문턱 선택 규칙인 청산 F2·축소 F1·추가 F0.5와 예측 양성 20개 이상을 보정 구간에만 적용한다. 직접 기준과 상수의 기존 문턱은 그대로 유지한다.

모든 보정·진단·월별 로그 손실·평균 정밀도·Brier·혼동표·문턱 통과·청산 우선순위 선택을 보존한다. 기준과 후보의 월별 평가 행이 정확히 같아야 한다. 모든 기간은 이미 관찰한 자료이며 이 가설도 반복 연구의 일부다.

## 후속 관리 후보 조건

v108과 같은 17개 조건 구조를 사용하되 직접 기준은 v108 B다. 세 행동 각각에서 후보의 로그 손실이 직접 기준과 새 선형 대조보다 1% 초과 개선되고, 평균 정밀도는 두 대조 이상이어야 한다. 학습 빈도 상수보다 로그 손실이 작아야 한다. 청산 재현율과 F2는 직접 기준보다 엄격하게 커야 한다. 비교 허용 차이는 기존 1e-12를 유지한다. 모든 조건 통과 후에만 별도 계획으로 자체 계좌 실행을 연결한다. 통과하지 못하면 모형·문턱·기준을 사후 수정하지 않는다.

## 검산과 범위

자정·월요일·음수 유닉스 시각·나노초/마이크로초·UTC·중복·미래 추가 불변과 기존 열·정답·행 보존을 검사한다. 독립 달력 계산으로 전체 네 입력을 대조하고, 새 모형의 192개 트리·선형 표준화/계수·모든 보정/진단 점수·단일 상태 추론·문턱·월별 지표·17개 판정을 별도 계산한다. 기존 B·상수 예측은 저장 모형에서 다시 대조한다. 원본·모형·개별 산출물은 로컬에만 보존한다.

주기가 관리 요청을 설명해도 원래 트레이더의 생활 패턴이나 당시 의도를 확정하지 않는다. 원본 상태에서의 행동 예측과 자체 계좌 순손익은 별도다. 실제 거래 연결 없이 v10의 다년·다시장·비용·펀딩·지연·낙폭·표본 기준과 미해결 goal을 유지한다.
