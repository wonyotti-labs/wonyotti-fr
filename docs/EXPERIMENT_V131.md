# 실험 v131 사전 계획: 절대 점수와 과거 분포 점수의 결합 보정

2026-10-12. v130의 과거 분포 대체는 재시작 검출을 늘렸지만 정밀도와 확률 품질을 악화시켰다. 절대 점수를 유지하면서 과거 분포 점수를 보조 입력으로 결합하는 한 후보를 검증한다. 동일한 적합 절차의 절대 점수 단독 대조도 함께 두어 보정기 자체의 유연성 증가와 보조 입력의 기여를 구분한다. 이전 턴은 원본 실행·수치 오류 수정·실패 보존·검산·결과 공개를 완료한 진행이다.

## 고정 출처·상태·지원

- v130 완료 증거와 이전 원본·모형의 봉인을 확인한다. 2020년 학습·2021년 상반기 보정·하반기 진단의 원래 1,018,460행과 50개 입력·정답·24시간 경계·포지션 분리를 유지한다. 전 기간을 이미 관찰했다.
- v127의 v126 공통 quiet 부스팅·선형 원시 점수와 v130의 검산된 과거 분포 변환 점수를 사용한다. 기본 모형과 30일 창·1,000개 지원 기준·현재 분 제외·동점·2020년 기준 분포는 변경하지 않는다. 저장된 모든 n/L/E·분위수 변환을 별도 누적 수 검산으로 다시 대조한다.
- 축소/추가×first/restart×기본 부스팅/선형의 8개 지원 집단이 대상이다. 지원은 v130과 완전히 같아야 한다. 미지원 quiet의 각 원시/보정 점수·요청, 청산 전체 및 recent는 v127을 그대로 유지한다. 모든 행을 포함한 결합 결과로 판정하며 미지원 양성도 제외하지 않는다.

## 고정 보정기와 문턱

절대 점수 단독 `absolute`는 기본 모형의 원시 확률 p의 logit 하나, 결합 `joint`는 p와 과거 분포 변환 확률 q의 logit 두 개를 입력으로 사용한다. logit 전에 머신 epsilon과 1−epsilon으로 제한한다. 동일한 상반기 지원 행만 사용하며 각 집단은 100행·양성/음성 각 20개 이상이어야 한다.

각 입력을 상반기 지원 행의 평균·표준편차로 표준화하고 로지스틱 회귀(C=0.1, L2, lbfgs, 절편 있음, 최대 2,000회, tol=1e-8, seed=0, 가중치 없음)를 적합한다. 원래 기본 모형은 재학습하지 않지만 **새 보정기 16개**를 학습한다. 계수 부호를 사후 고치거나 입력 조합·정규화 강도·학습 기간을 검색하지 않는다. 두 보정기를 상반기에 각각 적합하므로 단독 대조 역시 기존 v127과 다른 새 모델이다.

같은 상반기 지원 행에서 기울기 1 절편 보정([-64,64], 100회 이분법, 평균 빈도 오차 1e-12)을 추가로 적용한다. 원시/절편 보정 후 각각 축소 F1·추가 F0.5, 최소 예측 양성 20개·동률 시 높은 문턱으로 문턱을 정한다. 지원 빈도 상수를 유지한다. 보정기·표준화·추가 절편·문턱 함수에는 진단 정답을 전달하지 않는다.

상반기는 새 보정기의 적합과 문턱 선택에 모두 사용한 구간이며 독립 성능 검증이 아니다. 2020년 표 역시 이후 상반기 보정기를 적용한 적합 진단이다. 하반기도 반복 관찰된 연구 구간이므로 새 미관찰 검증 자료로 표시하지 않는다.

## 고정 판정 39개

결합 후보에는 v130의 35개 조건을 그대로 적용한다. 비교 기준은 기존 native/capacity, 결합 선형, 결합 절편 전, 상수, v127이다. 두 행동의 quiet 정밀도 native 이상과 restart 재현율 v127 초과도 유지한다.

보조 입력의 실효성을 위해 결합 부스팅이 새 절대 점수 단독 부스팅보다 두 행동 각각 quiet 로그 손실이 1% 초과 개선되고 평균 정밀도가 낮지 않아야 한다(4개 추가). 기존 1e-12 경계를 유지한다. 총 39개 조건 중 하나라도 미달하면 새 자체 계좌를 실행하지 않는다. v130 분포 단독 후보도 모든 상태·월별 대조로 보고하되 좋은 상태나 행동만 사후 결합하지 않는다. 통과해도 v10의 다년·다시장·비용·펀딩·지연·낙폭·표본 기준을 충족한 수익성 채택이 아니다.
