# 실험 v113 사전 계획: 원본 관리 입력과 실제 판단 상태의 차이

2026-10-12. v112의 계좌 크기 입력은 같은 기간의 기준 모델 대비 학습 손실을 개선했지만 보정·진단 손실을 악화했다. 새 특징이나 모델 크기를 다시 선택하기 전에, 기존 v35 관리 모델과 v48 정책이 실제로 받는 50개 입력의 지원 범위를 확인한다. v40의 최대 보유 시간, v53의 진입 초기 비중, v76·77의 봇 청산 효용 학습에 대한 방문 구간 연구를 반복한 것으로 표현하지 않는다.

## 고정 비교

- 기존 v35의 학습 2020년, 보정 2021년 상반기, 진단 2021년 하반기 행을 그대로 사용한다. 학습 행만으로 특징별 최솟값·1·5·25·50·75·95·99백분위·최댓값을 고정한다. 선형 보간 분위수를 사용한다. 보정·진단·봇 입력은 이 경계 산출에 사용하지 않는다.
- 봇은 기존 v48 그대로다. BTCUSDT 2022년 기본 조건과 ETHUSDT 2023~2025년 기본 조건을 추적한다. 이미 관찰한 BTC 양수·표본 부족과 ETH 손실의 설명 비교이며 새 검증 기간이나 수익 후보 선택이 아니다. 다른 기간·비용·지연·시장 실패와 최종 v10 기준을 유지한다.
- 정책이 관리 모델 입력을 실제 계산한 시점만 기록한다. 평탄 상태, 대기, 위험 차단 등 계산하지 않은 시점은 별도 호출 수로 집계한다. 가격·자체 계좌·과거 체결 이력만 관찰하며 의도·수량·모델·문턱·위험 설정을 바꾸지 않는다.

## 집계와 해석

50개 특징 각각의 학습 최솟값~최댓값 밖 비중과 1~99백분위 밖 비중을 보고한다. 시장 14개, 방향 곱 14개, 포지션 4개, 가격 경로·잔여 비중 4개, 분봉 8개, 체결 이력 6개의 그룹별 한 특징 이상 초과 비중도 계산한다. 경계와 같은 값은 범위 안이다. 비유한 입력은 따로 세며 범위 안으로 처리하지 않는다.

공동 상태는 방향, 0~5로 제한한 추가 횟수, 잔여 비중이 정확히 1인지, 과거 추가·축소 존재 여부의 조합으로 고정한다. 학습에서 관찰되지 않은 조합의 비중을 보고한다. 이는 50차원 전체의 분포 동일성 검사나 예측 정확도 판정이 아니다. 각 입력 시점은 독립 거래 표본이 아니며, 범위 초과 자체도 손실 원인의 증명은 아니다. 미래의 손익으로 상태를 제외하거나 새 청산 규칙을 적용하지 않는다.

원본 보정·진단과 봇 두 실행에 같은 집계를 적용한다. 봇은 전체 및 실제 요청 의도별로 나눠 비교한다. 모든 특징을 보고하고 큰 차이만 골라 공개하지 않는다. 이번 단계에서는 새 모델·거래 정책·수익성 채택이 없다. 결과에 따른 변경은 별도 계획에서 검증한다.

## 검증과 보존

입력 관찰을 켠 재생은 기존 저장 실행의 모든 분별 계좌·판단 결과·체결·종료 거래·최종 상태와 정확히 같아야 한다. 수수료·펀딩·현금 검산을 재사용한다. 관찰한 50개 값은 현재 시세·계좌와 판단에 저장된 경로·체결 상태에서 별도 수식으로 매 호출 대조한다. 분위수·범위 집계는 저장된 입력을 다시 읽는 별도 계산으로 대조한다.

합성 테스트에서 경계·중복 분위수·미관찰 조합·비유한 입력·호출 실패 후 원래 메서드 복원·정책 불변을 확인한다. 입력·기존 실행·코드·계획 지문을 고정하고 새 출력 폴더에만 저장한다. 저장 공간을 확인하며 기존 연구 파일을 삭제하지 않는다. 원본·모델·개별 입력 기록은 로컬에만 유지하고 코드·방법·전체 집계만 공개한다. 실제 거래 연결은 없다.
