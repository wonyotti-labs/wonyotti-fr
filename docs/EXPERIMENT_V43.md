# 실험 v43 사전 계획: 신규 진입 활동과 방향의 결합 예측

2026-10-04. v40의 약세 구간 편중은 활동 관문 전후에서 확대됐으며, v42에서 활동 모형만 부스팅으로 바꾼 진단은 실패했다. 두 확률의 분해 자체가 수학적 오류라는 뜻은 아니다. 활동 여부와 방향을 동일한 학습 목표로 추정하는 모형을 별도로 비교한다.

## 자료와 고정 모형

- v42의 2020년 학습·2021년 진단 행, 14개 시장 입력·다음 5분 첫 신규 포지션·현재와 목표 포지션 경계·양쪽 24시간 제거를 그대로 유지한다. 정답은 hold=0, short=1, long=2다. hold는 신규 포지션 사건 없음이며 기존 보유 관리의 hold와 구분한다. 모든 행과 원본 손실을 유지한다.
- 새 후보는 학습 전용 표준화와 다항 로지스틱 C=.1·lbfgs·최대 2,000회·seed 0 하나다. 가중치·별도 보정·추가 특징·설정 검색은 없다. 세 클래스의 순서와 확률 합·유한성, 학습 1,000행·진단 100행·각 클래스 20개 이상을 요구한다.
- 직접 비교는 v42의 2020년 활동 로지스틱과 v28 진단의 2018~2020년 방향 부스팅을 결합한다. 두 모형 모두 진단 2021년 이전 정보만 사용한다. p_hold=1-p_active, p_short=p_active×(1-p_buy), p_long=p_active×p_buy다. 기존 모델·학습 및 진단 지문·점수를 재현한다.
- 후보의 방향 학습 범위가 2020년으로 짧아지는 차이도 함께 존재한다. 결과를 결합 형식 하나만의 인과 효과로 주장하지 않는다. 기존 방향 학습의 1,000개 지원 기준을 낮춰 2020년의 조건부 방향 모델을 새로 적합하지 않는다.
- 상수 기준은 후보 학습의 세 클래스 빈도다. 활동 문턱은 각 학습의 1-p_hold 점수 .975 분위, 조건부 방향 문턱은 .65로 고정해 진단 기록만 남긴다. 진단 정답·봇 손익으로 문턱을 고르지 않는다.

## 사전 통과 기준과 검증

2021년의 다중 클래스 로그 손실이 기존 분해 결합보다 1% 초과 낮고 학습 빈도 상수보다 낮아야 한다. long·short 각각의 평균 정밀도가 기존 분해 결합 이상이어야 하며 활동 자체의 이진 로그 손실도 나빠지지 않아야 한다. 모든 조건을 통과해야 한다. 클래스별 지원·Brier·활동과 조건부 방향 지표·고정 문턱의 요청 및 적중·월별 오류를 기록한다. 단순 신호 수·롱숏 균형을 통과 근거로 쓰지 않는다.

원래 행·입력·활동과 방향 정답·기존 두 모형과 점수의 재현을 확인한다. 별도 학습 라이브러리·수기 softmax·로그 손실·평균 정밀도·문턱을 대조한다. 미래 입력·정답 변경은 학습 모델과 문턱에 영향을 주지 않아야 한다. 비정상 클래스·계수·확률과 원본 지문 변경을 거부한다. 통과해도 봇 적용은 별도 계획이며 실패한 모형을 매매에 적용하지 않는다. 관리·위험·체결·실거래 연결은 변경하지 않는다. 모든 기간은 이미 관찰했고 원본·파생 자료·모델·개별 결과는 로컬 전용이다.

세 클래스 학습과 softmax 출력은 [scikit-learn의 공식 LogisticRegression 문서](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.LogisticRegression.html)의 인터페이스를 사용한다. 모델 선택과 매매 효과는 별도로 검증한다.
