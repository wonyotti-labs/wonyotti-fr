# 실험 v20 사전 계획: 원본 관리 방식의 최신 구간 반영

2026-10-04. v19의 수량 상태·실제 축소 크기 학습도 개발·확인에서 손실을 남겼다. 원본을 반기별로 대조하면 잔여 수량 분포와 실제 축소 크기가 달라졌고, 2019년~2020년 상반기에 학습한 크기 모형은 2021년 원본의 지원 주문에서 실제보다 큰 축소를 예측했다. 2021년 원본은 기존 관리 모형의 학습·보정에 사용하지 않았다. 시기 변화와 봇의 손실을 같은 원인으로 단정하지 않으며, 최신 원본 구간을 반영하는 단일 비교를 고정한다.

## 변경 범위와 시간 경계

- 관리 행동 정답·잔여 수량·가격 경로·실제 축소 크기 정답은 v19와 같다. 청산·축소·추가의 분류, 작은 잔량, 부분 체결, 손실 원장을 그대로 유지한다.
- 관리 로지스틱 C=0.1과 축소 크기 Ridge alpha 100의 학습 창을 **2020-01-01 이상, 2021-07-01 미만**으로 옮긴다. 과거와 같은 18개월 길이를 사용하며 창 길이·시작점 후보 탐색은 없다.
- **2021-07-01 이상, 2022-01-01 미만**은 관리 행동 빈도 보정만 수행한다. 축소 크기 모형은 이 구간을 학습하지 않는다. 기존 행동 문턱 계산은 기록용이며 실행은 v19와 같은 사건 누적량을 사용한다.
- 학습·보정 창의 포지션 경계와 24시간 제거를 유지한다. 크기 정답은 마지막 실제 체결까지 포함해 경계를 판정한다. 크기 학습 100개·90일, 관리 행동별 지원 20개 등 기존 요건을 완화하지 않는다. 부족하면 그 실패를 기록한다.
- 첫 진입의 활동·방향 모델, 16bp·5분 대기, 초기·최대 노출, 추가 크기·횟수, 평탄 청산, 손절·손실 한도·비용은 원래 v14와 같다. 진입 모형의 재학습이나 순손익 필터·반전 실행을 함께 바꾸지 않는다.

## 비교와 해석

주 후보는 새 학습 창의 수량 관리 모델과 예측 축소 크기를 함께 사용한다. 같은 새 관리 모델에서 축소 크기만 원래 고정값으로 유지하는 대조를 보존하며, 손익으로 주 후보를 바꾸지 않는다. 기존 v19 모델·결과는 별도 보존한다.

2021년 전체 재생 두 개는 **학습·보정 구간이 겹치는 적합 진단**으로만 기록한다. 2021년의 양수를 시간순 예측 성과나 선택 근거로 쓰지 않는다. 2022년부터는 학습·보정 시점 이후의 고정 정책이다. 2022년 확인 양수·30거래 이상·영구 중지 없음 실패 시, 사전 고정한 BTC 후속 두 기간·세 독립 연도를 진단한다. 통과 시 세 시장·두 기간·열 조건과 아홉 독립 연도를 평가한다. 조건은 주 후보, 원래 v7, 현금, 추가 제거, 30분 제한, 비용 2배·3배, 추가 1분 지연, 원래 v14, 새 관리 모델의 고정 축소 대조다.

v10의 전체 수익성 기준을 그대로 적용한다. 2022년 이후도 이전 실험에서 이미 관찰했으므로 새 미사용 검증으로 부르지 않는다. 2021년 원본의 거래 수·시장 국면 차이, 반복 가설 선택, 실제 부분 체결 총량의 다음 거래 가능 시가 실행 근사를 함께 보고한다. 원본·모델·개별 결과는 로컬에 보존하고 실거래는 연결하지 않는다.

학습·보정 원장의 재생, 저장 모델 숫자·빈도 배율, 기존 v19의 기본 설정과 원래 v14의 출력 불변, 실제 프로세스 종료·분봉 재개 일치를 검증한다. 이 후보 실패도 전체 goal 완료 사유가 아니다.
