# 실험 v106 결과: 실제 신규 진입과 경계 표본

2026-10-11. [사전 계획](EXPERIMENT_V106.md)에 따라 원본 전체 XBTUSD 사건을 정수 수량으로 재생하고, 신규 진입·반전·관리 및 경계 상태를 독립 검산했다. 새 모형이나 매매 조건은 학습·선택하지 않았다.

실제 무포지션 진입 829개 중 810개가 2018년에 집중돼 있었다. 2020년은 17개, 2021년은 1개이며 최근 표본의 부족을 5분 경계 누락만으로 설명할 수 없다. 앞서 확인한 8개·1개는 지원되는 무포지션 창의 비영 정답 수로, 실제 진입 수와 구분해야 한다. 최근 행동을 더 자주 선택하게 하는 가중치 변경만으로는 이 학습 범위 차이를 해결하지 못한다.

이번에 고정한 Binance 시세 묶음은 2020~2025년을 포함하며 같은 14개 특징을 사용했다. 정확한 직전 확정 경계만 연결하고 보간하지 않았다. 표는 특징 가용성 진단이며, 새 학습의 전체 표본 지원·포지션 분리·성능 조건을 통과했다는 뜻이 아니다.

후속 파일 목록 점검에서 원거래소 BitMEX의 2018-03-01~2022-01-01 미만 5분 캐시도 확인했고 정규화 파일 해시가 manifest와 일치했다. 이번 표에 해당 특징을 혼합하지 않았으며 신규 진입의 원거래소 특징 지원은 아직 다시 계산하지 않았다. 후속 실험은 신호를 계산하는 거래소와 매매 시세의 거래소를 명시하고, 학습·실행 특징의 출처를 일관되게 유지해야 한다. 2018년의 진입 행동을 더 최근 연도에 그대로 일반화할 수 있다고 가정하지 않는다.

## 검증과 한계

신규 37개 검사와 Ruff를 통과했다. 정규화 원본 XBTUSD 944,968행의 모든 묶음 수량·비용·수수료·체결 수·최초 원본 행을 별도 정수 집계와 비교했다. 510,172개 사건의 전체 수량·행동·에피소드·공백·경계 상태와 모든 신규 진입의 시장·원본 연결, 전체·연도·월 요약을 독립 재생·검색·집계로 검산했다.

같은 시각에 반대 체결 방향이 있는 사건군은 2개다. 기존의 시각·최초 원본 행 순서를 유지했으며 거래소 내부의 유일한 순서를 복원했다고 주장하지 않는다. 원본 5개와 공개 소스 294개는 실행 전후 동일했고 기존 손실·무거래·미지원 결과를 보존했다.

시장 특징 가용성이나 신규 진입 수가 늘어도 곧바로 예측·수익성이 개선된 것은 아니다. 원본의 실제 상태를 봇 실행에 공급하지 않고, 후속 정보 시각·학습 정답·시간순 평가를 별도 고정한다. v10의 최종 수익성 기준과 전체 goal은 유지한다.
