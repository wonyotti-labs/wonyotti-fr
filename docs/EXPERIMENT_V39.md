# 실험 v39 사전 계획: 첫 관리 문턱의 자체 체결 적용

2026-10-04. v38은 첫 추가·축소 문턱에만 가산을 제거해 두 행동의 첫 재현율·F점수 개선과 전체 F점수 보존 조건을 통과했다. 독립 검증도 완료했으나 적중 표본은 적다. 동일 변경이 봇 자신의 실제 체결 상태에서 첫 주문 차단을 해소하고 순손익을 개선하는지 단일 후보로 검증한다.

## 고정 변경

- 기반은 v36이다. 진입·방향·관리 모형·절편·축소 크기, 최초 투입·추가 예산·손절·낙폭·비용·펀딩을 그대로 유지한다. 새 학습·문턱 검색은 없다.
- 동일 포지션에 해당 행동의 실제 과거 체결이 없을 때만 v38의 첫 추가·첫 축소 문턱을 그대로 사용한다. 주문 요청·거부·지연은 과거 체결로 취급하지 않는다.
- 청산 및 이미 같은 행동을 체결한 반복 추가·축소는 v36의 문턱과 배율 1.5를 그대로 유지한다. 15분 창에서 과거 주문이 빠져도 첫 행동 상태로 돌아가지 않는다.
- 실제 체결 이력·신규 포지션 초기화·가격 경로·3분 관리 대기·행동 우선순위·미체결 요청 중복 방지와 다음 봉 체결을 보존한다.
- v38 사전 진단의 모든 조건·모델 파일·문턱·입력 지문을 확인한다. 이전 후보의 모델·위험·최초 수량과 v36 전체 출력·최종 상태의 일치를 검사한다.

## 실행과 판정

2021년 후보·v36 대조 두 실행을 적합 진단으로 수행한다. 2022년 순수익 양수·종료 거래 30개 이상·영구 중지 없음 조건을 확인한다. 통과하면 두 후속 기간·세 시장의 기본 여덟 조건에 원래 위험의 v14와 동일 위험의 v31·v36을 더한 열한 조건, 아홉 독립 연도를 검증한다. 총 78개 실행이다. 실패하면 BTC 두 후속 기간과 세 독립 연도를 진단해 총 여덟 실행을 보존한다.

모든 후보 실행에서 자체 이력을 실제 체결 원장으로 별도 재구성하고 회계·활성 체결을 대조한다. 실제 프로세스 종료 후 대기·보유 복원과 월간 재개 전체 일치를 검사한다. 기존 후속 순손익·비용·지연·낙폭·표본·독립 연도 기준을 그대로 사용한다. 첫 주문 발생이나 한 거래의 큰 이익만으로 해결을 선언하지 않는다. 모든 기간은 이미 관찰했으며 원본·파생 자료·모델·개별 결과는 로컬에 보존하고 실거래는 제외한다.
