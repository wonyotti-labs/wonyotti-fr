# 후속 연구 v6: 최초 체결 시점의 해상도 검증

2026-10-01. v4·v5 평가와 2026년 9월의 무거래 결과를 관찰한 뒤 작성했다. 2026년 9월은 이제 관찰한 구간이다. 기존 평가 파일과 후보 선택은 바꾸지 않는다.

## 먼저 확인할 문제

5분봉 직후 시장가로 진입하는 봇과, 그 5분 안에서 더 유리한 가격에 체결된 원본을 구분해야 한다. v4의 최초 체결 연구에서 직전 5분 종가와 실제 최초 체결 가격 사이에 차이가 관찰됐다. 이 값에는 체결 전 시장 움직임과 표본 선택이 섞이므로 스프레드 수익이나 maker 효과로 단정할 수 없다.

새 후보를 추가 탐색하기 전에 원거래소 2018-03-01부터 2022-01-01 직전까지의 공식 1분봉으로 같은 독립 주문을 다시 연결한다. 기존 5분 자료는 보존하고 별도 폴더와 매니페스트를 사용한다. 공식 공개 자료만 읽으며 주문·인증·출금은 연결하지 않는다.

## 고정 진단

1. 원본 시각보다 엄격히 앞선 마지막 확정 1분·5분 종가를 같은 주문에 각각 연결한다. 실제 주문 제출 시각은 알 수 없다는 한계를 유지한다.
2. 이전 종가부터 실제 체결까지의 방향별 가격 차이를 연도·행동·유동성 공급 여부로 비교한다. 평균·중앙값·분위수와 연결 성공률을 모두 보고한다.
3. 최초 체결 5·15·60·240분 후 가격 변화는 설명용 결과 열이다. 입력 특징으로 사용하거나 손실 사례를 제거하지 않는다. 관찰 시점 오차를 1분 미만으로 줄인 결과와 기존 5분 결과를 구분한다.
4. 같은 기간의 1분봉 종가·거래량을 5분으로 집계해 기존 공식 5분 자료와 대조한다. 불일치는 원인별로 기록하며 원자료를 덮어쓰지 않는다.
5. 이 진단 이후에만 다음 전략 후보·후보 수·개발 범위를 별도로 고정한다. 높은 시간 해상도가 수익성을 보장한다고 가정하지 않는다.

공식 API 응답의 URL·로컬 해시·수집 범위·결측을 기록한다. 로컬 해시는 공급자 서명이나 과거 데이터의 불변성을 보장하지 않는다. BitMEX 봉의 open은 이전 종가이므로 실제 다음 봉 첫 체결 가격으로 사용하지 않는다.

## 전체 결과 확인 전의 보완 통계

2026-10-01, 전체 1분 자료 수집 중이며 첫 달의 집계 일치만 확인한 상태에서 고정했다. 같은 주문 쌍의 방향별 가격 차이 변화와 절대 가격 차이 감소에 대해 7일 달력 블록·1,000회·seed 0의 조건부 95% 구간을 추가한다. 60분 관찰을 연결한 주문을 연도·유동성별로 묶고 전체 주문과 노출 확대 주문을 각각 제시한다. 주문 수에 따라 가중하며 거래 없는 날도 포함한다. 관측일 14일 미만은 구간을 제시하지 않는다. 이 통계는 날짜별 집중의 영향을 설명하며, 다중 비교 보정이나 표본 선택·일반화 불확실성을 포함한 수익성 검정이 아니다.
