# 실험 v134 사전 계획: 누적 추가 횟수의 상태 혼합 진단

2026-10-12. v133은 37개 조건 중 23개만 통과했고 재시작 추가의 양성 123분을 모두 놓쳤다. 기존 입력 `adds_capped`는 원본 누적 추가 횟수를 5에서 자른다. 봇의 고정 설정도 추가 최대 5회이므로, 실제 5회와 그보다 훨씬 진행된 원본 상태가 같은 값으로 표현된다. 잘리기 전 횟수별 고정 예측을 진단해 이 차이가 누락에 어디까지 관련되는지 확인한다. 이전 턴은 모델 학습·실제 비교·실패 기록·푸시를 완료한 진행이다.

v19는 상한에 묶인 비중, v113은 이미 잘린 0~5 입력의 공동 상태를 조사했다. 이번에는 실제 누적 횟수를 복원해 v127/v133의 같은 분 예측을 분해한다. 상태 혼합이 손실 원인이라는 가정으로 시작하지 않으며 새로운 모델·문턱·행 선택·거래 제한을 정하지 않는다.

## 원본 횟수와 시간 복원

v133 완료 증거에서 v132·v127·원본 교사 표·체결 사건으로 이어지는 지문을 확인한다. 원래 학습 510,102행·보정 256,234행·진단 252,124행과 정답·24시간·포지션 경계를 모두 유지한다. 모든 기간은 이미 관찰했다.

기존 `teacher_states`의 정의로 누적 추가 횟수를 복원한다. 진입·반전은 횟수와 주문 집합을 초기화한다. 증가 사건에서 아직 본 적 없는 주문 키만 횟수를 늘린다. 나중 부분 체결, 최초 진입 주문의 후속 체결, 이미 축소로 관측한 같은 주문의 후속 증가를 별도 추가 주문으로 세지 않는다. 청산은 횟수 0으로 초기화하며 펀딩은 횟수를 바꾸지 않는다.

현재보다 엄격히 이전인 마지막 사건만 연결하고 같은 시각의 원본 순서를 유지한다. 원본 표의 `adds`, `adds_capped`, 상태 시각·진입 시각·방향·포지션과 대조한다. 독립 검산에서는 체결 방향과 수량의 누적 합으로 보유 수량·진입/반전 구간을 만들고, 구간별 첫 주문 키와 증가 여부로 횟수를 다시 계산한다. 행동 문자열로 만든 횟수를 그대로 재사용하지 않는다. 별도 시간순 순회로 모든 분의 원장 위치·시간 경계를 대조한다.

## 고정 구간과 예측 분해

- 누적 횟수 구간은 `0`, `1`, `2`, `3`, `4`, `5`, `>5`의 일곱 개로 고정한다. 5는 기존 입력과 봇 설정의 경계이며 손익·검출률을 보고 경계를 고르지 않는다. `all` 집계를 함께 보존한다.
- 축소·추가의 all/quiet/recent/first/restart 상태마다 같은 구간을 적용한다. 기존 v127과 가격 입력 v133의 상태 보정 부스팅 점수·요청을 그대로 사용한다. 다시 학습하거나 문턱을 바꾸지 않는다.
- 모든 기간·월·상태·구간의 행·양성 분·포지션 수·실제 횟수 범위와 두 모델의 TP/FP/FN·정밀도·재현율·F·로그 손실·Brier·평균 정밀도를 기록한다. 빈 구간과 양성 0개도 보존한다.
- 같은 상태의 일곱 구간을 합치면 전체 행·양성·요청·TP/FP/FN이 정확히 같아야 한다. 로그 손실·Brier의 행 수 가중 합도 전체와 대조한다. 평균 정밀도와 F는 구간 평균을 전체 지표로 사용하지 않는다.
- 추가에서 `0~4`는 추가 횟수 제한 하나를 아직 소진하지 않은 상태, `5 이상`은 그 제한에 닿은 상태다. 전자를 완전한 실행 가능 상태로 부르지 않는다. 청산 우선순위·대기·위험 제한·다른 상태 조건이 남아 있다. 원본 포지션의 횟수가 봇의 자체 포지션 횟수와 같다는 가정도 하지 않는다.

## 검산과 후속 판단

동시각 경계, 부분 체결, 최초 진입/반전 주문의 후속 체결, 축소 후 같은 주문의 증가, 포지션 초기화, 펀딩, 미래 사건 변경 시 과거 불변, 잘못된 수량·상태·출처·예측 손상을 검사한다. 독립 누적 계산·직접 지표 산식으로 모든 집계를 대조하고 기존 v127/v133의 전체 상태·월 지표를 재현한다. 새 출력 폴더와 실행 전후 지문·저장 후 동일성을 보존한다.

누락이 제한 전후 어디에 있든 원본 행을 사후 제외하거나 성공률을 다시 정의하지 않는다. 원인 근거가 충분할 때만 별도 사전 계획으로 입력 표현이나 학습·실행 상태 정렬을 비교한다. 진단으로 수익성 채택을 주장하지 않고 v10의 다년·다시장·비용·펀딩·지연·낙폭·표본·집중 기준과 기존 실패를 유지한다. 원본·원장·개별 예측은 로컬에만 두며 실제 거래 연결은 없다.
