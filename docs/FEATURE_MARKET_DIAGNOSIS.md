# 학습 특징과 실행 시장의 출처 진단

2026-10-11. v104 첫 실행은 모형 학습 전에 중단됐다. 원본 연결 표에 보존된 시장 특징을 실행용 Binance BTCUSDT 특징과 같은 값이라고 가정한 검사가 실패했다. 원본 표의 상위 사건 연구·활동 진단과 시세 지문을 따라 BitMEX XBTUSD 입력을 확인했다.

같은 특징 함수로 두 시장의 14개 특징을 다시 계산하고 모든 원본 시각에 정확히 연결했다. 시간 이동이나 허용 오차 조정은 하지 않았다.

| 원본 표 | 전체 행 | BitMEX 14개 특징 모두 정확히 일치 | Binance 14개 특징 모두 정확히 일치 |
|---|---:|---:|---:|
| 2020년 학습 | 104,148 | 104,148 | 0 |
| 2021년 진단 | 104,448 | 104,448 | 0 |

BitMEX의 2,920,344개 특징 값이 원본 표와 정확히 일치했다. 기존 표의 특징은 원거래소 시장 입력이고, v98 이후 자체 계좌의 실행 입력은 Binance 시장 특징이다. 같은 열 이름과 계산식이 같은 관측값을 뜻하지 않는다. 이 차이만으로 기존 손실·무거래의 원인이나 크기를 확정하지 않는다.

첫 실패는 학습과 매매 실행 이전이며 해당 실행·코드·계획·입력 지문·로그를 보존했다. 별도 진단에는 전체 행별 차이와 특징별 지표를 저장했다. 기존 원본 표나 과거 결과는 바꾸지 않았다.

[v104 보완 계획](EXPERIMENT_V104.md)은 새로운 두 모형의 학습·진단·실행 특징을 Binance로 통일한다. 원본 BitMEX 특징의 재현 검사와 신규 Binance 특징·실행 경계의 동일성 검사를 각각 수행한다. 이는 원본 정답을 Binance 거래 기록으로 바꾸는 작업이 아니다. 원본 계좌의 XBTUSD 정답과 다른 시장의 관측값을 연결하는 가정은 남아 있다. 시각 정렬의 효과는 새 두 모형 사이에서 비교하며 수익성 판정은 실제 연속 실행 이후로 유지한다.
