# 실험 v62 사전 계획: 청산 가치 입력의 경제적 상태 보완

2026-10-04. v61 금액 보정은 가중 평균 효과를 개선했지만 미보정 부스팅 대비 오차 개선 폭과 무가중 선택 효과에 미달했다. 보정 모형을 매매에 적용하지 않는다. 코드 검토에서 기존 50개 입력에 없는 현재 청산 추정 순손익이 v54의 실제 청산 문턱을 바꾸는 것을 확인했다. 또한 목표는 당시 순자산 대비 청산 순효과인데 실제 보유 명목가치의 순자산 비율이 입력에 없다. 같은 가격 이동·잔여 비율에서도 비용 누적과 노출 규모가 다르면 관리 선택과 목표 크기가 달라질 수 있다.

## 자료와 단일 변경

v60 전체 원장·입력 검증·학습·예측·지표를 다시 생성해 필수 출력과 정확히 대조한다. v60의 학습·진단 행과 포지션별 가중치, 원래 50개 입력, 순효과 정답, 전체 배제 원장을 그대로 사용한다. v61의 보정은 적용하지 않는다. 학습은 포지션 시작·판단이 2021년 1월 1일 이상이며 정답 종료가 9월 30일 전인 행, 진단은 포지션 시작·판단이 10월 2일 이상이며 정답 종료가 12월 31일 전인 행이다. 지원 조건은 v60 그대로다.

검증된 v59의 판단 당시 계좌 스냅샷에서 다음 두 입력만 추가한다. 실제 다음 체결 가격·향후 종료·미래 순손익은 사용하지 않는다. 원본 50개 입력을 삭제하거나 재계산 값으로 교체하지 않는다.

- `current_gross_exposure`: 현재 보유 수량 절댓값 × 현재 확정 종가 ÷ 현재 순자산.
- `current_exit_net_bps`: 현재 확정 종가로 청산할 때의 추정 포지션 전체 순손익 ÷ 현재 순자산 × 10,000. 이미 실현한 부분 손익·이미 낸 수수료·누적 펀딩·남은 수량 손익·현재 종가의 청산 슬리피지·예상 청산 수수료 포함.

스냅샷의 원자 연결·순서·전체 원장 대응과 읽기 전용 지문을 확인한다. 비양수 순자산·0 보유·비유한 입력은 조용히 제외하지 않고 오류로 중단한다. 경계 밖·미확정 행에도 현재 입력을 보존하며 모든 포함·배제 행이 원래 원장과 연결돼야 한다.

## 고정 후보와 판정

후보는 기존 50개와 새 2개를 사용하는 히스토그램 회귀 하나다. v60의 부스팅 설정을 그대로 사용한다. 64회·학습률 0.05·깊이 2·최대 말단 4·최소 말단 64·L2 1·구간 255·전체 특징·범주형 없음·조기 중지 없음·seed 0을 고정한다. v60과 같은 학습 행·포지션 가중치로 학습하며 표본·설정·문턱 검색은 없다.

대조는 그대로 재현한 v60의 50개 입력 부스팅·Ridge·학습 평균 상수다. 모든 진단 행에 대한 오차와 원래 청산을 보존한다. 추가 청산 선택은 예측 순효과가 0bp보다 크고 원래 청산 의도가 아닌 경우다. 다음 아홉 조건을 모두 요구한다.

1. 가중 평균 제곱 오차가 기존 부스팅·Ridge·상수 각각보다 1% 초과 개선: 세 조건.
2. 무가중 평균 제곱 오차가 기존 부스팅과 Ridge 각각보다 악화하지 않음: 두 조건.
3. 추가 청산 100행 이상·원래 포지션 30개 이상: 두 조건.
4. 선택한 실제 순효과의 가중·무가중 평균 모두 양수: 두 조건.

전체·방향·월별 오차·선택 수·포지션 수·실제 효과를 기록한다. 선택한 여러 시점의 효과를 더해 계좌 수익으로 표시하지 않는다. 실패 시 적용을 차단한다. 통과해도 전체 재학습·정책 적용은 별도 계획과 기존 다년·다시장·비용·표본·낙폭 검증을 요구한다.

## 검증과 한계

롱·숏·부분 실현·수수료·펀딩의 독립 현금 계산과 기존 엔진의 현재 청산 추정치를 대조한다. 기존 50개 입력이 같은데 비용·순자산을 바꾸면 새 입력과 실제 문턱이 달라지는 사례를 검사한다. 향후 체결·종료·정답 변경은 현재 입력을 바꾸지 않아야 한다. 모든 스냅샷의 새 두 입력, 기존 행·가중치·대조 모델·독립 재학습·숫자 내보내기·전체 지표·아홉 판정을 검산한다.

이번 비교는 현재 정책 상태를 설명하는 입력 보완이다. 원본 전략의 완전한 재현이나 수익성 확보가 아니다. 전체 시스템과 이전 연구가 이미 이 기간을 사용했다. 원본·파생 자료·개별 출력은 로컬에서 보존하고 Git에서 제외하며 실제 거래 연결은 추가하지 않는다. 전체 수익성 기준은 v10 그대로다.
