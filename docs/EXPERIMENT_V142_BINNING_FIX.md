# v142 구현 정정: 고정 정수 구간의 재표집 제거

2026-10-12. 원래 v142 계획과 가중치 생성 단계를 유지한다. 최종 비교의 첫 실행은 정수 구간 동등성 검사에서 중단됐다. 종료 코드 1, 당시 코드와 입력 지문, 실패 로그와 출력 폴더를 보존했다. 2021년의 새 후보 성적이나 42/48개 판정은 생성하지 않았다.

설치된 scikit-learn 1.9.1의 구간 매핑은 20만 행을 넘으면 가중치에 따른 복원 추출을 수행한다. 고유 수준 수가 255개 이하여도 이 추출은 먼저 실행된다. 최종 추가 학습 입력의 24,734,050개 원소 중 한 원소가 수준 9에서 8로 합쳐졌고 기존 검사가 이를 차단했다. 정수로 변환했다는 사실만으로 고정 구간을 보장할 수 없었다. 가중치 단계의 보조 모형이나 원래 무가중 구간을 바꾸는 오류는 아니다.

최종 **이미 변환된 정수 입력**의 구간 매핑에만 재표집을 제거한다. 원시 입력으로 학습하는 원래 모델·과거 보조 모델, 원래 무가중 구간, 두 원장과 양수 가중치, 부스팅·선형 설정, 보정·문턱·기간·판정은 유지한다. 모든 수준을 사용하면 255개 이하의 정수 고유값 사이 중점을 사용하므로 가중치에 따라 구간이 달라지지 않는다. 가중치는 손실 적합에 그대로 전달한다.

구현은 최종 학습기 인스턴스의 구간 적합에서만 subsample을 해제한다. 설치 라이브러리나 전역 상태를 수정하지 않는다. 정수 범위·연속 수준·양수 가중치와 실제 변환의 항등성을 검사한다. 별도 검산 학습기는 전체 정수 수준의 무가중 구간 적합으로 같은 경계를 만들고, 손실에는 원래 가중치를 적용한다. 원래 모델과 무가중 대조의 동등성 및 가중·무가중 수준 일치 조건은 그대로다.

20만 행 초과의 드문 수준 누락 재현, 전체 수준 보존, 잘못된 입력 차단과 기존 모든 최종 모델 검사를 추가한다. 작은 합성 표본만으로 재표집 경로를 검증한 것으로 간주하지 않는다. 수정 후 새 커밋·새 실행 폴더·새 종료 증거로 다시 비교하고 실패 실행을 덮어쓰지 않는다. 수익성 판단과 기준 완화는 없다.

수정 후 관련 434개 검사와 Ruff를 통과했다. 원본 행·두 가중치·동일 난수 시드의 구간 매핑만 따로 재현했을 때 기존 추가 매핑은 두 방식 모두 각각 한 원소가 달랐고, 수정 매핑은 네 행동·방식 조합에서 모두 원래 정수 입력과 정확히 일치했다. 축소는 수정 전후 모두 불일치가 없었다. 이 재현은 구간 원인 검산이며 최종 모형 성능이나 수익성 결과가 아니다.
