# 실험 v52 사전 계획: 기존 청산 점수의 판단 시간 범위

2026-10-04. v51의 범위 목표 직접 학습은 실패했다. 같은 진단에서 기존 v35 점수를 범위 목표에 보정한 대조는 더 많은 원래 청산 사건을 포착했다. 이는 이미 본 원본 상태의 설명 근거이며 새로운 독립 검증은 아니다. v48을 기반으로 모델을 그대로 유지하고 청산 문턱 선택의 목표 시간 범위만 바꾸는 단일 실행 후보를 계획한다. v50 재학습과 실패한 v51 신규 모델은 사용하지 않는다. v48 선택에는 이전 독립 연도 결과를 본 판단이 반영되어 있다.

## 고정 변경과 입력 대조

- 기존 v35 모델·절편·50개 특징을 그대로 사용한다. 청산 문턱만 v51에서 검증한 같은 포지션의 15분 정답과 2021년 상반기 보정 행으로 다시 계산한다. F2·예측 양성 최소 20개·동률 선택법을 유지하며 범위·문턱을 순손익으로 고르지 않는다.
- 원래 점수에서 직접 선택한 요청이 v51 기준 점수를 같은 목표에 절편 보정하고 선택한 요청과 상반기·하반기 모든 행에서 같아야 한다. 절편 재보정은 단조 변환인 만큼 별도 새 예측 정보를 추가하지 않는다. 하반기 원래 v48 문턱 대비 범위 목표 F2와 사건 포착이 낮아지면 매매 후보 생성을 차단한다.
- v51의 모든 입력 지문·시간 분할·원래 특징·연장한 정답 경계를 확인한다. v51 신규 모델의 실패는 그대로 보존한다. 같은 자료의 추가 대조를 새 진단 성공으로 세지 않는다.
- 진입 활동·방향·가격 대기, 첫·반복 추가와 축소, 수량·축소 크기·손절·최대 보유·중지·비용·펀딩·지연은 v48과 같다. 원래 모델·문턱 파일을 보존하고 범위 문턱과 근거를 별도 파일에 고정한다. 실행은 같은 평탄 청산이며 자동 반전하지 않는다.

## 실행과 채택 기준

2021년 후보와 원래 v48 대조를 기록하고 원래 정책의 전체 출력·최종 상태 일치를 요구한다. 2022년 순수익 양수·종료 거래 30개 이상·영구 중지 없음 조건 실패 시 BTC 후속 두 기간과 독립 세 연도만 진단해 총 여덟 실행을 보존한다.

통과 시 두 후속 기간·세 시장의 기본 여덟 조건에 원래 위험의 v14·v46·v48을 더한 열한 조건과 아홉 독립 연도를 수행해 총 78개 실행을 평가한다. 기본 조건은 후보·원래 v7·현금·추가 제거·30분 제한·비용 2배·3배·추가 1분 지연이다. 기존 표본·비용·다년·시장별 안정성·낙폭·최대 거래 집중·불확실성 보고 기준을 유지한다. 청산 요청이나 거래 수 증가 자체는 개선의 증거가 아니다.

독립 상반기 문턱·정답·예측 동등성, 자체 체결 이력·회계·진입 연결·시간 한도·실제 프로세스 종료와 월간 복원을 검증한다. 미래 매매 시세를 바꿔도 고정 문턱이 바뀌지 않아야 한다. 모든 기간의 사후 관찰과 기존 실패를 유지하고 원본·개별 파생 결과는 로컬에만 보존한다. 실제 거래 연결은 없다.
