# 실험 v66 사전 계획: 시간순 내부 선택으로 회귀 복잡도 점검

2026-10-04. v65 노출 변환은 앞 학습 오차를 줄였지만 뒤 진단 오차와 최초 선택 효과를 악화시켰다. 학습 적합 개선이 일반화 개선이라는 근거는 없다. 기존 고정 깊이 2·64회 모델의 표현력과 과적합을 구분하기 위해 복잡도 선택을 앞 학습 구간 안에서 수행한다. 노출 변환은 채택하지 않고 v64의 56개 현재 입력·원래 계좌 정답·포지션 가중치를 사용한다.

## 원장과 내부 시간 분리

v65를 이전 전체 원장 재현부터 다시 실행해 모든 대조·변환·최초 선택·주간 결과가 같음을 확인한다. 원래 94,105기회와 확정·미확정·경계 제외 원장을 보존한다. 기존 앞 학습 안에서 2021-01-01 이상 진입·판단부터 정답 종료가 2021-06-30 미만인 행을 내부 학습으로, 2021-07-02 이상 진입·판단부터 정답 종료가 2021-09-30 미만인 행을 내부 선택으로 사용한다. v61과 같은 포지션 분리와 최소 행·방향·기간 지원 조건을 적용한다. 각 내부 구간의 원래 포지션별 총 비중을 같게 하고 평균 가중치 1을 유지한다.

마지막 2021-10-02 이상 진입·판단부터 정답 종료가 2021-12-31 미만인 진단 구간은 복잡도 선택에 전달하지 않는다. 해당 구간은 전체 연구에서 이미 관찰한 기간이며 새 독립 평가라고 부르지 않는다.

## 고정 후보 네 개와 선택

후보는 깊이·최대 말단·반복 수가 각각 `(2,4,64)`, `(2,4,256)`, `(4,16,64)`, `(4,16,256)`인 네 개다. 학습률 0.05·최소 말단 64·L2 1·구간 255·전체 특징·범주형 없음·조기 중지 없음·seed 0을 유지한다. 임의 후보 추가나 깊이·기간·문턱 재검색은 없다.

네 모델을 내부 학습에만 적합하고 내부 선택의 원래 포지션 가중 평균 제곱 오차가 가장 낮은 하나를 선택한다. 정확한 동점은 위 목록에서 앞선 후보다. 각 후보의 학습·선택 오차, 선택 효과, 학습 평균 상수와 전체 예측·모델을 남긴다. 후보 선택 기준에 마지막 진단 지표·순손익·최초 선택 결과를 사용하지 않는다.

선택 뒤 해당 설정 하나만 원래 v64 전체 앞 학습으로 재학습하고 마지막 진단을 평가한다. 네 설정을 모두 마지막 진단에 적합·평가해 고르는 방식은 사용하지 않는다. 가중치·입력·계좌 기준 정답과 0bp 추가 청산 문턱은 v64 그대로다.

## 사전 비교 조건

대조는 그대로 재현한 v65 노출 변환, v64 의도 부스팅, v62 경제적 부스팅, v60 부스팅·Ridge·학습 상수 여섯 개다. 다음 열여섯 조건을 모두 요구한다.

1. 가중 제곱 오차가 여섯 대조 각각보다 1% 초과 개선: 여섯 조건.
2. 무가중 제곱 오차가 다섯 학습 대조 각각보다 악화하지 않음: 다섯 조건.
3. 추가 청산 100행 이상·30포지션 이상: 두 조건.
4. 선택한 실제 계좌 효과의 가중·무가중 평균 양수: 두 조건.
5. 최초 선택과 선택 없음의 0을 포함한 전체 공통 기준 포지션 평균 효과 양수: 한 조건.

전체·방향·월별 지표와 후보·v64의 최초 선택·방향·진입 월별 지표를 기록한다. 같은 13주 블록·1,000회·seed 63으로 공통 효과와 짝지은 차이의 2.5·97.5 백분위를 기록한다. 블록 구간으로 후보나 문턱을 다시 고르지 않는다.

## 검증과 후속 범위

숫자 모델은 허용한 네 설정만 지원하며 반복·깊이·노드 수·연결·숫자·특징을 검증한다. 기존 깊이 2·64회 모델의 형식과 모든 출력은 그대로 유지한다. 네 내부 모델 및 선택한 전체 재학습의 라이브러리 예측·전체 트리·초기 값을 독립 대조한다. 내부 선택의 정답·입력 변화가 내부 학습 모델을 바꾸지 않아야 하며 마지막 진단 변경이 네 후보·선택·최종 학습 모델에 영향을 주지 않아야 한다. 모든 시간 경계·가중치·오차·선택·열여섯 판정·최초 효과·블록 결과·원본 지문을 검산한다.

실패한 후보나 구간을 삭제하지 않는다. 통과해도 별도 계획의 연속 매매 검증이 필요하며 v10의 다년·다시장·비용·표본·낙폭 기준은 그대로다. 원본·가공 자료·모델은 Git에서 제외하고 실제 거래 연결은 추가하지 않는다.
