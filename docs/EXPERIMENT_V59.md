# 실험 v59 사전 계획: 보유 유지와 즉시 청산의 순효과 정답

2026-10-04. v58의 손절 확률 분리도 상수보다 확률 예측이 개선되지 않았고 금액 오차 조건에 미달했다. 기존 입력만으로 진입 시점에서 손절을 충분히 가려낸다는 근거를 얻지 못했다. 진입 이후 실제 가격·수량·과거 체결 상태가 드러났을 때 청산 판단을 개선할 수 있는지 연구하기 위해, 기존 관리 정책 유지와 청산의 경제적 차이를 먼저 복원한다. 이번 단계는 정답 생성과 검증만 수행하며 새 모델이나 봇 수익을 평가하지 않는다.

## 전체 기회와 같은 계좌 상태

- 기준은 고정 v54의 2021년 연속 실행이다. v56의 실패한 진입 필터는 사용하지 않는다. 원래 방향·진입·추가·축소·청산·위험·비용·펀딩·보유 한도는 그대로다.
- 모든 UTC 5분 경계에서 실제 관리 특징 계산이 이루어진 보유 판단을 수집한다. 관리 대기·입력 미지원·평탄·중지로 특징 계산이 없었던 경계도 건수와 사유를 기록한다. 미래 손익이나 종료 사유로 기회를 고르지 않는다. 기존 청산 요청도 포함해 같은 청산의 차이가 0인지 대조한다.
- 입력은 그 판단에서 기존 정책에 실제로 전달된 50개 시장·보유·과거 체결 특징이다. 판단 직후 계좌·보유·위험·정책 상태와 현재 순자산을 보존한다. 미래 종료 사유·가격·최종 손익은 특징에 넣지 않는다.
- 같은 상태에서 다음 대기 의도만 전량 청산으로 바꾼 별도 계좌를 만든다. 다음 거래 가능한 분봉부터 기존 엔진의 수수료·슬리피지·펀딩·갭 손절·위험 우선순위를 그대로 적용한다. 거래 없는 봉에서는 대기하며 닫힌 뒤 재진입하지 않는다. 기존 0 추가 지연 설정만 지원하고 지연·대기열을 임의로 제거하지 않는다.
- 유지 경로의 현재 포지션 종료 현금은 원래 전체 체결·거래·계좌 재생과 연결한다. 원래 이전 종료 거래 누적 손익과 현재 거래 순손익으로 계산하며 원래 연속 계좌 전체 출력과 최종 상태가 정확히 같아야 한다. 청산 반사실의 현금은 같은 시작 상태에서 독립 실행한다. 이후 새 진입의 이익은 양쪽 비교에 넣지 않는다.

## 정답·경계·재개

정답은 `(청산 경로 최종 현금 − 유지 경로의 현재 포지션 종료 현금) / 판단 당시 순자산 × 10,000`이다. 양수·음수·0을 모두 보존한다. 이는 현재 고정 정책에 대한 한 포지션의 청산 순효과이며 미래 최적 청산이나 새 정책의 장기 수익을 뜻하지 않는다. 새 정책이 다른 상태를 방문하는 한계도 남는다.

양쪽 모두 2021년 12월 31일 00:00 UTC 전에 자연 종료한 경우만 확정 정답으로 삼는다. 마지막 24시간·원래 마지막 강제 종료·어느 한쪽의 미종료는 배제 사유와 함께 보존한다. 정답 종료 시각은 양쪽 종료 봉의 늦은 경계다. 손실·손절·위험 종료를 버리지 않으며 마지막 가격 강제 청산으로 정답을 만들지 않는다.

입력·부모 선택·시세·코드·계획 지문과 완료 기회별 저장 연결을 검증한다. 중단 뒤 같은 입력에서 원래 경로를 재생해 기회와 상태를 다시 대조하고, 저장된 완료 반사실은 재사용한다. 부분 처리 한도는 점검용이며 전체 실행과 원장 검증 전에는 학습 가능한 완료로 표시하지 않는다. 재개 시도별 재생 출력과 실패 기록을 보존한다.

## 검증과 다음 단계

롱·숏·비용·펀딩·무거래 대기·위험 우선순위·경계 미확정·동일 청산·손실 회피와 이익 포기 사례를 수기로 대조한다. 실제 프로세스 저장 중단·재개, 입력 변경·저장 변조·기회 누락 거부를 검증한다. 전체 원래 출력·최종 상태와 현재 입력을 대조하며 모든 청산 반사실 현금 흐름·수량·수수료·펀딩 및 고정 간격의 유지 경로 표본을 별도 엔진으로 재생한다.

종료 포지션·월·방향별 지원과 정답 분포를 보고한다. 같은 원래 포지션의 여러 결정은 의존하므로 행 수를 독립 거래 수로 부르지 않는다. 시간순 분리·학습·후속 매매 적용은 정답 검증 후 별도 계획으로 고정한다. 이미 관찰한 구간과 실패를 유지하며 원본·파생 자료는 Git 제외, 실제 거래 연결도 제외한다. 전체 수익성 기준은 v10 그대로다.
