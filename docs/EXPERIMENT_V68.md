# 실험 v68 사전 계획: 최초 청산 선택을 기준으로 한 실행 문턱 보정

2026-10-04. v67의 주간 재학습은 반복 선택의 가중 효과를 양수로 바꿨지만 무가중 및 실제 최초 선택 효과는 음수였다. 예측값이 0을 조금 넘는 순간 즉시 청산하는 판단이 첫 실행에 적합한지 점검한다. 모델의 오차 개선을 주장하는 실험이 아니라 같은 고정 점수에서 실행 문턱만 선택하는 별도 의사결정 보정이다. 이전 실패는 그대로 유지한다.

## 고정 모델과 시간 분리

v67과 이전 모든 원장·모델·주간 학습 가용 시각·예측을 재현한다. 후보 모델은 v66 내부 후보의 기존 `depth2_iter64` 하나다. 2021-01-01 이상 진입·판단부터 정답 종료가 2021-06-30 미만인 행으로 이미 학습한 56개 입력 모델을 그대로 사용한다. 모델을 다시 선택하거나 전체 앞 구간으로 재적합하지 않는다. 뒤 구간의 점수 분포가 보정 대상과 달라지는 재학습도 이번에는 하지 않는다.

문턱 선택은 기존 2021-07-02 이상 진입·판단부터 정답 종료가 2021-09-30 미만인 내부 선택 행에서만 수행한다. 마지막 2021-10-02 이상 진입·판단부터 정답 종료가 2021-12-31 미만인 행은 문턱 선택에 사용하지 않는다. 전체 연구에서 이미 관찰한 기간이며 새 독립 평가라고 부르지 않는다.

## 사전 문턱 목록과 선택

후보 문턱은 계좌 순효과 기준 `0, 0.5, 1, 2, 4, 8bp` 여섯 개다. 예측이 문턱보다 엄격히 크고 원래 요청이 청산이 아닐 때 추가 청산을 선택한다. 같은 원래 포지션에서 최초로 선택된 기회만 실제 첫 효과로 계산하며 선택 없음은 0, 첫 이용 가능 판단의 공통 순자산 기준과 모든 손실을 유지한다. 더 나중의 좋은 손익을 골라 대체하지 않는다.

내부 선택에서 최초 선택 포지션이 30개 이상이고 전체 포지션 공통 기준 평균 효과가 양수인 후보만 적격이다. 적격 후보 중 이 전체 평균 효과가 가장 큰 문턱을 선택하며 정확한 동점에서는 더 높은 문턱을 사용한다. 선택 문턱의 평균이 0bp 문턱보다 엄격히 커야 한다. 적격 후보가 없거나 개선이 없으면 문턱 선택 실패로 기록하고 새 문턱의 마지막 평가·매매 적용을 차단한다. 모든 여섯 후보의 선택·손실·미선택·지표와 탈락 사유는 보존한다.

## 마지막 진단과 판정

선택에 성공하면 같은 고정 모델과 선택한 문턱 하나만 마지막 구간에 적용한다. 직접 대조는 같은 반년 모델의 0bp 문턱이다. 기존 v64 고정 모델과 v67 주간 모델, 다른 과거 대조도 보존한다. 문턱이 바뀌어도 점수·정답·모델·회귀 오차는 같아야 하며, 변하는 선택 결과를 예측 정확도 개선으로 표시하지 않는다.

다음 열 가지 조건을 모두 요구한다.

1. 내부 선택 지원·양수 효과·0bp 대비 개선 조건 통과.
2. 마지막 구간 추가 청산 기회 100개 이상.
3. 마지막 구간 최초 선택 포지션 30개 이상.
4. 선택 기회의 원래 가중 평균 실제 효과 양수.
5. 선택 기회의 무가중 평균 실제 효과 양수.
6. 선택 없음의 0을 포함한 전체 최초 선택 평균 효과 양수.
7. 같은 고정 반년 모델의 0bp보다 전체 최초 선택 평균 효과 개선.
8. 기존 v64 모델보다 전체 최초 선택 평균 효과 개선.
9. 후보 최초 효과의 주간 블록 95% 구간 하한 양수.
10. 후보와 같은 반년 모델의 0bp 차이의 짝지은 주간 블록 95% 구간 하한 양수.

기존 13개 주간 블록·1,000회·seed 63·2.5 및 97.5 백분위를 그대로 사용한다. 전체·방향·월별 행 지표와 최초 선택·방향·진입 월별 결과를 남긴다. 여섯 문턱의 내부 선택을 반복한 연구라는 한계를 유지한다. 마지막 구간의 결과로 문턱을 다시 바꾸지 않는다.

## 검증과 후속 범위

기본 0bp 동작은 기존 모든 결과와 같아야 한다. 문턱 경계·동점·지원 부족·선택 실패·양수 및 음수 최초 효과를 독립 계산한다. 미래 정답·뒤 구간 점수 변경이 내부 문턱을 바꾸지 않아야 한다. 고정 반년 모델·원래 행·가중치·점수·회귀 오차 보존, 모든 최초 선택·열 가지 조건·주간 비교와 원본 지문을 검증한다.
