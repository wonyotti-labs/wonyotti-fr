# 실험 v104 사전 계획: 완료된 행동 창과 시장 관측 시각의 정렬

2026-10-11. [v103](EXPERIMENT_V103_RESULTS.md)의 기록 공급 진단에서는 창 종료 후·가격 손절 없음의 두 조건만 양수였고, 창 시작 공급과 4% 손절 조건은 모두 손실·영구 중지였다. 사후 기록 공급을 예측 전략으로 사용할 수는 없다. 이번에는 실제 공급되는 원본 신호를 제거하고, 이미 끝난 5분의 시장 정보가 그 창의 행동을 설명하는지 학습한다.

v100은 창 시작의 시장 정보로 다음 5분의 행동을 맞히려 했다. 거래자가 그 5분 중 새로 나타난 정보에 반응했다면 관측 시각이 어긋날 수 있다는 가설이다. v103 결과가 이 가설을 증명한 것은 아니므로 동일 행·정답·설정의 창 시작 대조를 둔다. 기존 빈도 보정·문턱 변경·원본 과거 체결 이력의 실패를 보존한다.

## 자료와 정보 경계

v102의 2020년 학습·2021년 진단 전체 원본 행과 지원 사유를 사용한다. 정답은 XBTUSD만의 `xbtusd_execution_change`다. 전체 계좌 정답을 바꿔 과거 결과를 덮어쓰지 않는다. 다른 계약이 포함된 행이나 손실 거래를 사후 제외하지 않는다.

원본 창 [s, e)의 정답 하나에 다음 두 시장 입력을 정확한 시각으로 연결한다.

- 후보: e까지 확정된 14개 시장 특징으로 이미 끝난 [s, e)의 XBTUSD 변경량을 추정한다. 판단 시각은 e, 체결은 그 다음 거래 가능한 분봉 시가다.
- 대조: s까지 확정된 같은 14개 시장 특징으로 [s, e)의 변경량을 예측한다. 판단 시각은 s이며 기존 선행 예측 방식과 같다.

최근값 보간이나 가까운 시각 연결은 하지 않는다. 원본 전체 표에는 두 시각의 연결·유한성·지원 여부와 사유를 남긴다. 학습과 짝지은 지표 비교는 원본 분해 및 두 시각의 시장 특징이 모두 지원되는 동일 행만 사용한다. 시간 구간 밖·연결 없음·미지원은 삭제하지 않고 별도 집계한다. 학습의 두 결정 시각 모두 2021-01-01 이전이어야 하고, 진단의 두 결정 시각도 기존 2021년 범위 안이어야 한다.

원본 현재·종료 노출, 체결 이력, 지갑, 수량, 다음 창 값은 입력 특징에서 제외한다. 특히 종료 노출에 정답 행동이 이미 반영되는 상태 누출을 막는다. 실행 정책에는 학습된 숫자 모형과 현재까지 확정된 시장 특징만 공급한다. 원본 기록이나 실제 타인의 신호를 조회하는 경로를 만들지 않는다. 봇 자신의 현재 수량·평가액은 예측 변경량을 목표 노출로 바꿀 때만 사용한다.

## 고정 모형과 지표

각 시각에 분류기 한 개·음수 및 양수 크기 회귀 두 개를 학습한다. v100과 같은 HistGradientBoostingClassifier의 log_loss, 회귀 squared_error, 반복 64회·학습률 0.05·깊이 2·말단 4개·최소 말단 64·L2 1·최대 구간 255·조기 종료 없음·seed 0·클래스 가중치 및 재표집 없음으로 고정한다. 두 조건 모두 시장 특징 14개만 사용한다. 원본 상태를 포함했던 v100 모형을 동일 입력 대조라고 부르지 않는다.

1e-12 이내의 정답은 거래 없음이다. 각 행동 128개·총 1,000개 이상 학습 행을 요구하고 부족하면 기준을 낮추지 않는다. 방향별 크기 회귀는 해당 방향의 절댓값만 학습하고, 음수 크기 예측은 0으로 제한한다. 큰 정답을 사후 삭제·절단하지 않는다.

두 시각의 분류 대조로 학습 빈도 상수와 학습 전용 표준화·LogisticRegression(C=1, lbfgs, max_iter=2000, 가중치 없음, seed=0)를 사용한다. 크기는 방향별 학습 중앙값, 합성 변경량은 0 변경을 대조로 둔다. 2021년 전체·12개월의 로그 손실·혼동행렬·방향별 AP와 재현율·예측 행동 수·변경량 MSE/MAE를 기록한다. 전체 거래 없음 예측도 보존하며 지표를 보고 모형·시각·문턱을 선택하지 않는다.

## 원본 신호 없는 자체 계좌 실행

최대 확률 행동을 선택하며 동률·거래 없음·1e-12 이내 크기는 `None`으로 수량을 유지한다. 증가·감소 행동은 `현재 봇 수량 × 확정 종가 / 평가액 + 예측 변경량`을 [-0.5, 0.5]로 제한한다. 다음 분봉 시가·거래 없는 봉·비용·펀딩·청산·반전은 검산된 노출 실행기를 사용한다.

두 학습 시각 × 가격 손절 {0, 4%} × BTC {2021, 2022년}의 여덟 경로를 모두 실행한다. 학습이 지원되면 분류 지표가 나쁘거나 무거래라도 실행과 실패를 보존한다. 초기 10,000 USDT·수량 0·수수료 5bp·슬리피지 3bp·실제 펀딩·상한 0.5·최대 보유 77,699분·대기 15분·일일 손실 3%·최대 낙폭 25%를 유지한다. 두 연도의 전체 시세 입력은 v98·v100과 같아야 한다.

주 후보는 창 종료 학습·가격 손절 0이며 다른 세 조건은 대조다. 이 설정은 이미 관찰한 2021년 v103 진단 이후 고정한 후속 가설이며 미관찰 검증이라고 부르지 않는다. 이번 실험의 성과로 대조를 주 후보로 바꾸지 않는다. 기존 v98·v100 손실·무거래와 v103 기록 공급 여덟 결과를 해시로 연결한다. v103을 예측 모형이나 동일 정보 조건의 기준 수익률로 간주하지 않는다.

2022년 주 후보가 비용 후 양수·종료 거래 30개 이상·영구 중지 없음 조건을 모두 충족하면 고정 모형을 BTC 2023~2025년 연속·2026년 1~9월·2023/2024/2025 독립 연도·ETH·SOL·비용 2배/3배·지연 1분으로 확대한다. 미달이면 문턱이나 시점을 재선택하지 않고 실패를 보존한다. 기존 v10 최종 수익성 기준은 유지한다.

## 독립 검산과 공개 범위

합성 검사에서 정확한 창 경계·시각 전후 특징·시간 구간 경계·지원과 누락 보존·동일 학습 행·상태 입력 배제·미래 변경 불변성을 확인한다. 원본 정답이나 다른 원본 상태를 바꿔도 이미 학습된 실행 정책의 같은 시장 입력 예측은 달라지면 안 된다. 후보의 완료 창 정보 사용과 대조의 선행 예측을 섞지 않는다.

별도 시각 검색으로 전체 연결 행을, 독립 라이브러리 재학습으로 두 조건의 분류·크기 트리와 선형 대조를, 별도 스칼라 추론으로 전체 확률·크기를 비교한다. 실제 여덟 경로의 모든 분봉·판단·목표·체결·종료 거래·회계·지표와 두 중간 JSON 상태를 독립 검산한다. 코드·계획·입력은 실행 전후 고정한다. 원본·파생 자료·모형·개별 출력은 Git에서 제외하며 실제 주문·인증 연결은 없다.
