# 실험 v125 사전 계획: 고정 관리 요청의 시간 군집과 일대일 대응

2026-10-12. v124에서는 축소·추가의 순위 개선이 전체 요청 개선으로 이어지지 않았다. 새 입력·문턱을 다시 탐색하기 전에 잘못된 요청의 시간 구조를 분해한다. v32의 2분 허용 진단과 v51의 15분 청산 정답 학습을 반복하지 않는다. 이번 비교는 v124에 이미 봉인된 세 모델의 모든 관리 행동에 대한 오탐 군집과 **중복 대응을 금지한 양성 분 포착**이다.

## 고정 입력

- v124의 학습 2020년·보정 2021년 상반기·진단 하반기 전체 예측을 사용한다. native 64회, capacity 256회, 극값 시계 aged 256회의 보정 확률과 첫/전체 문턱을 그대로 사용한다. 모델·정답·행·기간·문턱·매매 정책 변경은 없다.
- 입력 파일 봉인과 v124 완료 증거, 원본 교사 자료의 지문을 연결한다. 원본 시각·포지션·정답·과거 행동 여부 및 저장된 문턱 통과를 전수 대조한다.
- 단위는 독립 주문 건수나 실제 계좌 종료가 아닌 **기존 정답의 양성 분**이다. 같은 분 여러 독립 주문을 하나의 분으로 채점하는 기존 의미를 유지한다. 문턱 통과는 행동별 독립 마스크이며 실제 주문·우선순위·크기·대기를 적용한 실행 결과가 아니다.

## 사전 고정 분해

1. 각 기간·모델·행동의 정확한 분 TP/FP/FN과 요청·양성 수를 재현한다. 27개 조합 모두 보고한다.
2. 같은 포지션에서 각 FP의 1~14분 후 정답, 1~14분 전 정답 존재를 검사해 미래만·과거만·양쪽·범위 밖·같은 포지션 정답 없음의 상호 배타적 다섯 집단으로 나눈다. 15분 경계는 제외한다. 과거 정답 근처의 요청을 성공 예측으로 해석하지 않는다.
3. 정확한 분 TP를 먼저 일대일 고정한다. 남은 요청과 양성 분에서 선행(정답−요청 1~14분), 후행(−14~−1분), 양방향(절댓값 1~14분)의 최대 일대일 대응을 각각 독립 계산한다. 같은 요청이나 양성 분의 중복 사용을 금지한다. 정확한 분 고정 제약 아래의 대응 수이며 제약 없는 최대치로 표시하지 않는다. 느슨한 존재 여부 포착 수와 비교해 중복 대응에 의한 과장을 드러낸다.
4. 같은 포지션에서 연속 요청 간격이 3분 이하인 요청들을 군집으로 묶는다. 군집 수·단일 요청 군집·최대 요청 수·최대 지속 분·전부 FP인 군집과 그 요청 수를 보고한다. 3분은 기존 관리 대기 길이이며 군집의 연결 기준일 뿐 실제 대기 정책 재생이나 요청 삭제가 아니다. 포지션·기간 경계를 넘겨 묶지 않는다.

## 검산과 후속 해석

시간순 두 포인터 대응과 별도 이분 그래프 최대 대응으로 건수를 검산한다. FP 분류는 직접 시간 차이로, 군집은 별도 순회로 검산한다. 경계 0/1/14/15분, 동일 분 고정, 다수 요청과 하나의 정답, 하나의 요청과 다수 정답, 포지션 격리, 비정렬·중복·비유한·시간 단위 오류를 합성 검사한다. 기간별 전체 입력·결과·검산 지문과 코드 스냅샷을 보존한다.

이번 진단에는 수익성 채택이나 새 계좌 실행 조건이 없다. 가까운 FP도 기존 채점에서는 FP로 보존하며, 결과가 좋아 보여도 v124 미채택을 바꾸지 않는다. 시간 근접성이 크면 실행 중복과 시점의 후속 가설을 구체화하고, 작으면 단순 시간 이동을 해결책으로 제시하지 않는다. 이미 관찰한 기간의 설명적 진단이며 수익 개선의 인과 증거가 아니다. 원본·모형·행별 결과는 로컬에만 보관하고 기존 v10 최종 검증 범위를 유지한다.
