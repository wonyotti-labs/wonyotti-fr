# 실험 v123 결과: 일간 변동성 단위의 보유 가격 경로

2026-10-12. 사전 31개 조건 중 23개를 통과해 후속 계좌의 예측·요청 조건에 미달했다. 새 계좌 실험으로 확대하지 않았다. 수익성 문제는 미해결이다. [계획](EXPERIMENT_V123.md)에 따라 기존 50개 입력에 현재·최선·최악·되돌림의 방향 보정 로그 가격 경로를 일간 변동성으로 나눈 네 값을 추가했다. 원래 분할·정답·행·기존 세 모형을 보존했다.

하반기 로그 손실은 기존 64회 대비 세 행동 모두 줄었지만, 청산은 34개 중 적중 0개·오탐 22개였다. 같은 크기 256회 대비 세 행동 AP가 모두 낮아졌고 기존 64회 대비 전체 F도 모두 낮아졌다. 기존 대비 청산·축소 AP 두 조건, 전체 F 세 조건, 같은 크기 대비 AP 세 조건의 총 8개 미달이다. 확률 오차 개선을 행동 재현이나 수익 개선으로 대신하지 않는다.

첫 축소는 기존 적중 1개·오탐 13개에서 적중 5개·오탐 121개로 바뀌었다. 재현율과 F는 개선됐지만 정밀도는 낮아졌다. 첫 추가는 적중 2개를 유지했고 오탐은 14개에서 13개로 줄었으나 반복 추가 적중은 10개에서 7개로 감소했다. 좋은 상태의 일부 개선만으로 후보를 채택하지 않았다. 새 네 입력은 세 행동의 트리에서 모두 사용됐으므로 입력이 전혀 쓰이지 않은 결과는 아니다.

## 사후 진단: 평균 오차와 청산 문턱의 차이

아래는 완료한 실행을 읽은 사후 설명이다. 새 모델·문턱을 선택하거나 매매 성과를 계산하지 않았다. 새 청산 문턱은 상반기에서 0.03490365658로 정해졌지만, 하반기 실제 청산 34개 행의 새 점수 최댓값은 0.03211269823이었다. 따라서 해당 문턱에서는 실제 청산을 한 건도 요청할 수 없었다. 원래 64회 문턱은 0.01445891587, 같은 크기 256회 문턱은 0.01135272408이다. 모형마다 점수 분포가 다르므로 다른 모형의 문턱을 옮겨 성공을 주장하지 않는다.

하반기 로그 손실을 실제 행동 행과 비행동 행으로 나누었다. 행동 행은 −log(p), 비행동 행은 −log(1−p)의 평균이며, 각 합을 전체 행 수로 나눈 기여를 더해 저장된 전체 로그 손실과 1e-12 이내로 대조했다. 아래 값은 클래스별 평균이어서 단순히 더하는 값이 아니다.

| 행동 | 모델 | 실제 행동 행의 평균 손실 | 비행동 행의 평균 손실 |
| --- | --- | --- | --- |
| 청산 | capacity256 | 6.300279104 | 0.0001450004091 |
| 청산 | scaled256 | 6.414101196 | 0.0001250676395 |
| 축소 | capacity256 | 4.576532555 | 0.001295994713 |
| 축소 | scaled256 | 4.548942936 | 0.001320344681 |

같은 크기 대비 청산·추가는 실제 행동 행의 평균 손실이 나빠졌지만 비행동 행의 개선으로 전체 손실이 작아졌다. 축소는 반대 방향이었다. 모든 행동의 실패를 하나의 평균 오차 설명으로 묶지 않는다. 청산 적중 0개의 직접 조건은 문턱과 점수 범위의 불일치이며, 세 행동의 순위 저하는 문턱 변경만으로 해결되는 문제가 아니다. 상반기 청산 AP는 같은 크기보다 개선됐지만 하반기로 이어지지 않았다. 앞선 v52의 낮은 문턱·잦은 거래 실패와 v122의 이진 균형 학습 실패도 보존한다.

## 검산·한계·후속

신규 25개와 관련 109개, 총 134개 검사 및 Ruff를 통과했다. 롱·숏 가격 비율, 작은 되돌림, 0 변동성 하한, 비정상 입력과 변조, 모형 형식·설정·숫자 추론, 미래 정답 변경과 원래 대조 보존을 검사했다. 관련 검사 첫 호출은 파일명 오류로 수집하지 못했고 정확한 파일명으로 다시 실행해 통과했다. 해당 오류 로그도 남겼다. 전체 테스트 모음이나 최신 원격 CI 통과는 주장하지 않는다.

실제 실행은 종료 코드 0으로 완료했다. 새 4,073,840개 입력을 행별 스칼라 계산으로, 새 768개 트리와 선형 계수를 독립 재적합으로 대조했다. 세 기간 1,018,460행의 전체 확률·절편·문턱·모든 월·네 이력 조합·변동성 구간·31개 조건을 검산했다. 기존 native64/capacity256/linear50은 v121의 봉인된 적합 근거를 확인하고 복원했으며 모든 기간의 점수·요청·문턱·월별 지표가 기존 저장 결과와 정확히 일치했다.

공개 모듈 349개와 총 368개 파일의 시작·종료 지문이 같았다. 기존 모형을 이번 실행에서 새로 학습했다고 주장하지 않는다.
