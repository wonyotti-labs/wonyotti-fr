# 실험 v74 사전 계획: 분별 청산 기회의 전체 복원

2026-10-09. v73의 이후 청산 비교 정답은 분류 지표를 개선했으나 최초 청산 효과가 음수였고 v72보다 나빠 미채택했다. 별도 시각·의도 대조에서 봇의 적격 관리 판단은 매분 존재하지만 v59 이후 정답은 5분 경계에서만 수집된 차이를 확인했다. 이 차이를 손실 원인으로 단정하지 않고 빠진 판단 시점을 복원한다.

## 고정 범위

기존 v54의 동일한 2021년 BTC 개발 경로·모델·위험·수량·수수료·슬리피지·펀딩·분봉·확정 특징을 사용한다. 원래 체결·거래·잔고·최종 상태를 그대로 재생한다. 5분마다 보던 수집 간격만 1분으로 확장하며 가격·손익·의도에 따라 시점을 고르지 않는다. 실제 관리 입력 호출이 있고 잔량이 남은 모든 분을 수집한다. 관리 대기·무포지션·위험 중지 등 제외 사유도 전부 기록한다.

새 모델·문턱·후보 선택과 연속 매매 성과 평가는 이번 단계에 없다. 원래 v59와 모든 후속 실패를 보존한다. 2021년 경로는 전체 2021년까지 학습한 진입 부모 등의 개발 적합 경로이며, 분별 확장이 봇 전체의 당시 가용 검증을 만들지는 않는다.

## 정답과 보존

각 판단 직후의 동일한 계좌·보유·대기·관리 상태에서 기존 정책 유지와 다음 거래 가능한 시점의 전량 청산을 비교한다. 기존 `close_effect_label`의 자연 종료 현금·즉시 청산 현금·판단 순자산 환산과 원래 50개 입력을 그대로 쓴다. 5분 시장 입력은 당시 확정된 값만 유지하며 분별 입력도 현재 확정 분까지만 사용한다. 미래 체결 가격·결과는 정답과 검산에만 저장한다.

수수료·슬리피지·펀딩·무거래 대기·가격 갭 손절·일별 손실·낙폭·보유 한도·부분 체결을 기존 엔진 그대로 반영한다. 2021-12-31 미만에서 확정된 결과만 확정 정답이며, 마지막 강제 종료·미확정·경계 밖·입력 부족·0 효과·손실을 제거하지 않는다. 원래 exit 의도를 늦추는 반사실은 이번 정답에 없다.

새 결과의 모든 5분 경계 행을 기존 v59 원장과 전체 열·행·시각·입력·손익·상태별로 정확히 대조한다. 일부 실행 재개 시에도 완료한 접두 구간의 교집합을 대조한다. 별도 새 폴더·원자 저장 원장·입력과 구현 지문을 사용하고, 재개 시 자료·수집 간격·구현 변경을 거부한다. 완료한 실행은 덮어쓰지 않는다.

## 완료 조건

1. 전체 원래 분봉 재생과 잔고·체결·거래·최종 상태의 동일성.
2. 적격 분별 시각과 원장 시각·원래 의도의 전수 연결, 중복·누락 없음.
3. 기존 5분 원장의 모든 행과 정답의 동일성 및 기존 파일 지문 불변.
4. 전체 새 원자 기록의 계좌·수량·수수료·슬리피지·펀딩·손익·정답 가용 시각·입력 검증.
5. 분 경계·무거래·위험 청산·미확정 결과·실제 중단과 재개·미래 값 변경 검사의 통과.

행 수 증가를 독립 거래 수 증가로 해석하지 않는다. 결과별·방향별·월별 지원을 기록하고 후속 학습에는 원래 포지션별 비중과 시간 분리의 필요성을 유지한다. 실제 학습·채택·매매 연결은 별도 사전 계획과 검증이 필요하며 최종 v10 다년·다시장·비용·지연·낙폭·표본 기준을 변경하지 않는다.
