# 실험 v104 결과: 시장 관측 시각을 맞춘 행동 학습

2026-10-11. [보완한 사전 계획](EXPERIMENT_V104.md)에 따라 원본 신호 공급 없이 시장 특징만 사용하는 두 모형을 학습하고, 2021·2022년 가격 손절 유무의 여덟 자체 계좌를 모두 독립 검산했다.

두 모형 모두 2021년 진단 전체 89,551행에서 변경 없음을 선택했고, 2021·2022년 여덟 자체 계좌도 거래 0건·수익률 0%였다. 창 종료 특징이 로그 손실과 방향별 AP를 개선했지만 실제 매매 행동과 수익성으로 이어지지 않았다. 후속 확대 기준 미달이며 수익성 문제는 미해결이다.

## 입력과 첫 실패 보존

첫 실행은 모형 학습 전에 시장 특징 동일성 검사에서 중단됐다. 전체 208,596행을 추적해 기존 특징 2,920,344개가 BitMEX XBTUSD에서 정확히 재현됨을 확인했다. [출처 진단](FEATURE_MARKET_DIAGNOSIS.md), 실패한 실행·코드·입력·로그를 보존했고 모형 성적을 보기 전에 계획을 보완했다.

새 두 모형은 Binance BTCUSDT 시세에서 같은 14개 특징을 계산했다. 원본 BitMEX 열을 보존하고 신규 시장 열을 별도로 연결했다. 원본 현재·종료 노출, 수량, 지갑, 과거 체결은 예측 입력에서 제외했다. 봇 자체 상태는 예측 이후 목표 수량 변환에만 사용했다.

| 표본 | 원본 전체 행 | 두 시각 공동 지원 행 |
|---|---:|---:|
| 2020년 학습 | 104,148 | 92,748 |

시각은 정확히 일치하는 창 시작·종료 경계만 연결했다. 학습과 짝지은 평가는 두 시각 모두 지원되는 같은 행을 사용했고, 미지원 사유와 원래 행은 모두 보존했다. 정답은 원본 XBTUSD 체결·정산의 노출 기여분이다. Binance 거래자의 실제 행동 정답으로 바꾼 것은 아니다.

## 검증 범위

신규 47개와 기존 공유 실행 검산 15개, 합계 62개 검사 및 Ruff를 통과했다. 전체 원본 특징의 BitMEX 재현과 두 입력 시각의 별도 검색, 두 모형 각각의 320개 트리·선형 대조 독립 재학습, 전체 진단 행의 스칼라 추론·월별 지표를 검산했다.

새 실행 입력의 두 연도 총 210,240개 5분 경계가 같은 Binance 특징 계산과 정확히 일치했다. 여덟 경로의 총 4,204,800분과 모든 확률·크기·목표·체결·종료 거래·지표, 각 175,200·350,400분의 중간 JSON 상태를 독립 확인했다. 원본 5개와 공개 소스 288개는 실행 전후 동일했다.

v103의 기록 공급 조건부 양수는 예측 봇 성과로 이전하지 않았다. 이번 고정 모형에서는 관측 시각과 시장을 정렬하는 것만으로 매매 시작 문제를 해결하지 못했다. 드문 행동의 학습과 실제 선택 규칙을 구분해 후속 가설을 검증한다. 모든 기간은 이미 관찰한 기간이며 기존 v10 최종 기준과 전체 수익성 goal은 유지한다.
