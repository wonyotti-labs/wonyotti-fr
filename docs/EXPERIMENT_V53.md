# 실험 v53 사전 계획: 추가 조기 청산의 현재 비용 조건

2026-10-04. v52는 원본 범위 정답의 포착을 늘렸으나 봇 자체 상태에서는 진입 직후 청산을 반복하며 실패했다. 같은 결과를 재현한 입력 기록에서 진입 초기 상태의 비중 차이와 비용 누적을 확인했다. 가격 손익도 손실이므로 비용 조건 하나로 해결된다고 가정하지 않는다. v52의 추가 조기 청산에 현재 추정 순손익 조건만 붙이는 단일 후보를 고정한다.

## 조건과 기존 손실 청산 보존

- 부모는 v52다. 모든 모델·절편·기존 청산 문턱·범위 문턱·다른 행동·진입·수량·위험은 그대로 유지한다. 재학습·문턱 선택·학습 기간 변경은 없다.
- 현재 확정 종가에서 보유 잔량을 청산한다고 가정한 해당 포지션의 총 순손익을 계산한다. 이미 실현한 부분 손익에서 현재까지의 실제 수수료·펀딩을 빼고, 현재 평균가 대비 잔량 손익에서 예상 청산 슬리피지·수수료를 뺀다. 실제 엔진 설정을 사용하므로 비용 2배·3배 조건에도 함께 반영한다.
- 추정 순손익이 0 이상일 때만 v52의 낮은 범위 문턱을 적용한다. 음수면 원래 v48의 청산 문턱으로 되돌린다. 원래 높은 청산 신호·손절·시간 제한·손실 중지는 손익 조건으로 막지 않는다. 추가 조기 청산이 거절돼도 원래 추가·축소 판단 순서를 유지한다.
- 판단은 현재까지의 체결·가격·펀딩만 사용한다. 실제 주문은 기존처럼 다음 거래 가능한 시가에 체결하며 이후 가격·펀딩 변화를 미리 보지 않는다. 따라서 추정이 0 이상이더라도 실제 손실 체결이 가능하고 그 기록을 모두 남긴다. 손실 거래의 사후 제외와 이익 보장을 금지한다.

## 대조와 평가

2021년 후보와 원래 v52를 기록하고 원래 v52의 전체 출력·최종 상태 일치를 확인한다. 엔진의 새 조회 값이 과거 정책의 판단을 바꾸지 않아야 한다. 2022년 순수익 양수·종료 거래 30개 이상·영구 중지 없음 실패 시 BTC 후속 두 기간과 독립 세 연도의 진단으로 총 여덟 실행을 보존한다.

통과 시 두 후속 기간·세 시장의 기본 여덟 조건에 원래 위험의 v14·v48·v52를 더한 열한 조건과 아홉 독립 연도를 수행해 총 78개 실행을 평가한다. 기본 조건은 후보·원래 v7·현금·추가 제거·30분 제한·비용 2배·3배·추가 1분 지연이다. 기존 표본·비용·다년·시장별 안정성·낙폭·집중·불확실성 보고 기준을 유지한다. 이익 거래 비율이나 수수료 감소만으로 채택하지 않는다.

롱·숏·추가·부분 축소·펀딩·실제 비용의 독립 계산, 같은 가격으로 실제 청산했을 때의 총 순손익 일치, 이후 가격 변경에 대한 현재 판단 불변을 검사한다. 자체 체결·회계·지연·무거래·실제 프로세스 종료·월간 복원 및 원본 보존을 대조한다. 모든 기간이 이미 관찰한 자료임을 유지하고 원본·개별 결과는 로컬에만 보존한다. 실제 거래 연결은 없다.
