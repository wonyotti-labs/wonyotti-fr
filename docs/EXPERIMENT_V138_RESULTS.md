# 실험 v138 결과: 같은 상반기 오신호 한도의 적중 비교

[사전 계획](EXPERIMENT_V138.md)에 따라 원본 전체와 고정 모델의 점수를 재현하고, 상반기 v127의 실제 오신호 수를 공통 한도로 문턱만 비교했다. 새 모델 학습·자체 계좌·실제 거래는 없고 수익성 문제는 미해결이다.

## 해석

한도 전 재시작 추가에서 v137의 새 적중 1분은 공통 오신호 한도를 적용하면 유지되지 않았다. 상반기 v127의 기존 FP 15분을 두 모델의 예산으로 고정했을 때 후보의 하반기 TP/FP/FN은 1/18/34에서 0/1/35로 바뀌었다. 기준 모델도 0/1/35다. 하반기 47,962행 중 양성은 35분이며, 원본 행 대조에서 후보만 새로 맞힌 1분의 유지 수는 0이다. 이 결과는 해당 추가 적중을 낮은 오신호 수준의 구분력 개선으로 볼 근거가 부족함을 보여준다. 모든 오신호 한도나 다른 모델의 가능성까지 부정하는 결과는 아니다.

상반기 후보 TP/FP/FN은 7/141/53에서 2/15/58로 줄었고 기준은 3/15/57이다. 학습 기간 후보는 29/208/185에서 6/17/208로 바뀌었다. 후보만 새로 맞혔던 분의 유지 수는 학습 22분 중 1분, 상반기 5분 중 1분, 하반기 1분 중 0분이다. 요청량을 늘린 결과와 점수의 구분 능력을 구별해야 하며, 이번 문턱 조정으로 확률 자체나 로그 손실·평균 정밀도가 좋아진 것은 아니다.

하반기 월별로도 이를 확인했다. 한도 전 재시작 추가에서 후보의 기존 적중 1분은 8월에 있었고 공통 문턱에서 제거됐다. 7·8·9·10월의 후보 FP는 각각 4·2·12·0분에서 0·0·1·0분으로 바뀌었으며, 공통 문턱의 TP는 모두 0분이다. 11·12월은 해당 집단의 행 자체가 없어 성적 없음으로 보존했다. 빈 달을 성공한 무거래 달로 계산하지 않았다.

다른 집단에서도 균일한 개선은 없었다. 횟수 전체의 quiet 축소에서 공통 문턱 하반기 TP/FP/FN은 기준 1/16/139, 후보 2/31/138이다. 적중 1분 증가와 함께 FP도 15분 늘었다. quiet 추가는 기준 2/20/144, 후보 1/22/145로 후보가 더 적게 맞히고 더 많이 잘못 요청했다. 한도 이후 재시작 축소에는 기준 0/2/98 대비 후보 1/5/97의 적중이 남았지만 전체 구분력 개선이나 실행 수익으로 해석하지 않는다. 집단별 문턱은 각각 별도로 고정했으므로 부분 집단 요청을 합해 전체 문턱 요청을 재구성할 수 없다.

동일한 것은 상반기에서 정한 FP 예산이다. 하반기의 FP를 같게 맞춘 실험이 아니며 실제로 여러 집단에서 달랐다. 상반기 행이 없던 한도 이후 최초 추가는 두 모델 모두 미지원으로 보존했다. 이 집단의 하반기 행도 0개여서 미지원 상태의 미래 예측 성능을 확인한 것은 아니다.

따라서 v137의 24/40개 조건 충족 및 미채택 판정을 유지한다. 이번에 확인한 문제는 한도 전 재시작 추가의 새 적중이 오신호 제한 아래 사라진다는 점이다. 거래 내역의 행동을 맞히는 문제와 봇의 손익 문제 사이에는 여전히 검증되지 않은 연결이 있다. 실제 손익을 새로 계산하지 않았으므로 손실 원인을 모두 해결했거나 수익성을 개선했다고 주장하지 않는다. 하반기 결과로 문턱·집단을 골라 실행 정책에 넣지 않으며, 다음 학습 또는 정책 변경은 별도 계획에서 고정해야 한다.

원본 1,018,460행·50개 입력·정답·시간·포지션 경계를 유지했다. 원본 사건의 횟수와 분기, 두 모델의 전체 확률·요청·보정·문턱·상태·월·횟수 집계와 v137의 24/40개 조건 충족을 재구성했다. 기존 실패 판정과 실행 정책은 그대로다.

문턱은 상반기 음성 점수의 B+1번째 큰 값 바로 다음 부동소수점 값이다. 모든 음성이 예산 이하면 0이며 보정 행이 없으면 미지원으로 남긴다. 같은 점수의 일부 행을 잘라 넣지 않았다. 정답의 양성 분·오신호 분은 독립 주문 수나 거래비용이 아니다. 상반기 FP 한도가 같아도 하반기 FP가 같아진다는 보장은 없다.
