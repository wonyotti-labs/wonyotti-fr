# 실험 v76 사전 계획: 최초 청산까지의 방문 구간 학습

2026-10-09. v75의 분별 학습·판단 후보는 선택 평균과 최초 효과가 음수였고 4/15 조건만 충족했다. 전체 입력·모델·지표의 독립 재검산을 완료했다. v75 결과 확인 전에 수행한 기존 실패 정책의 설명 집계에서는 다수의 반복 선택이 최초 청산 뒤에 있었다. 이 비중만으로 원인을 확정하지 않고, 학습 상태를 보조 정책이 방문하는 범위와 맞추는 후보 하나를 검증한다.

## 자료와 고정 범위

v75의 전체 분별 원장·74개 입력·자연 종료 대비 현금 정답·학습과 진단 분리·원래 비용과 위험을 유지한다. 학습은 2021-01-01 이상 진입·판단과 09-30 미만 정답 확정, 진단은 10-02 이상 진입·판단과 12-31 미만 정답 확정이다. 포지션 전체 분리와 미확정·기간 경계 밖 기록을 보존한다.

모델은 기존 64회·깊이 2·학습률 0.05·말단·규제·seed·조기 종료 미사용 설정을 그대로 사용한다. 비용은 포지션 비중과 자연 종료 대비 효과 절댓값의 곱이다. v73의 이후 정책 정답으로 바꾸지 않는다. 확정 시세 연결·현재 관리 의도와 입력 순서도 같다. 보조 점수·분할·방문 표식·최초 선택 시각은 검산 자료이며 예측 입력에 넣지 않는다.

2021년 경로는 2021년 말까지 학습한 부모 모델의 개발 적합 경로다. 보조 모델도 2021-10-02의 적합 시점에서 확정된 훈련 자료로 만들며, 훈련 내부 점수를 그 과거 시점에 실제 운용한 모델의 점수로 표시하지 않는다. 전체 평가 기간은 이미 관찰한 자료다.

## 포지션 제외 보조 정책과 방문 구간

포지션 진입 UTC 나노초의 10진 문자열을 SHA256으로 계산하고 그 정수를 5로 나눈 나머지로 다섯 분할을 고정한다. v73과 같은 분할 규칙이다. 각 보조 모델은 해당 분할의 포지션 전체를 제외한 학습 자료로 적합하고 제외한 포지션에만 점수를 연결한다. 기존 포지션 균등 비중과 같은 분별 비용 분류기를 사용한다. 보조 모델 다섯 개의 행 번호·포지션·학습 비용·점수·정답 확정 경계를 저장한다.

각 포지션에서 보조 점수 `q > 0.5`이고 원래 의도가 exit가 아닌 최초 분까지 포함한다. 그 선택 행도 학습에 포함한다. 선택이 없으면 해당 포지션의 원래 모든 행을 포함한다. 이후 행은 원래 값·행 번호·보조 점수·제외 사유와 함께 보존한다. 손익 부호로 구간을 선택하지 않으며 각 포지션의 최소 한 행을 유지한다.

유지한 행 안에서 포지션별 총 기여가 같도록 비중을 다시 계산하고 평균을 1로 정규화한다. 이 비중에 원래 정답의 절댓값을 곱해 후보 하나를 적합한다. 원래 전체 비중도 별도로 보존한다. 방문한 0 효과 행은 학습 기여만 0이며 원장에 남긴다. 방문 여부·실제 학습 기여·0 효과·최초 선택 이후의 제외를 구분한다.

보조와 최종 학습 모두 기존 확정 경계·기간·양방향·포지션 지원 조건을 충족해야 한다. 최종 방문 자료도 1,000행·100포지션·방향별 20포지션·180일 지원을 요구하며, 비용이 있는 학습 행 1,000개와 양쪽 정답 각각 64개 이상의 기존 조건을 유지한다. 지원이 부족하면 실패로 기록한다. 새 적합은 보조 다섯 개와 최종 후보 하나이며 반복 정책 갱신·설정 탐색은 없다.

## 동일 모집단 평가

후보는 방문 구간으로 학습한 **1분 청산 정책 하나**다. 원래 exit 의도를 제외한 `q > 0.5` 기준을 사용한다. 진단 전체 행·포지션·평가 비중과 최초 가용 분의 순자산은 v75와 같다. 학습에서 사용한 방문 표식으로 진단 행을 거르지 않는다.

v75의 기존 5분·기존 1분·분별 학습 5분·분별 학습 1분 정책과 학습 상수를 모두 보존한다. 새 방문 학습의 비용 상수도 추가한다. 모든 행의 선택·기회손실·비용 로그 손실·Brier와 최초 선택·선택 없음·방향·월별 결과를 보고한다. 두 기존 모델의 트리·비용·점수와 v75의 원래 모든 평가·실패 판정을 재현한다.

같은 13개 달력 주·1,000회·seed 63의 추출로 후보와 기존 네 정책·새 상수의 다섯 짝지은 비교를 기록한다. 후보 자체의 95% 구간도 같은 추출에서 계산한다. v75의 분별 학습 5분 정책은 설명 대조이며 후보로 재선택하지 않는다. 이는 고정 포지션 경로의 조건부 효과이고 연속 계좌 수익률은 별도 검증 대상이다.

## 후속 매매 연구 조건

다음 스무 조건을 모두 요구한다. 누락·비유한 지표는 실패다.

1. 후보 선택 기회 100개 이상.
2. 후보 선택 포지션 30개 이상.
3. 선택 기회의 가중 평균 효과 양수.
4. 선택 기회의 무가중 평균 효과 양수.
5. 선택 포지션의 최초 평균 효과 양수.
6. 전체 포지션의 최초 평균 효과 양수.
7. 후보 최초 효과 구간 하한 양수.
8. 기존 모델의 1분 정책 대비 최초 효과 차이 구간 하한 양수.
9. 기존 모델의 5분 정책 대비 최초 효과 차이 구간 하한 양수.
10. v75 분별 학습 1분 정책 대비 최초 효과 차이 구간 하한 양수.
11. 새 방문 학습 상수 대비 최초 효과 차이 구간 하한 양수.
12. 가중 기회손실이 기존 모델의 1분 정책보다 작음.
13. 가중 기회손실이 v75 분별 학습 1분 정책보다 작음.
14. 가중 기회손실이 새 방문 학습 상수보다 작음.
15. 비용 로그 손실이 기존 모델보다 1% 이상 개선.
16. 비용 로그 손실이 v75 분별 학습 모델보다 1% 이상 개선.
17. 비용 로그 손실이 새 방문 학습 상수보다 1% 이상 개선.
18. 비용 Brier가 기존 모델보다 악화되지 않음.
19. 비용 Brier가 v75 분별 학습 모델보다 악화되지 않음.
20. 비용 Brier가 새 방문 학습 상수보다 악화되지 않음.

Brier 허용치는 1e-12이며 나머지 개선·양수 조건은 엄격한 부등식이다. v75의 실패 조건을 보존하고 같은 기준에 직전 분별 모델·새 상수의 최초 효과 대조를 추가한다. 최종 v10의 다년·다시장·비용·지연·낙폭·표본·집중 조건은 변경하지 않는다.

## 검증과 보존

기존 분별 원장·확정 시세·계좌·학습 분리·모델·평가 결과와 입력 지문을 재현한다. 기존 점수나 모델을 바꾸고 지문을 다시 써도 후보 적합 전에 거부해야 한다. 원본 결과는 덮어쓰지 않는다.

합성 자료에서 최초 선택 포함·같은 포지션 분리·원래 exit 제외·0.5 동점·선택 없음·0 효과·비중·원래 행 번호·잘못된 시각·지원 부족을 검사한다. 자기 분할의 정답 변경은 그 분할을 예측하는 보조 모델과 점수를 바꾸지 않아야 한다. 뒤 진단의 정답 변경은 보조 학습·방문 구간·비중·최종 모델을 바꾸지 않아야 한다. 이미 최초 선택이 끝난 뒤의 고정 보조 점수 변경도 앞선 방문 구간을 바꾸지 않아야 한다.

실제 자료의 보조 다섯 모델·제외 포지션·방문 구간·비중·비용·최종 모델·모든 점수·최초 현금 효과·다섯 주간 비교·스무 판정을 독립 대조한다. 실패·제외·0 효과·선택 없음과 모든 이전 결과를 보존한다. 원본·파생 자료의 Git 공개와 실제 거래 연결은 없다.

일반적 배경은 정책의 행동이 관측 상태 분포를 바꿀 수 있음을 다룬 [Ross 외의 연구](https://proceedings.mlr.press/v15/ross11a.html)다. 이번 단일 방문 구간 학습을 그 연구의 DAgger 구현이나 이론적 성능 보장으로 표시하지 않는다. 개선 여부는 위 고정 검증으로 판단한다.
