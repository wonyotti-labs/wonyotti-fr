# 실험 v121 사전 계획: 원본 관리 모델의 시간순 내부 복잡도 선택

2026-10-12. v119의 첫 상태 분리와 v120의 이력 조합 입력은 후속 계좌 기준에 미달했다. 단순 표현력 부족을 입증한 결과는 아니며, v112에서도 추가 입력의 학습 개선이 이후 구간에서 악화했다. 더 큰 모델이 필요하다고 전제하지 않고 기존 크기를 포함한 네 설정을 2020년 내부에서만 비교한다. v66은 봇 청산의 경제 효과 회귀·56개 입력에 대한 비교였으며 이번 원본 관리 행동의 이진 분류·50개 입력과 정답이 다르다.

## 원본 보존과 내부 시간 분리

- v35의 원본 50개 입력과 전체 2020년 학습·2021년 상반기 보정·하반기 진단을 그대로 유지한다. v119 분리 모델이나 v120 추가 입력은 채택하지 않는다. 기존 분할·정답·행·지문을 확인한다.
- 내부 적합은 2020년 상반기, 내부 선택은 같은 해 하반기다. 각 구간 시작부터 24시간 이후의 판단만 포함하고 정답 종료는 구간 종료 24시간 전보다 엄격히 빨라야 한다. 진입은 해당 구간 시작 이후여야 한다. 7월 1일을 넘는 동일 에피소드는 양쪽에서 모두 제외하고 제외 사유·원래 행 번호를 보존한다.
- 계획 전 지원 집계는 내부 적합 258,703행·137에피소드·청산/축소/추가 양성 142/752/759, 선택 242,373행·135에피소드·160/579/615, 경계 횡단 1에피소드다. 이는 표본 지원 확인이며 어떤 후보도 아직 학습하거나 선택하지 않았다. 실제 실행에서 별도 순회로 대조한다.
- 두 내부 구간 각각 최소 1,000행과 세 행동별 양성·음성 20개 이상을 요구한다. 2021년 두 구간은 내부 선택에 전달하지 않는다. 외부 전체·첫/반복 지원 조건도 유지한다.

## 네 후보와 하나의 선택

후보는 깊이·최대 말단·반복 수 `(2,4,64)`, `(2,4,256)`, `(4,16,64)`, `(4,16,256)`이다. 기존 설정이 첫 후보다. 나머지는 학습률 0.05·최소 말단 64·L2 1·최대 구간 255·전체 특징·범주형 없음·seed 0·조기 종료 없음·클래스/표본 가중치 없음으로 고정한다.

각 후보의 세 이진 모델은 내부 적합 행만 사용한다. 후보별 내부 선택 원래 정답의 행동별 로그 손실을, 내부 적합의 양성 빈도 상수가 같은 선택 구간에서 얻은 해당 행동 로그 손실로 나눈다. 세 비율의 산술 평균이 가장 낮은 설정 하나를 고른다. 정확한 동점은 위 목록 순서다. 청산의 낮은 빈도가 단순 손실 합계에서 묻히지 않도록 행동별 비율을 사용한다. 내부 선택에는 절편 보정·요청 문턱·순손익을 사용하지 않는다. 후보별 적합·선택의 손실·평균 정밀도·상수·전체 점수·모델을 보존한다.

선택한 설정 하나만 전체 원래 2020년으로 재학습한다. 원래 깊이 2·64회 모델을 동일 전체 행으로 재현해 v35 트리·절편·저장 진단 점수 일치를 확인한다. 원본 50개 선형 대조도 동일 전체 행으로 학습한다. 네 후보를 2021년에 모두 평가해 다시 고르지 않는다. 첫 설정이 선택되면 이를 그대로 유지하며 새 설정을 강제하지 않는다.

## 이후 보정·요청·판정

상반기 절편 보정과 전체·첫 축소/추가 문턱은 v120과 같은 방식이다. 기울기 1·기계 정밀도 확률 경계·[-64,64]·이분법 100회·평균 오차 1e-12, 청산 F2·축소 F1·추가 F0.5, 예측 양성 최소 20개·동률 높은 문턱·배율 1.0을 유지한다.

하반기의 판정은 v120과 같은 25개 조건이다. 세 행동 각각 기존 부스팅 및 선형 대비 로그 손실 1% 초과 개선(1e-12 경계 제외)·평균 정밀도 보존, 보정 전 손실 보존·상반기 빈도 상수보다 개선의 18개, 전체 세 행동 F 보존 3개, 첫 축소·추가 각각 재현율과 F 보존 4개를 함께 요구한다. 모든 기간·월·첫/반복·네 이력 조합을 보존하고 작은 조합·양성 0개도 삭제하지 않는다. 내부 선택 결과가 좋다는 이유만으로 통과시키지 않는다.

## 검산과 후속

숫자 모델은 선언한 네 설정만 지원하고 기존 형식·기본 설정의 동작은 보존한다. 내보낸 초기 값·모든 트리·깊이·반복 수·노드 연결·유한성, 단일 행과 묶음 추론을 검증한다. 내부 네 적합과 최종 선택·기존 모델 및 선형을 별도 라이브러리 적합으로 대조하고, 전체 확률·분할·지원·제외·상수·손실·선택·보정·문턱·월별 지표·25개 판정을 독립 검산한다.

내부 선택 정답 변경이 내부 학습 모델을 바꾸지 않고, 2021년 정답 변경이 내부 후보·선택·2020년 최종 모델을 바꾸지 않는 검사를 둔다. 2021년 상반기 정답은 보정·문턱을 정하므로 이를 바꿔도 보정이 같다고 요구하지 않는다. 원래 공통 모델의 관련 기능도 회귀 검사한다. 실제 실행 전후 코드·입력·계획 지문을 확인하고 실패는 보존한다.

모든 기간은 이미 관찰한 자료다. 통과해도 새 계좌는 별도 고정 계획 후 전체 경로로 검증하며 v10의 다년·다시장·비용·펀딩·지연·낙폭·표본 기준을 유지한다. 원본·모델·개별 출력은 로컬에만 보존하고 실제 거래 연결은 없다.

모형 크기의 역할은 [scikit-learn 부스팅 API 문서](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.HistGradientBoostingClassifier.html)를 참조한다. [중첩 선택 문서](https://scikit-learn.org/stable/auto_examples/model_selection/plot_nested_cross_validation_iris.html)의 선택·평가 분리 원칙을 따르되, 무작위 분할 예제를 적용하지 않고 시간·에피소드 경계를 직접 고정했다. 설치된 잠금 버전과 실제 인자를 실행 기록에 보존한다.
