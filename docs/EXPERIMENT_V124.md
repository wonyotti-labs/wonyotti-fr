# 실험 v124 사전 계획: 보유 경로의 최선·최악 기록 후 경과 시간

2026-10-12. v123은 가격 경로를 일간 변동성으로 나누어도 관리 행동 재현 조건에 미달했다. 같은 크기 대비 청산·추가의 실제 행동 행 평균 손실이 나빠졌지만 비행동 행의 개선에 가려 전체 손실은 작아졌고, 상반기 청산 문턱은 하반기 실제 청산 점수 모두보다 높았다. 단순 문턱 하향(v52)과 이진 균형(v122)의 실패를 보존한다. 원래 50개 입력은 최선·최악 가격과 전체 보유 시간을 제공하지만 각 극값이 언제 갱신됐는지는 직접 제공하지 않는다. 이 시간 정보 추가가 원본 행동을 개선하는지 검증하며 원인이나 개선을 미리 확정하지 않는다.

## 과거 경로와 입력 복원

원본 v35의 2020년 전체 학습 510,102행·2021년 상반기 보정 256,234행·하반기 진단 252,124행과 50개 입력·정답·포지션·24시간 경계를 유지한다. v123의 네 입력은 미채택 상태로 남기고 이번에는 원래 50개에 두 입력만 추가한다.

- 입력은 `path_log_minutes_since_best`, `path_log_minutes_since_worst`다. 같은 포지션의 확정 1분 종가에서 각각 유리한 극값·불리한 극값을 마지막으로 **엄격히 갱신**한 시각 이후 분 수에 log1p를 적용한다. 같거나 움직이지 않은 가격은 시계를 초기화하지 않는다. 첫 관측에서 양쪽 경과 시간은 0이다. 롱의 최선은 최고 종가, 숏의 최선은 최저 종가다.
- 전체 분별 원본 가격 경로 자료에서 먼저 누적한 뒤 v35 행에 연결한다. 학습·보정·진단이나 지원 행으로 먼저 자르고 누적하지 않는다. 현재 확정 종가는 포함하지만 현재 판단 뒤의 종가·주문·정답은 읽지 않는다. 새 진입·반전은 새 경로이고 추가·축소에 따른 평균 진입가 변경은 극값 시계를 초기화하지 않는다.
- 원본 가격 경로의 `events.parquet`까지 v35→분봉 입력→수량 입력→가격 경로의 지문 연결을 확인한다. 원래 `end`, 종가, 평균 진입가, 진입 시각, 방향, 포지션 식별자와 기존 세 가격 경로 값을 v35와 대조한다. 청산 정답은 이후 수정된 v35 것을 그대로 쓰며 오래된 가격 경로 정답으로 덮어쓰지 않는다.
- 1분 연속성·UTC 시각·양수 유한 가격·포지션의 방향/진입 시각 일관성·재등장 없는 식별자를 검증한다. 각 v35 행의 포지션 첫 분 경계가 진입 시각 바로 다음 분 경계인지 확인한다. 최초 기록 전 경로가 없는 포지션을 임의로 0부터 시작한 정상 입력으로 취급하지 않는다. 연결 실패·누락·모순이 있으면 실패를 기록하고 행을 제거하지 않는다.

배치의 그룹별 누적 극값·엄격한 갱신 마스크·전방 채움과, 시간순 상태 갱신의 별도 구현을 전수 대조한다. 원래 세 가격 경로는 복원한 극값과 해당 시점 평균 진입가로 다시 계산해 확인한다. 소스 전 기간을 계산하되 모델의 행과 정답은 원래 세 분할만 사용한다. 시각 차이는 나노초 정수로 계산하고 1분의 정수 배수·0 이상·현재 보유 시간 이하를 검증한다.

## 고정 학습과 판정

52개 입력의 무가중 부스팅은 v121의 2020년 내부 선택 설정인 깊이 2·최대 말단 4·256회·학습률 .05·최소 말단 64·L2 1·255구간·전체 특징·범주형 없음·seed 0·조기 종료 없음·클래스/표본 가중치 없음이다. 같은 52개 입력의 학습 전용 StandardScaler·로지스틱 C=.1·2,000회·seed 0·무가중 대조를 적합한다. 새 모델 크기·시간창·기간 탐색은 없다.

v121의 봉인된 native64·capacity256·linear50과 절편을 복원해 모든 기간의 원시/보정 확률·요청·전체/첫 문턱·모든 월 지표를 정확히 재현한다. v123 완료·미채택 근거를 연결하되 해당 네 입력이나 모형을 이번 모델에 합치지 않는다.

상반기 절편 보정은 기울기 1·기계 정밀도 확률 경계·[-64,64]·100회 이분법·평균 오차 1e-12다. 전체 문턱은 청산 F2·축소 F1·추가 F0.5, 첫 축소·추가는 과거 해당 주문이 없는 행의 같은 기준이다. 최소 예측 양성 20개·동률 높은 문턱·배율 1.0을 유지한다. 하반기 정답으로 문턱을 다시 선택하지 않는다.

사전 31개 조건은 v123과 같은 구조다. 세 행동 각각 native64와 새 linear52 대비 로그 손실 1% 초과 개선(1e-12 경계 제외)·AP 보존, 자체 보정 전 손실 보존·상반기 상수 개선의 18개, native64 대비 전체 F 3개와 첫 축소/추가 재현율·F 4개, 같은 크기 capacity256의 행동별 로그 손실·AP 보존 6개다. 보존 허용 오차는 1e-12다. 모든 조건을 요구하며 일부 상태 개선이나 평균 손실 감소로 다른 미달을 덮지 않는다.

세 분할·모든 월·첫/반복·네 이력 조합·전체 확률·요청을 기록한다. 두 경과 시간은 각각 0분, 1~14분, 15~59분, 60~1,439분, 1,440분 이상으로 집계한다. 고정 구간은 설명 자료로만 쓰며 빈 구간·양성 0개를 남긴다. 두 변수의 분기 사용 수도 설명 자료이고 독립적인 중요도나 수익 기여가 아니다.

## 검증과 후속 범위

롱·숏·동일 가격·엄격한 갱신·평균가 변경·추가/축소·분 경계와 같은 진입·반전·무포지션·기록 시작 전 진입·누락 분·중복 포지션·비유한 값·과거/미래 시각 변조를 검사한다. 전체 자료에서 먼저 누적해야 구간 시작 전 극값이 보존되는 사례, 미래 가격/정답 변경 시 과거 입력 불변, 상태 저장·복원 후 일치도 확인한다.

새 2,036,920개 입력과 연결·기존 경로, 768개 트리와 선형 계수·전체 확률·절편·문턱·월/구간 지표·31개 판정을 별도 계산 및 재적합으로 대조한다. 2021년 정답 변경 시 모델은 같아야 하고 하반기 정답만 바꾸면 절편·문턱도 같아야 한다. 코드·계획·소스·원래 대조의 시작/종료 지문, 실패·사후 진단을 보존한다.

입력 지원이나 모델 조건이 미달하면 실패를 그대로 공개하고 새 계좌로 확대하지 않는다. 통과하더라도 실제 봇 상태·비용·펀딩·지연·낙폭·표본·다년·다시장 검증은 별도 고정 계획으로 이어간다. 모든 기간은 이미 관찰한 자료다. v10 최종 기준과 수익성 goal을 유지하고 원본·파생·모형·개별 출력은 로컬에만 두며 실제 주문·인증 연결은 추가하지 않는다.
