# 구현 상태

2026-10-01 기준. 원자료 복원과 사건별 연구·오프라인 재생을 구현하고 다년·새 기간 평가를 완료했다. 수익성 있는 전략으로 채택한 모델은 없다. 다음 후보는 [v3 사전 계획](EXPERIMENT_V3.md)에 따라 진행한다.

| 영역 | 확인한 상태 | 남은 한계·작업 |
| --- | --- | --- |
| 저장소·재현 환경 | 고정 의존성, 합성 테스트, 원격 CI 통과 | 작업 단위별 검증·커밋·즉시 푸시 유지 |
| 전체 원본 감사 | 전체 파일 처리와 원본 행 추적 | 추가 자료와 새로운 스키마는 별도 검사 |
| 전체 계약 복원 | 원본 정산 통화·비용을 사용한 역선물·선형·콴토·만기 정산 복원 | 같은 시각 순서와 시작 포지션 가정은 잔존 |
| 지갑 손익 대조 | 정오 UTC 정산 경계와 다음 날 기장할 펀딩 분리, 동일 기간 대조 완료 | 시각이 불완전한 일부 일별 현금 잔액 차이는 별도 유지 |
| 외부 체결 대조 | 분기별 공식 익명 체결 표본의 ID·가격·수량·UTC 일치 | 전체 체결·계정 소유·재산 인증은 아님 |
| 시장 데이터 | 원거래소 전체 연구 기간의 5분봉, 별도 시장의 다년 시세·펀딩 | 호가·주문 대기열·시장 충격은 미포함 |
| 행동 연구 | 보유 시간·독립 추가 주문·손실 집중·확정 시세 맥락 분석 | 취소 주문·뉴스·당시 의도는 복원 불가 |
| v1 후보 | 보유 방향 모사와 다년 평가 완료, 미채택 | 실패 기록 보존 |
| v2 후보 | 독립 주문 분리, 진입·관리 모델, 경계 에피소드 제거, 12개 설정 선택 완료 | 개발 후보 모두 손실. 일부 행동의 평가 표본 부족 |
| 후속 평가 | 두 기간·세 시장의 비용·지연·위험 규칙·기준 전략 비교 완료 | 고정 후보는 두 기간 모든 시장에서 손실·낙폭 중지 |
| 재학습·실패 분석 | 세 연도의 확장 학습 모사와 비용·회전율·손실 집중도 분해 완료 | 수익률 재학습 워크포워드나 확률 보정 입증은 아님 |
| 오프라인 봇 | 부분 매매, 영속 저널, 중복 거부, 중단 복원, 수동 중지 구현 | 실제 한 달 시세의 중단·재개와 단일 실행 일치 확인 |
| 실제 거래 | 범위 제외 | 주문·인증·출금 연결 없음 |

상세 수치·그림·실패 실행은 로컬 `artifacts/INDEX.md`에 보존한다. 원본·시장 자료·모델·개별 연구 결과는 Git에 포함하지 않는다.

## 다음 연구의 우선순위

1. 학습 클래스 빈도를 반영한 v3 점수 후보를 구현하고 고정한 12개 조합을 개발 구간에서 비교한다.
2. 원래 가중 점수와 매매 빈도·가격 손익·비용·낙폭을 비교한다. 희소한 진입 표본의 정확도만으로 일반화를 주장하지 않는다.
3. 개발 및 2021년 조건을 통과한 경우에만 2026년 9월의 짧은 미관찰 구간을 연다. 2026년 1~8월은 이제 관찰한 기간이다.
4. 실제 시세 장애·급변 및 변경한 정책의 재시작 검증을 계속하고 연구 결과를 보존한다.

동봉 서한은 작성일·원게시물 주소가 확인되지 않아 과거 거래 당시의 정답에 넣지 않았다. 원거래소의 잘못된 역사 자료 URL 한 개가 실패했던 초기 기록은 보존했으며, 이후 공식 공개 API에서 확보한 체결과 시세로 정정했다.
