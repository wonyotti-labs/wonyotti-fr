# 구현 상태

2026-10-04 기준. 수익성 문제는 미해결이며 연구 goal은 진행 중이다. v10·v11의 행동별 학습, v12의 가격 경로, v13의 반전 실행, v14의 빈도 누적을 검증했지만 채택 기준에 미달했다. [v15](EXPERIMENT_V15.md)·[v16](EXPERIMENT_V16.md)의 순손익 필터와 중첩 가중치를 각각 65개 실행으로 검증했지만 후속 손실·표본·비용 기준에 미달했다. v17의 기회 확대도 전체 71개 검증에서 후속 손실을 보였고, v18의 누적 관리 반전도 7개 실행·복원 검증 후 미채택했다. [v19](EXPERIMENT_V19.md)의 잔여 수량·실제 축소 크기 학습은 전체 358개 검사와 원격 CI를 통과했지만 2022년 확인에서 실패했다. 후속 BTC 검증도 실패했다. [v20](EXPERIMENT_V20.md)의 최신 원본 학습 역시 확인과 후속 기준에 미달했으며 원본·회계·실제 복원을 대조했다. [v21](EXPERIMENT_V21.md)은 2022년 확인을 통과했지만 전체 78개 실행의 후속 손익·비용·표본 기준에 미달했다. [v22](EXPERIMENT_V22.md)의 추가 순효과 학습도 적합 구간 개선과 달리 확인·후속 기준에 미달했다. 여덟 실행·정답·학습·실제 복원을 대조했다. [v23](EXPERIMENT_V23.md)의 신규 진입 갱신은 확인 조건 통과 후 전체 78개 실행을 검증했지만 장기 손실·비용·독립 연도 기준에 미달했다. [v24](EXPERIMENT_V24.md)의 실제 종료 청산은 비청산 입력·모델을 보존했지만 확인·후속 기준에 미달했다. [v25](EXPERIMENT_V25.md)의 활동 분리는 전체 78개 실행에서 후속 기준에 미달했다. [v26](EXPERIMENT_V26.md)의 방향 빈도 보정도 확인·후속에서 실패했고 여덟 실행을 대조했다. [v27](EXPERIMENT_V27.md)의 실제 신규 방향 직접 학습도 확인·후속에서 실패했고 여덟 실행을 대조했다. [v28](EXPERIMENT_V28.md)은 원본 내부 시간순 방향 예측 조건을 통과했지만 매매 확인과 후속에서 실패했다. 여덟 실행의 회계·원본·복원을 대조했다. [v29](EXPERIMENT_V29.md)는 최초 투입만 줄이고 전체 추가 여력을 유지했지만 확인·후속에서 손실을 보였다. 아홉 실행을 대조했다. [v30](EXPERIMENT_V30.md)은 추가·축소 예측이 개선됐지만 청산 로그 손실이 악화해 사전 조건에 미달했다. 새 관리 모형의 매매 실행은 차단했다. [v31](EXPERIMENT_V31.md)의 현재 점수 판단은 장기 연속 운용에서 개선됐지만 확인·최근 구간과 독립 연도 기준에 미달했다. 여덟 실행과 모델·원본·복원을 대조했다. [v32](EXPERIMENT_V32.md)는 학습·빈도 보정·진단을 세 구간으로 분리했지만 기존 청산 모델을 넘지 못해 미채택했다. 독립 재학습·절편·예측·원본을 대조하고 매매 적용을 차단했다. [v33](EXPERIMENT_V33.md)의 과거 독립 주문 이력은 축소·추가를 개선했지만 청산 개선 폭이 사전 조건에 미달해 미채택했다. [v34](EXPERIMENT_V34.md)의 부스팅은 원래 모델에 대한 세 행동 기준을 통과했지만 이력 선형 모델에 대한 축소 개선 조건에 미달했다. 매매 적용 없이 실패와 독립 재검증을 보존했다. 원본·이전 실패와 BTC 개별 체결 미연결 한계를 보존한다. 실험 단위 완료를 전체 문제 해결로 표시하지 않는다.

- v13의 반전·v14의 빈도 누적 가설을 고정 비교하고 실패를 보존했다. v15는 관리 정책을 유지하면서 전체 거래 순손익으로 진입을 거른다.
- v15·v16의 세 시장·아홉 조건·독립 연도 및 필터 제거 대조를 완료하고 실패를 보존했다.
- v17의 활동 관문 분리 후 첫 정답 생성에서 무거래 봉의 허위 청산을 발견했다. 체결 처리를 수정해 전체 기회를 다시 계산했고 기존 정답이 모두 일치했다. 확정 손실과 경계 미확정 원장을 보존하고 71개 실행을 대조했지만 수익성 기준에 미달했다.
- v18도 확인·후속 실패를 보존했다. v19에서 작은 잔량 보유와 원본 축소 크기, 봇의 고정 축소 비율 차이를 진단한다.
- 원래 정답·모델과 중첩 가중치를 다시 생성해 숫자 일치를 확인했다. 미래 시세를 진입 신호에 넣지 않는다.
- 가격 경로·관리 대기·실제 프로세스 종료 복원을 검증하고 원본 없이 재현할 수 있는 합성 테스트와 명령을 제공한다.

## 남은 연구의 한계

1. 원자료에 없는 미체결 주문·호가 대기열·뉴스·계좌 밖 헤지는 복원하지 못한다. 시장가 봇을 원본 지정가 실행의 재현으로 부르지 않는다.
2. 희소한 진입 표본과 상태 분포 변화가 남는다. 빈도 조정이 실제 행동 확률이나 수익 확률을 보장하지 않는다.
3. v3·v4는 선행 조건 실패로 9월을 열지 않았다. 이후 v5가 조건을 통과해 2026년 9월까지 개봉했으며, 다음 후보에서 해당 기간을 미사용 평가로 부를 수 없다.
4. 실시간 모의매매·실제 거래소 체결·주문 인증·출금은 범위에 포함하지 않았다. 다음 연구는 새 가설과 평가 계획으로 구분한다.
5. BTC 2025년 일부 체결의 일별·월별 집계 미연결 원인은 미확정이다. 바꾸지 않은 해당 분봉의 원체결 집계·기존 입력·공식 일별·월별 아홉 값 일치로 봉 기반 평가를 진행했다. 수정한 봉은 엄격한 체결 대조를 통과했으며 미연결 행과 종전 실패도 보존했다.
6. v8의 학습 기회는 특정 급변 월에 집중되고 정답 창이 겹친다. 실행 순손익을 학습해도 시장별 예측 오차와 표본 부족이 남는다. 후속 후보는 시간순 여러 학습 창의 안정성부터 새 계획으로 검증해야 하며 이미 관찰한 기간을 다시 미사용 평가로 부르지 않는다.
7. v9는 30분 강제 종료를 제거했지만 원본의 청산·축소 판단을 충분히 모사하지 못했다. v10~v12에서 정답 누락과 관리 입력을 보완했지만 원본과 봇의 상태·주문 의미 차이가 남았다. 높은 보유 정확도나 특정 시장의 수익만으로 문턱을 다시 선택하지 않는다.

동봉 서한은 작성일·원게시물 주소가 확인되지 않아 과거 거래 당시의 정답에 넣지 않았다. 원거래소의 잘못된 역사 자료 URL 한 개가 실패했던 초기 기록은 보존했으며, 이후 공식 공개 API에서 확보한 체결과 시세로 정정했다.
