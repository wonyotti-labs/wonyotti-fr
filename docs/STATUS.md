5. BTC 2025년 일부 체결의 일별·월별 집계 미연결 원인은 미확정이다. 바꾸지 않은 해당 분봉의 원체결 집계·기존 입력·공식 일별·월별 아홉 값 일치로 봉 기반 평가를 진행했다. 수정한 봉은 엄격한 체결 대조를 통과했으며 미연결 행과 종전 실패도 보존했다.
6. v8의 학습 기회는 특정 급변 월에 집중되고 정답 창이 겹친다. 실행 순손익을 학습해도 시장별 예측 오차와 표본 부족이 남는다. 후속 후보는 시간순 여러 학습 창의 안정성부터 새 계획으로 검증해야 하며 이미 관찰한 기간을 다시 미사용 평가로 부르지 않는다.

## v35 원본 진단과 후속 매매 연구

[v35](EXPERIMENT_V35.md)는 과거 주문 맥락과 시간순 빈도 보정을 결합해 세 행동 모두에서 사전 고정한 세 비교 모형의 예측 개선 조건을 통과했다. 독립 재학습·절편·수기 지표·원본 지문 대조도 완료했다. 이는 원본 상태의 예측 개선이며 봇 수익성 해결은 아니다. 다음 단계는 봇 자신의 실제 체결로 생성한 이력의 영속 실행과 별도 사전 계획에 따른 손익 검증이다.

[v36](EXPERIMENT_V36.md)의 자체 체결 이력은 실제 원장·복원 검사를 통과했지만 확인 조건에 미달했다. 원본 상태에서도 공통 실행 문턱이 첫 추가·첫 축소 점수 전체보다 높아 첫 관리가 막혔다. [v37](EXPERIMENT_V37.md)에서 첫 문턱만 분리했지만 기존 가산 배율 때문에 진단 구간의 첫 요청이 계속 없어 사전 개선 조건에 미달했다. 독립 수기 문턱·요청·지표 검증을 완료했고 해당 변경의 매매 적용은 차단했다.

v36의 후속 BTC 두 기간·독립 세 연도까지 여덟 실행을 완료했다. 장기 이익은 가장 큰 거래 한 건에 집중됐고 확인·최근 구간 손실과 거래 표본 부족이 남아 미채택했다. 전 기간의 실제 체결 이력·수량과 원장·회계·원본·월간 복원을 대조했다. 첫 주문의 판단 기준을 수정하는 연구를 계속하며 장기 합산 이익을 해결 증거로 표시하지 않는다.

[v38](EXPERIMENT_V38.md)은 계산된 첫 문턱에만 가산을 제거해 첫 추가·축소의 재현율·F점수와 전체 F점수 보존 조건을 통과했다. 청산·반복 요청은 정확히 같았고 독립 수기 대조도 완료했다. 첫 행동 적중 수는 여전히 적으며 예측 개선을 수익성 입증으로 해석하지 않는다. 다음 단계는 별도 계획에 따른 자체 체결 정책의 매매 대조다.

[v39](EXPERIMENT_V39.md)의 첫 문턱 적용은 실제 추가·축소 체결을 복원했지만 확인 구간 손실과 표본 부족으로 미채택했다. BTC 후속 두 기간과 독립 세 연도까지 여덟 실행을 검증했으며, 장기·최근 이익은 최대 거래를 제외하면 손실이었다. 모든 후보의 실제 체결 이력과 기존 모델·위험·대조 출력·복원을 확인했다. 다음 [v40](EXPERIMENT_V40.md)은 학습·보정 기록에서 관찰한 최대 보유 시간을 실행 한도로 고정해 범위 밖의 장기 보유를 제한한다. 수익성 문제는 계속 미해결이다.

[v41](EXPERIMENT_V41.md)의 포지션별 학습 기여 균등화는 기존 v35 대비 세 행동 모두의 분별 로그 손실과 평균 정밀도가 악화돼 미채택했다. 포지션별 평균 손실도 개선되지 않았다. 별도 표본 가중 재학습·절편 근 찾기·수기 지표와 원본 지문 대조를 완료했으며 해당 모형을 매매에 적용하지 않는다.

[v40](EXPERIMENT_V40.md)은 학습·보정 최대 시간으로 보유를 제한해 범위 밖 관리 판단을 없앴다. 장기 연속 수익과 최대 거래 제외 순손익은 양수였지만 확인·최근 구간 손실과 최근 표본 부족이 남아 미채택했다. 여덟 실행의 회계·원본·복원과 일곱 후보의 실제 체결 이력·시간 제한 경계를 대조했다. 방향 분해에서는 약세 확인 구간의 롱 편중이 진입 대기 전 활동 관문에서 크게 발생했다. 방향 모형 자체의 양쪽 신호 수만으로 실행 균형을 판단할 수 없으므로 진입 활동의 시간순 예측을 다음 연구 대상으로 삼는다.

[v42](EXPERIMENT_V42.md)의 신규 활동 부스팅은 다음 해 예측에서 기존 선형 모델보다 로그 손실·평균 정밀도가 악화되고 상수 기준도 넘지 못해 미채택했다. 원본 수량 전이·첫 사건·모든 시간 배제 원장과 독립 재학습·학습 문턱·수기 지표를 대조했다. 단순히 활동 모형을 복잡하게 만드는 변경을 매매에 적용하지 않는다.

[v43](EXPERIMENT_V43.md)의 신규 활동·방향 결합 학습도 기존 분해 모형보다 로그 손실과 양방향 평균 정밀도가 악화돼 미채택했다. 모든 행·원본 방향·독립 재학습·수기 확률과 지표·문턱·요청을 대조했다. 후보와 기준의 학습 연수 차이도 있어 결합 방식만의 인과 효과로 해석하지 않는다. 신규 진입과 보유 중 반전의 실행 의미 차이를 다음 원인 진단으로 이어간다.

[v44](EXPERIMENT_V44.md)는 신규 사건 대신 다음 경계 직전의 절대 보유 방향을 예측했지만 학습 빈도 상수를 넘지 못했고 월별 개선 일관성에도 미달했다. 방향별 평균 정밀도 개선만으로 채택하지 않았다. 독립 원장 연결·모든 행·재학습·수기 지표와 원본 지문 대조를 완료했다. 작은 잔량과 큰 보유를 같은 방향 정답으로 취급하는 차이를 추가 진단하며 수익성 문제는 미해결 상태다.

[v45](EXPERIMENT_V45.md)의 다일 시장 맥락 추가도 기존 보유 방향 모델과 상수 대비 예측 손실을 악화시켜 미채택했다. 기존 정답·행·점수를 보존하고 추가 특징·독립 재학습·수기 지표를 대조했다. 원본 보유 방향을 시장 정보만으로 충분히 재구성했다는 근거를 얻지 못했다. 이미 진단한 신규 활동 관문과 무포지션 진입의 의미 차이에 대해, 기존 방향·관리 모델을 고정한 최소 실행 대조를 다음 단계로 검증한다.

## v48 직접 청산 문턱의 실제 검증 완료

직접 청산 문턱은 기존 v46보다 장기 연속 결과와 독립 연도의 일관성을 개선했으며 장기 최대 이익 거래를 제외해도 순손익이 양수였다. 확인 구간은 양수였지만 거래 수에 미달했고 최근 구간은 이전의 희소 거래와 전체 출력이 그대로였다. 개발 적합 손실도 보존해 미채택했다. 여덟 실행과 전 후보 보유 분봉의 실제 체결 이력·시간 제한·원본·복원을 대조했다. 다른 시장·비용 배율·추가 지연은 사전 확인 실패 분기에 따라 미실행이며 수익성 문제를 해결한 것으로 표시하지 않는다.

## v64 결과와 v65 방향

v64의 트리·예측·선택은 v62와 같았고 추가 행동 입력은 개선을 만들지 못했다. 기존 음수 효과와 최초 선택 실패를 보존하며 매매에는 적용하지 않았다. 전체 현재 요청과 독립 재학습·통계를 대조했다. 다음 [v65](EXPERIMENT_V65.md)는 현재 노출을 출력에 곱하는 구조를 고정하고, 원래 계좌 기준 오차 비중을 보존하는 가중 변환을 검증한다.
