# 실험 v10 사전 계획: 관리 사건 보존과 행동별 판단

2026-10-03. 사용자의 해결까지 지속 요청에 따른 연구다. v9의 청산·축소 모사 실패와 5분 첫 주문 정답의 누락을 수정한다. v9 완료 표시는 해당 실험 범위의 기록이며 수익성 문제 해결로 취급하지 않는다. 이번에도 후보 수를 소진했다는 이유로 전체 goal을 완료하지 않는다.

## 정답과 시점

- 원거래소 1분 경계마다 직전 원본 보유 상태를 연결하고 가장 최근 확정 5분 시장 특징을 사용한다. 경계와 같은 시각의 체결은 상태에 넣지 않고 다음 1분의 정답에 넣는다.
- 독립 주문의 최초 체결을 기준으로 해당 분의 추가·축소·청산을 모두 센다. 같은 주문의 부분 체결을 새 행동으로 반복 학습하지 않는다. 반전은 기존 보유의 청산으로 분류한다.
- 당시 보유 방향·에피소드가 같은 주문만 그 상태의 관리 정답으로 연결한다. 분 안에서 새로 진입한 뒤 발생한 관리·다른 에피소드·범위 밖·특징 부족은 원인별 연결 원장에 남긴다. 순서가 있는 복수 주문을 하나의 실행 명령으로 완전히 복제할 수는 없다.
- 각 행동의 발생 여부를 별도 이진 정답으로 보존한다. 실행에서는 청산, 축소, 추가 순으로 우선한다. 정답의 공존과 실행에서 우선순위로 밀린 행동을 별도 집계한다. 1분보다 빠른 판단·제출·취소는 복원했다고 하지 않는다.

## 학습과 네 후보

- 시장 특징 14개, 방향을 곱한 시장 특징 14개, 현재 방향·유리한 가격 변화·보유 분 로그·추가 횟수 네 개를 사용한다. 미래 손익·최종 수량·원본 미래 상태는 예측 입력에서 제외한다.
- 2018~2019년으로 세 행동 모델을 학습한다. 모형은 표준화 로지스틱 C=0.1과 깊이 4·최소 말단 64개의 결정 트리 두 종류다. 클래스 가중치·임의 음성 표본 제거는 적용하지 않는다. 학습·검증 경계 포지션과 마지막 24시간을 제거한다.
- 2020년을 별도 행동 문턱 조정 구간으로 사용한다. 행동별 정밀도·재현율 곡선에서 청산 F2, 축소 F1, 추가 F0.5 최대값의 문턱을 선택한다. 동점은 더 높은 문턱이다. 최소 양성 20개와 최소 예측 양성 20개가 필요하며 부족하면 실패로 남긴다. 손익으로 이 문턱을 선택하지 않는다.
- 후보는 두 모형 × 문턱 배수 {1, 1.5}의 네 개다. 1보다 큰 문턱은 해당 행동을 차단한다. 보유/활동 공통 관문과 행동 점수 0.5 관문은 없앤다. 관리 판단 후 3분 동안 중복 관리를 기다린다. 위험 청산은 이 대기와 무관하게 엔진에서 수행한다.
- 진입은 기존 v7의 고정 신호·16bp·5분 만료를 유지한다. v9의 최초 25%·최대 50% 노출, 4% 손절·추가 최대 5회·학습 기반 고정 수량 기준·일별 3%와 누적 25% 한도를 고정한다. 시간 청산은 없다. 원본 레버리지를 추정하지 않는다.
- 2021년 BTC의 20거래 이상 후보 중 수익 - 0.5 × 낙폭 절댓값으로 선택하고 동점은 앞 후보다. 적격 후보가 없으면 기준을 완화하지 않는다. 선택 후 2022년 BTC 확인과 원본 상태의 2021년 행동별 모사 결과를 기록한다.

## 성과와 다음 단계

2022년 확인이 음수여도 실패 원인 대조를 위해 이미 관찰한 2023~2025년·2026년 1~9월을 평가할 수 있다. 새 독립 평가로 부르지 않는다. 고정 후보·기존 v7·현금·추가 제거·30분 제한·비용 2배·3배·추가 1분 지연의 여덟 조건과 세 시장, 아홉 연간 초기화를 유지한다. 가능하면 v9와도 같은 입력에서 비교한다. 이전 결과나 불리한 주문을 삭제하지 않는다.

양수 한 구간으로 완료하지 않는다. 수익성 후보로 판단하려면 BTC의 확인·두 후속 기간이 양수이고 낙폭 중지가 없어야 하며, 기간별 30거래 이상·비용 2배 양수·세 독립 연도 중 두 연도 이상 양수 여부를 확인한다. ETH·SOL 이전 성과와 비용 3배·지연·이익 집중·조건부 30일 블록 1,000회(seed 41)의 하위 분위도 함께 보고한다. 이 기준의 통과는 미래 수익 보장이 아니며 약한 다른 시장·불확실성을 숨기지 않는다. 미달하면 다음 원인과 수정 가설로 작업을 계속한다.

정답 연결 합계·경계·미래 변경 시 과거 입력 불변, 숫자 모델 내보내기·변조 거부, 행동 우선순위·관리 대기·부분 매매 회계·실제 종료 복원을 검증한다. 예측 값은 행동 점수이며 수익 확률이 아니다. 원본·파생 데이터·모델·개별 연구 결과는 Git 제외, 실제 거래 연결 제외, 작업별 한글 명사형 커밋 직후 푸시를 유지한다.
