# 실험 v108 사전 계획: 같은 상태에서 첫 주문과 복수 관리 정답의 학습 비교

2026-10-11. v107에서 첫 독립 주문 뒤의 관리 요청 4,785개를 확인했다. 이 누락을 복원하면 실제 예측이 좋아지는지 같은 창·입력·학습기로 비교한다. 현재 MinuteActionPolicy의 보유 중 관리는 활동 모델을 통과하지 않고 exit·reduce·increase를 직접 판단한다. 이미 제거된 관문을 다시 오류로 간주하거나 새 관문을 만들지 않는다. v35 등의 기존 분별 복수 관리 학습과 이번 5분 전체 과거 비교를 구분하며 기존 실패는 보존한다.

## 같은 입력과 두 정답

입력은 검산된 v107 전체 창·실제 사건·독립 요청, 원본 에피소드·체결 사건과 기존 BitMEX 5분 시세다. 원본을 새로 선택하거나 손실 거래를 제외하지 않는다. 창 시작 s의 확정 시장 특징 14개, 방향을 곱한 14개, direction·favorable_move·log_hold_minutes·adds_capped의 4개, 총 32개를 사용한다. 종료 e의 시장 특징과 현재 창의 체결은 입력 금지다.

원본 상태의 역선물 평균 진입가는 체결 원가와 수량으로 순차 계산한다. 동일 방향 추가는 원가 가중, 축소는 단위 원가 유지, 반전은 반전 체결의 단위 원가, 청산은 초기화한다. 보유 시작과 서로 다른 추가 주문 수도 엄격한 이전 사건으로 연결한다. 같은 시각의 마지막 상태를 사용하되 정확히 s의 사건은 제외한다. 현재 가격은 s에 끝난 BitMEX 봉 종가다. 기존 event_features.teacher_states와 별도 원가 재생을 대조한다. 원본 수량·잔고·수익은 모형 입력에서 제외한다.

모든 보유 창에서 A는 그 창의 첫 정상 독립 주문 하나가 같은 시작 에피소드에 해당할 때만 관리 정답을 가진다. B는 v107의 모든 같은 에피소드 관리 요청의 양성 여부를 가진다. A·B 모두 반전 요청은 기존 포지션의 청산이며 의도와 첫 부분 체결의 차이를 그대로 유지한다. A는 역사적 특정 정책의 전체 재현이 아니라 첫 주문 선택 효과만 분리하는 대조다. 복수 양성은 삭제하거나 하나의 클래스로 합치지 않는다.

## 시간 분리와 고정 학습

학습은 2018-01-01~2021-01-01 미만, 문턱 보정은 2021-01-01~2021-07-01 미만, 진단은 2021-07-01~2022-01-01 미만이다. 실제 있는 자료만 사용하며 각 기간 양쪽 24시간과 현재·창 안 관련 에피소드의 양쪽 경계 교차를 제거한다. 미종료 에피소드는 실제 청산으로 처리하지 않는다. 추가 배제 사유를 전체 원본 창에 남긴다.

A·B는 동일한 보유 창·32개 입력에서 고정된 독립 이진 히스토그램 부스팅 3개를 학습한다. 기존 설정인 64회·학습률 .05·깊이 2·말단 최대 4·최소 64행·L2 1·구간 255·seed 0, 가중치·조기 종료 없음이다. B의 표준화 로지스틱 C=.1·max_iter=2000·seed 0과 B 학습 빈도 상수도 같은 행의 대조로 둔다. 최소 학습 1,000행, 나머지 구간 100행, 각 행동 양성·음성 20개 기준을 유지한다. A·B 학습 및 B 보정·진단에 기준을 요구하며 부족하면 실패를 기록하고 완화하지 않는다.

청산 F2·축소 F1·추가 F0.5, 최소 예측 양성 20개로 2021년 상반기 B 정답에서 각 모형의 문턱을 고른다. 기존 select_threshold의 최대 점수·동률 시 높은 문턱을 사용하며 하반기 결과로 재선택하지 않는다. 보유 중 판단에는 활동 관문이 없고 요청 우선순위는 청산·축소·추가다. 개별 요청 마스크와 우선순위 적용 행동을 모두 기록한다.

## 전체 검산과 해석

원본 상태는 모사 진단용이다. 신규 진입 모델을 학습하거나 런타임에 원본 상태를 공급하지 않는다. 원거래소 신호를 Binance 실행 시세와 묵시적으로 섞지 않는다. 실제 매매 연결은 없다.

전체 상태·32개 특징·첫/전체 정답·기간 배제를 별도 순차 재생 및 시각 검색으로 검증한다. A·B의 총 384개 트리와 선형 계수·표준화를 독립 재학습해 비교하고 모든 예측·기간·월별 로그 손실·평균 정밀도·요청 혼동표·문턱 선택을 별도 계산한다. 미래 특징·정답 변경 시 이전 입력·학습 불변, 같은 시각과 경계, 공통 관문 없이 청산 요청 가능, 숫자 모형 직렬화와 변조 거부를 검사한다.

후속 자체 계좌 연구 허용에는 B 부스팅의 세 행동 모두가 A·B 선형 각각보다 로그 손실을 1% 초과 개선하고 학습 빈도 상수보다 좋아야 한다. 평균 정밀도는 A·B 선형 이상이어야 한다. 청산의 보정 문턱 요청 재현율과 F2는 A보다 엄격히 높아야 한다. 비교 오차 경계는 1e-12다. 일부 행동만 선택하거나 기준을 낮추지 않는다. 같은 원본 상태에서의 허용 판단은 수익성 채택이 아니며, 이후 자체 상태·신호와 실행 거래소·비용·지연·수량을 고정한 별도 실행 계획이 필요하다. 이미 관찰한 모든 기간과 v10 최종 수익성 기준은 유지한다.
