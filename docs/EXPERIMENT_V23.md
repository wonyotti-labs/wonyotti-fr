# 실험 v23 사전 계획: 신규 진입 모델의 최근 원본 학습

2026-10-04. v22의 추가 순효과 필터는 학습 적합 구간을 개선했지만 2022년 확인과 후속 다년·표본 기준에 미달했다. 새 필터를 이익이 난 기간만 선택해 채택하지 않는다. 관리 모델을 갱신하는 동안 신규 진입은 v4에서 선택한 2018~2019년 모델을 계속 사용했다. 원본의 노출 확대 빈도도 시기에 따라 달랐다. 기존 방향 모사의 최근 정확도가 낮아졌다고 확인된 것은 아니며, 모델의 나이만으로 손실 원인을 단정하지 않는다.

이번 비교는 v21을 기준으로 신규 진입의 학습 기간만 최근 두 해로 바꾼다. v22 필터를 함께 적용하거나 손익으로 둘 중 기준을 재선택하지 않는다. 기존 활동·방향 분리, 다음 5분의 첫 독립 노출 확대 주문 정답, 14개 시장 특징과 모형·분위·방향 문턱을 그대로 유지한다. 원본의 새 진입·반전·추가를 묶은 정답의 한계도 남긴다.

## 고정 학습

- 2020-01-01부터 2022-01-01 직전까지 원본 확정 5분 특징과 독립 노출 확대 주문을 사용한다. 왼쪽 첫 24시간과 오른쪽 마지막 24시간을 제거한다. 양쪽 경계를 넘는 보유 에피소드와 연결된 현재·정답 행을 제외하고 그 사유를 보존한다.
- 활동 모델은 전체 지원 행, 매수·매도 방향 모델은 활동이 있는 행만 학습한다. 기존 표준화 로지스틱 C=0.1, 최대 반복 2000과 기존 최소 행·양쪽 클래스 지원 기준을 그대로 적용한다. 클래스 가중치나 손실 주문 제거는 없다.
- 새 활동 모델의 학습 점수 97.5% 분위로 활동 문턱을 정한다. 이는 기존 v4 방식과 같다. 방향 문턱은 0.65로 유지하며 수익으로 분위나 문턱을 탐색하지 않는다. 후보는 하나다.
- 준비 조사에서 두 해의 지원 규모만 확인했다. 새 모델을 학습하거나 성과를 계산하기 전에 이 계획을 고정한다. 이후 지원 행·정답·모델·분위 값을 독립적으로 재구성한다.

## 고정 실행과 대조

원래 v21의 44개 관리 입력·관리와 축소 모델·누적 빈도·위험 설정을 그대로 보존한다. 신규 진입의 활동·방향 모델과 해당 학습 점수 분위만 바꾼다. 5분 신호 경계, 16bp 유리한 종가 대기, 5분 만료, 다음 거래 가능 시가 체결, 초기·추가 수량, 비용·펀딩·손절도 그대로다. 예전 진입 모델·설정을 별도로 남겨 이전 결과와 정확히 대조한다.

2021년 새 정책과 원래 v21 재생은 전체 시스템 학습과 겹치는 적합 진단이다. 새 모델 고정 후 2022년 확인에서 양수·30거래·영구 중지 없음 조건을 검사한다. 실패하면 BTC 두 후속 기간과 세 독립 연도만 진단한다. 통과하면 세 시장·두 기간·열한 조건과 아홉 독립 연도를 평가한다. 조건은 새 정책, 원래 v7, 현금, 추가 제거, 30분 제한, 비용 2배·3배, 추가 1분 지연, 원래 v14, 원래 v20, 원래 v21이다. 기존 v7·v14·v20·v21 대조에는 새 진입 모델을 적용하지 않는다.

전체 수익성 기준은 v10과 같고 이미 관찰한 기간의 반복 연구라는 한계를 유지한다. 원본 행동 모사 점수나 적합 수익으로 수익성 확보를 주장하지 않는다. 원본·이전 실패·미연결 체결 한계를 보존한다.

## 검증

원본·시세 지문과 지원 행, 경계 에피소드 제거, 첫 주문 정답·매수/매도 연결, 두 모델의 숫자 저장·학습 분위, 과거 입력의 미래 변경 불변을 검사한다. 신규 진입만 교체되었는지 고정 관리 파일과 대조 정책의 전체 체결·잔고·상태로 확인한다. 대기·보유 중 실제 종료 복원과 월간 재개, 비용·지연·회계를 검증한다. 원본·학습 자료·모델·개별 결과는 Git에서 제외하고 실제 거래를 연결하지 않는다.
