# 실험 v13 사전 계획: 모델 청산과 방향 반전의 구분

2026-10-03. v12의 가격 경로 특징은 원본 청산 순위·재현을 개선했지만 개발·확인·후속 BTC가 손실이다. 정답의 시간 허용 폭을 넓혀 본 진단도 순위의 상대 개선을 입증하지 못했다. 문턱을 계속 조정하는 대신 행동 의미를 다시 확인한다.

원본에서는 보유 중 추가 주문과 새 포지션 시작을 구분해야 한다. 기존 진입 모델의 양성에는 추가 주문이 포함되며, 최근 원본의 포지션 시작은 대부분 보유 방향 반전이다. 그런데 v9~v12는 반전을 청산 정답으로 합치고, 청산 후 다음 신규 진입 신호와 대기 조건을 다시 요구한다. 원본과 실행 의미가 다르다. 원본의 상태를 실제 봇 입력으로 쓰거나 이 차이를 손실의 단독 원인으로 단정하지 않는다.

## 변경 하나: 모델이 선택한 청산의 실행 의미

- v12에서 이미 고정한 모델·특징·문턱·배수·신규 진입 규칙·위험·수량을 그대로 보존한다. 다른 v12 후보를 재선택하거나 재학습하지 않는다.
- 단일 후속 후보는 모델 청산을 반대 방향 최초 진입으로 해석한다. 다음 1분 시가에 기존 보유분을 비용을 내고 닫고, 기존 최초 진입 한도 안에서 반대 보유를 연다. 추가 1분 지연 조건은 두 다리에 함께 적용한다.
- 위험 손절·일별 손실·누적 낙폭·수동 중지·평가 종료는 계속 평탄 청산이며 자동 반전하지 않는다. 원본의 소수 평탄 청산과 반전을 완전히 구분한 모델은 아니다. 이 근사와 반전 과잉·비용 위험을 명시한다.
- 관리 대기는 새 방향에 대해 3분 유지한다. 실제 반전 체결 시 가격 경로·추가 횟수·보유 시간은 새 포지션으로 초기화한다. 대기 의도와 실제 체결을 구분하고 체결 지연·거절·중단 복원을 검사한다.

## 평가

기존 v12 고정 후보를 대조로 보존한다. 새 단일 후보의 2021년 개발과 2022년 확인을 모두 기록하며 두 결과로 문턱을 고르지 않는다. 2021년이 양수여도 2022년 양수·30거래·중지 없음의 선행 조건을 통과하지 못하면 v12와 같은 BTC 두 후속 기간·세 연도 진단만 수행한다. 통과하면 v10 전체 세 시장·여덟 조건·아홉 연도 검증을 수행한다. 이미 관찰한 기간의 반복 연구이며 선택 불확실성이 누적된다.

반전 주문의 두 체결 비용·이전 포지션 종료·새 진입 회계, 방향·경로 초기화, 진입 대기 없는 반전과 일반 신규 진입의 연결을 검사한다. 원자료·모델·개별 연구 결과는 로컬에만 보존한다. 실거래 연결 없이, 수익성 문제 해결 전까지 연구를 지속한다.
