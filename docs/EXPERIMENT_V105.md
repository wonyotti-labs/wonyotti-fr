# 실험 v105 사전 계획: 희소 행동 학습과 선택 규칙의 분리

2026-10-11. v104의 두 모형은 전체 진단과 여덟 계좌에서 매매를 선택하지 않았다. 시장·시각 정렬만으로는 해결되지 않았으므로, 희소 행동을 동일 비중으로 학습했을 때의 변화와 기존 예측의 선택 점수만 바꿨을 때의 변화를 분리한다. 이번 계획은 신규 학습·성적 확인 전에 고정한다.

## 고정 입력과 학습

v104 창 종료 조건의 같은 Binance BTCUSDT 14개 특징, 공동 지원 2020년 학습 행·2021년 진단 행, XBTUSD 체결 기여분 정답을 사용한다. 원본 전체 행·미지원 사유와 기존 결과를 보존한다. 자체 계좌 상태·원본 체결 이력·종료 노출은 예측 특징에 넣지 않는다. 완료된 5분의 행동을 추정하고 다음 거래 가능한 분봉 시가에 실행한다.

새 분류기 한 개만 학습한다. 학습 클래스 k의 행 수 N_k와 전체 N으로 표본 가중치 w_k=N/(3N_k)를 정한다. 세 클래스 모두 128행 이상·전체 1,000행 이상을 요구한다. 2021년 빈도나 성적은 가중치 계산에 사용하지 않는다. 가중치는 [scikit-learn 공식 정의](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.HistGradientBoostingClassifier.html)의 balanced 계산과 같다. 고정된 로컬 의존성에서 sample_weight로 적용하고 class_weight는 None으로 두어 중복 적용을 막는다.

모형은 기존과 같은 log_loss·64회·학습률 0.05·깊이 2·말단 4·최소 말단 64·L2 1·최대 구간 255·전체 특징·seed 0·조기 종료 없음이다. 재표집·문턱 탐색·용량 변경은 하지 않는다. 방향별 크기 모형 두 개는 v104 창 종료 모형의 숫자를 그대로 재사용한다.

## 네 조건

기존 무가중 분류기의 출력은 p, 새 가중 분류기의 출력은 q다. normalize는 세 양수 점수의 합으로 나누는 연산이다. 동률은 보유다.

| 조건 | 학습 | 행동 선택 점수 | 역할 |
|---|---|---|---|
| A | 기존 무가중 | p | 기존 결과 재현 |
| B | 기존 무가중 | normalize(p × w) | 선택 규칙만 변경한 대조 |
| C | 새 역빈도 가중 | q | 사전 지정 주 후보 |
| D | 새 역빈도 가중 | normalize(q ÷ w) | 학습 모집단 빈도 복원 대조 |

B·C 점수를 원래 모집단의 보정된 확률로 주장하지 않는다. D의 역변환도 정확한 확률 보정을 보장하지 않으므로 실제 정답으로 평가한다. C 대 B는 같은 가중 선택 관점에서 학습 변화, D 대 A는 원래 빈도 관점에서 학습 변화, B 대 A와 C 대 D는 선택 규칙의 영향을 보여준다. 관찰 결과로 주 후보를 바꾸지 않는다. v26의 방향 빈도 보정 실패와 기존 문턱 탐색 실패를 유지한다.

전체·12개월에 네 조건의 로그 손실·혼동행렬·방향별 AP·정밀도·재현율·예측 수·변경량 MSE/MAE를 기록한다. 원래 모집단 관점 A·D와 학습 빈도 상수의 다중 클래스 Brier 점수 및 클래스별 고정 10구간 신뢰도 표를 별도로 남긴다. B·C의 행동 수 증가만으로 개선이라고 판단하지 않는다. 모든 진단 행의 점수·크기·행동과 미지원 행을 보존한다.

## 자체 계좌와 판정

네 조건 × BTC 2021·2022년, 총 여덟 경로를 지표와 관계없이 모두 실행한다. 가격 손절은 0으로 고정하고 v104 가격 손절 4% 경로는 기존 대조로 보존한다. 초기 10,000 USDT·수량 0·수수료 5bp·슬리피지 3bp·실제 펀딩·노출 상한 0.5·최대 보유 77,699분·대기 15분·일일 손실 3%·최대 낙폭 25%를 유지한다. 0 변경은 수량을 유지한다. 원본 신호를 실행 중 공급하지 않는다.

C의 2022년 비용 후 양수·종료 거래 30개 이상·영구 중지 없음이 모두 충족되면 고정 모형을 BTC 2023~2025년 연속·2026년 1~9월·2023/2024/2025 독립 연도·ETH·SOL·비용 2배/3배·지연 1분으로 확대한다. 미달이면 실패를 보존하고 같은 실험의 문턱·가중치를 다시 선택하지 않는다. 모든 기간은 이미 관찰했으며 기존 v10 최종 수익성 기준과 goal은 유지한다.
