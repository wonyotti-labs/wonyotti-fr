# 실험 v106 사전 계획: 실제 신규 진입과 경계 표본의 구분

2026-10-11. v105 가중 학습의 여덟 실행은 수익성 기준에 미달했다. 후속 상태 지원 집계에서 2020년 무포지션 5분 경계의 비영 변경 정답은 8개였으나, 이는 실제 신규 진입 횟수와 다르다. 이번에는 전체 과거 기록의 신규 진입·반전·관리를 구분하고, 짧은 청산·재진입이 경계 표본에서 누락되는지 확인한다. 새 모형이나 수익 결과를 보고 정답을 선택하지 않는다.

## 사건과 시각

검산된 원본 정규화 체결 전체와 XBTUSD 사건·행동 원장을 사용한다. 기존처럼 같은 시각·주문·체결 종류·방향·주문 유형의 부분 체결을 묶고 시각·최초 원본 행의 안정된 순서를 유지한다. 별도 사전·정수 집계로 모든 묶음의 수량·비용·수수료·원본 행·체결 수를 검산한다. 같은 시각의 반대 방향 사건은 관측 순서의 한계로 별도 집계하며 실제 거래소 내부 순서를 복원했다고 주장하지 않는다.

초기 수량 0 가정으로 체결 수량만 재생해 모든 사건의 직전·직후 수량과 open·reverse·increase·reduce·close·funding 분류, 에피소드 연결을 기존 행동 원장과 비교한다. open은 실제 수량 0에서의 진입이고 reverse는 보유 부호가 바뀌는 사건이다. 최초 주문 제출 의도나 미체결 주문을 복원하지 않는다. 부분 체결 사건 수와 고유 주문 수를 구분하고 특수 주문도 삭제하지 않는다.

각 open 사건에 직전 청산 이후 경과 시간과 1분·5분 경계 직전 수량을 연결한다. 경계 시각과 정확히 같은 사건은 경계 상태에 넣지 않는다. 최초 원본 사건 이전의 무포지션 지속 시간은 미상으로 보존한다. 펀딩이 무포지션 구간의 시작 시각을 덮어쓰면 안 된다. 같은 시각 청산·재진입, 경계 직후 청산, 경계와 같은 진입을 구분한다.

## 고정 집계

원본에 존재하는 전체 연도·월의 각 행동별 사건 수·고유 주문 수·최초 주문 체결 수를 기록한다. open의 매수·매도 수와 1분·5분 경계에서 무포지션을 관찰할 수 있었는지, 직전 무포지션 길이의 고정 구간 {0초, (0,60]초, (60,300]초, 300초 초과, 미상}를 남긴다. 사건 수가 독립된 전략 표본 수를 의미하지는 않는다.

현재 로컬 Binance 5분 자료에서 event_features의 같은 14개 특징을 계산한다. open 사건 직전 가장 최근 확정 경계의 정확한 시각만 연결하고, 누락·비유한 특징·연도 양쪽 24시간 제외를 별도 집계한다. 이 집계는 특징 가용성 진단이며 새로운 학습·수익성 판정이 아니다. 과거 시세를 새로 선택하거나 누락을 보간하지 않는다.

2020·2021년에는 v104 전체 정답 표에 open 사건을 그 사건이 속한 [s,e) 창으로 연결한다. 전체 원본 표 없음·기존 미지원·공동 지원을 구분하고, 지원 창에서 창 시작에 이미 보유했는지와 net 변경 정답이 0인지도 기록한다. 8개·1개라는 기존 집계를 수정하거나 실제 진입 수로 재명명하지 않는다. 같은 창의 복수 open도 모두 보존한다.

## 검증과 다음 판단

별도 스칼라 수량 재생·이진 검색·사건별 집계로 전체 행과 요약을 검산한다. 합성 검사에는 부분 체결·반전·청산·펀딩·정확한 시간 경계·같은 시각 반대 체결·최초 기록 이전 미상·잘못된 수량·중복·정렬·미래 사건 추가 불변성을 포함한다. 기존 모형·가중치·문턱·매매 조건과 손실 결과는 유지한다.

결과로 실제 신규 진입과 관측 경계의 표본 부족을 구별한 뒤, 학습 기간·정보 시각·정답에 관한 후속 가설을 따로 고정한다. 단순한 시간 해상도 변경이나 더 긴 학습 기간이 수익성을 보장한다고 주장하지 않는다. 원본·파생 자료·개별 원장은 로컬에만 저장하며 코드·합성 검사·방법·집계 결과만 공개한다. 실제 거래 연결은 없으며 기존 v10 수익성 기준과 goal은 유지한다.
