# 실험 v30 사전 계획: 관리 행동의 시간순 예측 진단

2026-10-04. v28 방향 모사 개선과 v29 최초 노출 분리 모두 2022년 수익성 확인을 통과하지 못했다. v28은 수수료·펀딩 차감 전 가격 손익도 후속 기간에서 음수였다. 비용만 낮춰 문제가 해결됐다고 가정하지 않는다. 이번 단계는 추가·축소·청산의 조건부 관계를 현재 선형 관리 모형이 충분히 표현하는지 검증하는 진단이다.

## 입력과 시간 경계

- 현재 관리의 기반인 v21 원본 분별 정답과 44개 확정 특징을 그대로 사용한다. 원래 독립 주문의 청산·축소·추가 요청 정답이다. 실제 최종 종료 체결을 목표로 한 v24와 의미가 다르며, 이번에 정답 종류를 함께 바꾸지 않는다.
- 기존과 같은 2020-01-01~2021-07-01 미만 학습, 2021-07-01~2022-01-01 미만 진단이다. 원래 양쪽 24시간·포지션 경계 제거를 재계산하고 v21 저장 학습·보정 행과 모든 열이 정확히 같아야 한다. 기간 간 포지션 교집합은 없어야 한다.
- 각 행동마다 학습 최소 1,000행·양성/음성 각각 20개, 진단 최소 100행·각각 20개를 요구한다. 자료·모델·부모 선택 지문을 대조하며 부족하면 실패를 보존하고 기준을 낮추지 않는다.
- 모든 원본 기간은 이미 관찰했다. 진단 기간은 기존 모델의 문턱·빈도 보정에도 쓰였으므로 새 미사용 평가가 아니다. 원본 행동의 모사 능력과 봇이 방문하는 상태의 순손익은 다르다.

## 고정 모형과 판단

기존 표준화 로지스틱 C=.1 모형을 비교 기준으로 보존한다. 동일한 과거 학습 행에서 숫자 모형을 재구성해 기존 v21과 정확히 대조한다. 각 행동의 학습 양성 비율을 항상 출력하는 상수 기준도 기록한다.

새 후보는 행동별 히스토그램 부스팅 하나씩, 총 세 개다. `HistGradientBoostingClassifier`의 로그 손실, 64회, 학습률 .05, 최대 말단 4개·깊이 2, 말단 최소 64, L2=1, 최대 구간 255, 전체 특징·무가중치·seed 0으로 고정한다. 자동 조기 종료를 끄고 학습 행 내부의 임의 검증 분할을 만들지 않는다. 매개변수·행동별 후보 조합을 검색하지 않는다.

진단 로그 손실·Brier·평균 정밀도(AP)·ROC AUC·실제 양성 수·평균 점수를 행동별로 기록한다. 세 행동 모두에서 부스팅 로그 손실이 기존보다 상대 1%를 초과해 개선되고 학습 빈도 상수 기준보다 낮으며 AP가 기존 이상이어야 후속 관리 후보를 허용한다. 동점·수치 경계는 미통과다. 하나라도 실패하면 새 관리 매매 후보를 만들지 않고 실패와 원래 정책을 보존한다. 수익률로 이 판단을 바꾸지 않는다.

이 단계에서는 매매를 실행하지 않는다. 통과하더라도 별도 매매 비교 계획을 먼저 고정한 뒤 진입·위험을 보존한 후속 후보를 검증한다. 새 관리 모형의 행동 문턱과 빈도 배율을 연결해야 하므로 예측 진단 통과 자체를 수익성 개선으로 표시하지 않는다.

## 숫자 모델과 재현

피클·실행 코드 직렬화 대신 제한된 숫자 JSON을 사용한다. 고정 의존성의 내부 트리 배열을 읽는 내보내기 부분은 노드 구조·종류·개수·깊이·유한 숫자를 검사한다. 독립 라이브러리 예측과 학습 및 진단 전체 점수가 허용 오차 내에서 같지 않으면 중단한다. 저장 후 예측은 검증한 숫자 배열만 사용하며 임의 코드를 로드하지 않는다. 입력·출력 해시, 단일 행/묶음 예측, 변조·순환·비정상 입력 거부와 판단 재계산을 검사한다.

[공식 히스토그램 부스팅 문서](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.HistGradientBoostingClassifier.html)에 따라 큰 자료에 맞는 모형과 명시적인 조기 종료 설정을 사용한다. 이는 수익성 또는 시장 변화에 대한 보증이 아니다. 원본·모델·개별 결과는 로컬에서만 보존하고 작업별 커밋 직후 푸시한다.
