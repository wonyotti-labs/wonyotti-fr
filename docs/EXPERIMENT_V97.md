# 실험 v97 사전 계획: 담보 포함 BTC 노출의 방향·크기 학습

2026-10-11. v96의 전체 계좌 평가와 가격 활동 검산을 완료했다. 기존 선물 수량의 부호를 계좌 전체 방향으로 해석하면 차이가 크다. 이번에는 BTC 부분 민감도를 계좌 평가액으로 나눈 부호 있는 노출을 학습 정답으로 연결한다. 아직 이번 정답으로 모형을 학습하지 않았으며, 기존 방향·수익성 실패를 보존한다.

## 정답과 시간 범위

v44의 2020년 학습·2021년 진단 전체 행, 양쪽 24시간 제거, 기존 포지션 경계 배제와 14개 확정 시장 입력을 유지한다. 입력에 원본 수량·지갑·계좌 평가액·미래 주문·현재 원본 노출을 넣지 않는다. 각 행의 label_end 직전 원장을 v96 검산 결과에 연결한다. 원본 경계의 체결 제외 규칙도 유지한다.

정답은 `BTC 부분 민감도 / BTC 계좌 평가액`이다. v96의 앞뒤 하루 확장 입출금 창에서 외부 입출금이 확정되고, 필요한 모든 가격에 해당 봉의 실제 거래가 있으며, 가격 ±1% 대조의 계좌 평가액 하한이 양수인 행에 기본 종가 정답을 부여한다. 정답 자체를 수익·크기·방향에 따라 자르거나 손실 행을 제외하지 않는다. 나머지 행은 정답 미지원 사유를 보존한다. 가격 민감도 구간이 0을 가로지르더라도 기본 종가 회귀 정답을 임의로 삭제하지 않고 별도 불확실성 지표에 반영한다.

각 목표의 기본 노출과 가격 ±1%의 노출 구간을 저장한다. 현재 경계의 노출도 같은 규칙으로 별도 연결하되, 이는 현재 원본 상태를 그대로 유지하는 진단 기준에만 사용한다. 그 기준은 실제 봇이 이용할 수 없는 원본 상태를 사용하므로 실행 가능한 전략으로 표시하지 않는다. 예측은 정답 미지원 행을 포함한 전체 시장 입력에 남긴다.

## 고정 모형과 대조

단일 비선형 후보는 HistGradientBoostingRegressor의 제곱 오차, 64회, 학습률 0.05, 최대 깊이 2·말단 4개, 최소 말단 표본 64개, L2 1, 최대 구간 255개, 전체 특징, 범주 특징 없음, 조기 종료 없음, seed 0이다. 시간순 학습 범위 밖의 입력·정답으로 구간·모형·상수를 맞추지 않는다. 숫자 트리로 저장하고 pickle을 사용하지 않는다.

대조는 학습 정답 평균 상수, BTC 노출 0과 1 상수, 학습 전용 StandardScaler와 Ridge(alpha=1, svd)의 선형 예측이다. 선형 모형은 고정된 설명용 대조이며 결과를 보고 비선형 후보와 교체하지 않는다. 학습 1,000행·진단 100행 및 학습의 양수·음수 정답 각각 20행 이상을 요구한다. 지속된 상태 행을 독립 거래로 세지 않는다.

전체·월별 MSE·MAE·방향 적중·각 방향 재현율과 예측 노출 분포를 기록한다. 예측이 v96 가격 민감도 구간 밖으로 벗어난 거리도 별도 계산한다. 현재 원본 노출 유지 기준은 양쪽 정답이 지원되는 같은 행에서만 비교하고 분모를 명시한다. 전체 정답 미지원 사유·월·기존 선물 방향도 유지한다. 예측 오차가 낮아졌다는 이유로 수익성을 채택하지 않는다.

## 검산과 정책 연결

별도 Decimal 나눗셈과 원본 비교 행 연결로 정답·지원 사유를 대조한다. 독립 라이브러리 재학습·숫자 트리·폐쇄형 릿지 해·직접 지표 계산으로 전체 예측과 월별 분모를 확인한다. 경계 오류·순서·미래 변경 불변·미지원 가격·입출금·비양수 계좌·모형 변조를 합성 검사한다. v93의 검산 중인 공유 소스는 바꾸지 않으며 별도 준비 코드로 실행하고, 운영 등록 시 전체 결과를 재현한다.

이 결과는 방향과 크기를 일관되게 반영하는 후속 매매 정책의 입력이다. 후속 정책의 노출 제한·재조정·위험 한도·비용·지연은 손익 계산 전에 별도 계획으로 고정한다. 원본 상태 유지 기준을 실제 봇에 주입하지 않는다. 예측 성적만으로 정책 검증을 끝내지 않고, 비용 포함 연속 매매와 v10의 다년·다시장·낙폭·표본 기준까지 계속한다. 모든 기간은 이미 관찰했으며 원전략·전체 알트코인 손익·재산 진위를 복원했다고 주장하지 않는다.

구현은 설치된 scikit-learn 1.9.1과 [공식 회귀 모형 명세](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.HistGradientBoostingRegressor.html)를 연결한다. 원본·시세·정답·모형·개별 결과는 로컬에만 보관한다.
