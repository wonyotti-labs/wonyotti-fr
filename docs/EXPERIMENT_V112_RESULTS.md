# v112 동일 표본의 계좌 크기 입력 비교 결과

2026-10-11. [사전 계획](EXPERIMENT_V112.md)에 따라 동일 행의 32개 기존 입력과 계좌 크기를 더한 33개 입력을 비교했다. 사전 조건 17개 중 8개 충족으로 **후속 예측 후보 조건 미달**이다. 원본 상태를 공급한 행동 예측 결과이며 자체 계좌 수익률은 아니다. 조건·모형·문턱을 성적 확인 뒤 바꾸지 않았다.

후보의 청산 신호 63개는 적중 0개·오탐 63개였으며 같은 행 대조는 85개 중 3개를 맞혔다. 청산·축소·추가 로그 손실은 대조보다 각각 4.83%·8.13%·3.87% 나빴다. 0.5배 이하에 청산이 집중된 v111의 관찰이 이번 조건에서 청산 시점 재현으로 이어지지 않았다. 이 후보를 매매에 연결하지 않는다.

## 동일 행 비교

학습 90,736행·207개 에피소드, 보정 42,513행·80개, 진단 46,738행·29개를 사용했다. 학습 양성 창은 청산 218·축소 875·추가 914개이며 보정 75·448·426개, 진단 27·162·149개다. v111의 전체 403,776개 원본 창과 미지원 행을 그대로 보존했다. 2018~2019년 계좌 지원은 없으므로 기존 32개 대조도 같은 2020년 행에서 다시 학습했다. 원래 전체 기간 v108 점수와 직접 비교하지 않는다.

두 부스팅의 설정·학습 행·정답은 같고, 후보에만 `log1p(절대 XBTUSD 명목 가치 / 계좌 자산 USD)`를 추가했다. 33개 선형 모형과 학습 빈도 상수도 같은 행을 사용했다. 문턱은 2021년 상반기에서 청산 F2·축소 F1·추가 F0.5로 고정했다. 다음은 하반기 전체 진단이다.

## 판정과 검산

미달 조건: `exit_log_loss_baseline`, `exit_log_loss_linear`, `reduce_log_loss_baseline`, `reduce_log_loss_linear`, `increase_log_loss_baseline`, `increase_ap_baseline`, `increase_log_loss_linear`, `exit_recall`, `exit_f_beta`.

두 부스팅의 384개 트리와 선형 계수를 별도로 학습해 대조했다. 전체 예측 89,251행과 모형별 단일 상태 추론 267,753개, 보정 문턱·모든 부분집합 지표·우선순위 선택·17개 조건을 독립 검산했다. 모든 공동 지원 행의 기존 열·기간 분리·v111 지원 수치와 저장·복원이 일치했다. 신규 검사 26개·관련 포함 145개 및 Ruff 검사를 통과했다. 전체 저장소 검사나 원격 CI 통과 주장과는 구분한다.

첫 실행은 검산용 학습 빈도를 예측 행마다 다시 합산하는 비효율을 실행 표본·중단 추적으로 확인해 중단했다. 당시 모형·자료·소스·로그를 보존했다. 합산을 한 번 수행하도록 수정한 뒤 다시 실행했으며 두 부스팅·선형 모형, 학습 지원 수치와 세 기간 자료 파일이 첫 실행과 바이트 단위로 같았다. 표본·설정·정답·문턱 선택 규칙 변경은 없다.

원본 5개·공유 소스 312개·동결 입력 401개 지문을 유지했다. 원본·파생 자료·모형·개별 출력은 Git 제외 상태다. 실제 주문·인증 연결은 없다.

수익성 문제는 미해결이다. 원본 BitMEX와 기존 Binance 시세, BTC 담보와 USDT 계좌의 차이가 남아 있으며 실제 운용 입력은 자체 계좌에서 계산해야 한다. 기존 v10 다년·다시장·비용·펀딩·지연·낙폭·거래 수 기준과 모든 이전 실패·기간 관찰 이력을 유지한다.


## 사후 진단: 학습 적합도와 이후 기간의 차이

후보의 복잡도를 늘리기 전에, 저장된 세 모형과 상반기 고정 문턱을 그대로 사용해 학습 자료의 점수도 계산했다. 새 학습·문턱 탐색·표본 변경은 없다. 아래는 같은 행 32개 대조에 대한 후보의 로그 손실 개선율 `100 × (1 - 후보 손실 / 대조 손실)`이다. 양수는 개선, 음수는 악화다.

| 기간 | 청산 | 축소 | 추가 |
| --- | --- | --- | --- |
| 학습 2020년 | +3.9177% | +3.3862% | +0.3796% |
| 보정 2021년 상반기 | -0.1634% | -1.9834% | -0.9639% |
| 진단 2021년 하반기 | -4.8321% | -8.1332% | -3.8715% |

계좌 크기는 학습 자료에서 세 행동의 적합도를 높였지만 이후 두 기간에서는 모두 악화됐다. 학습 자료 점수는 해당 정답으로 이미 학습한 모형의 값이므로 시간순 검증 성과로 사용할 수 없다. 같은 기간·같은 정답의 두 모형을 비교했으며, 기간 사이의 원시 로그 손실 크기는 행동 빈도 차이 때문에 직접 우열로 해석하지 않는다.

이 결과는 추가 입력의 학습상 이득이 이후 기간으로 이어지지 않았다는 근거다. 과적합·시장 변화·트레이더 행동 변화 중 어느 원인이 지배적인지, 더 깊은 모형이 반드시 실패할지는 확정하지 못한다. 단순 용량 부족을 전제로 다음 모형을 더 복잡하게 만들 근거도 아직 없다.

179,987개 학습·보정·진단 행의 고정 점수·문턱 지표를 별도로 계산하고 수기 지표와 대조했다. 보정·진단의 기존 점수·지표를 재현했고 학습 예측은 별도 새 폴더에 보존했다. 원본·입력·모형·공유 소스 지문을 유지했다. 전체 판정 8/17과 매매 미적용을 변경하지 않는다.
