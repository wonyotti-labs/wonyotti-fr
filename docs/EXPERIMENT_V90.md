# 실험 v90 사전 계획: 앞 학습 안의 시간순 정규화 선택

2026-10-10. 같은 첫 기회에 대한 선형 모델들은 확률 오차와 최초 청산 효과가 비교 기준을 넘지 못했다. 입력을 줄이거나 현재 정보를 추가하는 것만으로 해결되지 않았다. 기존 L2 강도 C=0.1을 고정해 온 제한을 분리하기 위해, 앞 학습 안에서만 시간순 검증으로 강도를 선택한다. 이미 반복 관찰한 외부 보정의 성과로 C를 선택하지 않는다.

## 같은 정답·입력과 네 강도

v89 독립 검산의 호출자 지정 지문과 전체 소비 파일·79개 입력·분봉 연결·부모·현금·비용·보정·코드 봉인을 확인해 재사용한다. 입력·시세·부모 모델·정답·첫 판단·수량·위험·비용·전체 모집단을 변경하거나 다시 생성하지 않는다. 기존 1,277개 첫 학습 행·0 효과·손실·비중·미확정·기회 없음·후속 행을 보존한다.

C 후보는 0.001, 0.01, 0.1, 1.0의 네 개로 고정한다. 다른 설정은 기존과 같은 L2, l1_ratio=0, lbfgs, fit_intercept=True, class_weight=None, seed 0, warm_start=False, max_iter=2000, tol=1e-9이다. 강도가 다른 별도 숫자 모델을 저장하며 전역 설정을 임시로 바꾸지 않는다. 수렴 실패는 보존하고 해당 실행을 중단하며 다른 후보로 대체하지 않는다.

모든 시각은 UTC다. 다음 세 구간만 검증에 사용한다. 각 모델의 학습은 전체 앞 원장에서 해당 시작 이틀 전보다 앞서 진입·판단·자연 종료가 모두 확정된 포지션으로 제한한다.

검증 행은 진입과 첫 판단이 해당 구간 안이고 자연 종료가 종료 경계 전인 행이다. 구간을 넘는 정답과 학습 제외·검증 제외 사유를 모든 원래 행에 기록한다. 같은 포지션이 같은 회차의 학습과 검증에 함께 들어가면 실패한다. 이전 검증 구간의 확정 정답은 이후 회차의 앞 학습에 포함될 수 있다. 전체 봇의 표본 외 평가로 표시하지 않는다.

각 학습은 기존 500포지션·양 방향 각각 20·양 비용 부호 각각 64·180일 지원을 요구한다. 각 검증은 30개 첫 포지션 이상과 양의 총 절대 비용을 요구한다. 지원 부족이면 구간을 변경하거나 다른 기간으로 대체하지 않고 실패를 기록한다.

각 회차의 표준화는 그 회차 앞 학습의 모든 첫 포지션에 동일 비중으로 적합한다. 비영 비용만 해당 앞 학습의 절대 bp 양의 평균으로 정규화해 적합한다. 같은 검증 행에서 네 모델과 그 회차 학습 비용 상수의 모든 점수를 보존한다. 검증 정답은 예측 시점의 입력·표준화·계수·학습 비중에 사용하지 않는다.

## 선택과 고정 보정

세 검증 구간의 모든 첫 행을 모은 비용 로그 손실로 C 하나를 고른다. 각 행의 절대 원래 bp로 로그 손실을 가중하고 전체 비용 합으로 나눈다. 구간 평균의 단순 평균이나 후보별 표본 제외는 없다. 최소값을 고르며 정확히 같은 값이면 더 작은 C를 선택한다. 비용 Brier·각 회차 지표·상수 비교·선택 수·첫 현금 효과도 전부 기록하지만 선택식을 변경하는 데 쓰지 않는다. 외부 보정 2021년 8~9월은 이 선택에 전혀 사용하지 않는다.

선택한 C로 기존 앞 학습 전체 1,277개를 한 번 적합하고, 기존 보정의 같은 첫 기회 93개·전체 96포지션에서 평가한다. 총 적합은 내부 12개와 최종 1개다. 최종 비용 원장·상수는 v89와 정확히 같아야 한다. C=0.1이 선택되면 v89와 같은 숫자 모델이어야 하며 같은 성과는 개선으로 인정하지 않는다. 마지막 진단에는 새 입력·예측을 만들지 않는다.

## 열여덟 정책·열다섯 조건

기존 열일곱 정책·점수·포지션·그룹·실패를 보존하고 선택한 선형 정책 하나만 추가한다. 기존 저장 점수에서 정책 산식을 대조한다. 첫 적격 기회에서 엄격히 0.5를 넘을 때만 청산하고 이후 점수·선택은 없다.

선택 30포지션 이상·전체 최초 평균 양수, v89 분봉 선형·세 확률 선형·77입력 선형·확장 트리·확장 선형·원래 선형·주간 선형·원래 첫 트리·직접 회귀·이후 정책 분류·자연 종료 분류·항상 첫 청산·확장 상수 각각보다 엄격한 개선, 열다섯 조건을 모두 요구한다. 동점은 실패다. 실패 시 마지막 진단과 매매 적용을 차단하며 통과 시 별도 계획으로 마지막 진단과 연속 계좌 검증을 진행한다.

## 검증·해석

전체 행의 세 회차 소속·시간 경계·제외 사유·학습 비중·검증 비용 합, 네 후보와 상수의 모든 예측·풀링·선택·동점 처리를 대조한다. 각 회차 이후 행의 변경이 이전 회차 모델을 바꾸지 않아야 하며 외부 보정의 변경은 C 선택과 최종 모델을 바꾸지 않아야 한다. 별도 학습으로 13개 표준화·계수·절편·모든 점수를 검산하고 79개 입력·원장·비용·열여덟 정책·열다섯 조건·후속 예측 부재를 확인한다. 실제 적합 전에 검사·검산 도구·계획을 고정한다.

부모의 2021년 학습과 반복 관찰한 외부 보정의 제한은 그대로다. 내부 교차검증이나 더 작은 확률 오차를 전체 봇 수익성으로 표시하지 않는다. 최종 v10 다년·다시장·비용·펀딩·지연·낙폭·표본·집중 기준을 유지하고 실제 거래 연결은 없다.
