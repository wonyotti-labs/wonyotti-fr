# 실험 v58 사전 계획: 손절 위험과 조건부 손익의 분리 진단

2026-10-04. v57의 단일 손익 부스팅은 선형 회귀보다 오차가 줄었지만 학습 평균 상수와 진입 표본 조건에 미달했다. 전체 행·분리·가중치·독립 재학습·예측·판정을 대조했으며 봇에는 적용하지 않았다. 전체 정답의 설명 집계에서 손절 종료의 평균 손실이 다른 종료의 평균 이익보다 훨씬 컸다. 직접 금액 회귀와 구별해 손절 발생 확률을 학습하는 단일 가설을 고정한다.

## 자료와 고정 모형

- v57의 모든 학습·진단 행, 31개 입력, 구간별 중첩 가중치와 배제 원장을 그대로 사용한다. 원래 v55·v56 자료와 부모 정책·현재 계획 지문, v57의 기존 모델과 예측을 재현한다. 손실·손절·0 손익을 삭제하거나 정답 금액을 절단하지 않는다.
- 학습은 2021년 1월 1일 이상 판단·9월 30일 00:00 UTC 전 종료, 진단은 10월 2일 이상 판단·12월 31일 전 종료다. 경계와 미확정 제외 사유를 보존한다. 기존 분리·방향·기간 지원과 함께 학습 전체 1,000행·손절/비손절 각각 64행, 진단 각각 20행 이상을 요구한다.
- 목표는 현재 정책에서 `intrabar_stop`으로 종료했는지다. 종료 사유는 미래 정답으로만 쓰고 진입 입력에는 넣지 않는다. 나머지 종료도 손익 부호와 관계없이 모두 비손절 집단에 남긴다.
- 히스토그램 분류기 하나를 로그 손실·64회·학습률 0.05·깊이 2·최대 말단 4·최소 말단 64·L2 1·최대 구간 255·전체 특징·범주형 없음·seed 0으로 학습한다. 양수 중첩 가중치만 쓰며 클래스 균등화·금액 가중·조기 중지·별도 보정·설정 탐색은 없다. 기존 관리 분류기의 고정 복잡도를 재사용한다.
- 학습 구간에서 손절 집단과 비손절 집단 각각의 가중 평균 순손익을 계산한다. 예측 순손익은 `손절 확률 × 학습 손절 평균 + (1−손절 확률) × 학습 비손절 평균`이다. 두 집단의 손익 크기를 입력에 따라 변화하지 않는 상수로 근사하는 제한을 명시한다. 확률은 학습된 값이며 진단 실제 사유를 예측식에 대입하지 않는다.

## 진단과 채택 조건

같은 진단 행에서 v57의 Ridge·금액 부스팅·학습 평균 상수와 모두 비교한다. 아래를 모두 만족해야 후속 매매 연구를 허용한다.

1. 가중 평균 제곱 오차가 세 기준 각각보다 1% 초과 작음.
2. 무가중 평균 제곱 오차가 두 학습 모형 각각보다 악화하지 않음.
3. 기존 8bp 기준을 통과한 기회가 30개 이상이며 선택한 기회의 가중·무가중 평균 순손익이 모두 양수.
4. 손절 확률의 가중 로그 손실이 학습 손절 빈도 상수보다 1% 초과 작고 가중 Brier 오차가 악화하지 않음.

전체·방향별·월별 금액 오차와 선택 표본·실제 손익, 손절 확률 오차를 모두 보고한다. 조건을 통과해도 연속 계좌 수익성이나 원본 전략의 복원을 뜻하지 않으며 봇 적용·전체 재학습은 별도 계획으로 고정한다. 실패한 경우 적용하지 않는다. 반복 관찰한 기간의 선택 편향과 기존 전체 시스템의 2021년 학습을 유지하며 미사용 평가로 부르지 않는다.
