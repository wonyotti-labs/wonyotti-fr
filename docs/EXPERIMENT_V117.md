# 실험 v117 사전 계획: 원본 관리 행동과 체결 방향

2026-10-12. v116에서 거래소 관측원 정렬은 세 행동의 로그 손실을 소폭 개선했지만 청산·추가의 사전 기준을 넘지 못했고 청산 오탐이 늘었다. 기존 50개 관리 입력에는 가격·총거래량·보유 상태·과거 주문이 있지만 매수 taker 비중이 없다. 이번에는 기존 입력과 원본 정답을 유지하고 시장의 체결 방향 열두 개만 더한다. 원본 트레이더가 이 정보를 사용했다고 단정하지 않는다.

v71의 다섯 창·방향 체결 입력과 v89의 직전 분봉 입력은 이미 봇의 추가 청산 손익 학습에서 사용했고 실패했다. 이번 검증 대상은 해당 손익 정답이 아닌 v35의 원본 청산·축소·추가 요청이다. 실패 이력을 보존하고 체결 방향의 최초 사용이라고 주장하지 않는다.

## 첫 단계: 기존 전체 행과 입력 검산

v116 입력·모형 완료 증거와 그 원본 연결 지문을 확인한 뒤 v35의 2020년 학습 510,102행, 2021년 상반기 보정 256,234행, 하반기 진단 252,124행을 읽는다. 기존 50개 입력·모든 열·정답·행 순서·24시간 제거·포지션 분리를 그대로 유지한다. 세 기간은 이미 반복 관찰했다. v116의 교체 입력에서 비유한이던 보정 55행도 원본 값이 유효하므로 이번에는 포함한다. 이 실험에서 가격 출처 교체나 행 제외는 없다.

새 입력의 출처는 v116에서 봉인한 Binance BTCUSDT USD-M 1분·5분 자료다. [Binance 공식 USD-M 공개 자료 설명](https://github.com/binance/binance-public-data/blob/master/README.md#klines-1)의 총 기본자산 거래량과 매수 taker 기본자산 거래량을 사용한다. 개별 트레이더의 주문이나 호가창을 관측한 것으로 해석하지 않는다. 원래 50개는 BitMEX 기반인 채 유지하며 새 열만 외부 시장 맥락이다. 동일한 원본 대조와의 차이는 이 추가 입력이다.

추가 열은 확정 1분·5분·15분·1시간·4시간·1일의 `2 × 매수 taker 거래량 합 / 전체 거래량 합 − 1` 여섯 개와 각각 현재 보유 방향을 곱한 여섯 개다. 1분은 판단 시각에 정확히 끝난 봉 하나, 나머지는 가장 최근 확정 5분 봉까지의 1·3·12·48·288개 창이다. 봉별 비율을 평균하지 않는다. 기존 v71·v89의 식·창·이름을 재사용하며 추가 창 탐색은 없다.

시간은 UTC 분·5분 경계, 중복·연속성·OHLC·체결 수를 검증한다. 거래량은 유한하며 `0 ≤ 매수량 ≤ 총량`이어야 한다. 총량이 0인 완전한 창만 불균형 0으로 기록하고 준비 부족을 0으로 채우지 않는다. 롤링 합의 부동소수점 경계 오차 1e-12 안에서만 비율을 [-1, 1]로 제한한다. 두 해상도의 기존 OHLC·총량 대조와 별도로 매수량도 1분 합과 5분 값의 절대 오차 1e-7 이하인지 검사한다. 불일치 시 보간·교체·행 삭제 없이 지원 실패를 보존한다.

원래 모든 행의 판단 시각·원본 행 번호·두 원천 봉 종료·열두 값·지원 사유를 저장한다. 세 기간 모두 전체 행 지원과 각 행동 양성·음성 20개 이상을 요구한다. 지원 부족이면 학습하지 않는다. 별도 이진 검색과 직접 창 합으로 모든 값을 검산하고 기존 열·정답·행 보존 및 저장 후 읽기 일치를 확인한다. 미래 봉 변경·연장이 과거 입력을 바꾸지 않아야 한다.

## 두 번째 단계: 고정 모형과 시간순 비교

입력 검산 통과 뒤 같은 전체 학습 행으로 원본 50개 부스팅, 확장 62개 부스팅 후보, 확장 62개 표준화 로지스틱을 각 한 번 적합한다. 원본 대조의 트리와 상반기 절편은 기존 v35와 정확히 같아야 한다. 부스팅은 64회·깊이 2·최대 말단 4·학습률 0.05·최소 64행·L2 1·255구간·seed 0·조기 종료 및 가중치 없음이다. 로지스틱은 기존 C=0.1·학습 전용 표준화·무가중치 설정을 유지한다. 하반기 입력·정답은 적합·보정·문턱 선택에 사용하지 않는다.

세 모형은 상반기에서만 기존 기울기 1·[-64, 64] 100회 이분법으로 절편을 보정한다. 동일 상반기 행동 빈도 상수와 모든 모형의 원시·보정 점수를 대조한다. 문턱은 상반기 청산 F2·축소 F1·추가 F0.5 최대화와 최소 예측 양성 20개 규칙으로 고정한다. 전체·월별 로그 손실·Brier·AP·양성 수·요청·TP·FP·FN, 새 입력의 분기 사용 수를 남긴다. 일부 행동·창·월의 결과만 골라 후속 후보를 만들지 않는다.

세 행동 모두에서 후보 보정 로그 손실이 원본 보정 부스팅과 확장 보정 로지스틱보다 각각 1% 초과 개선되고 AP는 두 대조 이상이어야 한다. 자체 원시 로그 손실보다 나쁘지 않고 보정 빈도 상수보다 좋아야 한다. 수치 경계 1e-12를 유지한 총 18개 조건을 모두 요구한다. v116 실패 후 문턱이나 기준을 낮추지 않는다. 독립 라이브러리 재학습의 384개 트리·표준화·계수, 별도 확률·절편·문턱·전체 및 월별 집계·판정을 검산한다.

## 후속 범위

예측 관문 실패 시 이번 후보의 자체 계좌 확장을 하지 않는다. 통과 시에만 별도 계획에서 원본 상태를 공급하지 않는 자기 계좌의 다년·다시장·비용·펀딩·지연·낙폭·표본·집중 검증을 진행한다. v115의 최근 BTC 8거래, 다른 구간의 손실 및 v10 최종 기준은 그대로 남는다. 행동 예측 개선은 수익성 달성과 별개다. 원본·시장·파생 자료·모델·개별 출력은 로컬에만 보존하고 실제 거래 연결은 추가하지 않는다.
