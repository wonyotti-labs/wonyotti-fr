# 실험 v3 사전 계획: 학습 행동 빈도를 반영한 정책

2026-10-01. v2의 개발·2022~2025년·2026년 1~8월 결과와 실패 원인 분해를 관찰한 뒤 작성한다. 해당 기간은 이후 후보의 새 미사용 평가가 아니다. 아래 후보를 아직 실행하지 않은 상태에서 계획을 고정한다.

## 가설

v2는 희소 행동을 학습하기 위해 클래스 균형 가중치를 사용했다. 이 손실 함수의 점수를 실제 행동 빈도를 반영한 확률로 해석할 수 없다. 원본의 무포지션·진입 표본은 연도별로 크게 다르며, 봇은 잦은 반전과 청산으로 비용을 누적했다.

학습 구간의 행동 빈도를 점수에 반영하면 불필요한 거래를 줄일 수 있는지 조사한다. 수익 개선이나 원전략 복원을 가정하지 않는다. 무거래가 되어 손실이 없더라도 충분한 거래가 없으면 후보 부적격이다.

## 고정 입력과 후보

v2의 2018~2019년 학습 모델·특징·계수를 그대로 사용한다. 학습 경계의 에피소드와 마지막 24시간을 제외한 자료에서 진입·관리 모델별 클래스 빈도 `pi`를 계산한다. 2020년 이후의 빈도나 수익을 여기에 섞지 않는다.

가중 분류기의 점수 `q`에 대해 `q_adjusted(c) ∝ q(c) × pi(c)^alpha`를 적용한다. `alpha=0`은 원래 점수, `alpha=1`은 균형 가중치의 빈도 효과를 역으로 조정하는 근사다. 정규화·유한 표본·모형 오류가 있으므로 이 조정을 검증된 확률 보정이나 수익 확률로 표현하지 않는다. 입력이 불완전하면 계속 대기하며 사전 빈도만으로 진입하지 않는다.

후보는 `alpha {0, 0.5, 1}` × 진입 기준 `{0.50, 0.65}` × 관리 기준 `{0.35, 0.50}`의 12개다. 두 모델에 같은 alpha를 사용한다. 위험 설정은 v2의 고정 선택 파일에서 그대로 가져오며 손절·보유 시간·규모를 다시 탐색하지 않는다. 수수료·슬리피지·펀딩·다음 봉 실행과 총 노출 한도를 유지한다.

## 선택과 평가 순서

1. 입력 해시·학습 빈도·12개 조합을 실행 폴더에 먼저 저장한다.
2. 2020년 BTC에서 종료 거래 20개 이상인 후보 중 `순수익 - 0.5 × 최대낙폭 절댓값`으로 선택한다. 동점은 후보 순서로 결정한다. 부적격이면 기준을 완화하지 않는다.
3. 선택을 고정한 뒤 2021년 모사 정확도·지원 표본·다중 클래스 Brier 점수·로그 손실과 매매 성과를 보고한다. 표본 부족은 성능 입증으로 해석하지 않는다.
4. 2022~2025년 세 시장과 이미 관찰한 2026년 1~8월에 같은 후보를 적용한다. 원래 점수의 같은 위험 설정과 비교하고 비용 2~3배·한 봉 지연·연도별 초기화를 구분한다. 이는 탐색적 진단이다.
5. 개발 순수익 양수, 2021년 BTC 순수익 양수·종료 거래 20개 이상·영구 중지 없음 조건을 모두 충족할 때만 아직 열지 않은 2026년 9월 자료를 고정 후보로 확인한다. 미충족이면 새 자료를 소비하지 않고 실패를 기록한다.

2026년 9월은 짧은 후속 점검이며 장기간 수익성을 입증하지 않는다. 자료 미공개·불완전·거래 수 부족이면 그대로 기록한다. 이미 본 기간을 다른 이름으로 최종 평가에 재사용하지 않는다.

## 실행·판정

원본 손실 거래를 삭제하지 않는다. 모델 구조·학습 빈도·후보 선택을 바꾼 실행은 별도 버전으로 보존한다. 향상 여부는 거래 수 감소와 비용 감소뿐 아니라 가격 손익·낙폭·다시장 안정성을 함께 확인한다. 모든 조건이 좋아도 실제 주문 연결을 승인하지 않는다.

빈도 적용의 수치 일치, alpha=0의 기존 점수 재현, 잘못된 빈도 거부, 결측 입력 대기, 같은 엔진의 재시작 일치를 검증한다. 가중 분류 점수와 실제 관측 빈도의 차이는 신뢰도 구간별 표본 수와 함께 보고한다.

## 방법 근거와 추론 범위

[scikit-learn 로지스틱 회귀 문서](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.LogisticRegression.html)는 balanced 가중치가 학습 클래스 빈도에 반비례함을 명시한다. [확률 보정 안내](https://scikit-learn.org/stable/modules/calibration.html)는 예측 확률과 관측 빈도의 일치 여부를 별도 평가한다. 이 문서들이 해당 매매 후보의 수익성을 지지하는 것은 아니다. 빈도 반영으로 거래가 줄어들 수 있다는 주장은 이번에 검증할 가설이다.
