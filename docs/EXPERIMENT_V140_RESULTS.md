# 실험 v140 결과: 높은 점수 음성의 가중 학습

2026-10-12. 고정한 42개 조건 중 20개를 충족해 후속 자체 계좌 연구 조건에 미달했다. 모든 원본 행을 유지한 가중 학습에서도 낮은 오신호 예산의 새 적중은 유지되지 않았다. 새 계좌 실행과 수익성 개선 증거는 없으며 손실 문제는 미해결이다.

핵심 집단인 하반기 한도 전 재시작 추가는 47,962행·양성 35분이다. 기존 v127의 TP/FP/FN 0/1/35가 후보에서 1/18/34로 변했다. 평균 정밀도는 0.01808798777에서 0.02422530000으로 개선됐지만 로그 손실은 0.004800102020에서 0.004986772885로 악화됐다. 한 적중 분과 전체 순위 지표 일부의 개선만으로 실행 가능성을 입증하지 못했다.

상반기 FP 예산 15를 고정하면 후보 상반기 TP/FP/FN은 4/68/56에서 0/15/60으로, 하반기는 1/18/34에서 0/7/35로 변했다. 하반기 기존 모델은 같은 보정 절차 아래 0/1/35였다. 후보는 새 적중을 잃으면서 기존보다 더 많은 오신호를 남겨 공통 예산의 두 조건 모두 미달했다. 하반기의 유일한 원래 적중은 7월에 있었으며 공통 예산에서는 사라졌다. 공통 예산 문턱의 하반기 오신호는 7월 5분·9월 2분이었다. 11·12월의 빈 원본 집단도 보존했다.

축소 quiet의 하반기 TP/FP/FN은 2/14/138에서 3/334/137로 변했고, 추가 quiet는 1/11/145에서 5/73/141로 변했다. 로그 손실은 각각 10.4033%, 5.5983% 악화됐다. 전체 상태의 F도 두 행동에서 모두 낮아졌다. 가중치 변경이 오신호와 확률 품질을 함께 개선하지 못했으며, 좋은 추가 상태만 선택해 축소 실패를 감추지 않았다.

가중 학습 행은 축소 497,219개·추가 494,681개다. 높은 점수 음성은 각각 4,965개·4,939개이며 경계 동점은 각각 하나였다. 유효 표본은 283,282.31개·280,375.43개로 지원 기준을 넘었다. 양성의 총 가중 비중은 1.3562%·1.5131%, 높은 점수 음성은 9.0503%·9.0363%였다. 나머지 음성도 양수 가중치로 모두 유지했다. 지원 부족이나 행 삭제로 생긴 성적으로 해석하지 않는다.

학습 핵심 집단의 평균 정밀도는 0.04308138989에서 0.06125318459로 높아졌지만 상반기에는 0.02832797889에서 0.01897552175로 낮아졌다. 같은 학습 자료에 적합한 기존 모델의 점수로 난도를 정한 절차가 이후 기간에서 일반화됐다는 근거를 얻지 못했다. 이번 비교는 가중치가 손실과 구간 경계에 함께 영향을 주며, 학습 점수의 낙관성이 실패의 유일한 원인이라는 인과 주장도 하지 않는다.

[사전 계획](EXPERIMENT_V140.md)의 자료·정답·가중치·42개 조건을 유지했다. 양성·TP·FP·FN은 분 단위이며 독립 거래 횟수가 아니다. 모든 평가 기간은 이미 관찰한 사후 연구다. 공통 예산은 상반기 v127의 FP로 정하고 하반기에서 다시 조정하지 않았다.

학습 시 원래 음성의 상위 1% 경계(동점 포함)와 모든 양성에 1, 나머지 음성에 0.1을 부여한 뒤 평균 1로 정규화했다. 원본 행은 모두 유지했다. 가중치의 기준 점수는 같은 2020년 자료에 적합한 기존 모델의 점수다. 독립 난도 추정이나 당시 실시간 가용 점수로 해석하지 않는다. 2021년 상반기 보정과 하반기 평가는 무가중이다.

같은 50개 입력과 행동별 256개 트리, 두 선형을 사용했다. StandardScaler는 학습 자료에서 무가중 적합하고 로지스틱 회귀에는 같은 표본 가중치를 전달했다. 설치된 scikit-learn 1.9.1에서 가중치는 히스토그램 구간에도 영향을 주므로 순수한 손실 비중만의 비교가 아니다. 상태 보정은 v127과 같이 first/restart의 원시 점수에 별도로 적합하며 전체 quiet 절편을 중첩 적용하지 않는다. 청산·recent의 확률과 요청을 보존했다.

## 검산과 실행 이력

새 검사 56개를 포함한 관련 297개 검사(24.22초)와 Ruff를 통과했다. 전체 테스트 모음이나 원격 CI를 실행했다고 주장하지 않는다. 기존 무가중 512개 트리·두 선형을 재현하고 새 가중 512개 트리·두 선형을 독립 재적합했다. 가중치·전체 확률·보정·문턱·모든 상태·월·횟수·공통 예산·42개 판정, 저장 후 재읽기와 입력 지문을 대조했다.

최초 실행은 디스크 공간 부족으로 로그 기록 중 중단됐다. 해당 폴더와 불완전 프로세스 기록을 보존했다. 재다운로드 가능한 uv 캐시 정리 후 같은 코드·계획으로 새 폴더에서 재실행해 정상 종료와 검산 완료를 확인했다. 원본·시장·기존 연구 증거는 삭제하지 않았다.

전체 대조·상태·월·횟수·가중치·오신호 예산과 요청 겹침은 [집계 부록](EXPERIMENT_V140_TABLES.md)에 수록했다. 원본·파생·모델·행별 출력은 로컬에만 보존한다. 실제 주문 연결은 없고 v10의 최종 다년·다시장 수익성 기준을 유지한다.
