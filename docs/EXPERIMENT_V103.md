# 실험 v103 사전 계획: 기록된 변경량을 공급한 자체 계좌 진단

2026-10-11. [v102](EXPERIMENT_V102_RESULTS.md)에서 정답의 계약 범위 차이를 확인했지만 기여량 대부분은 XBTUSD였다. 단순히 계약을 분리해 같은 학습을 반복하기 전에, 기록된 변경량을 현재 봇 계좌에 적용하는 변환과 실행 제약을 진단한다. 새 모형을 학습하거나 이 재생 결과를 예측 가능한 전략의 수익으로 채택하지 않는다.

## 앞선 원본 재생과의 관계

[v9](EXPERIMENT_V9.md)은 원본 XBTUSD 포지션의 역선물 수량·원가·펀딩을 재현하고 추가 제거·30분 제한·가격·비용을 비교했다. 이번에는 v98 이후의 초기 10,000 USDT·포지션 0 계좌와 노출 변경량 정책을 사용한다. 원본 원금과 수량을 복제하는 재생이 아니며 서로의 금액·수익률을 같은 기준으로 비교하지 않는다.

기록된 변경량은 당시 원본 계좌에서 얻은 값이다. 다른 상태에 있는 봇에 최적이거나 실제 거래자가 선택했을 정답이라고 가정하지 않는다. 매 시점 원본 잔고나 보유량을 봇에 주입하지 않는다. 초기 상태와 위험 청산 이후 상태의 차이를 보존한다.

## 입력과 여덟 대조 고정

이미 관찰한 BTC 2021년 한 기간을 사용한다. 시세·펀딩·확정 특징은 검산한 v98 공개 실행의 전체 525,600분과 정확히 같아야 한다. 원본 변경량은 v102의 2021년 전체 104,448행에서 가져오며 모든 지원·미지원·원래 행을 보존한다. 새 시세 수집·모형 학습·2022년 이후의 원본 신호 추정은 하지 않는다.

다음 세 축의 모든 조합, 총 여덟 경로를 실행한다. 성과를 보고 조합을 제외하지 않는다.

| 축 | 첫 조건 | 둘째 조건 |
|---|---|---|
| 공급하는 변경량 | 기존 전체 계좌 `execution_change` | 분리한 `xbtusd_execution_change` |
| 신호 공급 시각 | 원본 창 시작 `end` | 원본 창 종료 `label_end` |
| 가격 손절 | 기존 4% | 가격 손절만 비활성화 |

창 시작 공급은 앞으로 5분의 원본 사건·가격·계좌를 알고 있는 사후 설명 대조다. `historical_lookahead` 표시와 300초의 정보 선행을 모든 해당 판단에 기록한다. 이 경로는 미래 정보가 없는 봇이 아니며 엄밀한 성과 상한도 아니다.

창 종료 공급은 해당 정답 창이 끝난 뒤에만 값을 제공한다. 그래도 당시 타인의 실시간 계좌를 관찰할 수 있다고 입증한 정책은 아니다. 두 시각 대조 모두 원본 기록을 아는 설명용 재생으로만 표시한다. 미래 시세나 원본 값을 학습 특징으로 넣지 않는다.

## 판단과 실행 규약

5분 경계에서 해당 시각과 정확히 연결되는 원본 행 하나만 조회한다. 미지원·원본 행 없음은 `None`을 반환하고 사유를 기록한다. 공급 변경량의 절댓값이 기존 경계 `1e-12` 이하면 수량을 유지한다. 그 외에는 `현재 봇 수량 × 확정 종가 / 봇 평가액 + 공급 변경량`을 [-0.5, 0.5]로 제한해 목표로 제출한다. 원본 미래 절대 노출에 계좌를 다시 맞추거나 초기 노출을 사후 조정하지 않는다.

모든 경로는 다음 거래 가능한 분봉 시가·수수료 5bp·슬리피지 3bp·실제 펀딩을 적용한다. 기존 최대 보유 77,699분·대기 15분·일일 손실 3%·최대 낙폭 25%·노출 상한 0.5를 유지한다. 손절 비활성 조건은 `stop_fraction=0`만 바꾸며 일일·누적 위험 중지와 기간 종료 청산은 유지한다. 위험으로 호출되지 않은 원본 신호도 전체 원본 집계에서 없애지 않는다.

각 호출에 판단 시각·원본 창·정보 확정 시각·선행 시간·지원·사유·공급 값·현재 자체 노출·제한 전후 목표를 기록한다. 실제 체결·부분 감소·반전·종료 거래·중지·비용·최종 잔고를 보존한다. 지원 신호 수와 실제 호출·목표·체결 수를 혼동하지 않는다.

## 대조 보존과 검산

같은 기간의 v98 변경량 후보·절대 노출·학습 평균, v100 무거래 후보를 보존 대조로 연결한다. 기존 파일·입력·기본 설정의 해시와 수치를 확인하며 재학습·상수 재선택은 하지 않는다. 손절 비활성 경로의 설정 차이를 명시한다.

합성 검사는 두 정보 시각·정확한 경계·미지원·누락·0 변경·자체 상태 사용·목표 제한·손절 비활성화 시 다른 위험 중지 유지·거래 없는 봉·재시작·기록 변조를 포함한다. 창 종료 모드에서는 미래 원본 창을 바꿔도 과거 판단이 같아야 한다. 창 시작 모드는 명시한 5분 선행 범위 밖 사건을 바꿔도 과거 판단이 같아야 한다. 선행 모드를 숨겨 미래 정보 불변 검사를 통과했다고 표시하지 않는다.

실제 여덟 경로는 별도 정책 계산과 `ReferenceAccount`의 독립 현금·수량 방정식으로 모든 분봉·판단·체결·거래·지표를 재생한다. 각 계좌의 중간 JSON 복원도 대조한다. 입력·계획·코드를 실행 전후 고정하고 실패한 경로도 결과에 남긴다.

## 결과 해석

순수익률·낙폭·거래 수·영구 및 일일 중지·손절 종료·비용·펀딩·목표 제한·지원 및 호출 수를 여덟 경로 모두 보고한다. 같은 신호라도 위험 중지·보유 상태가 바뀌면 이후 경로가 달라진다는 점을 유지한다. 손절 제거의 결과를 일반적인 위험 관리 개선으로 확대하지 않는다.

이 진단은 기록된 신호를 현 실행기에 옮겼을 때의 조건부 결과다. 양수여도 거래 시점 예측 가능성·다년 안정성·실행 가능성이 증명되지 않는다. 음수여도 원본 자료의 진위나 거래자의 실제 수익을 부정하지 않는다. 이후 학습·정책 수정은 결과에 근거한 별도 계획으로 고정하며 기존 v10 수익성 기준과 전체 goal은 유지한다.
