# 실험 v16 사전 계획: 겹친 전체 거래 정답의 가중치

2026-10-04. v15는 2022년 확인 기준을 통과했지만 고정 후속 BTC 두 기간에서 손실이 확인됐다. 나머지 v15 조건은 중단하거나 삭제하지 않고 끝까지 보존한다. 2021년 학습 정답만 조사한 결과 같은 시장 구간을 여러 진입 기회가 공유하고 특정 월에 집중되어 있다. 손익이 양수인 정답을 우대하지 않고 공유 구간의 반복 반영만 줄이는 단일 학습 가설을 검증한다. 이 조정이 손실의 원인 해결이라는 결론은 아직 없다.

## 하나만 바꾸는 학습

v15의 정답 원장·현재 관리 정책·시장 입력·표준화 Ridge alpha 100·진입 기준 8bp·학습 기간·비용·위험 설정을 유지한다. 각 자연 종료 정답의 `[decision_time, label_end)` 구간에서 1분별 동시 정답 수 `c(t)`를 구한다. 각 행의 가중치는 해당 구간에서 `1 / c(t)`를 평균한 값이다. 전체 평균을 1로 정규화해 동일한 alpha와 비교한다.

손익·방향·승패·월별 성과·후속 기간은 가중치 계산에 사용하지 않는다. 모든 닫힌 정답에 양수 가중치를 부여하고 손실 사례도 유지한다. 미확정·학습 경계 밖 원장의 상태를 바꾸지 않는다. 같은 가중치를 표준화 평균·분산과 Ridge 목적함수 모두에 적용한다. 월별 균등화나 추가 가중치 후보는 이번 실험에 포함하지 않는다.

가중치가 참조하는 종료 시각은 2021년 학습 정답의 일부이며 실제 매매 예측 입력에는 들어가지 않는다. 학습 이후 시각은 가중치 계산에도 쓰지 않는다. 정답 중첩·월별 원래 비중·가중 비중·양수/음수 행·가중 평균 손익을 기록한다. `sum(w)^2 / sum(w^2)`는 가중치 불균형 진단으로만 표시하고 독립 표본 수로 해석하지 않는다.

## 검증과 재현

단일 모델을 학습하고 2021년 재생은 학습 적합 진단으로 표시한다. 2022년에서는 문턱이나 가중치 방식을 다시 고르지 않는다. 확인 기준은 양수·30거래 이상·낙폭 중지 없음이다. 실패하면 고정 BTC 두 후속 구간과 세 독립 연도 진단, 통과하면 v15와 같은 세 시장·아홉 조건·아홉 독립 연도를 수행한다. v15·v14의 동일 입력 결과와 비교한다. 전체 수익성 기준은 v10을 유지한다.

서로 겹친 구간의 작은 수기 사례, 경계가 맞닿은 정답의 비중복, 잘못된 시각·순서·간격·범위 거부, 미래 정답 추가 차단, 양수 가중치와 손실 보존을 검사한다. 표준화와 회귀는 별도 수기 가중 정규방정식 및 내보낸 숫자 예측과 비교한다. 원래 무가중 모델의 동작 불변, 모델·가중 정답 지문, 필터 결정·회계·실제 중단 복원을 검증한다.

모든 기간은 이미 관찰한 연구 자료다. 가중치 보정으로 표본 독립성·시간 안정성·수익성이 입증되지는 않는다. 추가 후보를 반복한 선택 편향을 보존하며 기준 미달 시 원인 연구를 계속한다. 원본·파생 정답·모델·개별 결과는 로컬에 유지하고 실거래는 연결하지 않는다.
