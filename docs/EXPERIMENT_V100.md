# 실험 v100 사전 계획: 체결 기여분의 희소 행동과 자기 계좌 실행

2026-10-11. v99에서 약 97.4%의 지원 창에는 체결·정산이 없었지만 총 노출 비율은 가격·펀딩 등으로 변했다. 이번에는 체결·정산 기여분을 사용하고, 거래 없음과 양방향 변화를 함께 예측하는 한 후보를 고정한다. 드문 체결 시점이 예측 가능한지는 아직 입증되지 않았다. 원본 상태를 공급한 진단과 봇 자체 계좌의 연속 매매를 각각 평가한다.

## 닫힌 계약의 가격 보완

먼저 v99의 추가 미지원 74개 행에서 필요한 계약·다음 경계 가격 목록을 고정한다. 기존 공개 원응답에 같은 계약·시각이 있으면 그대로 검산해 재사용하고, 없으면 기존 읽기 전용 BitMEX 공개 자료 수집 절차로 정확한 봉만 요청한다. 호스트·시간·크기 제한과 원응답 해시·재시도·실패 기록을 유지한다. 주문·인증·개인 거래 내역 전송은 없다.

원래 가격·v99 결과는 바꾸지 않는다. 별도 보완 파일의 시각·종가·실제 거래 수·수량을 독립 확인한 뒤 합친 새 입력으로 동일한 v99 분해를 전부 재현한다. 기존 지원 행의 모든 수치는 같아야 한다. 여전히 가격이 없거나 무거래인 경우 미지원 사유를 보존한다. 수집 성공이나 매매 방향에 따라 필요한 목록을 바꾸지 않는다.

## 정답·모형 고정

전체 원본 연결 행과 기존 시간순 분리를 유지한다. 현재·다음 정답 및 회계 분해가 지원되는 2020년 행만 학습에 사용한다. 2021년은 이미 관찰한 진단 기간이다. 입력은 확정 시장 특징 14개와 현재 부호 있는 BTC 노출 한 개다. 학습·한 단계 진단의 현재 상태는 원본이며, 실제 연속 실행의 현재 상태는 봇의 수량·확정 종가·평가액으로만 계산한다.

정답은 분해된 `execution_change`다. 1e-12 이내를 숫자상 0으로 취급하고, 음수·0·양수의 세 행동으로 구분한다. 체결이 있었어도 해당 BTC 부분 노출의 체결 기여분이 0이면 행동 정답은 0이다. 체결·정산이 없는 창의 정답 0을 검산한다. 다른 자산의 주문 의도나 원래 주문 수량을 그대로 복원한 정답이라고 부르지 않는다.

후보는 세 행동을 함께 예측하는 HistGradientBoostingClassifier 한 개와, 음수·양수 각각의 비영(非零) 크기를 예측하는 회귀 두 개다. 분류기는 log_loss, 회귀기는 절댓값 기여분에 squared_error를 사용한다. 모두 반복 64회·학습률 0.05·깊이 2·말단 4개·최소 말단 표본 64·L2 1·최대 구간 255·전체 특징·범주 특징 없음·조기 종료 없음·seed 0으로 고정한다. 분류에 클래스 가중치·재표집을 적용하지 않는다. 방향별 크기 학습 행이 128개 미만이면 크기 모형을 임의 대체하지 않고 지원 부족으로 기록한다. 크기의 음수 예측은 0으로 제한하며 학습 정답의 큰 값을 사후 삭제하거나 제한하지 않는다.

분류 대조는 학습 빈도 상수와 학습 전용 표준화·LogisticRegression(C=1, lbfgs, max_iter=2000, 클래스 가중치 없음, seed=0)다. 세 클래스 로그 손실·혼동행렬·방향별 AP/재현율·예측 행동 수를 전체와 월별로 기록한다. 크기 대조는 각 방향 학습 절댓값의 중앙값이다. 합성된 기대 변경량과 실제 행동 선택 변경량의 MSE·MAE를 변경량 0 및 같은 행의 기존 v98 모형과 비교한다. 대조의 성적에 따라 실제 후보를 바꾸지 않는다.

## 실행 정책과 실제 검증

분류기의 최대 확률 행동을 선택한다. 최대 확률이 동률이면 거래 없음으로 처리한다. 거래 없음은 기존 수량을 유지하는 `None` 명령이며, 현재 노출을 목표로 다시 제출해 가격 차이만큼 재조정하지 않는다. 별도의 활동 확률 관문이나 사후 조정한 확률 문턱을 두지 않는다.

양수·음수 행동이면 해당 방향 크기 모형을 사용해 `현재 봇 노출 + 부호 × 예측 크기`를 다음 목표로 정하고 [-0.5, 0.5]로 제한한다. 숫자상 0 크기는 주문을 만들지 않는다. 같은 방식으로 증가·감소·반전을 처리하며 위험 청산은 행동 분류 결과와 독립적으로 실행한다. 5분 확정 경계의 판단과 다음 거래 가능한 분봉 시가 체결, 비용 차감 후 목표 수량, 위험·펀딩·무거래·재개·종료 순서는 v98 실행기를 유지한다.

학습이 지원되면 예측 진단이 나쁘거나 거래 없음만 예측하더라도 BTC 2021년·2022년 자체 계좌 두 경로를 모두 실행한다. 초기 자본 10,000 USDT·포지션 0, 수수료 5bp·슬리피지 3bp·실제 펀딩, 목표 노출 상한 0.5·손절 4%·최대 보유 77,699분·대기 15분·일일 손실 3%·최대 낙폭 25%를 유지한다. 동일 입력·실행·위험 설정의 v98 여섯 경로를 보존 대조로 연결하며 전체 계좌 조건의 해시를 확인한다. 새로운 정책의 모든 분봉·확률·행동·크기·목표·체결·종료 거래·회계를 독립 재생한다.

2022년 후보가 비용 후 양수·종료 거래 30개 이상·영구 중지 없음 조건을 충족하면, 고정 후보를 2023~2025년 연속·2026년 1~9월·2023/2024/2025 독립 연도·ETH·SOL·비용 2배/3배·지연 1분으로 확대한다. 조건 미달이면 실패와 무거래 결과를 그대로 남긴다. 낮은 로그 손실, 거래 없음의 높은 적중률, 수집·검사 완료를 수익성으로 표시하지 않는다. 이미 관찰한 기간과 기존 v10 최종 기준을 유지하며 전체 goal은 계속 진행한다. v93 공유 소스의 검산 완료 전 준비 구현을 격리하고 운영 등록 시 동일 결과를 재현한다.
